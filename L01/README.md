# L01. История и этапы развития языков программирования. Основы алгоритмизации

Практические задания к теме №1 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Особенность этой темы

В отличие от большинства последующих тем курса, задания темы №1 **не требуют написания кода на C#**. Тема предшествует знакомству с языком (см. Л2), поэтому все 30 заданий — алгоритмические: составление псевдокода, построение блок-схем, анализ свойств алгоритма, сравнение вариантов решения и поиск логических ошибок.

## Структура папки

```
L01/
├── Easy/       5 заданий  (L01-ALG-001 – L01-ALG-005)
├── Middle/     15 заданий (L01-ALG-006 – L01-ALG-020)
└── Advanced/   10 заданий (L01-ALG-021 – L01-ALG-030)
```

## Уровни сложности

| Уровень | Диапазон | Характеристика |
|---|---|---|
| Easy | ALG-001–005 | Одна основная концепция; составление линейного псевдокода или распознавание нарушенного свойства алгоритма |
| Middle | ALG-006–020 | Несколько связанных концепций; блок-схемы разветвляющихся/циклических алгоритмов, сравнение вариантов решения, поиск логических ошибок |
| Advanced | ALG-021–030 | Комбинированные структуры (ветвление внутри цикла), анализ корректности и полноты алгоритма, edge cases |

## Формат каждого задания (V3)

Каждый файл `L01-ALG-XXX.md` содержит только два поля: **Условие** и **Ожидаемый результат**. Все необходимые ограничения включены непосредственно в условие. **Готовые решения не приводятся** — это соответствует правилам академической добросовестности курса.

## Материалы для подготовки

Перед выполнением заданий рекомендуется изучить лекцию по теме №1 (см. основной репозиторий пособия), в которой рассмотрены: понятие и свойства алгоритма, псевдокод, блок-схемы, три базовые алгоритмические структуры (линейная, разветвляющаяся, циклическая).
