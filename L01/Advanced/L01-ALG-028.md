# L01-ALG-028. Анализ алгоритма определения возраста по году рождения

**Тема:** Л1 — Этапы решения поставленной задачи в программировании: модель — метод решения — алгоритм — программа. Понятие алгоритма, способы его представления, свойства, виды и эффективность

## Условие
Дан алгоритм:
```
начало
  ввод birthYear, currentYear
  age := currentYear - birthYear
  вывод age
конец
```
Определить, при каких входных данных этот алгоритм даёт результат, не имеющий смысла с точки зрения реальной задачи, и объяснить причину.

## Ожидаемый результат
Конкретный класс входных данных, для которого результат не имеет смысла в рамках решаемой задачи, с объяснением причины.
