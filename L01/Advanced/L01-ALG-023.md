# L01-ALG-023. Одновременный поиск минимума и максимума за один проход

**Тема:** Л1 — Этапы решения поставленной задачи в программировании: модель — метод решения — алгоритм — программа. Понятие алгоритма, способы его представления, свойства, виды и эффективность

## Условие
Дано количество чисел N и сами N чисел. Составить алгоритм поиска одновременно наименьшего и наибольшего числа за один проход по данным, без повторного считывания.

## Ожидаемый результат
Верно найденные min и max за один проход (например, при числах 5, 1, 9, 3 — min = 1, max = 9).
