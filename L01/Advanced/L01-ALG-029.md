# L01-ALG-029. Анализ алгоритма классификации треугольника без проверки существования

**Тема:** Л1 — Этапы решения поставленной задачи в программировании: модель — метод решения — алгоритм — программа. Понятие алгоритма, способы его представления, свойства, виды и эффективность

## Условие
Дан алгоритм, который сразу, без предварительной проверки, классифицирует треугольник по трём сторонам a, b, c как равносторонний, равнобедренный или разносторонний. Определить, к какому некорректному результату может привести отсутствие проверки существования треугольника, и привести конкретный числовой пример.

## Ожидаемый результат
Числовой пример трёх «сторон», не удовлетворяющих неравенству треугольника, но формально классифицируемых алгоритмом как один из типов треугольника, с объяснением проблемы.
