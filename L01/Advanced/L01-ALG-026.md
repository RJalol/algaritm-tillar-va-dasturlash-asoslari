# L01-ALG-026. Анализ алгоритма поиска максимума при всех отрицательных числах

**Тема:** Л1 — История и этапы развития языков программирования. Основы алгоритмизации

## Условие
Дан алгоритм:
```
начало
  ввод N
  max := 0
  для i от 1 до N выполнять
    ввод x
    если x > max то max := x
  вывод max
конец
```
Определить, для какого класса входных данных этот алгоритм даёт заведомо неверный результат, и объяснить причину.

## Ожидаемый результат
Конкретный, воспроизводимый класс входных данных (а не единичный пример), для которого результат работы алгоритма противоречит его цели, с обоснованием, опирающимся на конкретный шаг алгоритма.
