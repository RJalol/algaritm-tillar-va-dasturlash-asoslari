# L01-ALG-022. Подсчёт положительных, отрицательных и нулевых чисел

**Тема:** Л1 — История и этапы развития языков программирования. Основы алгоритмизации

## Условие
Дано количество чисел N и сами N чисел. Составить алгоритм, подсчитывающий отдельно количество положительных, отрицательных чисел и нулей среди них за один проход.

## Ожидаемый результат
Три счётчика, сумма которых всегда равна N (например, при числах 3, -2, 0, 7, 0 — posCount = 2, negCount = 1, zeroCount = 2).
