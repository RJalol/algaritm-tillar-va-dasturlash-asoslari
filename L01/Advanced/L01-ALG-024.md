# L01-ALG-024. Классификация оценок с подсчётом и средним по категориям

**Тема:** Л1 — История и этапы развития языков программирования. Основы алгоритмизации

## Условие
Дано количество оценок N и сами N оценок по стобалльной шкале. Составить алгоритм, который для каждой из трёх категорий («отлично» — 90–100, «хорошо» — 70–89, «удовлетворительно и ниже» — до 70) одновременно подсчитывает количество оценок и вычисляет средний балл внутри категории, корректно обрабатывая категорию без единой оценки.

## Ожидаемый результат
Количество и средний балл для каждой из трёх категорий, без деления на ноль для пустой категории (например, при оценках 95, 72, 60, 91, 85 — «отлично»: 2 оценки, среднее 93, и т. д.).
