# L01-ALG-025. Проверка последовательности на отсортированность с досрочным завершением

**Тема:** Л1 — История и этапы развития языков программирования. Основы алгоритмизации

## Условие
Дано количество чисел N и сами N чисел. Составить алгоритм проверки, отсортирована ли последовательность по неубыванию, с прекращением дальнейшей проверки сразу при обнаружении первого нарушения порядка.

## Ожидаемый результат
Верный ответ «отсортирована»/«не отсортирована» без продолжения проверки после первого нарушения (например, при числах 1, 3, 3, 7, 5 — «не отсортирована»).
