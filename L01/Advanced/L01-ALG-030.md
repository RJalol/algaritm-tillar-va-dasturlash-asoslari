# L01-ALG-030. Комплексный анализ алгоритма с несколькими одновременными пробелами

**Тема:** Л1 — Этапы решения поставленной задачи в программировании: модель — метод решения — алгоритм — программа. Понятие алгоритма, способы его представления, свойства, виды и эффективность

## Условие
Дан алгоритм, который принимает количество чисел N, вводит N чисел, находит среди них максимум (с инициализацией max := 0), а затем вычисляет среднее значение всех чисел, которые больше половины найденного максимума, выводя частное от деления суммы таких чисел на их количество. Найти не менее трёх различных пробелов в этом алгоритме.

## Ожидаемый результат
Не менее трёх различных по своей природе пробелов, каждый подкреплён конкретным примером входных данных или математическим обоснованием.
