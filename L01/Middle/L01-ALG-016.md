# L01-ALG-016. Первые N чисел последовательности Фибоначчи

**Тема:** Л1 — История и этапы развития языков программирования. Основы алгоритмизации

## Условие
Дано число N (N ≥ 2). Составить алгоритм вычисления первых N чисел последовательности Фибоначчи (каждое следующее число равно сумме двух предыдущих, первые два числа равны 1 и 1).

## Ожидаемый результат
Последовательность из N чисел, где каждое, начиная с третьего, равно сумме двух предыдущих (например, при N = 6 — 1, 1, 2, 3, 5, 8).
