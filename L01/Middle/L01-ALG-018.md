# L01-ALG-018. Сравнение двух вариантов проверки чётности числа

**Тема:** Л1 — Этапы решения поставленной задачи в программировании: модель — метод решения — алгоритм — программа. Понятие алгоритма, способы его представления, свойства, виды и эффективность

## Условие
Рассмотрены два варианта проверки чётности числа N: Вариант 1 — через остаток от деления на 2; Вариант 2 — через цикл, вычитающий 2 на каждом шаге до получения 0 или отрицательного числа. Сравнить варианты по количеству шагов при разных N, простоте реализации и применимости к отрицательным числам.

## Ожидаемый результат
Обоснованное сравнение, отмечающее рост числа шагов во втором варианте с увеличением N и рассматривающее случай отрицательных чисел для обоих вариантов.
