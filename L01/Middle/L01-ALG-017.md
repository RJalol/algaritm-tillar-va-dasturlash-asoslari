# L01-ALG-017. Сравнение двух вариантов обмена значений переменных

**Тема:** Л1 — Этапы решения поставленной задачи в программировании: модель — метод решения — алгоритм — программа. Понятие алгоритма, способы его представления, свойства, виды и эффективность

## Условие
Рассмотрены два варианта алгоритма обмена значений переменных a и b: Вариант 1 — через вспомогательную переменную temp; Вариант 2 — без вспомогательной переменной, через арифметические действия (a := a + b; b := a − b; a := a − b). Сравнить оба варианта по количеству шагов, потребности в дополнительной памяти и риску некорректной работы при определённых входных данных.

## Ожидаемый результат
Обоснованное сравнение по всем трём указанным критериям, а не только констатация фактов.
