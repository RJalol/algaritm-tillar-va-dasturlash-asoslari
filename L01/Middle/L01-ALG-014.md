# L01-ALG-014. Максимальный элемент среди N введённых чисел

**Тема:** Л1 — История и этапы развития языков программирования. Основы алгоритмизации

## Условие
Дано количество чисел N и сами эти N чисел, вводимых по одному. Составить алгоритм поиска наибольшего из них.

## Ожидаемый результат
Верно найденное наибольшее число независимо от его позиции во вводимой последовательности (например, при числах 3, 9, 2, 7 — max = 9).
