# L01-ALG-009. Наибольшее из трёх чисел

**Тема:** Л1 — История и этапы развития языков программирования. Основы алгоритмизации

## Условие
Даны три числа. Составить алгоритм определения наибольшего из них, корректно обрабатывающий случаи равенства чисел между собой.

## Ожидаемый результат
Верно определённое наибольшее значение при любом соотношении чисел, включая равенство (например, при 5, 9, 9 — результат 9).
