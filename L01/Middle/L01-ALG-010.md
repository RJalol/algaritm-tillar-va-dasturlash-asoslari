# L01-ALG-010. Классификация оценки по баллам

**Тема:** Л1 — История и этапы развития языков программирования. Основы алгоритмизации

## Условие
Дан балл студента по стобалльной шкале. Составить алгоритм определения итоговой оценки: 90–100 — «отлично», 70–89 — «хорошо», 50–69 — «удовлетворительно», ниже 50 — «неудовлетворительно».

## Ожидаемый результат
Верное название оценки для любого балла, включая граничные значения 89/90, 69/70, 49/50 (например, при score = 90 — «отлично»).
