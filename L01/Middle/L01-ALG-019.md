# L01-ALG-019. Логическая ошибка в алгоритме поиска максимума

**Тема:** Л1 — История и этапы развития языков программирования. Основы алгоритмизации

## Условие
Дан алгоритм поиска наибольшего из N введённых чисел:
```
начало
  ввод N
  max := 0
  для i от 1 до N выполнять
    ввод x
    если x > max то max := x
  вывод max
конец
```
Найти логическую ошибку, которая проявляется на определённых входных данных, и объяснить, при каких значениях она приводит к неверному результату.

## Ожидаемый результат
Конкретный набор входных данных, демонстрирующий ошибку при пошаговой трассировке, и объяснение, опирающееся на конкретный шаг алгоритма.
