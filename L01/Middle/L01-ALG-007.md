# L01-ALG-007. Классификация треугольника по трём сторонам

**Тема:** Л1 — История и этапы развития языков программирования. Основы алгоритмизации

## Условие
Даны длины трёх отрезков. Составить алгоритм, определяющий, образуют ли они треугольник, и если да — является ли он равносторонним, равнобедренным или разносторонним. Случай «не треугольник» должен проверяться раньше классификации по типу.

## Ожидаемый результат
Верное сообщение «не треугольник» либо верно определённый тип треугольника (например, при a = 3, b = 3, c = 5 — «равнобедренный»).
