# L01-ALG-002. Обмен значений двух переменных через вспомогательную переменную

**Тема:** Л1 — История и этапы развития языков программирования. Основы алгоритмизации

## Условие
Даны значения переменных a и b. Составить алгоритм, меняющий их значения местами с использованием дополнительной переменной temp (без арифметических приёмов обмена без неё).

## Ожидаемый результат
Значения a и b, поменянные местами (например, при a = 5, b = 9 после выполнения a = 9, b = 5).
