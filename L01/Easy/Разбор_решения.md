# Разбор решения. L01-ALG-001. Площадь прямоугольника

## Условие
Даны длины двух сторон прямоугольника a и b. Составить алгоритм вычисления его площади.

## Ожидаемый результат
Площадь S, вычисленная как произведение двух сторон (например, при a = 4, b = 5 результат S = 20).

## Идея решения
Площадь прямоугольника равна произведению длин двух его сторон. Алгоритм линейный: ввод данных, одно вычисление, вывод результата.

## Решение
```text
Алгоритм «Площадь прямоугольника»
начало
  ввод a, b
  S := a * b
  вывод S
конец
```

## Пошаговое объяснение
1. Вводим длины сторон `a` и `b` — это исходные данные алгоритма.
2. Выполняем единственное действие `S := a * b` — присваиваем переменной `S` произведение сторон.
3. Выводим `S`. Каждый шаг определён однозначно (детерминированность), шагов конечное число (конечность), алгоритм подходит для любых положительных `a` и `b` (массовость).
4. Проверка на примере: `a = 4`, `b = 5` → `S := 4 * 5 = 20`.

## Результат
При a = 4, b = 5 алгоритм выводит S = 20.
