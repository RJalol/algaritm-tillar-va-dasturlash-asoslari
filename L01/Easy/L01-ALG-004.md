# L01-ALG-004. Анализ алгоритма с потенциально бесконечным циклом

**Тема:** Л1 — История и этапы развития языков программирования. Основы алгоритмизации

## Условие
Дан алгоритм:
```
начало
  ввод N
  i := 1
  пока i <= N выполнять
    вывод i
  вывод "готово"
конец
```
Определить, какое из пяти свойств алгоритма (дискретность, детерминированность, результативность, массовость, понятность) нарушено, и обосновать ответ, опираясь на конкретный шаг алгоритма.

## Ожидаемый результат
Точно названное нарушенное свойство и обоснование, связанное с конкретным шагом алгоритма, а не общими рассуждениями.
