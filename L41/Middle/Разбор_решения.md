# Разбор решения. L41 · Задание II · №4. Две формы

## Условие
Создать главную форму и вторую форму. Кнопка главной формы открывает вторую методом `Show`, другая — методом `ShowDialog`. Сравнить поведение.

## Ожидаемый результат
При `ShowDialog` главная форма недоступна, при `Show` — доступна.

## Идея решения
`Show()` открывает форму немодально (главная остаётся доступной), `ShowDialog()` — модально (главная блокируется до закрытия диалога).

## Решение
```csharp
using System;
using System.Drawing;
using System.Windows.Forms;

public class MainForm : Form
{
    public MainForm()
    {
        Text = "Главная форма";
        Size = new Size(320, 140);

        var btnShow = new Button { Text = "Show (немодально)", Left = 10, Top = 10, Width = 140 };
        var btnDialog = new Button { Text = "ShowDialog (модально)", Left = 160, Top = 10, Width = 140 };

        btnShow.Click += (s, e) => new SecondForm().Show();
        btnDialog.Click += (s, e) =>
        {
            using var f = new SecondForm();
            f.ShowDialog(this);
        };

        Controls.Add(btnShow);
        Controls.Add(btnDialog);
    }
}

public class SecondForm : Form
{
    public SecondForm()
    {
        Text = "Вторая форма";
        Size = new Size(260, 120);
        Controls.Add(new Label { Text = "Я — вторая форма", Left = 20, Top = 20, AutoSize = true });
    }
}
```

## Пошаговое объяснение
1. `btnShow.Click` создаёт и показывает вторую форму вызовом `Show()` — управление сразу возвращается, и главная форма продолжает отвечать на действия пользователя; можно открыть несколько вторых форм.
2. `ShowDialog(this)` блокирует родительскую форму, пока диалог не будет закрыт; метод возвращает `DialogResult`.
3. Для модального окна применяем `using`, чтобы освободить его ресурсы (после `ShowDialog` форма не уничтожается автоматически).
4. Проверка: при открытом модальном окне нельзя нажимать на главную форму, при немодальном — можно.

## Результат
При `Show` главная форма доступна во время работы второй; при `ShowDialog` недоступна до её закрытия.
