# Разбор решения. L41 · Задание I · №1. Пустая форма

## Условие
Создать проект Windows Forms. Задать форме заголовок «Мой первый проект», размер 400×300 и расположение по центру экрана свойствами `Text`, `Size`, `StartPosition`.
Проект — приложение Windows Forms (.NET 8, `net8.0-windows`).

## Ожидаемый результат
Форма открывается по центру с заданными заголовком и размером.

## Разбор условия
**Дано:** проект Windows Forms (.NET 8).
**Требуется:** задать форме заголовок «Мой первый проект», размер 400×300, положение по центру экрана.

## Теоретическая справка
**Windows Forms** — библиотека создания оконных приложений. Окно представлено классом `Form`; элементы управления (`Button`, `Label`, `TextBox`) — потомки `Control`.

Структура проекта:

| Файл | Назначение |
|---|---|
| `Program.cs` | точка входа: `ApplicationConfiguration.Initialize(); Application.Run(new Form1());` |
| `Form1.cs` | код формы (обработчики событий) |
| `Form1.Designer.cs` | сгенерированная часть: свойства и элементы (`InitializeComponent`) |

Основные свойства формы: `Text`, `Size`/`ClientSize`, `StartPosition`, `BackColor`, `FormBorderStyle`. `Application.Run` запускает цикл обработки сообщений: форма живёт, пока не закрыта.

## Идея решения
Форма — класс-наследник `Form`. Её внешний вид задаётся свойствами; в проекте шаблона Windows Forms они устанавливаются в конструкторе формы (или в дизайнере, который пишет то же в `Form1.Designer.cs`).

## Решение
```csharp
// Program.cs
using System;
using System.Windows.Forms;

static class Program
{
    [STAThread]
    static void Main()
    {
        ApplicationConfiguration.Initialize();
        Application.Run(new Form1());
    }
}

// Form1.cs
using System.Drawing;
using System.Windows.Forms;

public class Form1 : Form
{
    public Form1()
    {
        Text = "Мой первый проект";
        Size = new Size(400, 300);
        StartPosition = FormStartPosition.CenterScreen;
    }
}
```

## Пошаговое объяснение
1. Создаём проект «Приложение Windows Forms» (.NET 8); `Program.cs` запускает форму методом `Application.Run`.
2. `Text` — заголовок окна, `Size` — размер в пикселях, `StartPosition = CenterScreen` — открытие по центру экрана.
3. Эти же свойства можно задать в окне «Свойства» дизайнера — среда запишет их в `InitializeComponent`.
4. Запускаем приложение клавишей F5 и проверяем заголовок, размер и положение окна.

## Трассировка и проверка
| Свойство | Значение | Эффект |
|---|---|---|
| `Text` | «Мой первый проект» | заголовок окна |
| `Size` | 400×300 | размер вместе с рамкой |
| `StartPosition` | `CenterScreen` | открытие по центру |

`Size` включает рамку и заголовок; размер рабочей области задаёт `ClientSize`.

## Результат
Открывается окно 400×300 с заголовком «Мой первый проект» по центру экрана.

## Типичные ошибки
- Путать `Size` и `ClientSize`.
- Устанавливать `StartPosition` после показа формы (не сработает).
- Редактировать `Form1.Designer.cs` вручную и терять изменения при перегенерации.
- Забыть пометить `Main` атрибутом `[STAThread]`.

## Задания для закрепления
- Запретить изменение размера окна (`FormBorderStyle.FixedSingle`, `MaximizeBox = false`).
- Задать значок формы и цвет фона.
- Добавить кнопку «Закрыть», вызывающую `Close()`.
