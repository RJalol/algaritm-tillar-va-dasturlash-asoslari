# Разбор решения. L22 · Задание III · №1. Условные операторы для собственного типа

## Условие
Дополнить структуру задания II.14 операторами `true` и `false` так, чтобы состояние «пройдена» считалось определённо истинным, а «провалена» — определённо ложным. Написать два метода-проверки, печатающих сообщение при вызове, и сравнить поведение выражений с `\&` и с `\&\&`. Дополнительно использовать значение типа прямо в условии `if`.

## Ожидаемый результат
При `\&` печатаются сообщения обоих методов, при `\&\&` — только первого; результаты обоих выражений совпадают. Значение типа принято условием `if` без явного преобразования.

## Разбор условия
**Дано:** структура-результат проверки (пройдена/провалена).
**Требуется:** перегрузить `true`/`false` и `&`, сравнить поведение `&` и `&&`, использовать значение в условии `if`.

## Теоретическая справка
Операторы `true` и `false` определяют, когда значение типа считается истинным/ложным в условиях и операторах `&&`, `||`. Они всегда перегружаются **парой**.

Правило для `a && b`: вычисляется `false(a)`; если ответ «да», результат равен `a`, а `b` **не вычисляется**; иначе результат — `a & b`. Поэтому для `&&` нужно перегрузить `&` (и операторы `true`/`false`); аналогично для `||` — `|`.

Состояние «неопределённо» (ни `true`, ни `false`) допустимо — тогда оба оператора возвращают `false`.

## Идея решения
Операторы `true` и `false` позволяют использовать значение собственного типа в условиях. Для `&&` и `||` нужно ещё перегрузить `&` (`|`): тогда `a && b` вычисляется как `false(a) ? a : (a & b)`.

## Решение
```csharp
using System;

struct Result
{
    private readonly int _state;   // 1 - пройдена, -1 - провалена, 0 - неопределённо
    public Result(int state) { _state = state; }

    public static bool operator true(Result r)  => r._state > 0;
    public static bool operator false(Result r) => r._state < 0;

    public static Result operator &(Result a, Result b) =>
        new Result(a._state > 0 && b._state > 0 ? 1 : -1);
}

class Program
{
    static Result CheckA() { Console.WriteLine("CheckA"); return new Result(-1); }
    static Result CheckB() { Console.WriteLine("CheckB"); return new Result(1); }

    static void Main()
    {
        Console.WriteLine("--- & ---");
        Result r1 = CheckA() & CheckB();

        Console.WriteLine("--- && ---");
        Result r2 = CheckA() && CheckB();

        if (r1) Console.WriteLine("r1 пройдена"); else Console.WriteLine("r1 не пройдена");
        if (r2) Console.WriteLine("r2 пройдена"); else Console.WriteLine("r2 не пройдена");
    }
}
```

## Пошаговое объяснение
1. Операторы `true` и `false` объявляются парой: «пройдена» определённо истинно, «провалена» определённо ложно.
2. Оператор `&` вычисляет оба операнда, поэтому печатаются сообщения обоих методов.
3. Оператор `&&` сначала вызывает `false(CheckA())`; результат «провалена» определённо ложен, значит второй операнд не вычисляется — печатается только `CheckA`.
4. Благодаря оператору `true` значение типа можно ставить прямо в условие `if` без явного преобразования.

## Трассировка и проверка
| Выражение | Что выполняется | Вывод методов |
|---|---|---|
| `CheckA() & CheckB()` | оба операнда всегда | CheckA, CheckB |
| `CheckA() && CheckB()` | `false(CheckA())` = true → второй не вычисляется | только CheckA |

`CheckA()` возвращает «провалена». Результаты `r1` и `r2` оба «не пройдена». Условие `if (r1)` вызывает оператор `true`.

## Результат
При & — CheckA и CheckB; при && — только CheckA; обе проверки дают «не пройдена».

## Типичные ошибки
- Перегрузить только `true` без `false` (`CS0216`).
- Не перегрузить `&` и ожидать работы `&&`.
- Ожидать, что `&&` всегда вызывает обе функции.
- Использовать побочные эффекты в операндах — результат зависит от сокращённого вычисления.
