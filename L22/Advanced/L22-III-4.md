# L22 · Задание III · №4. Диагностика чужого класса

**Тема:** Л22 — Перегрузка операторов. Перегрузка арифметических бинарных и унарных операторов. Перегрузка логических операторов

## Условие
Подготовить класс, содержащий не менее шести внесённых ошибок из числа изученных: оператор без `static`; оператор не `public`; оператор, ни один параметр которого не относится к типу; `==` без `!=`; `<` без `>`; попытка перегрузить неперегружаемый оператор. Составить таблицу «строка — код — причина — исправление» и привести класс в рабочее состояние.

## Ожидаемый результат
Таблица содержит не менее шести строк с фактически полученными кодами; исправленный класс компилируется без ошибок и без предупреждений `CS0660` и `CS0661`.
