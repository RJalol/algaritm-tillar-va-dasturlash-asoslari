# L22 · Задание III · №7. Экспертиза уместности

**Тема:** Л22 — Перегрузка операторов. Перегрузка арифметических бинарных и унарных операторов. Перегрузка логических операторов

## Условие
Даны шесть предложений: «сложить два заказа», «вычесть одну дату из другой и получить длительность», «умножить студента на группу», «сложить два вектора», «объединить знаком `|` два запроса к базе данных», «сложить две денежные суммы». Для каждого решить, уместна ли перегрузка оператора, и обосновать ответ правилами проектирования. Для неуместных предложить метод с подходящим именем. Оформить результат программой, выводящей таблицу решений.

## Ожидаемый результат
Уместными признаны три предложения, неуместными — три; для каждого неуместного предложено имя метода, и приведено правило, на котором основано решение.
