# Разбор решения. L22 · Задание I · №1. Первый перегруженный оператор

## Условие
Объявить класс «денежная сумма» с полем суммы в сумах и методом `Add`, складывающим две суммы. Затем добавить оператор `+` с тем же смыслом. Сложить две суммы обоими способами и вывести результаты рядом.

## Ожидаемый результат
Обе строки вывода совпадают; оператор не изменил ни один из исходных объектов, а вернул новый.

## Идея решения
Перегруженный оператор — обычный статический метод со словом `operator`. Он должен вернуть *новый* объект, не меняя операндов.

## Решение
```csharp
using System;

class Money
{
    public decimal Amount { get; }

    public Money(decimal amount) { Amount = amount; }

    public Money Add(Money other) => new Money(Amount + other.Amount);

    public static Money operator +(Money a, Money b) => new Money(a.Amount + b.Amount);

    public override string ToString() => Amount + " сум";
}

class Program
{
    static void Main()
    {
        Money a = new Money(1500);
        Money b = new Money(2500);

        Console.WriteLine(a.Add(b));
        Console.WriteLine(a + b);
        Console.WriteLine(a + " и " + b);   // исходные суммы не изменились
    }
}
```

## Пошаговое объяснение
1. Метод `Add` возвращает новый объект с суммой полей.
2. Оператор `+` объявляется как `public static Money operator +(Money a, Money b)` и содержит ту же логику.
3. Выражение `a + b` компилятор превращает в вызов этого оператора.
4. Третья строка вывода показывает, что `a` и `b` остались прежними — оператор вернул новый объект.

## Результат
4000 сум / 4000 сум / 1500 сум и 2500 сум
