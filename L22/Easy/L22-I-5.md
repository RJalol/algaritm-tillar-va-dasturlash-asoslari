# L22 · Задание I · №5. Форма объявления

**Тема:** Л22 — Перегрузка операторов. Перегрузка арифметических бинарных и унарных операторов. Перегрузка логических операторов

## Условие
Поставить три опыта над рабочим оператором `+` класса задания I.1: убрать `static`; заменить `public` на `private`; объявить оператор с одним параметром. Для каждого опыта записать код ошибки и краткое объяснение, затем вернуть корректное объявление.

## Ожидаемый результат
Получены коды `CS0558` для первых двух опытов и `CS1019` для третьего; сформулировано правило: перегруженный оператор объявляется `public static` и имеет один параметр для унарного знака и два — для бинарного.
