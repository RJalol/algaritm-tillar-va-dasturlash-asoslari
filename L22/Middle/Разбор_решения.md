# Разбор решения. L22 · Задание II · №1. Класс дроби

## Условие
Объявить класс обыкновенной дроби с числителем и знаменателем, запретив нулевой знаменатель в конструкторе, и перегрузить операторы `+`, `-`, `*`, `/`. Метод `ToString` должен выводить дробь в виде `чис/знам`. Вычислить четыре выражения над дробями `5/4` и `1/2`.

## Ожидаемый результат
Все четыре операции дают верные дроби; сокращение не требуется. Попытка создать дробь с нулевым знаменателем и попытка деления на нулевую дробь завершаются исключением.

## Разбор условия
**Дано:** дроби 5/4 и 1/2.
**Требуется:** класс дроби с запретом нулевого знаменателя и перегрузкой `+`, `-`, `*`, `/`; вычислить четыре выражения.

## Теоретическая справка
Арифметика дробей:

| Операция | Формула |
|---|---|
| a/b + c/d | (ad + cb) / bd |
| a/b − c/d | (ad − cb) / bd |
| a/b · c/d | ac / bd |
| a/b ÷ c/d | ad / bc |

Деление на дробь с нулевым числителем даёт нулевой знаменатель, что запрещено в конструкторе — исключение возникает автоматически. Такой приём называется **защитой инварианта в одной точке**.

Сокращение дроби по условию не требуется, но его можно добавить в конструктор через НОД.

## Идея решения
Дробь хранит числитель и знаменатель; операторы выполняют действия по правилам дробей, а нулевой знаменатель запрещён в конструкторе.

## Решение
```csharp
using System;

class Fraction
{
    public int Num { get; }
    public int Den { get; }

    public Fraction(int num, int den)
    {
        if (den == 0) throw new ArgumentException("Знаменатель не может быть равен нулю");
        Num = num; Den = den;
    }

    public static Fraction operator +(Fraction a, Fraction b) =>
        new Fraction(a.Num * b.Den + b.Num * a.Den, a.Den * b.Den);

    public static Fraction operator -(Fraction a, Fraction b) =>
        new Fraction(a.Num * b.Den - b.Num * a.Den, a.Den * b.Den);

    public static Fraction operator *(Fraction a, Fraction b) =>
        new Fraction(a.Num * b.Num, a.Den * b.Den);

    public static Fraction operator /(Fraction a, Fraction b) =>
        new Fraction(a.Num * b.Den, a.Den * b.Num);   // при b.Num == 0 конструктор бросит исключение

    public override string ToString() => Num + "/" + Den;
}

class Program
{
    static void Main()
    {
        Fraction p = new Fraction(5, 4);
        Fraction q = new Fraction(1, 2);

        Console.WriteLine(p + q);
        Console.WriteLine(p - q);
        Console.WriteLine(p * q);
        Console.WriteLine(p / q);
    }
}
```

## Пошаговое объяснение
1. Сложение и вычитание приводят дроби к общему знаменателю: `a/b ± c/d = (ad ± cb)/bd`.
2. Умножение: `ac/bd`. Деление: `a/b : c/d = ad/bc`.
3. Для 5/4 и 1/2: сумма = (5·2 + 1·4)/(4·2) = 14/8; разность = 6/8; произведение = 5/8; частное = 10/4 (сокращение по условию не требуется).
4. Деление на нулевую дробь (числитель делителя 0) даёт знаменатель 0, и конструктор выбрасывает исключение; то же при `new Fraction(1, 0)`.

## Трассировка и проверка
Для 5/4 и 1/2:

| Операция | Вычисление | Результат |
|---|---|---|
| + | (5·2 + 1·4)/(4·2) | 14/8 |
| − | (5·2 − 1·4)/(4·2) | 6/8 |
| * | 5·1 / 4·2 | 5/8 |
| / | 5·2 / 4·1 | 10/4 |

Попытка `new Fraction(1, 0)` и деление на `0/1` бросают `ArgumentException`.

## Результат
14/8, 6/8, 5/8, 10/4; создание дроби со знаменателем 0 и деление на нулевую дробь вызывают исключение.

## Типичные ошибки
- Складывать числители и знаменатели отдельно (1/2 + 1/3 ≠ 2/5).
- Не проверять знаменатель.
- Забыть порядок в вычитании и делении.
- Менять операнды.
