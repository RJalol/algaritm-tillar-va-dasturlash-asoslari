# Разбор решения. L15-ALG-001. Обмен значений двух переменных

## Условие
Написать метод `Swap`, меняющий местами значения двух целых переменных. Вызвать его для переменных со значениями 3 и 8 и вывести их до и после вызова. Затем написать такой же метод **без** модификатора и показать, что он ничего не меняет.

## Ожидаемый результат
Метод без модификатора оставил значения `3 8`, метод с модификатором `ref` дал `8 3`; слово `ref` записано и в объявлении, и в вызове.

## Разбор условия
**Дано:** значения 3 и 8.
**Требуется:** метод `Swap` без модификатора и версия с `ref`; показать, что первая не меняет значения, вторая меняет.

## Теоретическая справка
**Передача по значению** (по умолчанию): метод получает *копию* значения; изменения внутри метода не видны снаружи.

**Передача по ссылке (`ref`):** параметр становится *псевдонимом* переменной вызывающего кода. Слово `ref` указывается и при объявлении, и при вызове. Переменная должна быть инициализирована до вызова.

Обмен значений — классическая задача, невозможная без `ref`, потому что требует изменения сразу двух переменных вызывающего кода.

## Идея решения
По умолчанию в метод передаётся копия значения, поэтому обмен внутри метода не виден снаружи. Модификатор `ref` передаёт ссылку на переменную.

## Решение
```csharp
using System;

class Program
{
    static void SwapCopy(int a, int b)
    {
        int t = a; a = b; b = t;
    }

    static void SwapRef(ref int a, ref int b)
    {
        int t = a; a = b; b = t;
    }

    static void Main()
    {
        int x = 3, y = 8;
        SwapCopy(x, y);
        Console.WriteLine(x + " " + y);   // 3 8

        SwapRef(ref x, ref y);
        Console.WriteLine(x + " " + y);   // 8 3
    }
}
```

## Пошаговое объяснение
1. `SwapCopy` меняет локальные копии параметров, переменные `x`, `y` не затрагиваются.
2. `SwapRef` работает с самими переменными: параметры — псевдонимы `x` и `y`.
3. Слово `ref` нужно и в объявлении метода, и в вызове — так видно, что значение может измениться.

## Трассировка и проверка
| Вариант | До | Внутри метода | После вызова |
|---|:--:|:--:|:--:|
| `SwapCopy(x, y)` | 3, 8 | копии меняются: 8, 3 | 3, 8 |
| `SwapRef(ref x, ref y)` | 3, 8 | сами переменные: 8, 3 | 8, 3 |

Метод `SwapCopy` ничего не возвращает и не имеет побочных эффектов — вызов бесполезен.

## Результат
Без ref: 3 8; с ref: 8 3.

## Типичные ошибки
- Не указать `ref` при вызове (`CS1620`).
- Передать неинициализированную переменную (`CS0165`).
- Ожидать изменения значений без `ref`.
- Передать в `ref` литерал (`Swap(ref 3, ref 8)` — ошибка).
