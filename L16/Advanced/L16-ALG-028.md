# L16-ALG-028. Каталог книг

**Тема:** Л16 — Создание класса и его объектов. Принципы ООП. Члены класса

## Условие
Создать массив из пяти объектов класса `Book` (название, автор, год) и написать статические методы: поиск всех книг заданного автора с выводом их названий; определение самой старой книги; подсчёт числа книг, изданных после заданного года. Метод `Main` должен состоять только из создания массива и вызовов.

## Ожидаемый результат
Каждый метод возвращает или выводит верный результат; в `Main` не осталось ни одного цикла обработки; поиск, не нашедший ни одной книги, обрабатывается без исключения.
