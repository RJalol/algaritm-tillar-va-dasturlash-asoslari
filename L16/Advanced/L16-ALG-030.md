# L16-ALG-030. Полный аудит программы с классом

**Тема:** Л16 — Создание класса и его объектов. Принципы ООП. Члены класса

## Условие
Дан код:

```
using System;

namespace ClassAudit
{
    class Product
    {
        public string Name;
        public decimal Price;
        public int Quantity;

        public Product(string name, decimal price)
        {
            Name = name;
            Price = price;
        }

        public decimal Total()
        {
            return Price * Quantity;
        }

        public void ApplyDiscount(decimal percent)
        {
            Price = Price - Price * percent / 100;
        }
    }

    class Program
    {
        static void Main(string[] args)
        {
            Product p1 = new Product("Тетрадь", 5000m);
            Product p2 = p1;
            p2.ApplyDiscount(200);

            Console.WriteLine(p1.Price);
            Console.WriteLine(p1.Total());
            Console.WriteLine(p1);

            Product p3 = new Product("Тетрадь", 5000m);
            Console.WriteLine(p1 == p3);
        }
    }
}
```

Провести полный аудит и разнести замечания по четырём категориям: поле, которое конструктор не заполняет; метод, не проверяющий допустимость аргумента; неожиданный результат из-за копии ссылки; вывод, не дающий сведений об объекте. Для каждого объяснить, почему компилятор не сообщает об ошибке, и назвать тест-кейс, выявляющий её. Привести исправленную версию.

## Ожидаемый результат
Категории разнесены верно: поле `Quantity` не заполняется конструктором, остаётся нулём, и метод `Total` всегда даёт `0` — компилятор выдаёт лишь предупреждение `CS0649`; метод `ApplyDiscount` не проверяет, что скидка не превышает 100 процентов, и при значении 200 цена становится **отрицательной** (`-5000`); переменные `p1` и `p2` — одно и то же, поэтому скидка изменила и `p1`; вывод объекта даёт полное имя типа, так как `ToString` не переопределён; сравнение `p1 == p3` даёт `False`, хотя поля совпадают. Приведён исправленный код.
