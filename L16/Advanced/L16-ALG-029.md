# L16-ALG-029. Предсказание вывода: ссылки и копии

**Тема:** Л16 — Создание класса и его объектов. Принципы ООП. Члены класса

## Условие
Дан код:

```
class Box { public int N; }

Box a = new Box();
a.N = 1;
Box b = a;
Box c = new Box();
c.N = 1;

b.N = 5;

Console.WriteLine(a.N);
Console.WriteLine(c.N);
Console.WriteLine(a == b);
Console.WriteLine(a == c);
Console.WriteLine(a.Equals(c));
Console.WriteLine(ReferenceEquals(a, b));
```

Не запуская программу, предсказать все шесть строк вывода. Затем запустить и объяснить каждую. Отдельно ответить: как изменился бы третий и четвёртый результаты, если бы в классе `Box` был переопределён `Equals`.

## Ожидаемый результат
Предсказано `5`, `1`, `True`, `False`, `False` и `True`; отмечено, что переопределение `Equals` изменило бы только пятый результат, но не поведение операции `==`.
