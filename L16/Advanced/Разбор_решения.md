# Разбор решения. L16-ALG-021. Пять нарушений в одном фрагменте

## Условие
Дан код:

```
class Base { public int A; }

struct Bad1 : Base { }

struct Bad2
{
    public int X;
    ~Bad2() { }
}

struct Point { public double X; public double Y; }

Point a = new Point();
Point b = new Point();
Console.WriteLine(a == b);

object boxed = 123;
short s = (short)boxed;

Point noNew;
Console.WriteLine(noNew.X);
```

Найти все нарушения и разнести их по трём группам: нарушение ограничений структурного типа; отсутствие операции; ошибка использования значения. Для каждого назвать код ошибки компилятора либо, если фрагмент компилируется, — возникающее исключение. Привести исправленный фрагмент.

## Ожидаемый результат
Названы коды `CS0527`, `CS0575`, `CS0019` и `CS0165`; выражение `(short)boxed` компилируется, но даёт `InvalidCastException`; группы разнесены верно.

## Идея решения
Проверяем ограничения структур (наследование, финализатор), отсутствие операции `==` и использование неинициализированного значения.

## Решение
```csharp
// Исправленный фрагмент
struct Bad1 { }                              // структура не наследует класс
struct Bad2 { public int X; }                // у структуры нет деструктора
struct Point
{
    public double X; public double Y;
    public static bool operator ==(Point p, Point q) => p.X == q.X && p.Y == q.Y;
    public static bool operator !=(Point p, Point q) => !(p == q);
    public override bool Equals(object o) => o is Point p && this == p;
    public override int GetHashCode() => (X, Y).GetHashCode();
}
Point a = new Point(); Point b = new Point();
Console.WriteLine(a == b);
object boxed = 123;
short s = (short)(int)boxed;                 // сначала распаковка в int
Point noNew = new Point();
Console.WriteLine(noNew.X);
```

## Пошаговое объяснение
1. Ограничения структур: `struct Bad1 : Base` — структура не может наследовать класс (`CS0527`); `~Bad2()` — деструкторы в структурах запрещены (`CS0575`).
2. Отсутствие операции: `a == b` — для структур `==` не определён автоматически (`CS0019`); его нужно перегрузить.
3. Использование значения: `Point noNew;` без инициализации — чтение поля `noNew.X` (`CS0165`).
4. `(short)boxed` при упакованном `int` компилируется, но распаковывать можно только в точный исходный тип: возникает `InvalidCastException`; верно `(short)(int)boxed`.

## Результат
Коды: CS0527, CS0575, CS0019, CS0165; (short)boxed даёт InvalidCastException.
