# L16-ALG-012. Метод, возвращающий объект

**Тема:** Л16 — Создание класса и его объектов. Принципы ООП. Члены класса

## Условие
Дополнить класс `Point` методом, возвращающим **новый** объект — точку, сдвинутую на заданные приращения по обеим координатам. Исходную точку не изменять. Проверить на точке (3; 4) со сдвигом (1; −2), выведя обе точки.

## Ожидаемый результат
Новая точка `(4; 2)`, исходная осталась `(3; 4)`; метод создаёт объект операцией `new` и возвращает его.
