# L16-ALG-010. Ключевое слово this

**Тема:** Л16 — Создание класса и его объектов. Принципы ООП. Члены класса

## Условие
Объявить класс с полем `score` и методом, принимающим параметр с **тем же** именем и присваивающим его полю. Написать метод сначала без `this` и объяснить, почему поле не изменяется, затем добавить `this` и убедиться, что изменяется.

## Ожидаемый результат
Без `this` поле сохранило прежнее значение, поскольку присваивание выполнялось параметру самому себе; с `this` поле получило переданное значение.
