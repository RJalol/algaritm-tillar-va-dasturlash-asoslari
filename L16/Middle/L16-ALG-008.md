# L16-ALG-008. Предсказание вывода: копия ссылки

**Тема:** Л16 — Создание класса и его объектов. Принципы ООП. Члены класса

## Условие
Дан код:

```
Counter c1 = new Counter();
Counter c2 = c1;
c2.Increment();
c2.Increment();
Console.WriteLine(c1.Value + " " + c2.Value);

Counter c3 = new Counter();
c3.Increment();
Console.WriteLine(c1 == c2);
Console.WriteLine(c1 == c3);
```

Не запуская программу, предсказать все три строки вывода. Затем запустить и объяснить каждую через понятие копии ссылки.

## Ожидаемый результат
Предсказано `2 2`, `True` и `False`; объяснено, что `c1` и `c2` — два имени одного объекта, а `c3` — другой объект, хотя поля у него могли бы совпадать.
