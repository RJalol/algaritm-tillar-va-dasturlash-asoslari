# Разбор решения. L16-ALG-006. Массив объектов

## Условие
Объявить класс `Student` с полями «имя», «группа», «балл» и конструктором. Создать массив из трёх студентов — `("Азиз", "ТТ-11", 87)`, `("Дилноза", "ТТ-11", 92)` и `("Рустам", "ТТ-12", 78)` — и вывести средний балл с двумя знаками и имя лучшего студента.

## Ожидаемый результат
Средний балл `85,67`, лучший — `Дилноза`; поиск лучшего начат с первого элемента массива, а не с нуля.

## Идея решения
Создаём массив ссылок на объекты `Student`, затем одним проходом считаем сумму баллов и ищем студента с наибольшим баллом.

## Решение
```csharp
using System;

class Student
{
    public string Name;
    public string Group;
    public int Score;

    public Student(string name, string group, int score)
    {
        Name = name; Group = group; Score = score;
    }
}

class Program
{
    static void Main()
    {
        Student[] students =
        {
            new Student("Азиз", "ТТ-11", 87),
            new Student("Дилноза", "ТТ-11", 92),
            new Student("Рустам", "ТТ-12", 78)
        };

        double sum = 0;
        Student best = students[0];
        foreach (Student s in students)
        {
            sum += s.Score;
            if (s.Score > best.Score) best = s;
        }

        Console.WriteLine("Средний балл: " + (sum / students.Length).ToString("F2"));
        Console.WriteLine("Лучший: " + best.Name);
    }
}
```

## Пошаговое объяснение
1. Массив классов хранит ссылки; каждый элемент нужно создать оператором `new`.
2. Сумма: 87 + 92 + 78 = 257; среднее 257 / 3 = 85,67 (формат `F2`).
3. `best` начинаем с первого элемента массива и заменяем, если нашёлся балл выше.
4. Лучший балл 92 — у Дилнозы.

## Результат
Средний балл: 85,67; Лучший: Дилноза
