# L16-ALG-020. Обращение к полю через null

**Тема:** Л16 — Создание класса и его объектов. Принципы ООП. Члены класса

## Условие
Дан код:

```
Student? empty = null;
Console.WriteLine(empty.Name);
```

Определить, скомпилируется ли фрагмент и что произойдёт при выполнении. Назвать исключение и объяснить, почему компилятор не считает это ошибкой. Переписать фрагмент с проверкой.

## Ожидаемый результат
Фрагмент компилируется (компилятор выдаёт лишь предупреждение о возможном `null`) и возбуждает `NullReferenceException`; в исправленном варианте перед обращением выполняется проверка на `null`.
