# L16-ALG-015. Метод GetType

**Тема:** Л16 — Создание класса и его объектов. Принципы ООП. Члены класса

## Условие
Вывести краткое и полное имя типа для объекта собственного класса, для целого числа и для строки, пользуясь методом `GetType`. Объяснить в комментарии, почему этот метод доступен у значений всех трёх видов.

## Ожидаемый результат
Для целого выведено `System.Int32`, для строки — `System.String`, для собственного класса — его имя с пространством имён; в комментарии указано, что все типы .NET происходят от `System.Object`.
