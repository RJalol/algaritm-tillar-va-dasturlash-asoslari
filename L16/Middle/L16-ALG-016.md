# L16-ALG-016. Финализатор в структуре

**Тема:** Л16 — Структуры. Объявление структур. Типы-значения и ссылочные типы. Работа со структурами

## Условие
Дан код:

```
struct Bad
{
    public int X;
    ~Bad() { }
}
```

Назвать код ошибки и объяснить, к какому виду типов относится финализатор. Указать, в какой теме курса финализаторы рассматриваются.

## Ожидаемый результат
Назван код `CS0575`; объяснено, что финализатор допустим только в классах, а рассматривается он в теме №18.
