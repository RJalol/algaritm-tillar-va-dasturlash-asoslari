# L16-ALG-016. Вызов конструктора без аргументов

**Тема:** Л16 — Создание класса и его объектов. Принципы ООП. Члены класса

## Условие
Дан класс с единственным конструктором `public Student(string name, int score)`. Определить, скомпилируется ли запись `new Student()`, и назвать код ошибки. Затем удалить конструктор из класса, повторить попытку и объяснить, почему результат изменился.

## Ожидаемый результат
С конструктором запись даёт `CS7036`; без объявленных конструкторов та же запись компилируется, поскольку компилятор предоставляет конструктор без параметров, а поля получают значения по умолчанию.
