# L16-ALG-014. Переопределение Equals

**Тема:** Л16 — Создание класса и его объектов. Принципы ООП. Члены класса

## Условие
Переопределить в классе `Point` метод `Equals` так, чтобы точки считались равными при совпадении обеих координат. Создать три переменные: две с одинаковыми координатами и третью, ссылающуюся на первую. Вывести результаты `Equals` и `==` для обеих пар и объяснить расхождение.

## Ожидаемый результат
Для двух разных объектов с одинаковыми координатами `Equals` даёт `True`, а `==` — `False`; для пары «объект и ссылка на него» оба способа дают `True`.
