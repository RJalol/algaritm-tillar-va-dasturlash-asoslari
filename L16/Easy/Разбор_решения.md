# Разбор решения. L16-ALG-001. Класс «точка»

## Условие
Объявить класс `Point` с двумя вещественными полями — координатами — и конструктором, задающим их. Добавить метод, возвращающий расстояние от точки до начала координат. Создать две точки, (3; 4) и (0; 0), и вывести оба расстояния.

## Ожидаемый результат
Выведено `5` и `0`; расстояние вычислено методом `Math.Sqrt`, поля заполнены конструктором.

## Идея решения
Класс — шаблон объекта: поля хранят состояние, конструктор задаёт начальные значения, метод вычисляет расстояние по формуле √(x² + y²).

## Решение
```csharp
using System;

class Point
{
    public double X;
    public double Y;

    public Point(double x, double y)
    {
        X = x;
        Y = y;
    }

    public double DistanceToOrigin()
    {
        return Math.Sqrt(X * X + Y * Y);
    }
}

class Program
{
    static void Main()
    {
        Point a = new Point(3, 4);
        Point o = new Point(0, 0);
        Console.WriteLine(a.DistanceToOrigin());
        Console.WriteLine(o.DistanceToOrigin());
    }
}
```

## Пошаговое объяснение
1. Конструктор `Point(double x, double y)` записывает аргументы в поля.
2. `new Point(3, 4)` создаёт объект в памяти и вызывает конструктор.
3. `Math.Sqrt(3² + 4²) = Math.Sqrt(25) = 5`; для начала координат — 0.

## Результат
5 и 0
