# Разбор решения. L16-ALG-001. Первая структура

## Условие
Объявить **структуру** `Point` с двумя вещественными свойствами — координатами, конструктором, методом вычисления расстояния до начала координат и переопределением `ToString`. Создать две точки, (3; 4) и (0; 0), и вывести их вместе с расстояниями.

## Ожидаемый результат
Выведено `(3; 4)` с расстоянием `5` и `(0; 0)` с расстоянием `0`; объявление отличается от объявления класса только словом `struct`.

## Идея решения
Структура объявляется ключевым словом `struct` и является значимым типом: хранится по значению, копируется при присваивании. Расстояние считаем так же, как для класса.

## Решение
```csharp
using System;

struct Point
{
    public double X { get; }
    public double Y { get; }

    public Point(double x, double y)
    {
        X = x;
        Y = y;
    }

    public double DistanceToOrigin() => Math.Sqrt(X * X + Y * Y);

    public override string ToString() => "(" + X + "; " + Y + ")";
}

class Program
{
    static void Main()
    {
        Point a = new Point(3, 4);
        Point o = new Point(0, 0);
        Console.WriteLine(a + " расстояние " + a.DistanceToOrigin());
        Console.WriteLine(o + " расстояние " + o.DistanceToOrigin());
    }
}
```

## Пошаговое объяснение
1. Объявление отличается от класса словом `struct`.
2. Конструктор структуры обязан присвоить все свойства.
3. `ToString` переопределён, поэтому при склейке со строкой выводится `(3; 4)`.
4. Структура — значимый тип: `Point b = a;` создаёт независимую копию.

## Результат
(3; 4) расстояние 5 и (0; 0) расстояние 0
