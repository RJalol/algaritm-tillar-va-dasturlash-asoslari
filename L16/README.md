# L16. Создание класса и его объектов. Принципы ООП. Члены класса

Практические задания к теме №16 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Особенность этой темы

Первые пятнадцать тем описывали программу как набор данных и действующих над ними методов. Разделение это условно: имя студента, его группа и балл — три отдельные переменные, хотя описывают **один** объект. Тема №16 вводит средство объединить их — и с неё начинается объектно-ориентированная часть курса.

Ключевая идея, вокруг которой построены задания ALG-008, ALG-014, ALG-026 и ALG-029: класс — **ссылочный** тип, поэтому

| Выражение | Что сравнивает | Результат для двух объектов с одинаковыми полями |
|---|---|---|
| `a == b` | ссылки | `False` |
| `a.Equals(b)` без переопределения | ссылки | `False` |
| `a.Equals(b)` с переопределением | поля | `True` |

Не используются: **перегрузка** и **свойства** (тема №17), **структуры** (тема №18), **модификаторы доступа** кроме `public` (тема №19), **статические члены** (тема №20), **перегрузка операторов** (тема №22), **наследование** и **полиморфизм** (темы №24–26). Каждый класс имеет не более одного конструктора.

## Ключевые идеи темы, проверяемые заданиями

- Переменная класса хранит **ссылку**; присваивание копирует ссылку, и оба имени указывают на один объект (ALG-008, ALG-029).
- Операция `==` для объектов класса сравнивает **ссылки**, а не содержимое; переопределение `Equals` этого не меняет (ALG-014, ALG-025, ALG-029).
- Поля без явного присваивания получают значение по умолчанию; компилятор выдаёт предупреждение `CS0649` (ALG-009, ALG-030).
- Объявление собственного конструктора **отменяет** конструктор без параметров: `new Student()` даёт `CS7036` (ALG-016, ALG-021).
- Вызов метода экземпляра через имя класса — `CS0120`; переменная без `new` — `CS0165`; несуществующий член — `CS1061` (ALG-017–ALG-019, ALG-021).
- Обращение к полю через `null` **компилируется** и даёт `NullReferenceException` (ALG-020).
- Переопределённый `ToString` вызывается автоматически в `Console.WriteLine`, при конкатенации и при интерполяции (ALG-005, ALG-013).
- Правило, помещённое **внутрь** класса (балл не более 100, дробь всегда сокращена, время всегда нормализовано), соблюдается при любом обращении — это и есть первая польза от объединения данных и методов (ALG-007, ALG-022, ALG-023).

## О диагностических заданиях

Задания Middle ALG-008, ALG-016–ALG-020 и Advanced ALG-021, ALG-029, ALG-030 содержат код для анализа: найти ошибку, назвать её код либо предсказать вывод до запуска.

Все коды сообщений (`CS0029`, `CS0120`, `CS0165`, `CS0649`, `CS1061`, `CS7036`) и **все числовые ответы** (средний балл 85,67 и лучший «Дилноза»; остатки 700 и 900; дроби `3/4`, `2`, `-1/3`, `5/6` и `1`; время `11:15`, `00:30`, `23:30` и `00:10`; длина вектора 5; отрицательная цена `-5000` при скидке 200 %) проверены фактической компиляцией и запуском на .NET 8 с культурой ru-RU.

## Формат каждого задания (V3)

Каждый файл `L16-ALG-XXX.md` содержит только два поля: **Условие** и **Ожидаемый результат**. **Готовые решения не приводятся.**

## Материалы для подготовки

Перед выполнением заданий рекомендуется изучить лекцию по теме №16: зачем нужен класс, объявление класса и поля, создание объекта операцией `new`, ссылочная семантика, методы экземпляра и `this`, конструкторы, класс `System.Object` как корень иерархии типов, переопределение `ToString` и `Equals`, карта четырёх принципов ООП со ссылками на темы курса.
