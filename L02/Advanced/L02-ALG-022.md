# L02-ALG-022. Тело метода вне класса

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Дан код:
```
using System;

namespace DemoApp
{
    class Program
    {
    }
    
    static void Main(string[] args)
    {
        Console.WriteLine("Готово");
    }
}
```
Определить, какое правило вложенности здесь нарушено, опираясь на трёхуровневую структуру «пространство имён → класс → метод».

## Ожидаемый результат
Точно указано, на каком уровне вложенности фактически расположен метод `Main`, и почему это нарушает ожидаемую структуру.
