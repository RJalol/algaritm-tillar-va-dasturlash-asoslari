# L02-ALG-029. Несовпадение имени класса и имени файла

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Объяснить, скомпилируется ли программа, если имя класса-контейнера не совпадает с именем файла `.cs`, в котором он находится (например, класс называется `Program`, а файл — `Main.cs`).

## Ожидаемый результат
Вывод, чётко разграничивающий требования самого языка C# и соглашения, принятые в среде разработки Visual Studio.
