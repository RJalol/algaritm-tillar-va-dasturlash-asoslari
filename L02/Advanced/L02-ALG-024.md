# L02-ALG-024. Лишняя закрывающая скобка в конце файла

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Дан код:
```
using System;

namespace DemoApp
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Готово");
        }
    }
}
}
```
Определить, что здесь нарушено, явно показав соответствие между каждой открывающей и закрывающей скобкой.

## Ожидаемый результат
Точно указана конкретная лишняя закрывающая скобка, не имеющая соответствующей открывающей.
