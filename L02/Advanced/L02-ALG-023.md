# L02-ALG-023. Два метода Main в одном классе

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Дан код:
```
using System;

namespace DemoApp
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Первый вариант");
        }

        static void Main(string[] args)
        {
            Console.WriteLine("Второй вариант");
        }
    }
}
```
Определить, в чём заключается структурная проблема, опираясь на понятие точки входа программы, а не только на общее правило «нельзя повторяться».

## Ожидаемый результат
Развёрнутое обоснование сути проблемы, связанное именно с понятием точки входа программы.
