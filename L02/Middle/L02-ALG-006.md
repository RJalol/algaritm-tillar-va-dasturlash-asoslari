# L02-ALG-006. Визитка проекта

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Написать программу, выводящую пять строк текста, представляющих «визитку» учебного проекта (например: название, автор, курс, тема, дата). Перед каждым вызовом `Console.WriteLine` должен стоять отдельный однострочный комментарий, поясняющий, что именно выводится этой строкой.

## Ожидаемый результат
Пять строк текста на экране; в коде — ровно пять комментариев, каждый непосредственно перед «своим» вызовом.
