# L02-ALG-010. Титульный экран программы

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Написать программу, начинающуюся с многострочного комментария (3–4 строки: автор, дата, краткое описание программы) перед директивой `using`, за которым следуют три строки вывода, образующие «титульный экран».

## Ожидаемый результат
Три строки текста на экране; в коде — один многострочный комментарий перед `using`.
