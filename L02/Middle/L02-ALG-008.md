# L02-ALG-008. Текстовое меню

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Написать программу, выводящую список из четырёх пунктов меню (текст — по выбору студента), каждый — на отдельной строке, с комментарием над каждым пунктом, поясняющим его номер и назначение.

## Ожидаемый результат
Четыре строки текста меню на экране; каждая сопровождена комментарием в коде.
