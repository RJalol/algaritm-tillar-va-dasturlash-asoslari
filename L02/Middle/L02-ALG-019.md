# L02-ALG-019. Три алгоритма в одной программе

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Написать одну программу, в методе `Main` которой последовательно выполняются все три алгоритма из темы №1 (линейный, разветвляющийся, циклический), каждый — в своём чётко обозначенном комментарием блоке.

## Ожидаемый результат
Три результата (по одному от каждого алгоритма), каждый на своей строке, в порядке следования блоков; блоки разделены комментариями.
