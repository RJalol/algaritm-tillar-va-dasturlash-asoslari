# L02 · Задание I · №3. Компиляция или интерпретация

**Тема:** Л2 — История и этапы развития языков программирования. Современные языки программирования и технологии

## Условие
Для языков C, Python, Java и C# указать, как выполняется программа: компилируется в машинный код, интерпретируется или компилируется в промежуточный код с последующим выполнением виртуальной машиной.

## Ожидаемый результат
Для каждого языка названа модель выполнения; для Java и C# отмечена промежуточная компиляция (байт-код, IL).
