# Разбор решения. L02 · Задание I · №1. Хронология языков

## Условие
Даны языки: C, Fortran, Python, Java, COBOL, Pascal, C#, Lisp. Расположить их в порядке появления (по году первой версии) и указать год для каждого.

## Ожидаемый результат
Порядок: Fortran (1957), Lisp (1958), COBOL (1959), Pascal (1970), C (1972), Python (1991), Java (1995), C# (2000).

## Идея решения
Для упорядочения нужно знать год появления первой версии каждого языка. Составляем пары «язык — год» и сортируем по году.

## Решение
```text
Fortran  — 1957
Lisp     — 1958
COBOL    — 1959
Pascal   — 1970
C        — 1972
Python   — 1991
Java     — 1995
C#       — 2000
```

## Пошаговое объяснение
1. Fortran (1957) — первый широко распространённый язык высокого уровня для научных расчётов.
2. Lisp (1958) — язык символьной обработки; COBOL (1959) — язык для бизнес-приложений.
3. Pascal (1970) создан Н. Виртом для обучения структурному программированию; C (1972) — Д. Ритчи для системного программирования (UNIX).
4. Python (1991, Г. ван Россум) и Java (1995, Дж. Гослинг, Sun) относятся к 1990-м годам.
5. C# (2000) — язык компании Microsoft, разработанный под руководством А. Хейлсберга для платформы .NET.
6. Проверка: список упорядочен по возрастанию года, повторяющихся лет нет.

## Результат
Fortran → Lisp → COBOL → Pascal → C → Python → Java → C# (1957 → 2000).
