# Разбор решения. L02 · Задание I · №1. Хронология языков

## Условие
Даны языки: C, Fortran, Python, Java, COBOL, Pascal, C#, Lisp. Расположить их в порядке появления (по году первой версии) и указать год для каждого.

## Ожидаемый результат
Порядок: Fortran (1957), Lisp (1958), COBOL (1959), Pascal (1970), C (1972), Python (1991), Java (1995), C# (2000).

## Разбор условия
**Дано:** восемь языков: C, Fortran, Python, Java, COBOL, Pascal, C#, Lisp.
**Требуется:** расположить их по году появления первой версии и указать год.
**Критерий:** опора на общепринятые даты первых версий (спецификаций), а не на даты популярности.

## Теоретическая справка
Развитие языков можно разделить на эпохи:

- **1950-е** — первые высокоуровневые языки: Fortran (научные расчёты), Lisp (символьная обработка), COBOL (бизнес-данные);
- **1960–1970-е** — структурное программирование и системные языки: Algol, Pascal, C;
- **1980–1990-е** — объектный подход и скриптовые языки: C++, Python, Java;
- **2000-е** — управляемые платформы: C# и .NET.

Годы в таблице — это годы первых версий; для Java и C# это публичные релизы (1995 и 2000), для Pascal — первая публикация языка (1970), для C — создание в Bell Labs (1972).

## Идея решения
Для упорядочения нужно знать год появления первой версии каждого языка. Составляем пары «язык — год» и сортируем по году.

## Решение
```text
Fortran  — 1957
Lisp     — 1958
COBOL    — 1959
Pascal   — 1970
C        — 1972
Python   — 1991
Java     — 1995
C#       — 2000
```

## Пошаговое объяснение
1. Fortran (1957) — первый широко распространённый язык высокого уровня для научных расчётов.
2. Lisp (1958) — язык символьной обработки; COBOL (1959) — язык для бизнес-приложений.
3. Pascal (1970) создан Н. Виртом для обучения структурному программированию; C (1972) — Д. Ритчи для системного программирования (UNIX).
4. Python (1991, Г. ван Россум) и Java (1995, Дж. Гослинг, Sun) относятся к 1990-м годам.
5. C# (2000) — язык компании Microsoft, разработанный под руководством А. Хейлсберга для платформы .NET.
6. Проверка: список упорядочен по возрастанию года, повторяющихся лет нет.

## Трассировка и проверка
| Год | Язык | Эпоха и роль |
|---:|---|---|
| 1957 | Fortran | научные и инженерные расчёты |
| 1958 | Lisp | искусственный интеллект, символьные вычисления |
| 1959 | COBOL | бизнес-приложения, учёт |
| 1970 | Pascal | обучение, структурное программирование |
| 1972 | C | системное программирование, UNIX |
| 1991 | Python | сценарии, обучение, анализ данных |
| 1995 | Java | переносимые приложения на виртуальной машине |
| 2000 | C# | платформа .NET |

Самопроверка: между Fortran и C# — 43 года; из восьми языков семь появились до 2000 года; первые три — в 1950-х годах.

## Результат
Fortran → Lisp → COBOL → Pascal → C → Python → Java → C# (1957 → 2000).

## Типичные ошибки
- Путать год появления языка с годом его стандартизации (например, у C — ANSI C, 1989).
- Считать Python «молодым» языком второй половины 2000-х — он появился в 1991 году.
- Утверждать, что C# старше Java: Java (1995) появилась раньше, и C# учёл её опыт.
- Опираться на память о «популярности», а не на даты первых версий.
