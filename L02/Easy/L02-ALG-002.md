# L02-ALG-002. Сборка одной строки из Write и WriteLine

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Написать программу, которая выводит на одной строке экрана текст `Итог: готово`, используя `Console.Write("Итог: ")` для первой части и `Console.WriteLine("готово")` для второй.

## Ожидаемый результат
На экране одна строка: `Итог: готово`, собранная из двух вызовов (`Write`, затем `WriteLine`).
