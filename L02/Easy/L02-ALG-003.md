# L02-ALG-003. Пустая строка между сообщениями

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Написать программу, которая выводит строку `Раздел 1`, затем пустую строку (с помощью `Console.WriteLine();` без аргументов), затем строку `Раздел 2`.

## Ожидаемый результат
```
Раздел 1

Раздел 2
```
