# L28 · Задание I · №3. Переопределение против сокрытия

**Тема:** Л28 — Полиморфизм. Виртуальные методы, свойства и их переопределение

## Условие
Объявить базовый класс с двумя методами: виртуальным и обычным. В производном классе первый переопределить, второй скрыть. Создать один объект производного класса, присвоить его переменной базового типа и вызвать оба метода через обе переменные. Подтвердить проверкой, что объект один и тот же.

## Ожидаемый результат
Виртуальный метод дал одинаковый результат через обе переменные, скрытый — разный; тождественность ссылок подтверждена.
