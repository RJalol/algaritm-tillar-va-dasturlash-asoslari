# L28 · Задание I · №4. Вызов базовой реализации

**Тема:** Л28 — Полиморфизм. Виртуальные методы, свойства и их переопределение

## Условие
Объявить базовый класс с виртуальным методом, выводящим заголовок документа, и производный класс, переопределение которого добавляет к заголовку дату, обратившись к базовой реализации. Добавить третий уровень, добавляющий подпись. Вывести результат для объектов всех трёх классов.

## Ожидаемый результат
Каждый следующий уровень дополнил результат предыдущего; в выводе объекта третьего класса присутствуют все три части.
