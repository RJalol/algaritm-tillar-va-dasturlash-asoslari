# L28 · Задание III · №6. Шаблон обработки

**Тема:** Л28 — Полиморфизм. Виртуальные методы, свойства и их переопределение

## Условие
Разработать базовый класс «обработчик данных» с невиртуальным методом, задающим общий порядок работы (подготовка, проверка, обработка, завершение), где каждый шаг — отдельный виртуальный метод с разумной реализацией по умолчанию. Построить три производных класса, каждый из которых переопределяет только те шаги, которые для него отличаются. Показать, что общий порядок не нарушается ни в одном из них.

## Ожидаемый результат
Все три обработчика выполняют шаги в одном порядке, различаясь только содержанием переопределённых шагов; метод, задающий порядок, не переопределён нигде.
