# L28 · Задание III · №1. Система учёта успеваемости

**Тема:** Л28 — Полиморфизм. Виртуальные методы, свойства и их переопределение

## Условие
Разработать иерархию из шести классов видов контроля (устный опрос, письменная работа, тест, лабораторная работа, курсовая работа, экзамен) с виртуальными методами расчёта итогового балла и виртуальным свойством веса в общей оценке. Базовый класс объявляет невиртуальный метод формирования протокола, обращающийся к виртуальным членам. Программа рассчитывает итоговую оценку студента по массиву не менее чем из десяти работ.

## Ожидаемый результат
Итоговая оценка рассчитана верно; метод формирования протокола не переопределяется ни в одном производном классе и не содержит проверок типа.
