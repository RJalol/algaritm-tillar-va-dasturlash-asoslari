# L28 · Задание III · №10. Полный аудит

**Тема:** Л28 — Полиморфизм. Виртуальные методы, свойства и их переопределение

## Условие
Дана программа, в которой одновременно: обработка массива построена на проверках типа вместо виртуальных методов; в одном месте применено сокрытие там, где требовалось переопределение; переопределение не вызывает базовую реализацию, хотя должно её дополнять; виртуальный метод вызывается из конструктора базового класса; часть виртуальных членов не переопределяется нигде и потому виртуальна напрасно. Провести аудит, разнести замечания по четырём категориям и привести исправленную версию.

## Ожидаемый результат
Все замечания названы с обоснованием; исправленная программа даёт верный результат, не содержит проверок типа в обработке массива и компилируется без предупреждений.
