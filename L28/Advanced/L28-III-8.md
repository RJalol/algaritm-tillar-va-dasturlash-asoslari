# L28 · Задание III · №8. Инвентаризация виртуальных членов

**Тема:** Л28 — Полиморфизм. Виртуальные методы, свойства и их переопределение

## Условие
Написать статический метод, который для заданного набора типов выводит перечень их методов с указанием: виртуальный ли метод, является ли он переопределением, запечатан ли, в каком классе объявлен изначально. Проверить метод на иерархии задания III.1 и сопоставить результат с исходным текстом.

## Ожидаемый результат
Перечень соответствует объявлениям; для переопределённых методов указан класс, где член объявлен изначально; запечатанные переопределения отмечены отдельно.
