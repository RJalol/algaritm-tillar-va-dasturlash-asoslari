# L28 · Задание III · №5. Разбор порядка вызовов

**Тема:** Л28 — Полиморфизм. Виртуальные методы, свойства и их переопределение

## Условие
Построить иерархию из пяти классов, в которой виртуальный метод переопределён не во всех классах, одно переопределение запечатано, а последний класс применяет сокрытие. Для каждого из пяти объектов вывести результат вызова через переменные **всех** типов иерархии, для которых это допустимо. Составить таблицу и объяснить каждую клетку.

## Ожидаемый результат
Таблица заполнена фактическими значениями; расхождения между строками объяснены сочетанием переопределения, запечатывания и сокрытия.
