# L28 · Задание II · №1. Несколько блоков catch

**Тема:** Л28 — Исключения и их обработка. Виды исключений и способы их генерации. Блок finally

## Условие
Написать метод, который читает два числа из строк и делит одно на другое. Использовать три блока `catch` для `FormatException`, `DivideByZeroException` и `OverflowException` с разными сообщениями.

## Ожидаемый результат
Для каждого типа ошибки выводится своё сообщение; порядок блоков корректен.
