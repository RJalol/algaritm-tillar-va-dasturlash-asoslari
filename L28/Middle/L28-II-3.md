# L28 · Задание II · №3. Виртуальное свойство

**Тема:** Л28 — Полиморфизм. Виртуальные методы, свойства и их переопределение

## Условие
Объявить базовый класс «товар» с виртуальным свойством «цена со скидкой», возвращающим полную цену, и три производных класса, переопределяющих это свойство по разным правилам. Вывести таблицу «товар — полная цена — цена со скидкой» для массива базового типа.

## Ожидаемый результат
Для каждого товара цена со скидкой вычислена по правилу его класса; переменная цикла объявлена базовым типом.
