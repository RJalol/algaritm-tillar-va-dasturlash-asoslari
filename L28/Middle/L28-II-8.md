# L28 · Задание II · №8. Три возможности производного класса

**Тема:** Л28 — Полиморфизм. Виртуальные методы, свойства и их переопределение

## Условие
Для одного виртуального метода базового класса построить три производных класса, воплощающих три возможности: переопределение; наследование без изменений; сокрытие невиртуальным членом. Вывести результат вызова для каждого через переменную базового типа и через переменную собственного типа. Составить таблицу шесть на два.

## Ожидаемый результат
Таблица заполнена; расхождение между столбцами есть только у класса, применившего сокрытие.
