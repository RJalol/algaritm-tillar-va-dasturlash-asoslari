# L03-ALG-016. Неявная типизация без инициализатора

**Тема:** Л3 — Алфавит и ключевые слова языка C#. Идентификаторы, литералы, переменные, константы и типы данных

## Условие
Дан код:

```
var result;
result = 42;
Console.WriteLine(result);
```

Объяснить, почему код не компилируется, хотя переменной впоследствии присваивается значение. Назвать код ошибки и указать, какая информация недоступна компилятору в момент обработки первой строки.

## Ожидаемый результат
Назван код `CS0818`; объяснено, что тип выводится из инициализатора, а при его отсутствии выводить тип не из чего.
