# L03-ALG-004. Проверка корректности идентификаторов

**Тема:** Л3 — Алфавит и ключевые слова языка C#. Идентификаторы, литералы, переменные, константы и типы данных

## Условие
Дан список предполагаемых имён переменных:

```
studentCount    2ndGroup    _temp       my-name
class           Class       student name    totalSum
```

Для каждого имени определить, является ли оно корректным идентификатором C#. Для некорректных указать конкретное нарушенное правило.

## Ожидаемый результат
Восемь ответов вида «корректно / некорректно»; для каждого некорректного имени названо конкретное правило языка (начало с цифры, недопустимый символ, зарезервированное слово, наличие пробела).
