# L03-ALG-024. Область видимости внутри блока

**Тема:** Л3 — Алфавит и ключевые слова языка C#. Идентификаторы, литералы, переменные, константы и типы данных

## Условие
Дан код:

```
{
    int inner = 5;
    Console.WriteLine(inner);
}
Console.WriteLine(inner);
```

Определить, какая из двух строк вывода не скомпилируется, и объяснить причину через понятие области видимости. Назвать код ошибки.

## Ожидаемый результат
Указана вторая строка; названа ошибка `CS0103`; объяснено, что область видимости локальной переменной ограничена блоком, в котором она объявлена.
