# Разбор решения. L03-ALG-021. Три нарушения в одном фрагменте

## Условие
Дан код:

```
int 1stPlace = 100;
const double Rate = 1.5;
Rate = 2.0;
var total;
total = 500;
```

Найти все нарушения, для каждого назвать код ошибки компилятора и объяснить причину отдельно. Указать, какие из нарушений относятся к правилам образования имён, а какие — к правилам использования уже объявленных величин.

## Ожидаемый результат
Три независимых нарушения с кодами `CS1001`, `CS0131` и `CS0818`, каждое с отдельным обоснованием и отнесением к соответствующей категории.

## Разбор условия
**Дано:** пять строк кода с объявлениями.
**Требуется:** найти три нарушения, назвать код ошибки компилятора для каждого, объяснить причину, отнести к категории — «правила образования имён» либо «правила использования объявленных величин».

## Теоретическая справка
Три группы правил, участвующих в задаче:

1. **Идентификаторы:** состоят из букв, цифр и подчёркиваний, не начинаются с цифры и не совпадают с ключевым словом.
2. **Константы (`const`):** значение задаётся при объявлении и далее не изменяется; присваивание константе недопустимо.
3. **Неявная типизация (`var`):** тип определяется компилятором по выражению-инициализатору; поэтому объявление `var` без инициализатора невозможно.

Все три ошибки обнаруживаются на этапе компиляции — в готовой программе их быть не может, но ошибки программиста находятся быстро по коду сообщения.

## Идея решения
Разбираем каждую строку отдельно и сверяем с правилами образования идентификаторов и использования констант и `var`.

## Решение
```csharp
// Исправленный фрагмент
int firstPlace = 100;        // имя не начинается с цифры
const double Rate = 1.5;     // константе значение больше не присваиваем
var total = 500;             // var требует инициализации при объявлении
```

## Пошаговое объяснение
1. `int 1stPlace = 100;` — идентификатор не может начинаться с цифры. Это нарушение *правил образования имён* (`CS1001`: ожидался идентификатор).
2. `Rate = 2.0;` — константа объявлена с `const`, её значение неизменно и присваивать его повторно нельзя (`CS0131`). Это нарушение *правил использования объявленной величины*.
3. `var total;` — для неявной типизации компилятор определяет тип по инициализатору; без него тип неизвестен (`CS0818`). Это тоже нарушение правил использования/объявления величины.
4. К правилам образования имён относится только первое нарушение; второе и третье связаны с использованием уже объявленных величин.

## Трассировка и проверка
Таблица разбора:

| Строка | Нарушенное правило | Код | Категория |
|---|---|---|---|
| `int 1stPlace = 100;` | имя не может начинаться с цифры | CS1001 | образование имён |
| `Rate = 2.0;` | присваивание константе | CS0131 | использование объявленной величины |
| `var total;` | `var` требует инициализатора | CS0818 | использование/объявление величины |

Сообщения компилятора могут сопровождаться вспомогательными (например, `CS1002` — ожидалась `;`), но основной код определяется самой первой ошибкой в строке. Исправленный фрагмент содержит три корректные строки и компилируется.

## Результат
Три нарушения: CS1001 (имя начинается с цифры), CS0131 (присваивание константе), CS0818 (var без инициализатора).

## Типичные ошибки
- Объяснять `CS0131` как «неправильное имя» — на самом деле имя `Rate` корректно, неверно действие над ним.
- Считать допустимым `var x = null;` — тип выразить нельзя (`CS0815`).
- Исправлять `const` на `var`, меняя замысел программы вместо исправления присваивания.
- Забывать, что имена в C# различают регистр: `rate` и `Rate` — разные идентификаторы.

- Выяснить, почему `const DateTime now = DateTime.Now;` недопустимо.
