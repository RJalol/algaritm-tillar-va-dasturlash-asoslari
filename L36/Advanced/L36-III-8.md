# L36 · Задание III · №8. Retry с делегатами

**Тема:** Л36 — Делегаты. Обобщённые делегаты. Делегаты Func и Action

## Условие
Написать метод `Retry<T>(Func<T> action, int attempts)`, повторяющий действие при исключении. Проверить на «нестабильной» операции.

## Ожидаемый результат
Успешная операция выполняется один раз; неудачная — заданное число раз с итоговым исключением.
