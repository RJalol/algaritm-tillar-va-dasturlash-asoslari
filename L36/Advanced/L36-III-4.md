# L36 · Задание III · №4. Обработчик команд

**Тема:** Л36 — Делегаты. Обобщённые делегаты. Делегаты Func и Action

## Условие
Реализовать консольный обработчик команд: словарь «имя команды — делегат», команды `help`, `add a b`, `exit`; неизвестные команды сообщают об ошибке.

## Ожидаемый результат
Команды выполняются; список доступных команд выводится по `help`.
