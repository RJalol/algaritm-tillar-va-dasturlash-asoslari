# Разбор решения. L36 · Задание II · №1. Делегат как параметр

## Условие
Написать метод `Calculate(int a, int b, Operation op)`, возвращающий результат операции, и вызвать его с четырьмя разными операциями (сложение, вычитание, умножение, деление).

## Ожидаемый результат
Результаты для (12, 4): 16, 8, 48, 3.

## Идея решения
Делегат передаётся в метод как параметр — так поведение (операция) выбирает вызывающий код, а метод только применяет его.

## Решение
```csharp
using System;

delegate int Operation(int a, int b);

class Program
{
    static int Calculate(int a, int b, Operation op) => op(a, b);

    static void Main()
    {
        Console.WriteLine(Calculate(12, 4, (x, y) => x + y));
        Console.WriteLine(Calculate(12, 4, (x, y) => x - y));
        Console.WriteLine(Calculate(12, 4, (x, y) => x * y));
        Console.WriteLine(Calculate(12, 4, (x, y) => x / y));
    }
}
```

## Пошаговое объяснение
1. `Calculate` ничего не знает о конкретных операциях: он просто вызывает переданный делегат.
2. Четыре лямбда-выражения реализуют сложение, вычитание, умножение и деление.
3. Сигнатура лямбды `(x, y) => ...` совпадает с типом `Operation`, поэтому преобразование допустимо.
4. Результаты для (12, 4): 16, 8, 48, 3 (деление целочисленное).

## Результат
16, 8, 48, 3
