# L32. Коллекции: списки, связанный список, стеки и очереди

Практические задания к теме №32 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
L32/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
└── Advanced/   10 заданий  (Задание III)
```

## Формат задания

Каждый файл `L32-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. Готовые решения не приводятся.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.
