# Разбор решения. L32 · Задание I · №1. Первый виртуальный метод

## Условие
Объявить базовый класс «животное» с виртуальным методом, возвращающим издаваемый звук, и три производных класса, переопределяющих этот метод. Заполнить массив базового типа объектами всех четырёх классов и вывести звук каждого в цикле, объявив переменную цикла базовым типом.

## Ожидаемый результат
Каждый объект вывел свой звук, хотя переменная цикла объявлена базовым типом; для объекта базового класса выведена его собственная реализация.

## Идея решения
Полиморфизм: вызов виртуального метода через ссылку базового типа выполняет реализацию из фактического класса объекта. Производные классы подменяют метод ключевым словом `override`.

## Решение
```csharp
using System;

class Animal
{
    public virtual string Sound() => "(тишина)";
}

class Dog : Animal
{
    public override string Sound() => "Гав!";
}

class Cat : Animal
{
    public override string Sound() => "Мяу!";
}

class Cow : Animal
{
    public override string Sound() => "Муу!";
}

class Program
{
    static void Main()
    {
        Animal[] animals = { new Animal(), new Dog(), new Cat(), new Cow() };

        foreach (Animal a in animals)
            Console.WriteLine(a.GetType().Name + ": " + a.Sound());
    }
}
```

## Пошаговое объяснение
1. В базовом классе метод помечен `virtual` — разрешено переопределение.
2. Каждый производный класс объявляет метод с тем же именем и сигнатурой и ключевым словом `override`.
3. Массив имеет тип `Animal[]`, поэтому переменная цикла — тоже `Animal`; выбор реализации происходит во время выполнения по фактическому типу объекта (позднее связывание).
4. Для объекта самого `Animal` вызывается собственная реализация базового класса.

## Результат
Animal: (тишина) / Dog: Гав! / Cat: Мяу! / Cow: Муу!
