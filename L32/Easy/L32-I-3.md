# L32 · Задание I · №3. Поиск и сортировка в списке

**Тема:** Л32 — Коллекции: списки, связанный список, стеки и очереди

## Условие
Для списка объектов собственного класса применить `Contains`, `IndexOf`, `Find`, `FindAll` и две сортировки: без аргументов и с лямбдой. Показать оба исхода `IndexOf` — найденное значение и отсутствующее. Подобрать данные так, чтобы обе сортировки давали **разный** порядок.

## Ожидаемый результат
Все пять методов применены; `IndexOf` для отсутствующего значения вернул `-1`; два порядка сортировки различаются, и различие видно в выводе.
