# L32 · Задание I · №2. Список против массива

**Тема:** Л32 — Коллекции: списки, связанный список, стеки и очереди

## Условие
Решить одну задачу дважды: «прочитать неизвестное заранее число значений и вывести их в обратном порядке» — сначала массивом с запасом и счётчиком, затем списком. Сравнить оба решения по числу строк и по тому, что происходит при превышении заданного запаса.

## Ожидаемый результат
Оба решения дают одинаковый результат; для варианта с массивом показано поведение при превышении запаса; подсчитано, сколько строк кода избавил список.
