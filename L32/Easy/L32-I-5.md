# L32 · Задание I · №5. Переопределение `ToString`

**Тема:** Л32 — Полиморфизм. Виртуальные методы и свойства, их переопределение

## Условие
Объявить два класса с одинаковыми полями: в первом переопределить `ToString()`, во втором — нет. Вывести объекты обоих классов через `Console. WriteLine` и через переменную типа `object`. Объяснить различие в выводе.

## Ожидаемый результат
Первый класс вывел осмысленный текст, второй — полное имя типа; результат одинаков при выводе через переменную типа `object`, поскольку `ToString` виртуален.
