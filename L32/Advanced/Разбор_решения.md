# Разбор решения. L32 · Задание III · №1. Система учёта успеваемости

## Условие
Разработать иерархию из шести классов видов контроля (устный опрос, письменная работа, тест, лабораторная работа, курсовая работа, экзамен) с виртуальными методами расчёта итогового балла и виртуальным свойством веса в общей оценке. Базовый класс объявляет невиртуальный метод формирования протокола, обращающийся к виртуальным членам. Программа рассчитывает итоговую оценку студента по массиву не менее чем из десяти работ.

## Ожидаемый результат
Итоговая оценка рассчитана верно; метод формирования протокола не переопределяется ни в одном производном классе и не содержит проверок типа.

## Идея решения
Базовый класс задаёт «шаблонный» невиртуальный метод `Protocol`, который использует виртуальные члены `Weight` и `Score`. Производные классы определяют только эти члены; протокол не переопределяется и не проверяет типы.

## Решение
```csharp
using System;
using System.Collections.Generic;

abstract class Assessment
{
    public string Subject { get; }
    protected double Points { get; }       // набранные баллы по шкале 0–100

    protected Assessment(string subject, double points) { Subject = subject; Points = points; }

    public virtual double Weight => 0.1;                          // вес в общей оценке
    public virtual double Score() => Points;                      // балл за работу
    public virtual string Kind => "Контроль";

    // Невиртуальный метод: общая логика, обращение к виртуальным членам
    public string Protocol() =>
        $"{Kind,-20} {Subject,-14} балл {Score(),6:F1}  вес {Weight:P0}  вклад {Score() * Weight,6:F2}";
}

class OralQuiz : Assessment
{
    public OralQuiz(string s, double p) : base(s, p) { }
    public override string Kind => "Устный опрос";
    public override double Weight => 0.05;
}

class WrittenWork : Assessment
{
    public WrittenWork(string s, double p) : base(s, p) { }
    public override string Kind => "Письменная работа";
    public override double Weight => 0.10;
}

class Test : Assessment
{
    private readonly int _correct, _total;
    public Test(string s, int correct, int total) : base(s, 0) { _correct = correct; _total = total; }
    public override string Kind => "Тест";
    public override double Weight => 0.15;
    public override double Score() => 100.0 * _correct / _total;
}

class LabWork : Assessment
{
    private readonly bool _late;
    public LabWork(string s, double p, bool late) : base(s, p) { _late = late; }
    public override string Kind => "Лабораторная";
    public override double Weight => 0.20;
    public override double Score() => _late ? Points * 0.8 : Points;     // штраф за опоздание
}

class CourseProject : Assessment
{
    public CourseProject(string s, double p) : base(s, p) { }
    public override string Kind => "Курсовая работа";
    public override double Weight => 0.25;
}

class Exam : Assessment
{
    public Exam(string s, double p) : base(s, p) { }
    public override string Kind => "Экзамен";
    public override double Weight => 0.25;
}

class Program
{
    static void Main()
    {
        var works = new List<Assessment>
        {
            new OralQuiz("Алгоритмы", 80), new OralQuiz("C#", 90),
            new WrittenWork("Циклы", 75), new WrittenWork("Массивы", 85),
            new Test("Типы данных", 18, 20), new Test("Методы", 15, 20),
            new LabWork("ЛР-1", 90, false), new LabWork("ЛР-2", 100, true),
            new CourseProject("Проект", 88), new Exam("Итог", 92)
        };

        double total = 0, weights = 0;
        foreach (Assessment a in works)
        {
            Console.WriteLine(a.Protocol());
            total += a.Score() * a.Weight;
            weights += a.Weight;
        }
        Console.WriteLine($"Итоговая оценка: {total / weights:F2}");
    }
}
```

## Пошаговое объяснение
1. Шесть видов контроля — шесть классов-наследников; каждый переопределяет вес (`Weight`), а там, где правило расчёта особое, — метод `Score` (тест — доля верных ответов, лабораторная — штраф за опоздание).
2. Метод `Protocol` в базовом классе не виртуальный: общая логика формирования строки находится в одном месте и не переопределяется.
3. `Protocol` обращается к виртуальным `Kind`, `Score()`, `Weight`, поэтому для каждого вида работы выводятся его собственные значения — типы нигде не проверяются (`is`, `GetType`).
4. Итоговая оценка — взвешенное среднее: сумма (балл × вес), делённая на сумму весов.
5. Добавление нового вида контроля сводится к новому классу; код `Main` и `Protocol` не меняется.

## Результат
Протокол по каждой из десяти работ и итоговая взвешенная оценка; метод Protocol не переопределяется и не проверяет типы.
