# Разбор решения. L32 · Задание III · №1. Текстовая база данных

## Условие
Реализовать класс-хранилище на `StreamReader`/`StreamWriter`: добавление, поиск, обновление и удаление записей.

## Ожидаемый результат
Все операции сохраняют целостность файла.

## Идея решения
Простая текстовая база хранится в файле: одна запись на строку, поля через `;`. Класс-хранилище читает файл через `StreamReader` и перезаписывает через `StreamWriter`; для изменений загружаем все записи, правим список и записываем целиком (во временный файл, чтобы не потерять данные при сбое).

## Решение
```csharp
using System;
using System.Collections.Generic;
using System.IO;

class Record
{
    public int Id;
    public string Name;
    public int Score;
    public override string ToString() => $"{Id};{Name};{Score}";
    public static Record Parse(string line)
    {
        string[] p = line.Split(';');
        return new Record { Id = int.Parse(p[0]), Name = p[1], Score = int.Parse(p[2]) };
    }
}

class Storage
{
    private readonly string _path;
    public Storage(string path) { _path = path; }

    public List<Record> LoadAll()
    {
        var list = new List<Record>();
        if (!File.Exists(_path)) return list;
        using (StreamReader r = new StreamReader(_path))
        {
            string line;
            while ((line = r.ReadLine()) != null)
                if (line.Length > 0) list.Add(Record.Parse(line));
        }
        return list;
    }

    private void SaveAll(List<Record> list)
    {
        string temp = _path + ".tmp";
        using (StreamWriter w = new StreamWriter(temp))
            foreach (Record r in list) w.WriteLine(r);
        File.Move(temp, _path, true);                 // замена целиком
    }

    public void Add(Record r)
    {
        var list = LoadAll();
        r.Id = list.Count == 0 ? 1 : list[list.Count - 1].Id + 1;
        list.Add(r);
        SaveAll(list);
    }

    public Record Find(string name) => LoadAll().Find(x => x.Name == name);

    public bool Update(int id, int newScore)
    {
        var list = LoadAll();
        Record r = list.Find(x => x.Id == id);
        if (r == null) return false;
        r.Score = newScore;
        SaveAll(list);
        return true;
    }

    public bool Delete(int id)
    {
        var list = LoadAll();
        bool removed = list.RemoveAll(x => x.Id == id) > 0;
        if (removed) SaveAll(list);
        return removed;
    }
}

class Program
{
    static void Main()
    {
        Storage db = new Storage("students.txt");
        db.Add(new Record { Name = "Азиз", Score = 87 });
        db.Add(new Record { Name = "Дилноза", Score = 92 });

        Console.WriteLine(db.Find("Дилноза"));
        db.Update(1, 90);
        db.Delete(2);
        foreach (Record r in db.LoadAll()) Console.WriteLine(r);
    }
}
```

## Пошаговое объяснение
1. Формат записи: `Id;Name;Score`. `ToString` формирует строку, `Parse` разбирает её.
2. `LoadAll` читает файл `StreamReader` до `null`, пропуская пустые строки.
3. `SaveAll` пишет данные `StreamWriter` во временный файл и затем заменяет им основной (`File.Move(..., true)`): если программа упадёт во время записи, исходный файл не повредится.
4. Операции `Add`, `Find`, `Update`, `Delete` работают через загрузку списка, изменение и сохранение; `Add` присваивает новый идентификатор.
5. Целостность сохраняется, потому что файл никогда не остаётся записанным наполовину.

## Результат
После добавления двух записей, обновления первой и удаления второй в файле остаётся одна строка: 1;Азиз;90.
