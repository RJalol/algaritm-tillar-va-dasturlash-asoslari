# L32 · Задание III · №4. Шесть исключений

**Тема:** Л32 — Коллекции: списки, связанный список, стеки и очереди

## Условие
Поставить шесть опытов, вызвав по одному: `Argument``OutOfRange``Exception` при обращении по неверному индексу; `Key``Not``Found``Exception` при чтении отсутствующего ключа; `Argument``Exception` при повторном ключе; `Argument``Null``Exception` при ключе `null`; `Invalid``Operation``Exception` при извлечении из пустой очереди и оно же при изменении коллекции во время перебора. Для каждого записать сообщение и способ избежать.

## Ожидаемый результат
Получены все шесть; составлена таблица «действие — исключение — как избежать»; отдельно отмечено, что два разных случая дают одно и то же исключение.
