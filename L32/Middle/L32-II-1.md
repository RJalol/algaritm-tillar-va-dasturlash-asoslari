# L32 · Задание II · №1. Подсчёт вхождений

**Тема:** Л32 — Коллекции: списки, связанный список, стеки и очереди

## Условие
По массиву строк построить словарь «значение — сколько раз встретилось», пользуясь методом `Try``Get``Value`. Вывести результат, отсортированный по убыванию числа вхождений. Отдельно объяснить, почему при первом появлении ключа переменная получает ноль без всякой проверки.

## Ожидаемый результат
Подсчёт верен для данных не менее чем с тремя различными значениями и повторами; вывод упорядочен; объяснено поведение `Try``Get``Value` для отсутствующего ключа.
