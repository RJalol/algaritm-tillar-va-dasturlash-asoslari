# L32 · Задание II · №13. Типобезопасность коллекций

**Тема:** Л32 — Коллекции: списки, связанный список, стеки и очереди

## Условие
Поставить три опыта: добавить в список строк число; передать в словарь с целым ключом строковый ключ; создать список без указания аргумента типа. Для каждого записать код ошибки. Затем объяснить, чем это отличается от поведения необобщённой коллекции `ArrayList`.

## Ожидаемый результат
Получены коды ошибок компиляции; объяснено, что обобщённая коллекция обнаруживает ошибку при компиляции, а необобщённая — только при выполнении; приведена связь с темой №31.
