# L34. Интерфейсы. Использование методов в интерфейсах и их реализация. Копирование и сортировка объектов интерфейсных типов

Практические задания к теме №34 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
L34/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
└── Advanced/   10 заданий  (Задание III)
```

## Формат задания

Каждый файл `L34-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. Готовые решения не приводятся.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.
