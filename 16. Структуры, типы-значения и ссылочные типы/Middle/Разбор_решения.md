# Разбор решения. L16-ALG-006. Структура «дата» с проверкой

## Условие
Объявить структуру `Date` с закрытыми полями дня и месяца и свойствами, приводящими значения к допустимым пределам: день — к отрезку от 1 до 31, месяц — от 1 до 12. Год — автоматическое свойство. Переопределить `ToString` в формате `ДД.ММ.ГГГГ`. Проверить на значениях (15, 3, 2026) и (40, 20, 2026).

## Ожидаемый результат
Выведено `15.03.2026` и `31.12.2026`; конструктор присваивает **свойствам**, а не полям, поэтому проверка действует и при создании.

## Разбор условия
**Дано:** значения (15, 3, 2026) и (40, 20, 2026).
**Требуется:** структура `Date` с проверяемыми свойствами дня (1…31) и месяца (1…12), автосвойство года, `ToString` в формате `ДД.ММ.ГГГГ`.

## Теоретическая справка
Свойство с проверкой скрывает поле и контролирует записываемое значение: `set` приводит значение к допустимому диапазону.

Нюанс структур: в конструкторе до обращения к свойствам необходимо **инициализировать все поля** (в современных версиях — присвоением по умолчанию), иначе возникает ошибка «`this` используется до присвоения всех полей». Поэтому конструктор сначала задаёт поля, а затем присваивает значения через свойства, чтобы проверка действовала и при создании.

Формат `{Day:00}` дополняет число нулём до двух цифр.

## Идея решения
Свойства проверяют и корректируют значения; конструктор присваивает именно свойствам (а не полям), поэтому проверка действует и при создании.

## Решение
```csharp
using System;

struct Date
{
    private int _day;
    private int _month;
    public int Year { get; set; }

    public int Day
    {
        get => _day;
        set => _day = Math.Min(Math.Max(value, 1), 31);
    }

    public int Month
    {
        get => _month;
        set => _month = Math.Min(Math.Max(value, 1), 12);
    }

    public Date(int day, int month, int year)
    {
        _day = 1; _month = 1; Year = year;   // поля инициализируются до вызова свойств
        Day = day;
        Month = month;
    }

    public override string ToString() => $"{Day:00}.{Month:00}.{Year}";
}

class Program
{
    static void Main()
    {
        Console.WriteLine(new Date(15, 3, 2026));
        Console.WriteLine(new Date(40, 20, 2026));
    }
}
```

## Пошаговое объяснение
1. `Math.Min(Math.Max(value, 1), 31)` приводит значение к отрезку.
2. В конструкторе структуры все поля нужно инициализировать до использования `this`, поэтому сначала задаём `_day`, `_month`, `Year`, а затем присваиваем через свойства.
3. Формат `:00` дополняет число нулём до двух цифр.

## Трассировка и проверка
| Вызов | День | Месяц | Результат |
|---|---:|---:|---|
| `new Date(15, 3, 2026)` | 15 | 3 | 15.03.2026 |
| `new Date(40, 20, 2026)` | 40 → 31 | 20 → 12 | 31.12.2026 |

Свойства используют `Math.Min(Math.Max(value, 1), 31)`: сначала нижняя граница, затем верхняя. Проверка «31 февраля» не выполняется: это дополнительное требование к улучшенной версии.

## Результат
15.03.2026 и 31.12.2026

## Типичные ошибки
- Присваивать полям напрямую в конструкторе и обходить проверку.
- Перепутать порядок `Min`/`Max` — получится нарушение ограничения.
- Не инициализировать поля до обращения к свойствам.
- Забыть формат `00` — получится «5.3.2026».
