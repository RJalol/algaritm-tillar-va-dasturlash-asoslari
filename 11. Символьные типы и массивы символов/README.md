# Тема 11. Символьные типы и работа с массивами символов. Стандартные методы обработки символов

Практические задания к теме №11 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
11. Символьные типы и массивы символов/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
└── Advanced/   10 заданий  (Задание III)
```

## Формат задания

Каждый файл `L11-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. В каждой из папок `Easy/`, `Middle/`, `Advanced/` приведён один образцовый разбор — файл `Разбор_решения.md`.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.
