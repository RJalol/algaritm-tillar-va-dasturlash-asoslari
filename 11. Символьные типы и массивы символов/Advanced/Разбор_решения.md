# Разбор решения. L11 · Задание III · №1. Определение анаграмм

## Условие
Определить, являются ли два слова анаграммами, используя массивы символов и сортировку. Регистр не учитывать.

## Ожидаемый результат
`"Лес"` и `"сел"` — анаграммы; `"мир"` и `"мура"` — нет.

## Разбор условия
**Дано:** два слова.
**Требуется:** определить, являются ли они анаграммами (регистр не учитывается).

## Теоретическая справка
**Анаграммы** — слова, составленные из одних и тех же букв в разном порядке. Два слова анаграммы тогда и только тогда, когда совпадают **мультимножества** их букв.

Способы проверки:

1. **Сортировка:** отсортировать буквы обоих слов и сравнить массивы — сложность O(n log n).
2. **Счётчики:** подсчитать вхождения каждой буквы — O(n), но требует таблицы счётчиков.

В решении применён первый способ: он короче и не зависит от алфавита.

## Идея решения
Два слова — анаграммы, если после приведения к одному регистру они состоят из одинаковых символов. Сортируем символы каждого слова и сравниваем получившиеся массивы.

## Решение
```csharp
using System;

class Program
{
    static bool AreAnagrams(string a, string b)
    {
        if (a.Length != b.Length) return false;

        char[] x = a.ToLower().ToCharArray();
        char[] y = b.ToLower().ToCharArray();
        Array.Sort(x);
        Array.Sort(y);

        for (int i = 0; i < x.Length; i++)
            if (x[i] != y[i]) return false;
        return true;
    }

    static void Main()
    {
        Console.WriteLine(AreAnagrams("Лес", "сел"));
        Console.WriteLine(AreAnagrams("мир", "мура"));
    }
}
```

## Пошаговое объяснение
1. Разная длина слов сразу означает, что анаграммами они быть не могут.
2. `ToLower()` убирает влияние регистра: `"Лес"` и `"сел"` содержат одни и те же буквы `е`, `л`, `с`.
3. Сортировка приводит символы к каноническому порядку: у анаграмм получаются одинаковые массивы.
4. Сравниваем массивы поэлементно (можно также `x.SequenceEqual(y)` из LINQ).
5. Для `мир` и `мура` длины 3 и 4 — результат `False` без сортировки.

## Трассировка и проверка
Для «Лес» и «сел»:

| Шаг | Слово 1 | Слово 2 |
|---|---|---|
| нижний регистр | лес | сел |
| символы | л, е, с | с, е, л |
| после сортировки | е, л, с | е, л, с |
| сравнение | совпало | → анаграммы |

Для «мир» и «мура»: длины 3 и 4 — результат `false` без сортировки.

## Результат
True для («Лес», «сел») и False для («мир», «мура»).

## Типичные ошибки
- Забыть приведение к одному регистру.
- Сравнить неотсортированные массивы.
- Не проверить равенство длин (экономит работу и исключает частные случаи).
- Игнорировать пробелы и знаки препинания там, где они должны игнорироваться по условию.
