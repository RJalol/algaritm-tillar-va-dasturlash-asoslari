# Разбор решения. L44 · Задание I · №1. Первая линия

## Условие
На форме нарисовать линию методом `Graphics.DrawLine` в обработчике `Paint` и показать её после изменения размера формы.

## Ожидаемый результат
Линия перерисовывается при каждом `Paint`.

## Разбор условия
**Дано:** форма Windows Forms.
**Требуется:** нарисовать линию в обработчике `Paint`; убедиться, что она перерисовывается при изменении размера.

## Теоретическая справка
**Графика GDI+.** Класс `Graphics` — «холст». Получить его правильно можно в обработчике события `Paint` (из `PaintEventArgs`). Рисование через `CreateGraphics()` временное: при перекрытии окна или сворачивании рисунок пропадает.

Основные объекты:

| Объект | Роль |
|---|---|
| `Pen` | перо (контур): цвет, толщина, стиль |
| `Brush` | кисть (заливка) |
| `Point`, `PointF` | точка |
| `Color` | цвет |

Система координат: начало (0,0) в левом верхнем углу, ось X вправо, ось Y **вниз**. `Pen` и `Brush` — неуправляемые ресурсы, их освобождают (`using`).

## Идея решения
Рисовать нужно в обработчике события `Paint`: система вызывает его заново каждый раз, когда область формы требуется перерисовать (изменение размера, сворачивание, перекрытие).

## Решение
```csharp
using System;
using System.Drawing;
using System.Windows.Forms;

public class Form1 : Form
{
    public Form1()
    {
        Text = "Линия";
        Size = new Size(400, 300);
        Paint += OnPaint;
        ResizeRedraw = true;          // перерисовывать при изменении размера
    }

    private void OnPaint(object sender, PaintEventArgs e)
    {
        using var pen = new Pen(Color.DarkBlue, 3);
        e.Graphics.DrawLine(pen, 20, 20, ClientSize.Width - 20, ClientSize.Height - 20);
    }
}
```

## Пошаговое объяснение
1. Объект `Graphics` приходит в `PaintEventArgs` и действителен только внутри обработчика.
2. `Pen` — перо (цвет и толщина). Оно хранит системные ресурсы, поэтому освобождается через `using`.
3. Координаты задаются в пикселях клиентской области; начало (0,0) — верхний левый угол.
4. Линия привязана к `ClientSize`, а `ResizeRedraw = true` заставляет форму вызывать `Paint` при каждом изменении размера — линия всегда идёт из угла в угол.

## Трассировка и проверка
| Событие | Что делает программа |
|---|---|
| первое отображение | `Paint` → линия нарисована |
| изменение размера (при `ResizeRedraw = true`) | `Paint` → линия перерисована в новых границах |
| перекрытие окна | `Paint` → линия восстановлена |

Если рисовать в `Load` через `CreateGraphics`, после перекрытия линия исчезнет.

## Результат
Диагональная линия от точки (20, 20) к противоположному углу сохраняется при любых изменениях размера окна.

## Типичные ошибки
- Рисовать через `CreateGraphics` вне `Paint`.
- Не освободить `Pen`.
- Забыть `ResizeRedraw` — после изменения размера остаются артефакты.
- Перепутать направление оси Y.
