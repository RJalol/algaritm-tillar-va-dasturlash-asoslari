# Разбор решения. L37 · Задание I · №1. Анонимный метод

## Условие
Записать анонимный метод с ключевым словом `delegate` для вычисления квадрата числа и присвоить его переменной `Func<int,int>`. Вызвать для 9.

## Ожидаемый результат
Результат 81.

## Разбор условия
**Дано:** потребность вычислить квадрат числа.
**Требуется:** записать анонимный метод ключевым словом `delegate`, присвоить `Func<int,int>`, вызвать для 9.

## Теоретическая справка
**Анонимный метод** — метод без имени, записанный в месте использования: `delegate (int x) { return x * x; }`. Он появился в C# 2.0 и позже был вытеснен лямбда-выражениями.

Отличия от лямбда-выражения:

| Признак | Анонимный метод | Лямбда |
|---|---|---|
| Запись | `delegate (int x) { … }` | `x => …` |
| Список параметров можно опустить | да | нет |
| Тело | только блок | выражение или блок |
| Вывод типов параметров | нет | да |

Оба вида **захватывают** внешние переменные (замыкания).

## Идея решения
Анонимный метод — метод без имени, записанный в месте использования ключевым словом `delegate`. Он присваивается переменной подходящего типа делегата.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        Func<int, int> square = delegate (int x)
        {
            return x * x;
        };

        Console.WriteLine(square(9));
    }
}
```

## Пошаговое объяснение
1. `Func<int,int>` — делегат, принимающий `int` и возвращающий `int`.
2. `delegate (int x) { return x * x; }` — анонимный метод: список параметров в скобках и тело в фигурных скобках.
3. Метод не имеет имени, поэтому вызвать его можно только через делегат `square`.
4. В современном коде вместо анонимных методов обычно пишут лямбда-выражения (`x => x * x`).

## Трассировка и проверка
| Шаг | Результат |
|---|---|
| `square = delegate (int x) { return x * x; }` | делегат создан |
| `square(9)` | 81 |

Тип `Func<int,int>` совместим с анонимным методом, имеющим один параметр `int` и возвращающим `int`.

## Результат
81

## Типичные ошибки
- Забыть `return` в теле анонимного метода.
- Пытаться вызвать анонимный метод по имени.
- Путать синтаксис `delegate` и `=>`.
- Захватить переменную цикла и получить неожиданное значение.
