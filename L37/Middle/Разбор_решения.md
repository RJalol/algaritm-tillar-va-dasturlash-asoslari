# Разбор решения. L37 · Задание II · №1. Лямбда в методах массива

## Условие
С помощью `Array.FindAll`, `Array.Exists`, `Array.Find` и лямбда-выражений найти в массиве {3, 8, 12, 5, 20}: все числа больше 7, наличие числа 12 и первое чётное.

## Ожидаемый результат
Найдены {8, 12, 20}, `True`, 8.

## Разбор условия
**Дано:** массив {3, 8, 12, 5, 20}.
**Требуется:** найти элементы больше 7, проверить наличие 12 и найти первый чётный методами `Array.FindAll`, `Exists`, `Find` с лямбда-выражениями.

## Теоретическая справка
Лямбда-выражение `x => x > 7` компилируется в делегат: для `Predicate<int>` (параметр → `bool`). Методы `Array.FindAll`, `Array.Exists`, `Array.Find` принимают `Predicate<T>`.

Различие методов:

| Метод | Возвращает |
|---|---|
| `FindAll` | массив всех подходящих |
| `Find` | первый подходящий (или `default(T)`) |
| `Exists` | `bool` |
| `FindIndex` | индекс первого или −1 |

Для `int` значение `default` равно 0 — поэтому `Find` не отличает «не найдено» от найденного нуля; для таких случаев предпочтительнее `FindIndex`.

## Идея решения
Методы класса `Array` принимают делегаты: `FindAll` — `Predicate<T>`, `Exists` — `Predicate<T>`, `Find` — `Predicate<T>`. Лямбда-выражение превращается в нужный делегат автоматически.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        int[] a = { 3, 8, 12, 5, 20 };

        int[] big = Array.FindAll(a, x => x > 7);
        Console.WriteLine(string.Join(", ", big));          // 8, 12, 20

        Console.WriteLine(Array.Exists(a, x => x == 12));   // True

        Console.WriteLine(Array.Find(a, x => x % 2 == 0));  // 8
    }
}
```

## Пошаговое объяснение
1. `Array.FindAll(a, x => x > 7)` возвращает новый массив всех элементов, для которых условие истинно.
2. `Array.Exists` отвечает, есть ли хотя бы один подходящий элемент.
3. `Array.Find` возвращает первый подходящий элемент (для int при отсутствии — 0).
4. Лямбда `x => x % 2 == 0` проверяет чётность; первое чётное число в массиве — 8.

## Трассировка и проверка
| Вызов | Результат |
|---|---|
| `FindAll(a, x => x > 7)` | {8, 12, 20} |
| `Exists(a, x => x == 12)` | True |
| `Find(a, x => x % 2 == 0)` | 8 |

Порядок элементов сохраняется; первое чётное — 8 (3 нечётное).

## Результат
8, 12, 20 / True / 8

## Типичные ошибки
- Считать, что `Find` бросает исключение при отсутствии — он возвращает значение по умолчанию.
- Путать `Predicate<T>` и `Func<T,bool>` (они совместимы по сигнатуре, но разные типы).
- Изменять массив внутри предиката.
- Забывать, что `FindAll` создаёт новый массив.
