# Разбор решения. L37 · Задание II · №1. Лямбда в методах массива

## Условие
С помощью `Array.FindAll`, `Array.Exists`, `Array.Find` и лямбда-выражений найти в массиве {3, 8, 12, 5, 20}: все числа больше 7, наличие числа 12 и первое чётное.

## Ожидаемый результат
Найдены {8, 12, 20}, `True`, 8.

## Идея решения
Методы класса `Array` принимают делегаты: `FindAll` — `Predicate<T>`, `Exists` — `Predicate<T>`, `Find` — `Predicate<T>`. Лямбда-выражение превращается в нужный делегат автоматически.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        int[] a = { 3, 8, 12, 5, 20 };

        int[] big = Array.FindAll(a, x => x > 7);
        Console.WriteLine(string.Join(", ", big));          // 8, 12, 20

        Console.WriteLine(Array.Exists(a, x => x == 12));   // True

        Console.WriteLine(Array.Find(a, x => x % 2 == 0));  // 8
    }
}
```

## Пошаговое объяснение
1. `Array.FindAll(a, x => x > 7)` возвращает новый массив всех элементов, для которых условие истинно.
2. `Array.Exists` отвечает, есть ли хотя бы один подходящий элемент.
3. `Array.Find` возвращает первый подходящий элемент (для int при отсутствии — 0).
4. Лямбда `x => x % 2 == 0` проверяет чётность; первое чётное число в массиве — 8.

## Результат
8, 12, 20 / True / 8
