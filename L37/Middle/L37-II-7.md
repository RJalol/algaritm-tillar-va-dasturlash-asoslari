# L37 · Задание II · №7. Лямбда и тип делегата

**Тема:** Л37 — Анонимные методы. Лямбда-выражения. Лямбда-выражения с несколькими параметрами и без параметров

## Условие
Выяснить, какой тип выводит компилятор для `var f = (int x) => x + 1;` и что произойдёт при `var g = x => x + 1;`.

## Ожидаемый результат
В первом случае выводится `Func<int,int>`; второй вариант не компилируется (`CS8917`): без явного типа параметра компилятор не может вывести тип делегата.
