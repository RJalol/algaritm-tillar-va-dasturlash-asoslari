# Разбор решения. L37 · Задание III · №1. Собственный Where и Select

## Условие
Реализовать методы расширения `MyWhere` и `MySelect` для `IEnumerable<T>` с лямбда-выражениями. Применить к последовательности чисел и строк.

## Ожидаемый результат
Результат совпадает с LINQ-эквивалентами для тестовых данных.

## Идея решения
Метод расширения `MyWhere` для `IEnumerable<T>` принимает `Func<T,bool>`; `MySelect` — `Func<T,R>`. Реализуем их через итераторы `yield return`, чтобы вычисление было ленивым, как в LINQ.

## Решение
```csharp
using System;
using System.Collections.Generic;

static class MyLinq
{
    public static IEnumerable<T> MyWhere<T>(this IEnumerable<T> source, Func<T, bool> predicate)
    {
        foreach (T item in source)
            if (predicate(item))
                yield return item;
    }

    public static IEnumerable<R> MySelect<T, R>(this IEnumerable<T> source, Func<T, R> selector)
    {
        foreach (T item in source)
            yield return selector(item);
    }
}

class Program
{
    static void Main()
    {
        int[] numbers = { 1, 2, 3, 4, 5, 6 };
        var squares = numbers.MyWhere(n => n % 2 == 0).MySelect(n => n * n);
        Console.WriteLine(string.Join(", ", squares));       // 4, 16, 36

        string[] words = { "кот", "слон", "муравей" };
        var lengths = words.MySelect(w => w.Length);
        Console.WriteLine(string.Join(", ", lengths));        // 3, 4, 7
    }
}
```

## Пошаговое объяснение
1. Метод расширения объявляется статическим методом статического класса с первым параметром `this`.
2. Оператор `yield return` превращает метод в итератор: элементы создаются по одному, по мере перебора.
3. Благодаря ленивости цепочка `MyWhere(...).MySelect(...)` не создаёт промежуточных коллекций.
4. Обобщённые параметры `T` и `R` позволяют применять методы к последовательностям любых типов — чисел и строк.
5. Результаты совпадают с эквивалентами LINQ `Where` и `Select`.

## Результат
4, 16, 36 и 3, 4, 7
