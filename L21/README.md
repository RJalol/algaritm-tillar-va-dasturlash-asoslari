# L21. Пространство имён. Объявление пространства имён, классы в другом файле и связь с проектом. Псевдонимы

Практические задания к теме №21 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
L21/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
└── Advanced/   10 заданий  (Задание III)
```

## Формат задания

Каждый файл `L21-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. Готовые решения не приводятся.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.
