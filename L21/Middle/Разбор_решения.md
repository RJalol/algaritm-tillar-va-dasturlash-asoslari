# Разбор решения. L21 · Задание II · №1. Два одноимённых класса

## Условие
Объявить два пространства имён — `Banking` и `Geometry` — и поместить в каждое класс с именем `Account` и `Point` соответственно так, чтобы в обоих пространствах имён оказался класс с общим именем `Record`, но с разным набором полей. Создать по объекту каждого типа и вывести их описания, обращаясь по полным именам. Подтвердить выводом, что типы различны.

## Ожидаемый результат
Оба объекта созданы и выведены; сравнение типов даёт `True` для их различия, а полные имена различаются пространствами имён.

## Идея решения
Одноимённые типы в разных пространствах имён не конфликтуют: их различают по полным именам. Для сравнения типов используем `GetType()`.

## Решение
```csharp
using System;

namespace Banking
{
    class Record
    {
        public string Owner = "Азиз";
        public decimal Balance = 1500;
        public override string ToString() => "Banking.Record: " + Owner + ", " + Balance;
    }
}

namespace Geometry
{
    class Record
    {
        public double X = 3;
        public double Y = 4;
        public override string ToString() => "Geometry.Record: (" + X + "; " + Y + ")";
    }
}

class Program
{
    static void Main()
    {
        Banking.Record a = new Banking.Record();
        Geometry.Record g = new Geometry.Record();

        Console.WriteLine(a);
        Console.WriteLine(g);
        Console.WriteLine(a.GetType() != g.GetType());
        Console.WriteLine(a.GetType().FullName);
        Console.WriteLine(g.GetType().FullName);
    }
}
```

## Пошаговое объяснение
1. В обоих пространствах объявлен класс с одним и тем же простым именем `Record`, но разным набором полей.
2. Обращаясь по полным именам (`Banking.Record`, `Geometry.Record`), мы однозначно указываем нужный тип.
3. Сравнение `GetType()` объектов даёт «не равны» — это разные типы.
4. Полные имена отличаются префиксом пространства имён.

## Результат
Выведены оба описания; сравнение типов (!=) даёт True; полные имена — Banking.Record и Geometry.Record.
