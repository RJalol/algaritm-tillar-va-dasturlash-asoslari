# L21 · Задание II · №3. Область действия директивы

**Тема:** Л21 — Пространство имён. Объявление пространства имён, классы в другом файле и связь с проектом. Псевдонимы

## Условие
В одном файле объявить два блочных пространства имён. В первом разместить директиву `using System. Text;` внутри блока и класс, собирающий строку через `String``Builder`. Во втором — класс, решающий ту же задачу, но без этой директивы. Вызвать оба класса из `Main` и получить одинаковый результат.

## Ожидаемый результат
Обе строки собраны одинаково; во втором пространстве имён тип записан полным именем, поскольку директива первого блока туда не распространяется.
