# Разбор решения. L21 · Задание I · №1. Первое пространство имён

## Условие
Объявить пространство имён `Shapes` и поместить в него класс с полем-размером и методом, вычисляющим площадь. В классе `Program`, объявленном вне этого пространства имён, создать объект по полному имени и вывести площадь. Вывести также полное имя типа объекта и полное имя типа `Program`.

## Ожидаемый результат
Площадь вычислена; полное имя типа выведено в виде `Shapes.<имя класса>`, полное имя `Program` совпадает с простым, поскольку класс находится в глобальном пространстве имён.

## Идея решения
Пространство имён группирует типы и даёт им полные имена вида `Пространство.Класс`. Класс `Program` вне пространства имён находится в глобальном пространстве, и его полное имя совпадает с простым.

## Решение
```csharp
using System;

namespace Shapes
{
    class Square
    {
        public double Size;

        public Square(double size) { Size = size; }

        public double Area() { return Size * Size; }
    }
}

class Program
{
    static void Main()
    {
        Shapes.Square sq = new Shapes.Square(5);
        Console.WriteLine(sq.Area());
        Console.WriteLine(sq.GetType().FullName);
        Console.WriteLine(typeof(Program).FullName);
    }
}
```

## Пошаговое объяснение
1. Объявляем `namespace Shapes` и внутри него класс `Square` с полем размера и методом `Area`.
2. `Program` объявлен вне пространства имён, поэтому к `Square` обращаемся по полному имени `Shapes.Square` (директива `using` не использована).
3. `GetType().FullName` возвращает полное имя типа объекта — `Shapes.Square`.
4. `typeof(Program).FullName` — просто `Program`, так как класс в глобальном пространстве имён.

## Результат
25, Shapes.Square, Program
