# Разбор решения. L21 · Задание I · №1. Первое пространство имён

## Условие
Объявить пространство имён `Shapes` и поместить в него класс с полем-размером и методом, вычисляющим площадь. В классе `Program`, объявленном вне этого пространства имён, создать объект по полному имени и вывести площадь. Вывести также полное имя типа объекта и полное имя типа `Program`.

## Ожидаемый результат
Площадь вычислена; полное имя типа выведено в виде `Shapes.<имя класса>`, полное имя `Program` совпадает с простым, поскольку класс находится в глобальном пространстве имён.

## Разбор условия
**Дано:** класс «квадрат» в пространстве имён `Shapes` и класс `Program` вне него.
**Требуется:** создать объект по полному имени, вывести площадь, полное имя типа объекта и полное имя `Program`.

## Теоретическая справка
**Пространство имён** (`namespace`) группирует типы и предотвращает конфликты имён. **Полное имя** типа состоит из пространства имён и имени: `Shapes.Square`.

Доступ к типу из другого пространства: по полному имени либо директивой `using Shapes;` (тогда можно писать просто `Square`). Тип без `namespace` находится в **глобальном** пространстве; его полное имя совпадает с простым.

`GetType().FullName` возвращает полное имя типа объекта во время выполнения, `typeof(T).FullName` — полное имя типа по его обозначению.

## Идея решения
Пространство имён группирует типы и даёт им полные имена вида `Пространство.Класс`. Класс `Program` вне пространства имён находится в глобальном пространстве, и его полное имя совпадает с простым.

## Решение
```csharp
using System;

namespace Shapes
{
    class Square
    {
        public double Size;

        public Square(double size) { Size = size; }

        public double Area() { return Size * Size; }
    }
}

class Program
{
    static void Main()
    {
        Shapes.Square sq = new Shapes.Square(5);
        Console.WriteLine(sq.Area());
        Console.WriteLine(sq.GetType().FullName);
        Console.WriteLine(typeof(Program).FullName);
    }
}
```

## Пошаговое объяснение
1. Объявляем `namespace Shapes` и внутри него класс `Square` с полем размера и методом `Area`.
2. `Program` объявлен вне пространства имён, поэтому к `Square` обращаемся по полному имени `Shapes.Square` (директива `using` не использована).
3. `GetType().FullName` возвращает полное имя типа объекта — `Shapes.Square`.
4. `typeof(Program).FullName` — просто `Program`, так как класс в глобальном пространстве имён.

## Трассировка и проверка
| Выражение | Результат |
|---|---|
| `new Shapes.Square(5).Area()` | 25 |
| `sq.GetType().FullName` | Shapes.Square |
| `typeof(Program).FullName` | Program |

Иерархия вложенных пространств имён записывается через точку: `namespace Academy.Models` — то же, что `namespace Academy { namespace Models { } }`.

## Результат
25, Shapes.Square, Program

## Типичные ошибки
- Обратиться к типу из другого пространства без `using` и без полного имени (`CS0246`).
- Поместить `using` внутрь тела метода — директива пишется в начале файла (или внутри `namespace`).
- Путать пространство имён и сборку: одно пространство может находиться в нескольких сборках.
- Удивляться отсутствию префикса у `Program` — он лежит в глобальном пространстве.
