# L21 · Задание III · №7. Стоимость директивы `using static`

**Тема:** Л21 — Пространство имён. Объявление пространства имён, классы в другом файле и связь с проектом. Псевдонимы

## Условие
Написать вычислительный класс, использующий не менее восьми членов типа `System``.``Math`, в двух вариантах: с `using static` и без него. Затем добавить в файл собственный статический метод с именем, совпадающим с именем одного из импортированных членов, и определить, какой из них будет вызван. Сформулировать правило, когда `using static` уместна, а когда вредна.

## Ожидаемый результат
Оба варианта дают одинаковые числовые результаты; установлено, какой метод выбирается при совпадении имён, и сформулировано правило применения директивы.
