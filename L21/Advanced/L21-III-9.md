# L21 · Задание III · №9. Каталог типов проекта

**Тема:** Л21 — Пространство имён. Объявление пространства имён, классы в другом файле и связь с проектом. Псевдонимы

## Условие
Для проекта III.1 написать статический класс, выводящий каталог всех его типов: полное имя, простое имя и имя пространства имён, отсортированный по пространству имён, а внутри — по простому имени. Список типов задать массивом объектов `Type`, полученных операцией `typeof`. Дополнительно вывести число типов в каждом пространстве имён.

## Ожидаемый результат
Каталог выведен в заданном порядке; для каждого пространства имён указано число входящих в него типов, а сумма совпадает с общим числом типов проекта.
