# L21 · Задание III · №3. Диагностика чужого проекта

**Тема:** Л21 — Пространство имён. Объявление пространства имён, классы в другом файле и связь с проектом. Псевдонимы

## Условие
Подготовить проект из четырёх файлов, содержащий не менее пяти внесённых ошибок из числа изученных: неразрешённое имя, неоднозначная ссылка, нарушение порядка директив, нарушение ограничений формы уровня файла, псевдоним в правой части директивы. Составить таблицу «файл — строка — код ошибки — причина — исправление» и привести проект в рабочее состояние.

## Ожидаемый результат
Таблица содержит не менее пяти строк с фактически полученными кодами ошибок; исправленный проект компилируется и выполняется.
