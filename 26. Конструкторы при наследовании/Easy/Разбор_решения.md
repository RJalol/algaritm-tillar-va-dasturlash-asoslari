# Разбор решения. L26 · Задание I · №1. Первый конструктор производного класса

## Условие
Объявить базовый класс «сотрудник» с конструктором, принимающим имя и год приёма на работу, и производный класс «преподаватель», добавляющий кафедру. Объявить конструктор производного класса, передающий два аргумента базовому. Создать объект и вывести все три значения. Из каждого конструктора вывести сообщение с его именем.

## Ожидаемый результат
Сообщение конструктора базового класса выведено **раньше** сообщения конструктора производного; все три значения заданы верно.

## Разбор условия
**Дано:** классы «сотрудник» и «преподаватель».
**Требуется:** конструктор базового принимает имя и год; конструктор производного передаёт их базовому и добавляет кафедру; вывести сообщения конструкторов.

## Теоретическая справка
**Цепочка конструкторов.** При создании объекта производного класса сначала выполняется конструктор базового класса, затем — производного. Выбор конструктора базового класса задаёт `: base(аргументы)`. Если `base(...)` не указан, вызывается конструктор базового класса без параметров — его отсутствие вызывает ошибку `CS7036`.

Порядок гарантирует, что в момент выполнения тела конструктора производного класса базовая часть объекта уже полностью построена.

## Идея решения
При создании объекта производного класса сначала выполняется конструктор базового, затем производного. Аргументы базе передаются через `: base(...)`.

## Решение
```csharp
using System;

class Employee
{
    public string Name;
    public int HireYear;

    public Employee(string name, int hireYear)
    {
        Name = name; HireYear = hireYear;
        Console.WriteLine("Конструктор Employee");
    }
}

class Teacher : Employee
{
    public string Department;

    public Teacher(string name, int hireYear, string department)
        : base(name, hireYear)
    {
        Department = department;
        Console.WriteLine("Конструктор Teacher");
    }
}

class Program
{
    static void Main()
    {
        Teacher t = new Teacher("Дилноза", 2010, "Информатика");
        Console.WriteLine(t.Name + ", " + t.HireYear + ", " + t.Department);
    }
}
```

## Пошаговое объяснение
1. `: base(name, hireYear)` вызывает конструктор базового класса с двумя аргументами.
2. Тело конструктора `Teacher` начинает выполняться только после завершения конструктора `Employee`.
3. Поэтому «Конструктор Employee» печатается раньше «Конструктор Teacher».
4. Три значения (имя, год, кафедра) заданы корректно.

## Трассировка и проверка
Создание `new Teacher("Дилноза", 2010, "Информатика")`:

| Шаг | Что выполняется |
|--:|---|
| 1 | вызывается `Teacher(...)`, сразу передаёт управление `base(name, hireYear)` |
| 2 | выполняется тело `Employee(...)`: «Конструктор Employee» |
| 3 | выполняется тело `Teacher(...)`: «Конструктор Teacher» |

Вывод значений: «Дилноза, 2010, Информатика».

## Результат
Конструктор Employee / Конструктор Teacher / Дилноза, 2010, Информатика

## Типичные ошибки
- Не указать `base(...)` при отсутствии конструктора без параметров.
- Ожидать, что конструктор производного выполнится раньше.
- Присваивать поля базового класса в конструкторе производного вместо передачи через `base`.
- Вызывать виртуальные методы из конструктора базового класса.
