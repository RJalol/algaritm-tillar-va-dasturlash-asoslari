# Разбор решения. L26 · Задание III · №1. Иерархия учебных изданий

## Условие
Разработать иерархию из пяти классов: «издание» — «книга», «периодическое издание»; «книга» — «учебник»; «периодическое издание» — «журнал». Каждый класс объявляет собственные поля только для чтения и конструктор, проверяющий свои аргументы и передающий остальные базовому. Классы разместить по файлам согласно теме №21. Программа создаёт не менее восьми объектов и печатает каталог.

## Ожидаемый результат
Каталог выведен; каждое поле присвоено в конструкторе своего класса; некорректный аргумент любого уровня отвергается исключением из соответствующего конструктора.

## Разбор условия
**Дано:** иерархия из пяти классов изданий.
**Требуется:** каждый класс объявляет собственные поля только для чтения и конструктор, проверяющий свои аргументы и передающий остальные базовому; создать не менее восьми объектов и напечатать каталог.

## Теоретическая справка
**Принцип «каждый проверяет своё».** Конструктор класса отвечает за допустимость собственных аргументов, а проверку общих делегирует базовому через `base(...)`. Так проверка не дублируется, а объект никогда не оказывается в некорректном состоянии.

**Поля `readonly`** присваиваются только в конструкторе своего класса — состояние объекта фиксируется при создании.

Исключения при некорректных аргументах — `ArgumentException`, `ArgumentOutOfRangeException` с указанием `paramName` (оператор `nameof`).

## Идея решения
Каждый класс проверяет *свои* аргументы и передаёт остальные базовому конструктору; поля — `readonly` и задаются в конструкторе своего класса. Классы для краткости показаны в одном листинге (в проекте — по файлам).

## Решение
```csharp
using System;
using System.Collections.Generic;

namespace Library
{
    public class Publication
    {
        public readonly string Title;
        public readonly int Year;
        public Publication(string title, int year)
        {
            if (string.IsNullOrWhiteSpace(title)) throw new ArgumentException("Пустое название", nameof(title));
            if (year < 1450 || year > 2026) throw new ArgumentOutOfRangeException(nameof(year));
            Title = title; Year = year;
        }
        public override string ToString() => $"{Title} ({Year})";
    }

    public class Book : Publication
    {
        public readonly string Author;
        public Book(string title, int year, string author) : base(title, year)
        {
            if (string.IsNullOrWhiteSpace(author)) throw new ArgumentException("Нет автора", nameof(author));
            Author = author;
        }
        public override string ToString() => Author + ". " + base.ToString();
    }

    public class Textbook : Book
    {
        public readonly string Subject;
        public Textbook(string title, int year, string author, string subject) : base(title, year, author)
        {
            if (string.IsNullOrWhiteSpace(subject)) throw new ArgumentException("Нет предмета", nameof(subject));
            Subject = subject;
        }
        public override string ToString() => base.ToString() + " [учебник: " + Subject + "]";
    }

    public class Periodical : Publication
    {
        public readonly int Issue;
        public Periodical(string title, int year, int issue) : base(title, year)
        {
            if (issue <= 0) throw new ArgumentOutOfRangeException(nameof(issue));
            Issue = issue;
        }
        public override string ToString() => base.ToString() + ", выпуск " + Issue;
    }

    public class Magazine : Periodical
    {
        public readonly string Topic;
        public Magazine(string title, int year, int issue, string topic) : base(title, year, issue)
        {
            if (string.IsNullOrWhiteSpace(topic)) throw new ArgumentException("Нет темы", nameof(topic));
            Topic = topic;
        }
        public override string ToString() => base.ToString() + " - " + Topic;
    }

    class Program
    {
        static void Main()
        {
            var catalog = new List<Publication>
            {
                new Book("Алгоритмы", 2019, "Кормен"), new Book("Чистый код", 2008, "Мартин"),
                new Textbook("Основы C#", 2021, "Каримов", "программирование"),
                new Textbook("Дискретная математика", 2018, "Рахимов", "математика"),
                new Periodical("Вестник", 2024, 3), new Periodical("Новости науки", 2023, 12),
                new Magazine("Наука и жизнь", 2025, 5, "физика"), new Magazine("Техника", 2022, 7, "электроника")
            };
            foreach (Publication p in catalog) Console.WriteLine(p);

            try { new Textbook("Ошибка", 2020, "A", ""); }
            catch (ArgumentException e) { Console.WriteLine("Отвергнуто: " + e.ParamName); }
        }
    }
}
```

## Пошаговое объяснение
1. Иерархия: Publication → Book → Textbook; Publication → Periodical → Magazine (пять классов плюс базовый).
2. Каждый конструктор проверяет только собственные аргументы (`author`, `subject`, `issue`, `topic`) и передаёт общие вверх через `base(...)`.
3. Поля `readonly` присваиваются в конструкторе того класса, где объявлены.
4. Некорректный аргумент любого уровня приводит к исключению именно из конструктора соответствующего класса (например, пустой предмет — из `Textbook`).
5. В `Main` создаются восемь объектов и печатается каталог.

## Трассировка и проверка
Создание `new Textbook("Основы C#", 2021, "Каримов", "программирование")`:

| Конструктор | Проверяет | Передаёт вверх |
|---|---|---|
| Textbook | предмет | название, год, автор |
| Book | автор | название, год |
| Publication | название, год | — |

Попытка `new Textbook("Ошибка", 2020, "A", "")` отвергается исключением из конструктора `Textbook` (пустой предмет); `ParamName` = `subject`.

## Результат
Каталог из восьми изданий; попытка создать учебник с пустым предметом отвергается исключением (Отвергнуто: subject).

## Типичные ошибки
- Проверять в производном классе то, за что отвечает базовый (дублирование).
- Присваивать `readonly`-поле вне конструктора.
- Допускать создание «полуготового» объекта.
- Не указывать имя параметра в исключении.
