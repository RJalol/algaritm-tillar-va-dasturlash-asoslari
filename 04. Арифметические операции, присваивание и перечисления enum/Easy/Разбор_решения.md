# Разбор решения. L04-ALG-001. Пять операций над одной парой чисел

## Условие
Написать программу, которая объявляет две целочисленные переменные со значениями 23 и 4 и выводит результаты всех пяти арифметических операций над ними, каждый на отдельной строке, в порядке: сумма, разность, произведение, частное, остаток.

## Ожидаемый результат
Пять строк со значениями `27`, `19`, `92`, `5`, `3`; частное получено целочисленным делением.

## Разбор условия
**Дано:** два целых числа 23 и 4.
**Требуется:** вывести сумму, разность, произведение, частное и остаток в указанном порядке, каждое — на отдельной строке.
**Особенность:** частное и остаток — результаты целочисленного деления.

## Теоретическая справка
Арифметические операции C#: `+`, `-`, `*`, `/`, `%`.

- Если **оба** операнда целые, операция `/` — **целочисленное деление**: дробная часть отбрасывается (усечение к нулю). 23 / 4 = 5, а не 5,75.
- Операция `%` возвращает остаток. Для неотрицательных чисел верно тождество `a == (a / b) * b + a % b`: 23 = 5·4 + 3.
- Если хотя бы один операнд вещественный, деление вещественное: `23.0 / 4` даёт 5,75.

Знак остатка совпадает со знаком делимого: `-23 % 4` равно `-3`.

## Идея решения
Для двух целых чисел 23 и 4 вычисляем сумму, разность, произведение, целочисленное частное и остаток от деления.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        int a = 23;
        int b = 4;

        Console.WriteLine(a + b);
        Console.WriteLine(a - b);
        Console.WriteLine(a * b);
        Console.WriteLine(a / b);
        Console.WriteLine(a % b);
    }
}
```

## Пошаговое объяснение
1. `a + b = 27`, `a - b = 19`, `a * b = 92`.
2. Оба операнда типа `int`, поэтому `/` выполняет целочисленное деление: 23 / 4 = 5 (дробная часть отбрасывается).
3. Оператор `%` возвращает остаток: 23 − 4·5 = 3.

## Трассировка и проверка
Выполнение:

| Выражение | Вычисление | Результат |
|---|---|---:|
| `a + b` | 23 + 4 | 27 |
| `a - b` | 23 − 4 | 19 |
| `a * b` | 23 · 4 | 92 |
| `a / b` | ⌊23 / 4⌋ | 5 |
| `a % b` | 23 − 5·4 | 3 |

Самопроверка: `5 * 4 + 3 = 23` — частное и остаток согласованы.

## Результат
Пять строк: 27, 19, 92, 5, 3.

## Типичные ошибки
- Ожидать `5,75` от выражения `23 / 4` для целых операндов.
- Перепутать `%` (остаток) с процентами.
- Менять порядок операций вывода относительно условия.
- Не учесть деление на ноль: `a / 0` для целых вызывает `DivideByZeroException`.

## Задания для закрепления
- Выполнить те же операции для чисел −23 и 4 и объяснить знак остатка.
- Вычислить частное как вещественное число, не меняя типы переменных.
- Найти последнюю цифру числа 12345 с помощью `%`.
