# Разбор решения. L49 · Задание II · №1. Агрегаты по объектам

## Условие
По списку студентов найти средний, минимальный и максимальный балл и количество сдавших.

## Ожидаемый результат
Значения соответствуют данным.

## Разбор условия
**Дано:** список студентов.
**Требуется:** найти средний, минимальный, максимальный балл и число сдавших (≥ 60).

## Теоретическая справка
Агрегаты с **селектором** принимают лямбда-выражение, указывающее, какое значение брать из объекта: `students.Average(s => s.Score)`.

Для вещественных результатов используют форматирование (`:F2`). Условие внутри `Count(s => s.Score >= 60)` избавляет от отдельного `Where`.

Выбор между `Max(s => s.Score)` и `MaxBy(s => s.Score)` (в .NET 6+): первый возвращает значение, второй — сам объект.

## Идея решения
К списку объектов применяем агрегаты с селекторами: `Average(s => s.Score)`, `Min`, `Max`, `Count(условие)`.

## Решение
```csharp
using System;
using System.Collections.Generic;
using System.Linq;

record Student(string Name, string Group, int Score);

class Program
{
    static void Main()
    {
        var students = new List<Student>
        {
            new("Азиз", "ТТ-11", 87), new("Дилноза", "ТТ-11", 92),
            new("Рустам", "ТТ-12", 78), new("Малика", "ТТ-12", 95), new("Тимур", "ТТ-13", 55)
        };

        Console.WriteLine($"Средний балл: {students.Average(s => s.Score):F2}");
        Console.WriteLine($"Минимум: {students.Min(s => s.Score)}");
        Console.WriteLine($"Максимум: {students.Max(s => s.Score)}");
        Console.WriteLine($"Сдали (>= 60): {students.Count(s => s.Score >= 60)}");
    }
}
```

## Пошаговое объяснение
1. Селектор `s => s.Score` указывает, по какому полю считать агрегат.
2. Сумма баллов 87+92+78+95+55 = 407; среднее 407/5 = 81,4.
3. `Count(s => s.Score >= 60)` считает только удовлетворяющих условию — четыре студента.
4. Для пустого списка `Average`, `Min`, `Max` выбросят `InvalidOperationException`; перед вызовом следует проверить `Any()`.

## Трассировка и проверка
Баллы {87, 92, 78, 95, 55}:

| Агрегат | Результат |
|---|--:|
| `Average` | 81,40 |
| `Min` | 55 |
| `Max` | 95 |
| `Count(≥ 60)` | 4 |

Сумма: 407; 407 / 5 = 81,4.

## Результат
Средний балл: 81,40 / Минимум: 55 / Максимум: 95 / Сдали (>= 60): 4

## Типичные ошибки
- Вызывать агрегаты для пустого списка без проверки.
- Путать `Max` (значение) и `MaxBy` (объект).
- Использовать целочисленное деление вручную вместо `Average`.
- Многократно перебирать источник с дорогим вычислением.
