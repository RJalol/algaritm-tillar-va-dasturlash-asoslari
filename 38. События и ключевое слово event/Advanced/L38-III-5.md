# L38 · Задание III · №5. Событие с отменой

**Тема:** Л38 — События и управление ими. Ключевое слово event

## Условие
Реализовать событие `Closing` с данными `CancelEventArgs`: подписчик может отменить закрытие.

## Ожидаемый результат
Если хотя бы один подписчик отменил операцию, закрытие не происходит.
