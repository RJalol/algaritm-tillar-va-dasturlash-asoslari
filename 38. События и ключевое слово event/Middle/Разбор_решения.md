# Разбор решения. L38 · Задание II · №1. Собственные данные события

## Условие
Создать класс `TemperatureEventArgs : EventArgs` с полем температуры и событие `EventHandler<TemperatureEventArgs>` в классе «датчик». Подписчик выводит значение.

## Ожидаемый результат
Обработчик получает температуру в `e.Value`.

## Разбор условия
**Дано:** класс «датчик» и измерения температуры.
**Требуется:** собственный класс данных события, событие `EventHandler<TemperatureEventArgs>`, подписчик выводит значение.

## Теоретическая справка
**Данные события** передаются в объекте, унаследованном от `EventArgs`. Обобщённый делегат `EventHandler<TEventArgs>` избавляет от объявления собственных типов делегатов.

Стандартный шаблон:

1. класс `XxxEventArgs : EventArgs` с неизменяемыми свойствами;
2. событие `public event EventHandler<XxxEventArgs> Xxx;`
3. защищённый виртуальный метод `OnXxx(XxxEventArgs e)` вызывает событие;
4. подписчики получают `sender` (источник) и `e` (данные).

## Идея решения
Для передачи данных о событии создают класс-наследник `EventArgs` и используют обобщённый делегат `EventHandler<TEventArgs>`.

## Решение
```csharp
using System;

class TemperatureEventArgs : EventArgs
{
    public double Value { get; }
    public TemperatureEventArgs(double value) { Value = value; }
}

class Sensor
{
    public event EventHandler<TemperatureEventArgs> TemperatureChanged;

    public void Measure(double value)
    {
        TemperatureChanged?.Invoke(this, new TemperatureEventArgs(value));
    }
}

class Program
{
    static void Main()
    {
        Sensor sensor = new Sensor();
        sensor.TemperatureChanged += (s, e) =>
            Console.WriteLine("Температура: " + e.Value + " °C");

        sensor.Measure(21.5);
        sensor.Measure(23.0);
    }
}
```

## Пошаговое объяснение
1. `TemperatureEventArgs` хранит значение измерения в свойстве `Value`.
2. Событие типа `EventHandler<TemperatureEventArgs>` передаёт подписчикам источник (`sender`) и данные (`e`).
3. Издатель создаёт объект аргументов и вызывает событие.
4. Подписчик — лямбда-выражение; значение читается как `e.Value`.

## Трассировка и проверка
| Вызов | Вывод |
|---|---|
| `sensor.Measure(21.5)` | Температура: 21,5 °C |
| `sensor.Measure(23.0)` | Температура: 23 °C |

Подписчик не имеет доступа к внутреннему состоянию датчика — только к данным события.

## Результат
Температура: 21,5 °C / Температура: 23 °C

## Типичные ошибки
- Передавать данные через поля издателя (нарушается инкапсуляция).
- Делать `EventArgs` изменяемым и давать подписчикам портить данные других подписчиков.
- Забыть проверку на `null`.
- Использовать нестандартную сигнатуру делегата.
