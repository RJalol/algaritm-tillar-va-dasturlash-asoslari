# L03-ALG-008. Разделитель разрядов в длинных числах

**Тема:** Л3 — Алфавит и ключевые слова языка C#. Идентификаторы, литералы, переменные, константы и типы данных

## Условие
Написать программу, объявляющую переменную типа `long` для численности населения (значение не менее десяти миллионов) и переменную типа `int` для расстояния в метрах (значение не менее миллиона). Оба литерала записать с разделителем разрядов `_` для удобства чтения. Вывести оба значения.

## Ожидаемый результат
Два числа выведены без символов подчёркивания — разделитель существует только в исходном коде и на значение не влияет.
