# L03-ALG-012. Приведение имён к соглашениям

**Тема:** Л3 — Алфавит и ключевые слова языка C#. Идентификаторы, литералы, переменные, константы и типы данных

## Условие
Дан фрагмент объявлений:

```
int STUDENT_COUNT = 30;
double avg_mark = 4.5;
string f = "Информатика";
const int max = 100;
```

Все четыре объявления компилируются, но нарушают принятые в .NET соглашения об именовании. Переписать их с исправленными именами и для каждого указать, какое именно соглашение было нарушено.

## Ожидаемый результат
Четыре исправленных объявления; для каждого назван нарушенный принцип (стиль `camelCase` для локальных переменных, `PascalCase` для констант, содержательность имени).
