# Разбор решения. L03-ALG-006. Целочисленные типы и их предельные значения

## Условие
Написать программу, которая объявляет по одной переменной типов `byte`, `short`, `int` и `long` и инициализирует каждую её максимальным значением, взятым из таблицы диапазонов лекции (записать числа литералами вручную, не обращаясь к свойствам типа). Вывести все четыре значения. Для типа `long` использовать суффикс `L`.

## Ожидаемый результат
Четыре строки: `255`, `32767`, `2147483647`, `9223372036854775807`; программа компилируется без ошибок, что подтверждает правильность выбранных литералов.

## Разбор условия
**Дано:** четыре целочисленных типа — `byte`, `short`, `int`, `long`.
**Требуется:** записать в переменные максимальные значения литералами (не через свойства типа) и вывести.
**Особенность:** литерал `long` нужно записывать с суффиксом `L`.

## Теоретическая справка
Целочисленные типы отличаются размером и знаковостью:

| Тип | Размер | Диапазон | Максимум |
|---|---:|---|---|
| `byte` | 8 бит | 0 … 255 | 255 |
| `short` | 16 бит | −32 768 … 32 767 | 32767 |
| `int` | 32 бита | −2³¹ … 2³¹−1 | 2147483647 |
| `long` | 64 бита | −2⁶³ … 2⁶³−1 | 9223372036854775807 |

**Литерал** — запись значения прямо в тексте программы. Литерал без суффикса, не помещающийся в `int`, получает тип `long` автоматически, однако суффикс `L` (лучше заглавный, чтобы не путать с единицей) делает намерение явным. Если значение выходит за диапазон типа переменной, компилятор сообщает об ошибке на этапе компиляции.

## Идея решения
Максимумы целочисленных типов: byte — 255, short — 32767, int — 2147483647, long — 9223372036854775807. Литерал типа `long` записываем с суффиксом `L`.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        byte  maxByte  = 255;
        short maxShort = 32767;
        int   maxInt   = 2147483647;
        long  maxLong  = 9223372036854775807L;

        Console.WriteLine(maxByte);
        Console.WriteLine(maxShort);
        Console.WriteLine(maxInt);
        Console.WriteLine(maxLong);
    }
}
```

## Пошаговое объяснение
1. Диапазон `byte` — 0…255 (8 бит без знака), поэтому максимум 255.
2. Диапазон `short` — −32768…32767 (16 бит со знаком).
3. Диапазон `int` — −2 147 483 648…2 147 483 647 (32 бита со знаком).
4. Диапазон `long` — до 9 223 372 036 854 775 807 (64 бита); суффикс `L` показывает компилятору, что литерал имеет тип `long`.
5. Если бы значение выходило за диапазон типа, компилятор выдал бы ошибку — её отсутствие подтверждает правильность чисел.

## Трассировка и проверка
Проверка корректности самими типами (мысленный эксперимент):

- `byte b = 256;` → ошибка: значение выходит за диапазон (256 = 255 + 1);
- `short s = 32768;` → ошибка;
- `int i = 2147483648;` → литерал получает тип `long`, присвоить его `int` без приведения нельзя (`CS0266`/`CS0031`);
- `long l = 9223372036854775807L;` → допустимо, это максимум.

Как проверить числа без доверия к памяти: максимум знакового n-битного типа равен 2^(n−1) − 1; для 16 бит: 2¹⁵ − 1 = 32 767; для 32 бит: 2 147 483 647.

## Результат
Четыре строки: 255, 32767, 2147483647, 9223372036854775807.

## Типичные ошибки
- Записать `255` для `short` как максимум (максимум для `byte` и для `short` разный).
- Пропустить суффикс `L` и выйти за пределы `int` (ошибка компиляции или молчаливое изменение типа выражения).
- Перепутать 9223372036854775807 с числом 9223372036854775808 (на единицу больше — вне диапазона).
- Использовать свойства `byte.MaxValue` там, где условие требует литерал.

## Задания для закрепления
- Вывести минимальные значения тех же типов.
- Проверить, что произойдёт при `byte b = 255; b++;` в контекстах `checked` и `unchecked`.
- Сравнить размеры типов через `sizeof(...)`.
