# Разбор решения. L03-ALG-006. Целочисленные типы и их предельные значения

## Условие
Написать программу, которая объявляет по одной переменной типов `byte`, `short`, `int` и `long` и инициализирует каждую её максимальным значением, взятым из таблицы диапазонов лекции (записать числа литералами вручную, не обращаясь к свойствам типа). Вывести все четыре значения. Для типа `long` использовать суффикс `L`.

## Ожидаемый результат
Четыре строки: `255`, `32767`, `2147483647`, `9223372036854775807`; программа компилируется без ошибок, что подтверждает правильность выбранных литералов.

## Идея решения
Максимумы целочисленных типов: byte — 255, short — 32767, int — 2147483647, long — 9223372036854775807. Литерал типа `long` записываем с суффиксом `L`.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        byte  maxByte  = 255;
        short maxShort = 32767;
        int   maxInt   = 2147483647;
        long  maxLong  = 9223372036854775807L;

        Console.WriteLine(maxByte);
        Console.WriteLine(maxShort);
        Console.WriteLine(maxInt);
        Console.WriteLine(maxLong);
    }
}
```

## Пошаговое объяснение
1. Диапазон `byte` — 0…255 (8 бит без знака), поэтому максимум 255.
2. Диапазон `short` — −32768…32767 (16 бит со знаком).
3. Диапазон `int` — −2 147 483 648…2 147 483 647 (32 бита со знаком).
4. Диапазон `long` — до 9 223 372 036 854 775 807 (64 бита); суффикс `L` показывает компилятору, что литерал имеет тип `long`.
5. Если бы значение выходило за диапазон типа, компилятор выдал бы ошибку — её отсутствие подтверждает правильность чисел.

## Результат
Четыре строки: 255, 32767, 2147483647, 9223372036854775807.
