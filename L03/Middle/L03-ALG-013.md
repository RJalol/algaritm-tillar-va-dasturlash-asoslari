# L03-ALG-013. Ключевое слово C# и тип .NET

**Тема:** Л3 — Алфавит и ключевые слова языка C#. Идентификаторы, литералы, переменные, константы и типы данных

## Условие
Написать программу, которая объявляет две переменные с одинаковым значением: первую — с использованием ключевого слова `int`, вторую — с использованием полного имени типа `System.Int32`. Вывести результат сравнения `GetType()` обеих переменных на равенство.

## Ожидаемый результат
Выведено `True`, что подтверждает: ключевое слово `int` является псевдонимом типа `System.Int32`, а не отдельным типом.
