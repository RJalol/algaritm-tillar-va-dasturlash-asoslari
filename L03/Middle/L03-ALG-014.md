# L03-ALG-014. Попытка изменить константу

**Тема:** Л3 — Алфавит и ключевые слова языка C#. Идентификаторы, литералы, переменные, константы и типы данных

## Условие
Дан код:

```
const int MaxStudents = 30;
MaxStudents = 35;
Console.WriteLine(MaxStudents);
```

Определить, скомпилируется ли этот фрагмент. Назвать код ошибки, объяснить формулировку сообщения компилятора и предложить корректный вариант кода, если величина должна изменяться.

## Ожидаемый результат
Указано, что фрагмент не компилируется (ошибка `CS0131`); объяснено, почему константа не может стоять слева от знака присваивания; предложена замена `const` на обычную переменную.
