# L03. Алфавит и ключевые слова языка C#. Идентификаторы, литералы, переменные, константы и типы данных

Практические задания к теме №3 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Особенность этой темы

Тема №2 разобрала **оболочку** программы — директиву `using`, пространство имён, класс-контейнер и точку входа `Main`. Тема №3 переходит к её **содержимому**: из чего складываются объявления величин внутри метода `Main`.

Содержание заданий строго ограничено рамками темы: алфавит и ключевые слова, идентификаторы, литералы, переменные, константы, встроенные типы данных и неявная типизация (`var`). **Арифметические операции** (тема №4), **ввод данных с клавиатуры** (тема №5), **преобразование типов и класс `Convert`** (тема №6), а также **управляющие конструкции** (темы №7–9) в заданиях не используются. Вывод значений выполняется вызовами `Console.Write` и `Console.WriteLine`, изученными в теме №2.

## Структура папки


## Уровни сложности

| Уровень | Диапазон | Характеристика |
|---|---|---|
| Easy | ALG-001–005 | Объявление переменных и констант основных типов; формы записи литералов; проверка корректности идентификаторов; первое знакомство с `var` |
| Middle | ALG-006–020 | Диапазоны целочисленных типов, суффиксы литералов, управляющие последовательности и буквальные строки, соглашения об именовании; диагностика типовых ошибок объявления по коду ошибки компилятора |
| Advanced | ALG-021–030 | Несколько одновременных нарушений в одном фрагменте; точность `double` и `decimal`; область видимости; ограничения `const`; обоснованный подбор типов под предметную область; полный аудит объявлений |

## О диагностических заданиях

Часть заданий (Middle: ALG-014–018; Advanced: ALG-021, ALG-023–027, ALG-030) содержит приведённый код с намеренной ошибкой — студенту нужно найти её, назвать код ошибки компилятора и объяснить причину, а не написать программу с нуля.

Все коды ошибок, фигурирующие в ожидаемых результатах (`CS0029`, `CS0031`, `CS0103`, `CS0128`, `CS0131`, `CS0165`, `CS0283`, `CS0818`, `CS1001`), **проверены фактической компиляцией** соответствующих фрагментов на .NET 8 (`TargetFramework=net8.0`, `LangVersion=12.0`) в рамках QA курса.

## Формат каждого задания (V3)

Каждый файл `L03-ALG-XXX.md` содержит только два поля: **Условие** и **Ожидаемый результат**. **Готовые решения не приводятся.**

## Материалы для подготовки

Перед выполнением заданий рекомендуется изучить лекцию по теме №3 (см. основной репозиторий пособия), в которой рассмотрены: лексический состав программы, зарезервированные и контекстные ключевые слова, правила образования идентификаторов и соглашения об именовании, виды литералов, объявление переменных и констант, таблицы встроенных типов данных и неявная типизация.
