# Разбор решения. L03-ALG-001. Переменные пяти основных типов

## Условие
Написать программу, которая объявляет и инициализирует пять переменных: целое количество студентов в группе, вещественную среднюю оценку, символ буквенной оценки, логический признак наличия задолженности и строку с названием факультета. Значения выбрать самостоятельно. Каждое значение вывести на отдельной строке. Имена переменных записать в стиле `camelCase` и сделать содержательными.

## Ожидаемый результат
На экране пять строк — по одному значению в каждой; типы переменных соответствуют смыслу величин (`int`, `double`, `char`, `bool`, `string`).

## Идея решения
Подбираем тип по смыслу величины: количество — `int`, средняя оценка — `double`, буква — `char`, признак — `bool`, название — `string`. Имена пишем в `camelCase`.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        int studentCount = 24;
        double averageGrade = 4.35;
        char letterGrade = 'B';
        bool hasDebt = false;
        string facultyName = "Информационные технологии";

        Console.WriteLine(studentCount);
        Console.WriteLine(averageGrade);
        Console.WriteLine(letterGrade);
        Console.WriteLine(hasDebt);
        Console.WriteLine(facultyName);
    }
}
```

## Пошаговое объяснение
1. `int studentCount = 24;` — целое число людей.
2. `double averageGrade = 4.35;` — вещественное значение (дробная часть).
3. `char letterGrade = 'B';` — одиночный символ в одинарных кавычках.
4. `bool hasDebt = false;` — логическое значение `true`/`false`.
5. `string facultyName = "...";` — строка в двойных кавычках.
6. Каждое значение выводим отдельным `Console.WriteLine`.

## Результат
Пять строк: 24, 4,35, B, False, Информационные технологии (десятичный разделитель зависит от региональных настроек).
