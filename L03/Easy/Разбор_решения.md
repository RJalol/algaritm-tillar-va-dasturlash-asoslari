# Разбор решения. L03-ALG-001. Переменные пяти основных типов

## Условие
Написать программу, которая объявляет и инициализирует пять переменных: целое количество студентов в группе, вещественную среднюю оценку, символ буквенной оценки, логический признак наличия задолженности и строку с названием факультета. Значения выбрать самостоятельно. Каждое значение вывести на отдельной строке. Имена переменных записать в стиле `camelCase` и сделать содержательными.

## Ожидаемый результат
На экране пять строк — по одному значению в каждой; типы переменных соответствуют смыслу величин (`int`, `double`, `char`, `bool`, `string`).

## Разбор условия
**Дано:** смысловое описание пяти величин: количество студентов, средняя оценка, буква оценки, наличие задолженности, название факультета.
**Требуется:** объявить пять переменных подходящих типов, дать значения, вывести каждое на отдельной строке.
**Требования к именам:** `camelCase`, содержательные.

## Теоретическая справка
**Переменная** — именованная область памяти, тип которой определяет допустимые значения и операции.

| Смысл величины | Тип | Диапазон/особенность |
|---|---|---|
| целое количество | `int` | −2 147 483 648 … 2 147 483 647 |
| вещественное число | `double` | ≈ 15–16 значащих цифр |
| один символ | `char` | одиночные кавычки: `'B'` |
| да/нет | `bool` | только `true` или `false` |
| текст | `string` | двойные кавычки |

**Соглашение camelCase:** первое слово со строчной буквы, остальные — с прописной (`studentCount`). Имя должно описывать смысл, а не тип: `averageGrade` лучше, чем `d1`.

## Идея решения
Подбираем тип по смыслу величины: количество — `int`, средняя оценка — `double`, буква — `char`, признак — `bool`, название — `string`. Имена пишем в `camelCase`.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        int studentCount = 24;
        double averageGrade = 4.35;
        char letterGrade = 'B';
        bool hasDebt = false;
        string facultyName = "Информационные технологии";

        Console.WriteLine(studentCount);
        Console.WriteLine(averageGrade);
        Console.WriteLine(letterGrade);
        Console.WriteLine(hasDebt);
        Console.WriteLine(facultyName);
    }
}
```

## Пошаговое объяснение
1. `int studentCount = 24;` — целое число людей.
2. `double averageGrade = 4.35;` — вещественное значение (дробная часть).
3. `char letterGrade = 'B';` — одиночный символ в одинарных кавычках.
4. `bool hasDebt = false;` — логическое значение `true`/`false`.
5. `string facultyName = "...";` — строка в двойных кавычках.
6. Каждое значение выводим отдельным `Console.WriteLine`.

## Трассировка и проверка
Выполнение построчно:

| Оператор | Что происходит в памяти |
|---|---|
| `int studentCount = 24;` | резервируется 4 байта, записано 24 |
| `double averageGrade = 4.35;` | 8 байт, значение 4,35 |
| `char letterGrade = 'B';` | 2 байта, код символа 66 |
| `bool hasDebt = false;` | 1 байт, значение `false` |
| `string facultyName = "…";` | ссылка на строку в куче |

Вывод: пять строк в порядке объявления. Десятичный разделитель в `4,35` зависит от региональных настроек (в русской культуре — запятая).

## Результат
Пять строк: 24, 4,35, B, False, Информационные технологии (десятичный разделитель зависит от региональных настроек).

## Типичные ошибки
- Записать `char` в двойных кавычках (`"B"` — это уже строка, ошибка `CS0029`).
- Записать строку в одинарных кавычках — несколько символов в литерале `char` недопустимы.
- Дать имя с прописной буквы или с подчёркиваниями (`Student_Count`), нарушив соглашение.
- Использовать `int` для оценки 4,35 — дробная часть будет потеряна (на самом деле будет ошибка преобразования).

## Задания для закрепления

- Объявить те же величины с помощью `var` и проверить, какие типы выведет компилятор.
- Оформить вывод с подписями: «Студентов: 24».
