# L03-ALG-025. Повторное объявление в одной области

**Тема:** Л3 — Алфавит и ключевые слова языка C#. Идентификаторы, литералы, переменные, константы и типы данных

## Условие
Дан код:

```
int count = 1;
int count = 2;
Console.WriteLine(count);
```

Объяснить, почему фрагмент не компилируется, назвать код ошибки и указать, чем эта ситуация принципиально отличается от простого присваивания нового значения уже объявленной переменной.

## Ожидаемый результат
Назван код `CS0128`; проведено чёткое различие между повторным *объявлением* имени и повторным *присваиванием* значения.
