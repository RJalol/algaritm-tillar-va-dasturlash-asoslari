# L03-ALG-027. Допустимые типы констант

**Тема:** Л3 — Алфавит и ключевые слова языка C#. Идентификаторы, литералы, переменные, константы и типы данных

## Условие
Определить, какие из перечисленных объявлений констант допустимы, а какие — нет: константа типа `int`; константа типа `string`; константа типа `bool`; константа типа `double`; константа типа `System.DateTime`. Для недопустимых назвать код ошибки и объяснить причину через понятие константы времени компиляции.

## Ожидаемый результат
Первые четыре объявления признаны допустимыми, объявление константы типа `DateTime` — недопустимым с кодом `CS0283`; причина связана с требованием вычислимости значения на этапе компиляции.
