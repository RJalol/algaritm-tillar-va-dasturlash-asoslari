# L03-ALG-029. Определение типа литерала без запуска программы

**Тема:** Л3 — Алфавит и ключевые слова языка C#. Идентификаторы, литералы, переменные, константы и типы данных

## Условие
Для каждого из литералов определить тип, который присвоит ему компилятор, не запуская программу:

```
42        42L       0x1F      3.14      3.14f
3.14m     'A'       "A"       true      1.5e3
```

Ответ для каждого литерала обосновать конкретным признаком записи (форма, суффикс, вид кавычек).

## Ожидаемый результат
Десять пар «литерал — тип» с указанием признака, по которому тип определён; различие между `'A'` и `"A"` объяснено видом кавычек.
