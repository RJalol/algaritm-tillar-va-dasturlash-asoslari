# L03-ALG-026. var и строгая типизация

**Тема:** Л3 — Алфавит и ключевые слова языка C#. Идентификаторы, литералы, переменные, константы и типы данных

## Условие
Дан код:

```
var value = 5;
value = "текст";
Console.WriteLine(value);
```

Определить, скомпилируется ли фрагмент. На основании полученного результата обосновать утверждение: «`var` не является средством динамической типизации». Назвать код ошибки и указать, в какой момент переменная получила свой тип.

## Ожидаемый результат
Назван код `CS0029`; показано, что тип `int` закреплён за переменной на этапе компиляции в момент объявления и далее неизменен; вывод об отличии от динамической типизации обоснован именно этим фактом.
