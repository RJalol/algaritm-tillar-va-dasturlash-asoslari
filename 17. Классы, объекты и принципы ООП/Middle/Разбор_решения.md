# Разбор решения. L17-ALG-006. Массив объектов

## Условие
Объявить класс `Student` с полями «имя», «группа», «балл» и конструктором. Создать массив из трёх студентов — `("Азиз", "ТТ-11", 87)`, `("Дилноза", "ТТ-11", 92)` и `("Рустам", "ТТ-12", 78)` — и вывести средний балл с двумя знаками и имя лучшего студента.

## Ожидаемый результат
Средний балл `85,67`, лучший — `Дилноза`; поиск лучшего начат с первого элемента массива, а не с нуля.

## Разбор условия
**Дано:** три студента — (Азиз, ТТ-11, 87), (Дилноза, ТТ-11, 92), (Рустам, ТТ-12, 78).
**Требуется:** класс `Student`, массив из трёх объектов, средний балл с двумя знаками и имя лучшего студента.

## Теоретическая справка
**Массив объектов** хранит *ссылки*; каждый элемент нужно создать отдельно (`new Student(…)`), иначе он равен `null`.

Поиск максимума по полю: начинаем с первого элемента (`best = students[0]`) и сравниваем остальные. Начинать с 0 нельзя — нет объекта «нулевого студента».

Среднее: сумма баллов / количество. Чтобы сохранить дробную часть, сумма накапливается в `double` или используется вещественное деление. Форматирование `ToString("F2")` — два знака после запятой.

## Идея решения
Создаём массив ссылок на объекты `Student`, затем одним проходом считаем сумму баллов и ищем студента с наибольшим баллом.

## Решение
```csharp
using System;

class Student
{
    public string Name;
    public string Group;
    public int Score;

    public Student(string name, string group, int score)
    {
        Name = name; Group = group; Score = score;
    }
}

class Program
{
    static void Main()
    {
        Student[] students =
        {
            new Student("Азиз", "ТТ-11", 87),
            new Student("Дилноза", "ТТ-11", 92),
            new Student("Рустам", "ТТ-12", 78)
        };

        double sum = 0;
        Student best = students[0];
        foreach (Student s in students)
        {
            sum += s.Score;
            if (s.Score > best.Score) best = s;
        }

        Console.WriteLine("Средний балл: " + (sum / students.Length).ToString("F2"));
        Console.WriteLine("Лучший: " + best.Name);
    }
}
```

## Пошаговое объяснение
1. Массив классов хранит ссылки; каждый элемент нужно создать оператором `new`.
2. Сумма: 87 + 92 + 78 = 257; среднее 257 / 3 = 85,67 (формат `F2`).
3. `best` начинаем с первого элемента массива и заменяем, если нашёлся балл выше.
4. Лучший балл 92 — у Дилнозы.

## Трассировка и проверка
| Студент | Балл | sum | best |
|---|--:|--:|---|
| Азиз | 87 | 87 | Азиз |
| Дилноза | 92 | 179 | Дилноза |
| Рустам | 78 | 257 | Дилноза |

Среднее: 257 / 3 = 85,666… → `85,67`. Лучший — Дилноза (92).

## Результат
Средний балл: 85,67; Лучший: Дилноза

## Типичные ошибки
- Начинать поиск максимума с 0 или `null` без проверки.
- Делить целую сумму на целое количество и терять дробную часть.
- Объявить массив, но не создать объекты.
- Сравнивать студентов по имени вместо балла.
