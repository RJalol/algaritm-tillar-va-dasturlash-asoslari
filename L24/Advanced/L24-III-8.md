# L24 · Задание III · №8. Инвентаризация частей

**Тема:** Л24 — Сохранение классов в нескольких файлах и работа с ними по частям

## Условие
Написать программу, которая по набору файлов с исходным текстом определяет: какие типы объявлены частичными, сколько частей у каждого, какие частичные методы объявлены и какие из них имеют реализующее объявление. Проверить программу на проекте задания III.5 и сопоставить результат с фактическим составом файлов.

## Ожидаемый результат
Для каждого частичного типа указано число частей и перечень частичных методов с пометкой о наличии реализации; результат полностью соответствует исходным файлам.
