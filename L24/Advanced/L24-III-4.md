# L24 · Задание III · №4. Диагностика чужого частичного класса

**Тема:** Л24 — Сохранение классов в нескольких файлах и работа с ними по частям

## Условие
Подготовить частичный класс, содержащий не менее семи внесённых ошибок из числа изученных: частичный метод вне частичного типа; два объявляющих объявления; реализация без объявления; отсутствие обязательной реализации во всех трёх случаях; расхождение подписей по доступности и по типу результата. Составить таблицу «файл — строка — код — причина — исправление» и привести класс в рабочее состояние без предупреждений.

## Ожидаемый результат
Таблица содержит не менее семи строк с фактически полученными кодами; исправленный класс компилируется без ошибок и без предупреждений `CS8826` и `CS1066`.
