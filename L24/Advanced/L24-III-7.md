# L24 · Задание III · №7. Точка расширения или обычный метод

**Тема:** Л24 — Сохранение классов в нескольких файлах и работа с ними по частям

## Условие
Даны шесть требований к классу: «выводить сообщение при добавлении записи, если разработчик того пожелает»; «обязательно проверять данные перед сохранением»; «возвращать код завершения»; «замерять время выполнения, если включена отладка»; «вычислять итоговую сумму»; «уведомлять о превышении предела». Для каждого решить, уместна ли точка расширения в виде частичного метода или требуется обычный метод, и обосновать решение условиями раздела 5.5.

## Ожидаемый результат
Уместность определена для всех шести требований; для каждого неуместного случая указано, какое именно условие нарушено.
