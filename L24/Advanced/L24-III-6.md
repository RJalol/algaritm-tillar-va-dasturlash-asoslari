# L24 · Задание III · №6. Согласование подписей: полный разбор

**Тема:** Л24 — Разделение класса на части, хранение его в нескольких файлах и работа с такими файлами

## Условие
Для одного частичного метода составить шесть пар объявлений, различающихся по одному признаку: доступность; тип результата; имя параметра; тип параметра; модификатор параметра; значение параметра по умолчанию. Для каждой пары определить опытом реакцию компилятора и заполнить таблицу «признак — ошибка или предупреждение — код — следствие для вызывающей стороны».

## Ожидаемый результат
Таблица заполнена фактически полученными кодами; отдельно отмечено, что при несовпадении имён в сборку попадает имя объявляющего объявления, а значение по умолчанию из реализующего объявления не действует.
