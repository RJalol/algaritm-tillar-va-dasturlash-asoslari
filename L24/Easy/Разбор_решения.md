# Разбор решения. L24 · Задание I · №1. Разделение по назначению

## Условие
Разделить класс «книга» на три файла: данные и конструктор; правила проверки (год издания, число страниц); вывод и форматирование. Имена файлов должны отражать содержимое части. Создать корректный и некорректный объекты и вывести отчёт по каждому.

## Ожидаемый результат
Оба отчёта выведены; метод вывода из третьего файла вызывает проверки из второго и читает закрытые поля первого без дополнительных объявлений.

## Идея решения
Ключевое слово `partial` позволяет разнести один класс по нескольким файлам; компилятор склеивает части. Все части видят закрытые члены друг друга.

## Решение
```csharp
// ---- Book.Data.cs ----
public partial class Book
{
    private string _title;
    private int _year;
    private int _pages;

    public Book(string title, int year, int pages)
    {
        _title = title; _year = year; _pages = pages;
    }
}

// ---- Book.Validation.cs ----
public partial class Book
{
    private bool IsYearValid()  => _year >= 1450 && _year <= 2026;
    private bool IsPagesValid() => _pages > 0;
    public  bool IsValid()      => IsYearValid() && IsPagesValid();
}

// ---- Book.Output.cs ----
using System;
public partial class Book
{
    public void PrintReport()
    {
        Console.WriteLine($"{_title}, {_year}, {_pages} стр.: " +
            (IsValid() ? "данные корректны" : "данные некорректны"));
    }
}

// ---- Program.cs ----
class Program
{
    static void Main()
    {
        new Book("Алгоритмы", 2020, 320).PrintReport();
        new Book("Ошибка", 3000, -5).PrintReport();
    }
}
```

## Пошаговое объяснение
1. Три файла: данные и конструктор, правила проверки, вывод — их имена отражают назначение.
2. В каждом файле объявление `public partial class Book`; модификаторы доступа согласованы.
3. Метод вывода обращается к закрытым полям `_title`, `_year`, `_pages` и к закрытому методу — дополнительных объявлений не нужно, так как это один и тот же класс.
4. Для корректного объекта проверки проходят, для некорректного (год 3000, страниц −5) — нет.

## Результат
Алгоритмы, 2020, 320 стр.: данные корректны / Ошибка, 3000, -5 стр.: данные некорректны
