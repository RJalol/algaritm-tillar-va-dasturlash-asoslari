# L24 · Задание I · №3. Первый частичный метод

**Тема:** Л24 — Разделение класса на части, хранение его в нескольких файлах и работа с такими файлами

## Условие
Объявить частичный класс со счётчиком и методом добавления записи. В одной части объявить частичный метод-точку расширения без тела и вызвать его из метода добавления; в другой части предоставить реализацию, выводящую сообщение. Добавить три записи.

## Ожидаемый результат
Для каждой записи выведено сообщение реализации; счётчик равен трём.
