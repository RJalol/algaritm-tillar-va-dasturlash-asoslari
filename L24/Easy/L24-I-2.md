# L24 · Задание I · №2. Имитация кода среды

**Тема:** Л24 — Сохранение классов в нескольких файлах и работа с ними по частям

## Условие
Воспроизвести приём разделения по происхождению кода: в файле с суффиксом `.Designer. cs` объявить закрытые поля «элементов» и метод их настройки, а в файле без суффикса — конструктор, вызывающий этот метод, и метод вывода карточки в консоль. Пояснить в комментарии, почему первый файл не правят вручную.

## Ожидаемый результат
Карточка выведена; конструктор из второго файла успешно вызывает метод, объявленный в первом; в комментарии указана причина запрета на ручную правку.
