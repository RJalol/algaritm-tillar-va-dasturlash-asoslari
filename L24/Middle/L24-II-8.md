# L24 · Задание II · №8. Точки расширения импорта

**Тема:** Л24 — Сохранение классов в нескольких файлах и работа с ними по частям

## Условие
Разработать частичный класс «импорт данных» с тремя точками расширения: начало обработки, обработка одной строки, завершение. Шаблонная часть вызывает их в подходящих местах цикла. Во второй части реализовать только две из трёх и проверить работу на массиве строк, часть из которых пуста.

## Ожидаемый результат
Сообщения реализованных точек выведены, нереализованная не оставила следа; итоговые числа принятых и отклонённых строк верны.
