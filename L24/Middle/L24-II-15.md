# L24 · Задание II · №15. Полный набор ошибок частичных методов

**Тема:** Л24 — Сохранение классов в нескольких файлах и работа с ними по частям

## Условие
Составить программу, содержащую по одной ошибке каждого из изученных видов: частичный метод вне частичного типа; два объявляющих объявления; реализация без объявления; отсутствие обязательной реализации при модификаторе доступа; расхождение типов результата.
