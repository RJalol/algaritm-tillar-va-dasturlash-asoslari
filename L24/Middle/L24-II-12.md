# L24 · Задание II · №12. Когда разделять не нужно

**Тема:** Л24 — Сохранение классов в нескольких файлах и работа с ними по частям

## Условие
Взять небольшой класс из тридцати строк и разнести его члены по трём файлам произвольно, без общего признака. Сравнить читаемость с исходным вариантом и сформулировать признаки, по которым разделение оправдано, а по которым — нет. Оформить вывод в виде списка из пяти пунктов.

## Ожидаемый результат
Список содержит не менее трёх признаков оправданного разделения и не менее двух признаков неоправданного; вывод программы в обоих вариантах одинаков.
