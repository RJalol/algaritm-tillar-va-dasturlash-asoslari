# L24 · Задание II · №7. Чьё имя параметра попало в сборку

**Тема:** Л24 — Сохранение классов в нескольких файлах и работа с ними по частям

## Условие
Для частичного метода с разными именами параметров в двух объявлениях определить, какое имя попало в сборку, средствами получения сведений о типе. Затем вызвать метод именованным аргументом (тема №14), употребив сначала одно имя, затем другое, и записать, какой вызов компилируется.

## Ожидаемый результат
В сборку попало имя из объявляющего объявления; именованный аргумент с этим именем компилируется, а с именем из реализующего объявления — нет.
