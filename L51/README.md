# L51. Элементы управления, компоновки и события в WPF

Практические задания к теме №51 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
L51/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
└── Advanced/   10 заданий  (Задание III)
```

## Формат задания

Каждый файл `L51-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. В каждой из папок `Easy/`, `Middle/`, `Advanced/` приведён один образцовый разбор — файл `Разбор_решения.md`.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.
