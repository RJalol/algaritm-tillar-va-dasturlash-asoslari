# Разбор решения. L49 · Задание III · №3. Топ-N по группам

## Условие
Для каждой группы найти трёх лучших студентов.

## Ожидаемый результат
В каждой группе не более трёх записей.

## Идея решения
Группируем студентов по группе, внутри каждой сортируем по убыванию балла и берём три первых (`Take(3)`).

## Решение
```csharp
using System;
using System.Collections.Generic;
using System.Linq;

record Student(string Name, string Group, int Score);

class Program
{
    static void Main()
    {
        var students = new List<Student>
        {
            new("Азиз", "ТТ-11", 87), new("Дилноза", "ТТ-11", 92), new("Бобур", "ТТ-11", 70), new("Лола", "ТТ-11", 99),
            new("Рустам", "ТТ-12", 78), new("Малика", "ТТ-12", 95), new("Тимур", "ТТ-12", 60)
        };

        var top = students
            .GroupBy(s => s.Group)
            .OrderBy(g => g.Key)
            .Select(g => new
            {
                Group = g.Key,
                Best = g.OrderByDescending(s => s.Score).Take(3).ToList()
            });

        foreach (var g in top)
        {
            Console.WriteLine(g.Group);
            foreach (var s in g.Best)
                Console.WriteLine($"  {s.Name} - {s.Score}");
        }
    }
}
```

## Пошаговое объяснение
1. `GroupBy` создаёт группы по полю `Group`.
2. Внутри каждой группы элементы сортируются по убыванию балла, и `Take(3)` оставляет не более трёх.
3. Если в группе меньше трёх студентов (как в ТТ-12 — их три, но в общем случае возможно меньше), `Take` не выбрасывает исключение — вернёт все доступные.
4. Результат — последовательность анонимных объектов «группа — список лучших».

## Результат
ТТ-11: Лола 99, Дилноза 92, Азиз 87; ТТ-12: Малика 95, Рустам 78, Тимур 60.
