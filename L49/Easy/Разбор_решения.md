# Разбор решения. L49 · Задание I · №1. Count и Sum

## Условие
Для массива {4, 8, 15, 16, 23, 42} найти количество и сумму элементов методами `Count` и `Sum`.

## Ожидаемый результат
Количество 6, сумма 108.

## Разбор условия
**Дано:** {4, 8, 15, 16, 23, 42}.
**Требуется:** найти количество и сумму элементов.

## Теоретическая справка
**Агрегатные методы** сводят последовательность к одному значению: `Count`, `Sum`, `Min`, `Max`, `Average`, `Aggregate`. В отличие от `Where` и `Select` они выполняются **немедленно**.

Дополнительные формы: с предикатом (`Count(x => x > 10)`) и с селектором (`Sum(s => s.Score)`).

Для пустой последовательности `Sum` и `Count` возвращают 0, а `Min`, `Max`, `Average` бросают `InvalidOperationException` (для типов, не допускающих `null`).

## Идея решения
`Count()` возвращает число элементов, `Sum()` — сумму. Это агрегатные методы LINQ: они сводят последовательность к одному значению.

## Решение
```csharp
using System;
using System.Linq;

class Program
{
    static void Main()
    {
        int[] data = { 4, 8, 15, 16, 23, 42 };

        Console.WriteLine("Количество: " + data.Count());
        Console.WriteLine("Сумма: " + data.Sum());
    }
}
```

## Пошаговое объяснение
1. Для массива `Count()` можно заменить свойством `Length`, но `Count()` работает с любой последовательностью.
2. `Sum()` суммирует числовые элементы: 4 + 8 + 15 + 16 + 23 + 42 = 108.
3. Агрегатные методы выполняются немедленно (в отличие от `Where` и `Select`, которые откладывают выполнение).

## Трассировка и проверка
| Агрегат | Вычисление | Результат |
|---|---|--:|
| `Count()` | 6 элементов | 6 |
| `Sum()` | 4+8+15+16+23+42 | 108 |

Эти значения позволяют сразу найти среднее: 108 / 6 = 18.

## Результат
Количество: 6, Сумма: 108

## Типичные ошибки
- Использовать `Count()` там, где достаточно `Length` или `Any()`.
- Забыть, что `Average` возвращает `double`.
- Не обрабатывать пустую последовательность.
- Переполнение `int` при суммировании больших чисел (`Sum` в `checked`-контексте бросает `OverflowException`).
