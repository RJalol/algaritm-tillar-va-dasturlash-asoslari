# L18-ALG-004. Массив структур

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Создать массив из трёх значений структуры `Point` записью `new Point[3]` и вывести все три элемента, не присваивая им ничего. Затем создать массив из трёх объектов класса с теми же полями и попытаться вывести первый элемент. Объяснить расхождение.

## Ожидаемый результат
Массив структур сразу содержит три точки с нулевыми координатами; в массиве объектов элементы равны `null`, и обращение к их членам даёт `NullReferenceException`.
