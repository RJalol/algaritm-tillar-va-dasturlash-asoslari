# L18-ALG-003. Предсказание вывода: присваивание структуры

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Дан код:

```
struct Counter { public int Value; public void Increment() { Value++; } }

Counter a = new Counter();
a.Increment();
a.Increment();
Counter b = a;
b.Increment();
Console.WriteLine($"{a.Value} {b.Value}");
```

Не запуская программу, предсказать вывод. Затем заменить слово `struct` на `class`, ничего больше не меняя, запустить оба варианта и объяснить расхождение.

## Ожидаемый результат
Для структуры выведено `2 3`, для класса — `3 3`; объяснено, что в первом случае присваивание скопировало значение, а во втором — ссылку.
