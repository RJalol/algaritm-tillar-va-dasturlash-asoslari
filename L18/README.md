# L18. Объявление структур. Значимые и ссылочные типы. Работа со структурами

Практические задания к теме №18 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Особенность этой темы

Тема №15 дала вводное различение значимых и ссылочных типов; тема №18 доводит его до полного и вводит собственный **значимый** тип — структуру.

Центральное задание темы — ALG-003 и ALG-024. Один и тот же текст программы даёт **разные результаты** в зависимости от единственного слова:

```
Counter a = new Counter();
a.Increment(); a.Increment();
Counter b = a;
b.Increment();
Console.WriteLine($"{a.Value} {b.Value}");
```

| Объявление | Вывод | Почему |
|---|---|---|
| `struct Counter` | `2 3` | присваивание копирует **значение** |
| `class Counter` | `3 3` | присваивание копирует **ссылку** |

Второй важный результат: у структур `Equals` **по умолчанию сравнивает поля** (базовый тип — `System.ValueType`), тогда как у классов — ссылки. Зато операция `==` для структуры без перегрузки вовсе не определена (`CS0019`).

Не используются: модификатор `readonly` для структур, выражение `with`, записи, первичные конструкторы, `ref struct`, **интерфейсы** (тема №27), **обобщения** (темы №34–35), **перегрузка операторов** (тема №22), **наследование** (темы №24–26).

## Ключевые идеи темы, проверяемые заданиями

- Переменная структурного типа содержит **сам экземпляр**; присваивание и передача в метод **копируют** его (ALG-003, ALG-007, ALG-024, ALG-029).
- Изменение структуры внутри метода не видно вызывающему коду — нужен `ref` (ALG-007, ALG-030).
- `new T()` и `default(T)` для структуры дают одно и то же; массив структур **сразу готов**, а массив объектов класса заполнен `null` (ALG-004, ALG-027).
- Значение по умолчанию **обходит конструктор**, поэтому инвариант, установленный конструктором, может быть нарушен: `new Fraction[3]` даёт дробь `0/0` (ALG-012).
- Структура не может наследовать (`CS0527`) и не может иметь финализатора (`CS0575`); конструктор не обязан присваивать все поля — недостающие заполнит компилятор (ALG-015, ALG-016, ALG-018).
- `Equals` для структуры сравнивает **поля** без всякого переопределения; `==` без перегрузки — `CS0019` (ALG-009, ALG-017).
- Структуру с **открытыми полями** можно создать без `new`; со скрытыми полями автосвойств — нельзя (`CS0165`) (ALG-011).
- Упаковка **копирует** значение: после `object o = i;` изменение `i` упакованный объект не затрагивает (ALG-005, ALG-029).
- Распаковать можно только в **тот же** тип: упакованный `int` как `short` — `InvalidCastException`; распаковка `null` — `NullReferenceException` (ALG-019, ALG-020, ALG-030).

## О диагностических заданиях

Задания Middle ALG-011, ALG-015–ALG-020 и Advanced ALG-021, ALG-029, ALG-030 содержат код для анализа: найти ошибку, назвать её код либо предсказать вывод до запуска.

Все коды сообщений (`CS0019`, `CS0165`, `CS0527`, `CS0575`), типы исключений (`InvalidCastException`, `NullReferenceException`) и **все числовые ответы** (`2 3` против `3 3`; `15.03.2026` и `31.12.2026`; дроби `3/4`, `2`, `-1/3`, `5/6`; вектор длиной `5` и сумма `(3; 4; 1)`; время `23:50`, `00:10`, `02:10`; сумма квадратов `30`; `Ответ42True`; сумма `500500`) проверены фактической компиляцией и запуском на .NET 8 с культурой ru-RU.

## Формат каждого задания (V3)

Каждый файл `L18-ALG-XXX.md` содержит только два поля: **Условие** и **Ожидаемый результат**. **Готовые решения не приводятся.**
