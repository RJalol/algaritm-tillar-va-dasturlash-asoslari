# L18-ALG-018. Конструктор, заполняющий не все поля

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Дан код:

```
struct Pair
{
    public int X;
    public int Y;
    public Pair(int x) { X = x; }
}
```

Определить, скомпилируется ли структура, и объяснить результат, опираясь на документацию. Вывести значение поля `Y` для объекта `new Pair(5)`.

## Ожидаемый результат
Структура компилируется; поле `Y` равно `0`, поскольку компилятор дописывает в конструктор инициализацию недостающих полей значением по умолчанию.
