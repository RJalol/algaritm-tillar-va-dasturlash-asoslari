# L18-ALG-019. Неверная распаковка

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Дан код:

```
object boxed = 123;
short bad = (short)boxed;
```

Определить, скомпилируется ли фрагмент и что произойдёт при выполнении. Назвать исключение и объяснить, почему оно возникает, хотя преобразование `int` в `short` само по себе существует. Привести исправление.

## Ожидаемый результат
Фрагмент компилируется и возбуждает `InvalidCastException`; объяснено, что распаковать можно только в тот тип, который был упакован; исправление — запись `(short)(int)boxed`.
