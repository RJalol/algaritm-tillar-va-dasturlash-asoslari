# L18-ALG-015. Попытка наследования структуры

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Дан код:

```
class Base { public int A; }
struct Bad : Base { }
```

Назвать код ошибки, привести формулировку сообщения и объяснить, почему структура не может наследовать, опираясь на способ хранения данных значимого типа.

## Ожидаемый результат
Назван код `CS0527` с сообщением «тип в списке интерфейсов не является интерфейсом»; объяснено, что значимый тип содержит данные непосредственно, и расширить его подтипом с добавочными полями невозможно.
