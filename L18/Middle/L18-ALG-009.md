# L18-ALG-009. Сравнение структур без переопределения

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Создать два значения структуры `Point` с одинаковыми координатами и сравнить их методом `Equals`. Затем проделать то же с двумя объектами класса, объявленного точно так же. Вывести оба результата и объяснить расхождение, назвав базовый тип структуры.

## Ожидаемый результат
Для структуры получено `True`, для класса — `False`; объяснено, что базовым типом структуры служит `System.ValueType`, в котором `Equals` сравнивает поля.
