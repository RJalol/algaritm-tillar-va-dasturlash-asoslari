# L18-ALG-017. Операция == для структуры

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Дан код:

```
struct Point { public double X; public double Y; }

Point a = new Point();
Point b = new Point();
Console.WriteLine(a == b);
```

Назвать код ошибки и объяснить, чем это поведение отличается от поведения класса. Привести два способа сравнить два значения структуры средствами настоящей темы.

## Ожидаемый результат
Назван код `CS0019`; отмечено, что для класса та же запись компилируется и сравнивает ссылки; предложены вызов `Equals` и посимвольное сравнение полей.
