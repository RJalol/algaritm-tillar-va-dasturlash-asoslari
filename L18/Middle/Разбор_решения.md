# Разбор решения. L18-ALG-006. Свойство с проверкой границ

## Условие
Объявить класс `Student` со свойством `Score`, метод `set` которого приводит значение к отрезку от 0 до 100: меньшее заменяется нулём, большее — сотней. Присвоить свойству последовательно 87, 200, −50 и 95, выводя значение после каждого присваивания.

## Ожидаемый результат
Выведено `87`, `100`, `0` и `95`; ни одно присваивание не вызвало ни ошибки, ни исключения.

## Разбор условия
**Дано:** значения 87, 200, −50, 95.
**Требуется:** класс `Student` со свойством `Score`, `set` которого приводит значение к отрезку [0; 100]; присвоить значения и вывести после каждого присваивания.

## Теоретическая справка
**Свойство** — член класса, внешне похожий на поле, а на деле пара методов доступа:

```
public int Score
{
    get { return _score; }
    set { _score = ...; }      // value — присваиваемое значение
}
```

Преимущества: контроль значений, возможность менять реализацию без изменения клиентов, вычисляемые значения. Поле остаётся закрытым (`private`).

**Опасная ошибка:** внутри `get`/`set` обращаться к самому свойству (`get { return Score; }`) — бесконечная рекурсия и `StackOverflow`. Нужно обращаться к полю.

## Идея решения
Свойство с логикой в `set`: значение приводится к отрезку [0; 100] прежде чем попасть в закрытое поле.

## Решение
```csharp
using System;

class Student
{
    private int _score;

    public int Score
    {
        get { return _score; }
        set
        {
            if (value < 0) _score = 0;
            else if (value > 100) _score = 100;
            else _score = value;
        }
    }
}

class Program
{
    static void Main()
    {
        Student s = new Student();
        foreach (int v in new[] { 87, 200, -50, 95 })
        {
            s.Score = v;
            Console.WriteLine(s.Score);
        }
    }
}
```

## Пошаговое объяснение
1. `value` — неявный параметр `set`, содержащий присваиваемое значение.
2. Значения вне диапазона заменяются границей, исключения не возникает.
3. Поле `_score` закрыто, поэтому обойти проверку нельзя.

## Трассировка и проверка
| Присваивание | value | Результат в `_score` | Вывод |
|---|--:|--:|--:|
| `s.Score = 87` | 87 | 87 | 87 |
| `s.Score = 200` | 200 | 100 | 100 |
| `s.Score = -50` | −50 | 0 | 0 |
| `s.Score = 95` | 95 | 95 | 95 |

Ни одно присваивание не вызвало исключения — выбрана стратегия *приведения к границе*; альтернатива — бросать `ArgumentOutOfRangeException`.

## Результат
87, 100, 0, 95

## Типичные ошибки
- Возвращать из `get` само свойство (рекурсия).
- Забыть `else` и перезаписать корректное значение.
- Сделать поле открытым и обойти проверку.
- Путать `value` с именем поля.
