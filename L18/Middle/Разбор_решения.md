# Разбор решения. L18-ALG-006. Свойство с проверкой границ

## Условие
Объявить класс `Student` со свойством `Score`, метод `set` которого приводит значение к отрезку от 0 до 100: меньшее заменяется нулём, большее — сотней. Присвоить свойству последовательно 87, 200, −50 и 95, выводя значение после каждого присваивания.

## Ожидаемый результат
Выведено `87`, `100`, `0` и `95`; ни одно присваивание не вызвало ни ошибки, ни исключения.

## Идея решения
Свойство с логикой в `set`: значение приводится к отрезку [0; 100] прежде чем попасть в закрытое поле.

## Решение
```csharp
using System;

class Student
{
    private int _score;

    public int Score
    {
        get { return _score; }
        set
        {
            if (value < 0) _score = 0;
            else if (value > 100) _score = 100;
            else _score = value;
        }
    }
}

class Program
{
    static void Main()
    {
        Student s = new Student();
        foreach (int v in new[] { 87, 200, -50, 95 })
        {
            s.Score = v;
            Console.WriteLine(s.Score);
        }
    }
}
```

## Пошаговое объяснение
1. `value` — неявный параметр `set`, содержащий присваиваемое значение.
2. Значения вне диапазона заменяются границей, исключения не возникает.
3. Поле `_score` закрыто, поэтому обойти проверку нельзя.

## Результат
87, 100, 0, 95
