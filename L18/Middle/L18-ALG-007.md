# L18-ALG-007. Передача структуры в метод

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Написать три статических метода, принимающих структуру `Counter`: первый — по значению, второй — с модификатором `ref`, третий — принимающий объект класса с теми же членами. Каждый увеличивает счётчик. Вызвать все три и вывести значения после каждого вызова.

## Ожидаемый результат
После первого вызова значение осталось `0`, после второго стало `1`, после третьего объект класса тоже содержит `1`; первый и третий методы записаны одинаково, а результат различен.
