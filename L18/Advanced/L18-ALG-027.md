# L18-ALG-027. Массив структур против массива объектов

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Создать массив из десяти значений структуры `Point` и массив из десяти объектов класса с теми же членами, оба записью `new T[10]`. Для каждого попытаться сразу, без заполнения, прочитать координату первого элемента и присвоить ей значение. Описать, что произошло в каждом случае, и объяснить причину. Затем привести код, правильно заполняющий массив объектов класса.

## Ожидаемый результат
Массив структур позволяет и читать, и присваивать сразу; массив объектов даёт `NullReferenceException`, поскольку его элементы равны `null`; в правильном коде каждый элемент создан операцией `new` в цикле.
