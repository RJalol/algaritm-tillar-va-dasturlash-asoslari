# L18-ALG-029. Предсказание вывода: копии и упаковка

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Дан код:

```
struct S { public int N; }

S a = new S();
a.N = 1;
S b = a;
b.N = 5;
Console.WriteLine(a.N);

object o = a;
a.N = 9;
Console.WriteLine(((S)o).N);
Console.WriteLine(a.Equals(b));

S c = new S();
c.N = 1;
Console.WriteLine(a.Equals(c));
Console.WriteLine(o.GetType().Name);
```

Не запуская программу, предсказать все пять строк вывода. Затем запустить и объяснить каждую, различая копирование значения при присваивании и копирование значения при упаковке.

## Ожидаемый результат
Предсказано `1`, `1`, `False`, `False` и `S`; объяснено, что упаковка скопировала значение в момент присваивания переменной `o`, поэтому последующее изменение `a` на упакованный объект не повлияло.
