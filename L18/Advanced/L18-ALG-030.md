# L18-ALG-030. Полный аудит программы со структурами

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Дан код:

```
using System;
using System.Collections.Generic;

namespace StructAudit
{
    struct Money
    {
        public decimal Amount;
        public string Currency;

        public Money(decimal amount, string currency)
        {
            Amount = amount;
            Currency = currency;
        }

        public override string ToString() => $"{Amount:F2} {Currency}";
    }

    class Program
    {
        static void AddBonus(Money m)
        {
            m.Amount += 1000;
        }

        static void Main(string[] args)
        {
            Money[] wallet = new Money[2];
            Console.WriteLine(wallet[0]);

            Money salary = new Money(500000m, "UZS");
            AddBonus(salary);
            Console.WriteLine(salary);

            List<object> log = new List<object>();
            for (int i = 0; i < 3; i++)
            {
                log.Add(salary);
            }
            Money first = (Money)log[0];
            Console.WriteLine(first);

            object boxed = 42;
            long value = (long)boxed;
            Console.WriteLine(value);
        }
    }
}
```

Провести полный аудит и разнести замечания по четырём категориям: значение по умолчанию, нарушающее смысл типа; метод, не выполняющий заявленного действия из-за значимой семантики; излишняя упаковка; неверная распаковка. Для каждого указать код ошибки либо исключение и объяснить, почему компилятор молчит там, где он молчит. Привести исправленную версию.

## Ожидаемый результат
Категории разнесены верно: элементы массива `wallet` имеют нулевую сумму и валюту `null`, поэтому первый вывод содержит `0,00` и пустое место — значение по умолчанию обходит конструктор; метод `AddBonus` получил **копию** структуры, и оклад остался `500000,00 UZS` — нужен модификатор `ref`; добавление структуры в `List<object>` выполняет упаковку трижды, чего можно избежать списком `List<Money>`; выражение `(long)boxed` компилируется, но даёт `InvalidCastException`, поскольку упакован был `int`, — правильная запись `(long)(int)boxed`.
