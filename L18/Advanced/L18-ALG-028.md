# L18-ALG-028. Структура или класс

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Для каждой из шести ситуаций выбрать структуру или класс и обосновать выбор, сославшись на условия из лекции: (а) точка на плоскости; (б) банковский счёт с историей операций; (в) денежная сумма с валютой; (г) студент с именем, группой и оценками; (д) цвет как тройка чисел от 0 до 255; (е) узел связного списка. Для двух ситуаций написать код объявления.

## Ожидаемый результат
Структура выбрана для (а), (в) и (д), класс — для (б), (г) и (е); для случая (е) отмечено, что узел содержит ссылку на такой же узел, что для значимого типа невозможно.
