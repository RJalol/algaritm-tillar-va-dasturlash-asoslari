# Разбор решения. L18-ALG-021. Пять нарушений в одном фрагменте

## Условие
Дан код:

```
class Demo
{
    public string Code { get; }
    public int Computed => 42;
    public Demo(string code) { Code = code; }

    public int F(int a)    { return a; }
    public double F(int a) { return a; }
}

class Amb
{
    public static void G(int a, double b) { }
    public static void G(double a, int b) { }
}

Demo d = new Demo("X");
d.Code = "Y";
d.Computed = 1;
Amb.G(1, 2);
```

Найти все нарушения, назвать код ошибки для каждого и разнести их по трём группам: невозможность различить перегрузки; невозможность выбрать перегрузку; присваивание тому, что присваивать нельзя. Привести исправленный фрагмент.

## Ожидаемый результат
Названы коды `CS0111`, `CS0121` и `CS0200` (дважды); группы разнесены верно; отмечено, что два случая `CS0200` различаются устройством свойства, но не кодом ошибки.

## Идея решения
Анализируем перегрузки (отличаются ли списки параметров, однозначен ли выбор) и присваивания свойствам без `set`.

## Решение
```csharp
// Исправленный фрагмент
class Demo
{
    public string Code { get; set; }               // добавлен set
    public int Computed => 42;
    public Demo(string code) { Code = code; }
    public int F(int a)       { return a; }
    public double F(double a) { return a; }       // другой список параметров
}
class Amb
{
    public static void G(int a, double b) { }
    public static void G(double a, int b) { }
}
Demo d = new Demo("X");
d.Code = "Y";
Amb.G(1, 2.0);                                   // однозначный выбор
```

## Пошаговое объяснение
1. Невозможность различить: `int F(int)` и `double F(int)` отличаются лишь типом результата (`CS0111`).
2. Невозможность выбрать: `Amb.G(1, 2)` подходит под обе перегрузки с одинаковой «стоимостью» преобразований (`CS0121`).
3. Присваивание недоступному: `d.Code = "Y"` — свойство `Code` без `set` (`CS0200`) и `d.Computed = 1` — вычисляемое свойство только для чтения (`CS0200`). Устройство различается (автосвойство без сеттера и свойство-выражение), код ошибки одинаков.

## Результат
Коды: CS0111, CS0121, CS0200 (дважды).
