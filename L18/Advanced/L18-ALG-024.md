# L18-ALG-024. Один код — два поведения

**Тема:** Л18 — Объявление структур. Значимые и ссылочные типы. Работа со структурами

## Условие
Написать программу, работающую с типом `Box`, содержащим единственное целое поле: создать значение, скопировать его во вторую переменную, изменить копию, передать исходное значение в метод, изменяющий поле, и после каждого шага вывести содержимое обеих переменных. Затем объявить `Box` **дважды** — как структуру и как класс — и запустить одну и ту же программу с каждым вариантом. Составить таблицу «шаг → результат для структуры → результат для класса» и объяснить каждое расхождение.

## Ожидаемый результат
Таблица содержит не менее трёх шагов; для структуры копия независима, а метод исходное значение не изменяет; для класса обе переменные ссылаются на один объект, и метод его изменяет; текст программы в обоих случаях одинаков.
