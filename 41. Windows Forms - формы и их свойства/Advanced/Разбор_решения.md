# Разбор решения. L41 · Задание III · №2. Форма входа

## Условие
Реализовать форму входа (логин/пароль), после успешной проверки открывается главная форма, а форма входа скрывается; три неудачные попытки закрывают приложение.

## Ожидаемый результат
Логика попыток и переходов работает.

## Разбор условия
**Дано:** форма входа.
**Требуется:** проверка логина и пароля; при успехе открыть главную форму, скрыв форму входа; три неудачные попытки закрывают приложение.

## Теоретическая справка
**Жизненный цикл приложения:** `Application.Run(form)` завершает работу, когда закрывается *форма, переданная в `Run`*. Если форма входа скрыта (`Hide`), а не закрыта, приложение продолжает работать. Поэтому при закрытии главной формы нужно закрыть и скрытую форму входа (или вызвать `Application.Exit()`).

Другие приёмы: `AcceptButton` (Enter вызывает «Войти»), `UseSystemPasswordChar` (маскирование пароля), счётчик попыток.

Безопасность: в реальных программах пароль не хранится в тексте и не сравнивается строкой; используют хэш с солью.

## Идея решения
Форма входа проверяет логин и пароль; после успеха скрывается и открывается главная форма. Счётчик неудачных попыток завершает приложение после третьей ошибки.

## Решение
```csharp
using System;
using System.Drawing;
using System.Windows.Forms;

public class LoginForm : Form
{
    private readonly TextBox _login = new TextBox { Left = 100, Top = 15, Width = 150 };
    private readonly TextBox _password = new TextBox { Left = 100, Top = 50, Width = 150, UseSystemPasswordChar = true };
    private int _attempts;

    public LoginForm()
    {
        Text = "Вход";
        Size = new Size(300, 170);
        StartPosition = FormStartPosition.CenterScreen;

        var ok = new Button { Text = "Войти", Left = 100, Top = 85, Width = 150 };
        ok.Click += OnLogin;
        AcceptButton = ok;

        Controls.AddRange(new Control[]
        {
            new Label { Text = "Логин:",  Left = 15, Top = 18, AutoSize = true },
            new Label { Text = "Пароль:", Left = 15, Top = 53, AutoSize = true },
            _login, _password, ok
        });
    }

    private void OnLogin(object sender, EventArgs e)
    {
        if (_login.Text == "admin" && _password.Text == "1234")
        {
            Hide();
            var main = new MainForm();
            main.FormClosed += (s, a) => Close();   // закрытие главной формы закрывает форму входа
            main.Show();
            return;
        }

        _attempts++;
        if (_attempts >= 3)
        {
            MessageBox.Show("Три неудачные попытки. Приложение будет закрыто.");
            Application.Exit();
        }
        else
        {
            MessageBox.Show($"Неверные данные. Осталось попыток: {3 - _attempts}");
        }
    }
}

public class MainForm : Form
{
    public MainForm()
    {
        Text = "Главная форма";
        Size = new Size(400, 250);
        Controls.Add(new Label { Text = "Добро пожаловать!", Left = 20, Top = 20, AutoSize = true });
    }
}

// Program.cs: Application.Run(new LoginForm());
```

## Пошаговое объяснение
1. Приложение запускается с `LoginForm`. Пароль скрывается свойством `UseSystemPasswordChar`.
2. Кнопка «Войти» назначена `AcceptButton`, поэтому Enter тоже запускает проверку.
3. При верных данных форма входа скрывается (`Hide`), открывается `MainForm`; когда главная форма закрывается, закрываем и скрытую форму входа, иначе процесс остался бы работать.
4. Счётчик `_attempts` увеличивается при каждой ошибке; после третьей приложение завершается `Application.Exit()`.
5. В учебном примере логин и пароль заданы константами; в реальной программе пароль не хранят открытым текстом (используют хэш).

## Трассировка и проверка
| Попытка | Ввод | Результат |
|--:|---|---|
| 1 | неверный | «Осталось попыток: 2» |
| 2 | неверный | «Осталось попыток: 1» |
| 3 | неверный | сообщение и `Application.Exit()` |
| любая | admin / 1234 | открывается `MainForm`, форма входа скрыта |

## Результат
Верные данные открывают главную форму; три ошибки подряд закрывают приложение с сообщением.

## Типичные ошибки
- Скрыть форму входа и не закрыть её — процесс останется в памяти.
- Хранить пароль в тексте программы в реальном приложении.
- Не сбрасывать счётчик попыток после успешного входа.
- Показывать причину ошибки подробно (логин верный/неверный) — подсказка злоумышленнику.
