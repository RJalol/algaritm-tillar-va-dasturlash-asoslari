# L41 · Задание I · №4. Событие Load формы

**Тема:** Л41 — Приложения Windows Forms. Свойства и события форм. Связывание форм

## Условие
В обработчике события `Load` формы вывести в заголовок текущую дату. В обработчике `FormClosing` запросить подтверждение закрытия (`MessageBox.Show` с кнопками Да/Нет).

## Ожидаемый результат
Дата отображается при запуске; закрытие отменяется при ответе «Нет».
