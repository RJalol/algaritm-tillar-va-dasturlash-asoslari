# L41 · Задание II · №5. Передача данных между формами

**Тема:** Л41 — Приложения Windows Forms. Свойства и события форм. Связывание форм

## Условие
Во второй форме ввести имя в `TextBox`; при закрытии передать его в главную форму через открытое свойство второй формы.

## Ожидаемый результат
Имя отображается в главной форме после закрытия второй.
