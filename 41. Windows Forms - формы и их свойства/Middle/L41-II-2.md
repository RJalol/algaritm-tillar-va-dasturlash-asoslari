# L41 · Задание II · №2. События мыши формы

**Тема:** Л41 — Приложения Windows Forms. Свойства и события форм. Связывание форм

## Условие
Выводить координаты указателя в заголовке формы по событию `MouseMove` и менять цвет фона по `MouseDown`/`MouseUp`.

## Ожидаемый результат
Координаты обновляются непрерывно, цвет меняется при нажатии.
