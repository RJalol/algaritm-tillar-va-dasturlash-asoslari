# L41 · Задание II · №3. События клавиатуры

**Тема:** Л41 — Приложения Windows Forms. Свойства и события форм. Связывание форм

## Условие
Обрабатывать нажатия клавиш на форме (`KeyDown`, свойство `KeyPreview`): стрелки двигают метку, `Escape` закрывает форму.

## Ожидаемый результат
Метка перемещается стрелками; `Esc` закрывает форму.
