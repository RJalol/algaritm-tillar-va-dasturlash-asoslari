# L39 · Задание II · №9. Словарь списков

**Тема:** Л39 — Списки и связанные списки в языке программирования C#

## Условие
Сгруппировать массив объектов собственного класса по значению одного из полей, построив словарь, значением в котором является список. Вывести каждую группу с числом элементов. Предусмотреть создание списка при первом появлении ключа.

## Ожидаемый результат
Группировка верна для данных не менее чем с тремя группами; при первом появлении ключа список создаётся, при последующих — дополняется; объяснено, почему здесь удобен `Try``Get``Value`.
