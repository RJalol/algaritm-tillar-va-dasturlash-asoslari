# Разбор решения. L39 · Задание II · №1. Подсчёт вхождений

## Условие
По массиву строк построить словарь «значение — сколько раз встретилось», пользуясь методом `TryGetValue`. Вывести результат, отсортированный по убыванию числа вхождений. Отдельно объяснить, почему при первом появлении ключа переменная получает ноль без всякой проверки.

## Ожидаемый результат
Подсчёт верен для данных не менее чем с тремя различными значениями и повторами; вывод упорядочен; объяснено поведение `TryGetValue` для отсутствующего ключа.

## Идея решения
Для подсчёта используем `Dictionary<string,int>`. `TryGetValue` возвращает `false` для отсутствующего ключа и записывает в выходной параметр значение по умолчанию (для `int` — 0), поэтому счётчик можно сразу увеличить на 1.

## Решение
```csharp
using System;
using System.Collections.Generic;
using System.Linq;

class Program
{
    static void Main()
    {
        string[] words = { "яблоко", "груша", "яблоко", "слива", "груша", "яблоко", "вишня" };

        var counts = new Dictionary<string, int>();
        foreach (string w in words)
        {
            counts.TryGetValue(w, out int n);      // n = 0, если ключа ещё нет
            counts[w] = n + 1;
        }

        foreach (var pair in counts.OrderByDescending(p => p.Value).ThenBy(p => p.Key))
            Console.WriteLine($"{pair.Key}: {pair.Value}");
    }
}
```

## Пошаговое объяснение
1. `TryGetValue(key, out value)` не бросает исключения: возвращает `true`/`false` и записывает значение в `value`.
2. Если ключа нет, в `n` записывается `default(int)`, то есть 0, — поэтому `counts[w] = n + 1` корректно создаёт запись со значением 1 без отдельной проверки `ContainsKey`.
3. Если ключ есть, в `n` попадает текущий счётчик, и он увеличивается на 1.
4. Вывод упорядочен по убыванию числа вхождений (`OrderByDescending`), при равенстве — по алфавиту (`ThenBy`).

## Результат
яблоко: 3 / груша: 2 / вишня: 1 / слива: 1
