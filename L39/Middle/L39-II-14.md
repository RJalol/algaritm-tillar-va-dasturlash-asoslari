# L39 · Задание II · №14. Пять структур на одних данных

**Тема:** Л39 — Списки и связанные списки в языке программирования C#

## Условие
По одному набору данных не менее чем из пятнадцати записей ответить на пять вопросов, применив пять разных структур: список, множество, словарь, очередь и стек. Для каждого вопроса указать, почему выбрана именно эта структура и почему остальные подходят хуже.

## Ожидаемый результат
Пять ответов получены; для каждого выбор обоснован по требуемой операции, а не по привычке; названо, какая структура была бы неверным выбором и почему.
