# Разбор решения. L39 · Задание I · №1. Первый список

## Условие
Создать список строк, заполнить его не менее чем шестью значениями и применить операции добавления в конец, вставки по индексу, удаления по значению и по индексу. После каждой операции выводить содержимое и значение `Count`. Отдельно вывести `Capacity` до и после заполнения.

## Ожидаемый результат
Содержимое после каждой операции соответствует ожидаемому; показано, что `Count` и `Capacity` различаются; объяснено, какое из двух чисел следует использовать в цикле.

## Идея решения
`List<T>` — динамический массив. `Count` — число элементов, `Capacity` — размер внутреннего массива (при переполнении удваивается). В циклах нужно использовать `Count`.

## Решение
```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Show(List<string> list, string action) =>
        Console.WriteLine($"{action,-28} [{string.Join(", ", list)}]  Count={list.Count}");

    static void Main()
    {
        var list = new List<string>();
        Console.WriteLine($"Capacity до заполнения: {list.Capacity}");

        foreach (string s in new[] { "один", "два", "три", "четыре", "пять", "шесть" })
            list.Add(s);
        Show(list, "Add (6 значений)");
        Console.WriteLine($"Capacity после заполнения: {list.Capacity}");

        list.Insert(2, "ДВА-ПОЛОВИНЫ");
        Show(list, "Insert(2, ...)");

        list.Remove("пять");
        Show(list, "Remove(\"пять\")");

        list.RemoveAt(0);
        Show(list, "RemoveAt(0)");
    }
}
```

## Пошаговое объяснение
1. Пустой `List<string>` имеет ёмкость 0; после первого `Add` она становится 4 и затем удваивается: 8 при добавлении пятого элемента (после шести добавлений `Capacity` = 8).
2. `Insert(2, ...)` вставляет значение по индексу, сдвигая остальные вправо; `Remove(значение)` удаляет первое вхождение; `RemoveAt(индекс)` — элемент по номеру.
3. `Count` отражает фактическое число элементов, `Capacity` — запас внутреннего массива; они различаются.
4. В цикле `for (int i = 0; i < list.Count; i++)` следует использовать `Count`: элементов с индексом от `Count` до `Capacity` в списке нет (обращение даст `ArgumentOutOfRangeException`).

## Результат
Capacity: 0, после шести добавлений — 8; Count после операций: 6, 7, 6, 5.
