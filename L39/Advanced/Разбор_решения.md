# Разбор решения. L39 · Задание III · №1. Учёт студентов

## Условие
Реализовать учёт студентов, поддерживающий одновременно: список всех записей в порядке поступления; словарь «номер зачётной книжки — студент» для быстрого поиска; множество групп; словарь «группа — список студентов». Все четыре хранилища должны оставаться согласованными при добавлении и удалении студента.

## Ожидаемый результат
Добавление и удаление изменяют все хранилища согласованно; поиск по номеру не требует перебора; для каждого хранилища указано, на какой вопрос оно отвечает.

## Идея решения
Четыре хранилища отвечают на разные вопросы: список — «в каком порядке поступали», словарь по номеру — «кто это» (поиск за O(1)), множество — «какие группы есть», словарь групп — «кто учится в группе». Чтобы они не расходились, все изменения проходят через два метода: `Add` и `Remove` — единственное место, где трогаются все четыре структуры.

## Решение
```csharp
using System;
using System.Collections.Generic;
using System.Linq;

record Student(string Id, string Name, string Group);

class Registry
{
    private readonly List<Student> _all = new();                           // порядок поступления
    private readonly Dictionary<string, Student> _byId = new();            // поиск по номеру
    private readonly HashSet<string> _groups = new();                      // множество групп
    private readonly Dictionary<string, List<Student>> _byGroup = new();   // состав групп

    public bool Add(Student s)
    {
        if (_byId.ContainsKey(s.Id)) return false;                         // номер уникален
        _all.Add(s);
        _byId[s.Id] = s;
        _groups.Add(s.Group);
        if (!_byGroup.TryGetValue(s.Group, out var list))
            _byGroup[s.Group] = list = new List<Student>();
        list.Add(s);
        return true;
    }

    public bool Remove(string id)
    {
        if (!_byId.Remove(id, out var s)) return false;
        _all.Remove(s);
        var list = _byGroup[s.Group];
        list.Remove(s);
        if (list.Count == 0)                                               // группа опустела
        {
            _byGroup.Remove(s.Group);
            _groups.Remove(s.Group);
        }
        return true;
    }

    public Student Find(string id) => _byId.TryGetValue(id, out var s) ? s : null;
    public IEnumerable<Student> InOrder() => _all;
    public IEnumerable<string> Groups => _groups.OrderBy(g => g);
    public IEnumerable<Student> Members(string group) =>
        _byGroup.TryGetValue(group, out var l) ? l : Enumerable.Empty<Student>();
}

class Program
{
    static void Main()
    {
        var r = new Registry();
        r.Add(new Student("A-001", "Азиз", "ТТ-11"));
        r.Add(new Student("A-002", "Дилноза", "ТТ-11"));
        r.Add(new Student("A-003", "Рустам", "ТТ-12"));

        Console.WriteLine(r.Find("A-003")?.Name);                          // поиск без перебора
        Console.WriteLine(string.Join(", ", r.Groups));                    // ТТ-11, ТТ-12
        Console.WriteLine(string.Join(", ", r.Members("ТТ-11").Select(s => s.Name)));

        r.Remove("A-003");                                                 // группа ТТ-12 исчезла
        Console.WriteLine(string.Join(", ", r.Groups));
        Console.WriteLine(r.Find("A-003") is null);
    }
}
```

## Пошаговое объяснение
1. Список `_all` хранит записи в порядке поступления (вопрос «в каком порядке»).
2. Словарь `_byId` даёт поиск по номеру зачётной книжки за константное время без перебора списка.
3. Множество `_groups` хранит уникальные группы; словарь `_byGroup` — состав каждой группы.
4. `Add` и `Remove` — единственные точки изменения: добавление пополняет все хранилища, удаление чистит все, а при удалении последнего студента группы удаляются её записи в `_byGroup` и `_groups`.
5. Дублирующий номер отклоняется до изменения любого хранилища — состояния остаются согласованными.
6. Выводы после операций: Рустам найден, группы «ТТ-11, ТТ-12»; после удаления — только «ТТ-11», а `Find("A-003")` возвращает `null`.

## Результат
Азиз и Дилноза остаются в ТТ-11, группа ТТ-12 после удаления Рустама исчезает из всех хранилищ; поиск по номеру не перебирает список.
