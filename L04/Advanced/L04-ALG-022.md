# L04-ALG-022. Цепочка инкрементов и декрементов

**Тема:** Л4 — Арифметические операции в C#. Операторы присваивания и структурированные (составные) присваивания

## Условие
Дан код:

```
int i = 4;
int r1 = i++;
int r2 = ++i;
int r3 = i--;
Console.WriteLine(r1);
Console.WriteLine(r2);
Console.WriteLine(r3);
Console.WriteLine(i);
```

Не запуская программу, определить все четыре выводимых значения. Для каждой из трёх операций отдельно указать, какое значение она вернула и каким стало значение переменной `i` после её выполнения. Затем проверить ответ запуском.

## Ожидаемый результат
Предсказанные значения `4`, `6`, `6`, `5` совпали с фактическим выводом; для каждого шага показано состояние переменной `i` до и после операции.
