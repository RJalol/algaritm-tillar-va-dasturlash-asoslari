# L04-ALG-029. Определение типа результата без запуска программы

**Тема:** Л4 — Арифметические операции в C#. Операторы присваивания и структурированные (составные) присваивания

## Условие
Для каждого из выражений определить тип его результата, не запуская программу:

```
7 / 2        7 / 2.0      7.0f / 2     7m / 2
s1 + s2      (где s1 и s2 объявлены как short)
ch + 1       (где ch объявлена как char)
```

Ответ по каждому выражению обосновать конкретным правилом: совпадением типов операндов, приведением к объемлющему типу либо правилом преобразования малых целочисленных типов. Проверить ответы с помощью `GetType()`.

## Ожидаемый результат
Шесть пар «выражение — тип»; для двух последних выражений указано, что результат имеет тип `int`, поскольку `short` и `char` не определяют бинарных арифметических операций и приводятся к `int`.
