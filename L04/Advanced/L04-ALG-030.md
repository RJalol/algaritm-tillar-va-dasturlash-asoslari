# L04-ALG-030. Полный аудит арифметического фрагмента

**Тема:** Л4 — Арифметические операции в C#. Операторы присваивания и структурированные (составные) присваивания

## Условие
Дан код:

```
using System;

namespace AuditDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            int totalSeconds = 3725;
            double hours = totalSeconds / 3600;
            byte counter = 250;
            counter = counter + 10;
            int divisor = 0;
            int result = 100 / divisor;
            Console.WriteLine(hours);
            Console.WriteLine(counter);
            Console.WriteLine(result);
        }
    }
}
```

Провести полный аудит и разнести замечания по трём категориям: ошибка, обнаруживаемая компилятором; ошибка, проявляющаяся только во время выполнения; логическая ошибка, которая не вызывает ни того ни другого, но даёт неверный результат. Для каждой категории указать конкретную строку и объяснить последствия.

Затем привести исправленную версию. **Внимание:** исправляя ошибку компиляции в строке с переменной `counter`, проверьте фактический результат — простейшее исправление устраняет сообщение компилятора, но порождает ошибку четвёртого рода. Объясните, какую именно, и предложите исправление, свободное от неё.

## Ожидаемый результат
Три категории замечаний разнесены верно: `CS0266` на строке со сложением `byte`; `DivideByZeroException` во время выполнения на делении на нулевую переменную; молчаливая логическая ошибка на вычислении `hours`, где целочисленное деление отбрасывает дробную часть до присваивания вещественной переменной. Отдельно отмечено, что замена на `counter += 10` снимает ошибку компиляции, но даёт `4` вместо `260` из-за молчаливого приведения к `byte`; корректное исправление изменяет тип переменной на вмещающий результат. Приведён итоговый код, компилирующийся и дающий верные значения.
