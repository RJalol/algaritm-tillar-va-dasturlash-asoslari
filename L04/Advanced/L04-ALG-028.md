# L04-ALG-028. Цепочка составных присваиваний с переполнением

**Тема:** Л4 — Арифметические операции в C#. Операторы присваивания и структурированные (составные) присваивания

## Условие
Дан код:

```
byte value = 100;
value += 100;
Console.WriteLine(value);
value += 100;
Console.WriteLine(value);
```

Не запуская программу, определить оба выводимых значения. Объяснить, почему фрагмент компилируется, несмотря на то что запись `value = value + 100` компилироваться не будет, и почему второй результат отличается от арифметической суммы. Проверить ответ запуском.

## Ожидаемый результат
Предсказанные значения `200` и `44` совпали с выводом; объяснено, что составное присваивание выполняет приведение к типу левого операнда автоматически и молча, а 300 в диапазон `byte` не помещается.
