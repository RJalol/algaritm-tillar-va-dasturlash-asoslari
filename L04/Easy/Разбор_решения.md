# Разбор решения. L04-ALG-001. Пять операций над одной парой чисел

## Условие
Написать программу, которая объявляет две целочисленные переменные со значениями 23 и 4 и выводит результаты всех пяти арифметических операций над ними, каждый на отдельной строке, в порядке: сумма, разность, произведение, частное, остаток.

## Ожидаемый результат
Пять строк со значениями `27`, `19`, `92`, `5`, `3`; частное получено целочисленным делением.

## Идея решения
Для двух целых чисел 23 и 4 вычисляем сумму, разность, произведение, целочисленное частное и остаток от деления.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        int a = 23;
        int b = 4;

        Console.WriteLine(a + b);
        Console.WriteLine(a - b);
        Console.WriteLine(a * b);
        Console.WriteLine(a / b);
        Console.WriteLine(a % b);
    }
}
```

## Пошаговое объяснение
1. `a + b = 27`, `a - b = 19`, `a * b = 92`.
2. Оба операнда типа `int`, поэтому `/` выполняет целочисленное деление: 23 / 4 = 5 (дробная часть отбрасывается).
3. Оператор `%` возвращает остаток: 23 − 4·5 = 3.

## Результат
Пять строк: 27, 19, 92, 5, 3.
