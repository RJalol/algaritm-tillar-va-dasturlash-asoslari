# L04-ALG-005. Инкремент как отдельный оператор

**Тема:** Л4 — Арифметические операции в C#. Операторы присваивания и структурированные (составные) присваивания

## Условие
Написать программу, которая объявляет целочисленную переменную-счётчик со значением 10, выводит её значение, затем трижды увеличивает её на единицу с помощью операции инкремента, выводя значение после каждого увеличения, и в конце один раз уменьшает с помощью декремента, снова выводя значение.

## Ожидаемый результат
Пять строк: `10`, `11`, `12`, `13`, `12`.
