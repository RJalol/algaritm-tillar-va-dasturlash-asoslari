# Разбор решения. L04-ALG-006. Обмен значений двух переменных

## Условие
Написать программу, которая объявляет две целочисленные переменные со значениями 15 и 40, выводит их, затем обменивает их значения, используя третью вспомогательную переменную, и выводит результат обмена.

## Ожидаемый результат
Четыре строки: сначала `15` и `40`, затем `40` и `15`; обмен выполнен через вспомогательную переменную.

## Идея решения
Чтобы обменять значения, одно из них нужно временно сохранить, иначе при первом присваивании оно будет потеряно.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        int x = 15;
        int y = 40;
        Console.WriteLine(x);
        Console.WriteLine(y);

        int temp = x;   // запоминаем x
        x = y;          // x получает значение y
        y = temp;       // y получает старое значение x

        Console.WriteLine(x);
        Console.WriteLine(y);
    }
}
```

## Пошаговое объяснение
1. Выводим исходные значения 15 и 40.
2. `temp = x` сохраняет 15 во вспомогательной переменной.
3. `x = y` записывает 40 в `x` — старое значение `x` уже сохранено, поэтому не потеряно.
4. `y = temp` записывает в `y` сохранённое 15.
5. Выводим значения после обмена.

## Результат
Четыре строки: 15, 40, затем 40, 15.
