# Разбор решения. L04-ALG-006. Обмен значений двух переменных

## Условие
Написать программу, которая объявляет две целочисленные переменные со значениями 15 и 40, выводит их, затем обменивает их значения, используя третью вспомогательную переменную, и выводит результат обмена.

## Ожидаемый результат
Четыре строки: сначала `15` и `40`, затем `40` и `15`; обмен выполнен через вспомогательную переменную.

## Разбор условия
**Дано:** переменные `x = 15` и `y = 40`.
**Требуется:** вывести их, обменять значения через вспомогательную переменную и вывести снова.
**Ограничение:** не использовать арифметические приёмы обмена без третьей переменной.

## Теоретическая справка
Присваивание `x = y` **заменяет** старое значение `x`. Поэтому, чтобы не потерять его, нужно сохранить копию.

Обмен через временную переменную — три присваивания в строгом порядке:

```
temp := x
x    := y
y    := temp
```

Аналогия: переливание жидкости между двумя стаканами требует третьего пустого сосуда.

## Идея решения
Чтобы обменять значения, одно из них нужно временно сохранить, иначе при первом присваивании оно будет потеряно.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        int x = 15;
        int y = 40;
        Console.WriteLine(x);
        Console.WriteLine(y);

        int temp = x;   // запоминаем x
        x = y;          // x получает значение y
        y = temp;       // y получает старое значение x

        Console.WriteLine(x);
        Console.WriteLine(y);
    }
}
```

## Пошаговое объяснение
1. Выводим исходные значения 15 и 40.
2. `temp = x` сохраняет 15 во вспомогательной переменной.
3. `x = y` записывает 40 в `x` — старое значение `x` уже сохранено, поэтому не потеряно.
4. `y = temp` записывает в `y` сохранённое 15.
5. Выводим значения после обмена.

## Трассировка и проверка
| Шаг | `x` | `y` | `temp` |
|---|---:|---:|---:|
| начало | 15 | 40 | — |
| `temp = x` | 15 | 40 | 15 |
| `x = y` | 40 | 40 | 15 |
| `y = temp` | 40 | 15 | 15 |

Нарушение порядка: если сначала выполнить `x = y; y = x;`, оба значения станут равны 40 — старое значение `x` потеряно.

## Результат
Четыре строки: 15, 40, затем 40, 15.

## Типичные ошибки
- Выполнить `x = y; y = x;` без временной переменной — значения совпадут.
- Переставить присваивания местами и потерять значение.
- Использовать временную переменную другого типа (например, `byte`) и потерять данные.
- Выводить значения до обмена после него.

## Задания для закрепления
- Обменять значения без третьей переменной арифметически (сумма и разность) и отметить риск переполнения.
- Обменять значения двух элементов массива.
- Реализовать циклический сдвиг трёх переменных: `a → b → c → a`.
