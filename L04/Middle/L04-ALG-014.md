# L04-ALG-014. Логическое значение в арифметическом выражении

**Тема:** Л4 — Арифметические операции в C#. Операторы присваивания и структурированные (составные) присваивания

## Условие
Дан код:

```
bool isReady = true;
int result = isReady + 1;
Console.WriteLine(result);
```

Определить, скомпилируется ли фрагмент, назвать код ошибки и объяснить причину. Указать, чем поведение C# в этом отношении отличается от языков, где логическое значение автоматически приравнивается к нулю или единице.

## Ожидаемый результат
Назван код `CS0019`; объяснено, что `bool` не относится к числовым типам и неявного преобразования к `int` в C# не существует.
