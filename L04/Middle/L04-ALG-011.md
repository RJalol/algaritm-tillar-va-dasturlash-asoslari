# L04-ALG-011. Предсказание результата инкремента

**Тема:** Л4 — Арифметические операции в языке C#. Операторы присваивания и составного присваивания. Перечисляемые типы (enum)

## Условие
Дан код:

```
int x = 5;
int a = x++;
int y = 5;
int b = ++y;
Console.WriteLine(a);
Console.WriteLine(x);
Console.WriteLine(b);
Console.WriteLine(y);
```

Не запуская программу, определить все четыре выводимых значения и объяснить каждое, опираясь на различие префиксной и постфиксной форм. После этого проверить ответ запуском.

## Ожидаемый результат
Четыре предсказанных значения совпали с фактическим выводом; для каждого дано объяснение, какое значение возвращает выражение и каким становится значение переменной.
