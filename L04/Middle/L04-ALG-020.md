# L04-ALG-020. Три способа получить вещественное частное

**Тема:** Л4 — Арифметические операции в C#. Операторы присваивания и структурированные (составные) присваивания

## Условие
Даны две целочисленные переменные со значениями 15 и 4. Написать программу, которая тремя различными выражениями вычисляет их частное с сохранением дробной части. Ни объявленный тип переменных, ни операцию явного преобразования типов (тема №6) использовать нельзя — разрешено изменять только само выражение. Вывести все три результата и в комментарии кратко описать каждый приём.

## Ожидаемый результат
Три одинаковых вещественных результата, равных `3,75`; в каждом выражении вещественным сделан один из операндов, из-за чего деление выполняется по правилам вещественной арифметики.
