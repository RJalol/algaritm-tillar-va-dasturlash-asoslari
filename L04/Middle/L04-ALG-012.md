# L04-ALG-012. Сложение переменных типа byte

**Тема:** Л4 — Арифметические операции в C#. Операторы присваивания и структурированные (составные) присваивания

## Условие
Дан код:

```
byte count = 10;
count = count + 5;
Console.WriteLine(count);
```

Определить, скомпилируется ли фрагмент. Назвать код ошибки, объяснить причину через правило преобразования операндов малых целочисленных типов и предложить исправление, не меняющее тип переменной.

## Ожидаемый результат
Указано, что фрагмент не компилируется (ошибка `CS0266`); объяснено, что результат сложения имеет тип `int`; предложена замена на составное присваивание.
