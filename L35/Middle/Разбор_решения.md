# Разбор решения. L35 · Задание II · №1. Обобщённый стек

## Условие
Реализовать обобщённый стек на массиве с операциями добавления, извлечения, просмотра вершины и получения числа элементов. Предусмотреть разумное поведение при извлечении из пустого стека. Проверить стек на числах, строках и объектах собственного класса.

## Ожидаемый результат
Один класс обслужил три типа; порядок «последним пришёл — первым вышел» соблюдён; извлечение из пустого стека обработано и не приводит к необработанному исключению.

## Разбор условия
**Дано:** потребность в стеке для разных типов.
**Требуется:** обобщённый стек на массиве с `Push`, `Pop`, `Peek`, `Count`; контролируемое поведение при пустом стеке; проверка на числах, строках и объектах класса.

## Теоретическая справка
**Динамический массив:** при заполнении создаётся массив вдвое большего размера, элементы копируются (`Array.Resize`). Амортизированная сложность добавления — O(1).

**Освобождение ссылок:** после `Pop` ячейка получает `default`, иначе массив продолжает удерживать ссылку, и сборщик мусора не освобождает объект (утечка).

**Поведение при ошибке:** на пустом стеке `Pop` бросает `InvalidOperationException`; безопасный вариант `TryPop(out T)` возвращает `false`. Выбор зависит от того, считается ли пустой стек ошибкой.

## Идея решения
Стек на массиве: массив хранит элементы, счётчик `Count` указывает на первую свободную ячейку. При переполнении массив удваивается; для пустого стека `Pop` возвращает контролируемую ошибку.

## Решение
```csharp
using System;

class MyStack<T>
{
    private T[] _items = new T[4];
    public int Count { get; private set; }

    public void Push(T item)
    {
        if (Count == _items.Length)
            Array.Resize(ref _items, _items.Length * 2);
        _items[Count++] = item;
    }

    public T Pop()
    {
        if (Count == 0)
            throw new InvalidOperationException("Стек пуст");
        T item = _items[--Count];
        _items[Count] = default;           // освобождаем ссылку для сборщика мусора
        return item;
    }

    public T Peek()
    {
        if (Count == 0)
            throw new InvalidOperationException("Стек пуст");
        return _items[Count - 1];
    }

    public bool TryPop(out T item)
    {
        if (Count == 0) { item = default; return false; }
        item = Pop();
        return true;
    }
}

class Program
{
    static void Main()
    {
        var ints = new MyStack<int>();
        for (int i = 1; i <= 6; i++) ints.Push(i);          // вызовет увеличение массива
        Console.WriteLine(ints.Pop() + " " + ints.Pop() + " (осталось " + ints.Count + ")");

        var words = new MyStack<string>();
        words.Push("один"); words.Push("два");
        Console.WriteLine(words.Peek());

        var empty = new MyStack<double>();
        Console.WriteLine(empty.TryPop(out double d) ? d.ToString() : "Стек пуст");
    }
}
```

## Пошаговое объяснение
1. Один класс `MyStack<T>` обслуживает числа, строки и объекты любого класса.
2. `Push` увеличивает массив вдвое при заполнении (`Array.Resize`), поэтому ёмкость не ограничена.
3. `Pop` и `Peek` на пустом стеке бросают понятное `InvalidOperationException`, а `TryPop` предоставляет вариант без исключения.
4. Записывая `default` на освобождённую позицию, мы не удерживаем ссылку на объект (важно для ссылочных типов).
5. Порядок LIFO проверяется: после 1…6 извлекаются 6 и 5, остаётся 4.

## Трассировка и проверка
Добавление 1…6 в стек с начальной ёмкостью 4:

| Шаг | Ёмкость | Count |
|---|--:|--:|
| Push 1–4 | 4 | 4 |
| Push 5 | 8 | 5 |
| Push 6 | 8 | 6 |
| Pop, Pop | 8 | 4 (извлечены 6 и 5) |

`TryPop` на пустом `MyStack<double>` возвращает `false` — исключения нет.

## Результат
6 5 (осталось 4) / два / Стек пуст

## Типичные ошибки
- Не увеличивать массив — `IndexOutOfRangeException`.
- Не очищать ячейку при `Pop`.
- Увеличивать массив на один элемент (квадратичная сложность).
- Использовать публичное поле `_items` и позволять менять стек извне.
