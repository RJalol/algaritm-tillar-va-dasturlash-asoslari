# Разбор решения. L30 · Задание I · №1. Запись текста в файл

## Условие
Записать в файл `notes.txt` три строки с помощью `File.WriteAllText` или `File.WriteAllLines`.

## Ожидаемый результат
Файл содержит три строки.

## Разбор условия
**Дано:** три строки.
**Требуется:** записать их в `notes.txt` через `File.WriteAllLines`, прочитать и вывести.

## Теоретическая справка
Для небольших текстовых файлов класс `File` предлагает методы «всё сразу»:

| Метод | Действие |
|---|---|
| `File.WriteAllText(path, text)` | записывает строку |
| `File.WriteAllLines(path, lines)` | записывает строки |
| `File.AppendAllText(path, text)` | дописывает |
| `File.ReadAllText(path)` | читает весь файл строкой |
| `File.ReadAllLines(path)` | читает строки в массив |

Методы сами открывают, читают/пишут и закрывают файл. Кодировка по умолчанию — UTF-8 (без метки порядка байтов при записи).

## Идея решения
Для небольших файлов удобны статические методы класса `File`: они сами открывают, записывают и закрывают файл.

## Решение
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string[] lines = { "Первая строка", "Вторая строка", "Третья строка" };
        File.WriteAllLines("notes.txt", lines);

        Console.WriteLine(File.ReadAllText("notes.txt"));
        Console.WriteLine("Строк в файле: " + File.ReadAllLines("notes.txt").Length);
    }
}
```

## Пошаговое объяснение
1. `File.WriteAllLines` записывает каждый элемент массива отдельной строкой и перезаписывает файл, если он существует.
2. Для записи единым текстом подходит `File.WriteAllText(path, text)`.
3. Проверка: чтение обратно возвращает три строки.

## Трассировка и проверка
| Вызов | Результат |
|---|---|
| `WriteAllLines("notes.txt", lines)` | файл из 3 строк |
| `ReadAllText(...)` | единая строка с переводами строк |
| `ReadAllLines(...).Length` | 3 |

Метод `WriteAllLines` перезаписывает файл; для добавления используют `File.AppendAllLines`.

## Результат
Файл notes.txt содержит три строки; чтение показывает их и число 3.

## Типичные ошибки
- Ожидать дозаписи от `WriteAllLines`.
- Читать огромные файлы `ReadAllText` — расход памяти.
- Не учитывать кодировку при обмене с другими программами.
- Использовать относительный путь, не зная текущего каталога.
