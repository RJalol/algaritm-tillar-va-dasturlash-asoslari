# L30 · Задание I · №1. Запись байтов в файл

**Тема:** Л30 — Потоки данных. Использование объекта FileStream для записи байтовых потоков в файл и чтения из файла. Чтение данных из текстовых файлов и запись в них

## Условие
Открыть `FileStream` в режиме `Create`, записать в него массив из пяти байтов и закрыть поток.

## Ожидаемый результат
Файл создан, его размер равен пяти байтам.
