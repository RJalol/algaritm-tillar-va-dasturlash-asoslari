# Разбор решения. L30 · Задание I · №1. Запись байтов в файл

## Условие
Открыть `FileStream` в режиме `Create`, записать в него массив из пяти байтов и закрыть поток.

## Ожидаемый результат
Файл создан, его размер равен пяти байтам.

## Разбор условия
**Дано:** массив из пяти байтов.
**Требуется:** записать его в файл через `FileStream` и вывести размер файла.

## Теоретическая справка
**Поток** (`Stream`) — абстракция последовательности байтов с чтением/записью. `FileStream` — поток, связанный с файлом.

Открытие: `new FileStream(путь, режим[, доступ[, совместное использование]])`.

| `FileMode` | Поведение |
|---|---|
| `Create` | создаёт новый файл или обнуляет существующий |
| `CreateNew` | ошибка, если файл существует |
| `Open` | открывает существующий (ошибка, если нет) |
| `OpenOrCreate` | открывает или создаёт |
| `Append` | дописывает в конец (только запись) |

`Write(buffer, offset, count)` записывает `count` байтов массива, начиная с `offset`. Поток нужно **закрыть** (`Close`/`Dispose`/`using`) — иначе данные могут остаться в буфере, а файл — заблокированным.

## Идея решения
`FileStream` работает с файлом как с потоком байтов. Режим `FileMode.Create` создаёт новый файл (или обнуляет существующий).

## Решение
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        byte[] data = { 10, 20, 30, 40, 50 };

        FileStream fs = new FileStream("bytes.bin", FileMode.Create);
        fs.Write(data, 0, data.Length);
        fs.Close();

        Console.WriteLine("Размер файла: " + new FileInfo("bytes.bin").Length + " байт");
    }
}
```

## Пошаговое объяснение
1. `new FileStream("bytes.bin", FileMode.Create)` открывает поток записи в файл.
2. `Write(buffer, offset, count)` записывает `count` байтов массива, начиная с позиции `offset`.
3. `Close()` сбрасывает буфер на диск и освобождает файл (надёжнее использовать `using`, см. следующие задания).
4. Размер файла проверяем через `FileInfo.Length`.

## Трассировка и проверка
| Шаг | Состояние |
|---|---|
| `FileMode.Create` | файл создан, длина 0 |
| `Write(data, 0, 5)` | записано 5 байтов |
| `Close()` | буфер сброшен на диск |
| `new FileInfo(...).Length` | 5 |

Повторный запуск не добавляет данные, а заменяет содержимое (режим `Create`).

## Результат
Размер файла: 5 байт

## Типичные ошибки
- Забыть закрыть поток — данные могут не попасть на диск.
- Использовать `Append` и ожидать перезаписи.
- Перепутать `offset` и `count`.
- Открыть уже занятый файл (`IOException`).
