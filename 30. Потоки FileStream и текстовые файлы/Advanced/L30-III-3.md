# L30 · Задание III · №3. Хранилище записей фиксированной длины

**Тема:** Л30 — Потоки данных. Использование объекта FileStream для записи байтовых потоков в файл и чтения из файла. Чтение данных из текстовых файлов и запись в них

## Условие
Реализовать хранение структур одинакового размера в файле с доступом по индексу через `Seek`.

## Ожидаемый результат
Любую запись можно прочитать и изменить без перезаписи всего файла.
