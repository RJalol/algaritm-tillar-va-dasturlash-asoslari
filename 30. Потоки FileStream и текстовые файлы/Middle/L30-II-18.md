# L30 · Задание II · №18. Сумма чисел из файла

**Тема:** Л30 — Потоки данных. Использование объекта FileStream для записи байтовых потоков в файл и чтения из файла. Чтение данных из текстовых файлов и запись в них

## Условие
В файле записаны целые числа по одному в строке. Вычислить их сумму, игнорируя некорректные строки.

## Ожидаемый результат
Сумма верна; число пропущенных строк выведено.
