# L30 · Задание II · №4. Чтение с конца файла

**Тема:** Л30 — Потоки данных. Использование объекта FileStream для записи байтовых потоков в файл и чтения из файла. Чтение данных из текстовых файлов и запись в них

## Условие
С помощью `Seek(-N, SeekOrigin.End)` прочитать последние N байтов файла.

## Ожидаемый результат
Выведены корректные последние N байтов.
