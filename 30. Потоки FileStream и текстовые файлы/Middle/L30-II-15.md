# L30 · Задание II · №15. MemoryStream как альтернатива

**Тема:** Л30 — Потоки данных. Использование объекта FileStream для записи байтовых потоков в файл и чтения из файла. Чтение данных из текстовых файлов и запись в них

## Условие
Записать данные в `MemoryStream`, затем сбросить их в файл методом `WriteTo`.

## Ожидаемый результат
Содержимое файла совпадает с данными потока.
