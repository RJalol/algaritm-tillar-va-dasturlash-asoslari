# L30 · Задание II · №21. Замена слова в файле

**Тема:** Л30 — Потоки данных. Использование объекта FileStream для записи байтовых потоков в файл и чтения из файла. Чтение данных из текстовых файлов и запись в них

## Условие
Заменить во всём файле одно слово другим и сохранить результат в новый файл.

## Ожидаемый результат
Все вхождения заменены; исходный файл не изменён.
