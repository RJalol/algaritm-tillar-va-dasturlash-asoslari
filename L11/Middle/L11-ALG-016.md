# L11-ALG-016. Попытка изменить символ строки

**Тема:** Л11 — Объявление и работа со строками. Форматирование строк

## Условие
Дан код:

```
string s = "abc";
s[0] = 'X';
int n = s.Length();
Console.WriteLine(s + n);
```

Объяснить, почему фрагмент не компилируется. Назвать код ошибки для каждой из двух строк и переписать фрагмент так, чтобы он выводил строку `Xbc` и её длину.

## Ожидаемый результат
Названы коды `CS0200` и `CS1955`; в исправленном варианте новая строка собрана конкатенацией, а `Length` записано без круглых скобок.
