# L11-ALG-006. Подсчёт гласных

**Тема:** Л11 — Объявление и работа со строками. Форматирование строк

## Условие
Написать программу, которая подсчитывает число гласных букв в слове `"Программирование"`. Список гласных задать строкой `"аеёиоуыэюя"` и сравнивать символы посимвольно, учитывая, что первая буква слова прописная. Вывести число гласных и общее число символов.

## Ожидаемый результат
Гласных `7` из `16` символов; проверка выполнена вложенным циклом по строке гласных, без методов класса `String`.
