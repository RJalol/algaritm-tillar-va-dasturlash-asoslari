# L11-ALG-009. Подсчёт вхождений символа

**Тема:** Л11 — Объявление и работа со строками. Форматирование строк

## Условие
Написать программу, которая подсчитывает, сколько раз заданный символ встречается в строке `"программирование"`, и выводит это число. Проверить работу для символов `'р'` и `'ф'`.

## Ожидаемый результат
Для `'р'` выведено `3`, для `'ф'` — `0`.
