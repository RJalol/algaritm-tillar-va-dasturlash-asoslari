# Разбор решения. L11 · Задание II · №1. Подсчёт цифр в строке

## Условие
Для строки `"a1b22c333"` подсчитать количество цифр, превратив строку в массив символов и использовав `char.IsDigit`.

## Ожидаемый результат
Результат: 6 цифр.

## Разбор условия
**Дано:** строка `"a1b22c333"`.
**Требуется:** подсчитать цифры, преобразовав строку в массив символов и использовав `char.IsDigit`.

## Теоретическая справка
Статические методы класса `char` проверяют категорию символа: `IsDigit`, `IsLetter`, `IsLetterOrDigit`, `IsWhiteSpace`, `IsUpper`, `IsLower`, `IsPunctuation`. Они учитывают Unicode, поэтому работают и для кириллицы.

`ToCharArray()` создаёт массив-копию символов строки. Строки неизменяемы, а массив `char[]` — изменяем; через него можно менять отдельные символы и затем собрать строку конструктором `new string(chars)`.

## Идея решения
Строку преобразуем в массив символов `ToCharArray()` и перебираем циклом `foreach`, проверяя каждый символ методом `char.IsDigit`.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        string text = "a1b22c333";
        char[] chars = text.ToCharArray();

        int count = 0;
        foreach (char c in chars)
        {
            if (char.IsDigit(c))
                count++;
        }

        Console.WriteLine("Цифр: " + count);
    }
}
```

## Пошаговое объяснение
1. `ToCharArray()` создаёт копию строки в виде массива `char[]`.
2. `foreach` перебирает символы по одному; переменная цикла доступна только для чтения.
3. `char.IsDigit(c)` истинно для десятичных цифр Unicode.
4. В строке `a1b22c333` цифры: 1, 2, 2, 3, 3, 3 — шесть штук.

## Трассировка и проверка
| Символ | `char.IsDigit` | count |
|:--:|:--:|--:|
| a | нет | 0 |
| 1 | да | 1 |
| b | нет | 1 |
| 2 | да | 2 |
| 2 | да | 3 |
| c | нет | 3 |
| 3, 3, 3 | да, да, да | 6 |

Ответ: 6.

## Результат
Цифр: 6

## Типичные ошибки
- Сравнивать символ с диапазоном `'0'..'9'` вручную с ошибкой в границах (проще `char.IsDigit`).
- Путать количество цифр и их сумму.
- Изменять `foreach`-переменную.
- Пытаться изменить символ строки напрямую (`s[0] = 'X'` — `CS0200`).
