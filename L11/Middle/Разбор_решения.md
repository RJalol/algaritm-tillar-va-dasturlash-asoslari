# Разбор решения. L11 · Задание II · №1. Подсчёт цифр в строке

## Условие
Для строки `"a1b22c333"` подсчитать количество цифр, превратив строку в массив символов и использовав `char.IsDigit`.

## Ожидаемый результат
Результат: 6 цифр.

## Идея решения
Строку преобразуем в массив символов `ToCharArray()` и перебираем циклом `foreach`, проверяя каждый символ методом `char.IsDigit`.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        string text = "a1b22c333";
        char[] chars = text.ToCharArray();

        int count = 0;
        foreach (char c in chars)
        {
            if (char.IsDigit(c))
                count++;
        }

        Console.WriteLine("Цифр: " + count);
    }
}
```

## Пошаговое объяснение
1. `ToCharArray()` создаёт копию строки в виде массива `char[]`.
2. `foreach` перебирает символы по одному; переменная цикла доступна только для чтения.
3. `char.IsDigit(c)` истинно для десятичных цифр Unicode.
4. В строке `a1b22c333` цифры: 1, 2, 2, 3, 3, 3 — шесть штук.

## Результат
Цифр: 6
