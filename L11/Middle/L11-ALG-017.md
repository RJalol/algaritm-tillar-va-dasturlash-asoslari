# L11-ALG-017. Обратная косая черта в литерале

**Тема:** Л11 — Объявление и работа со строками. Форматирование строк

## Условие
Дан код:

```
string path = "C:\Users\Student";
Console.WriteLine(path);
```

Определить, скомпилируется ли фрагмент, и назвать код ошибки. Привести **два** исправления — через обычный литерал и через дословный — и показать, что обе строки равны.

## Ожидаемый результат
Назван код `CS1009`; приведены варианты `"C:\\Users\\Student"` и `@"C:\Users\Student"`, сравнение которых даёт `True`.
