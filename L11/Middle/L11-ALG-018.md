# L11-ALG-018. Предсказание вывода: неизменяемость

**Тема:** Л11 — Объявление и работа со строками. Форматирование строк

## Условие
Дан код:

```
string first = "Алгоритм";
string second = first;
first = first + " и язык";
Console.WriteLine(first);
Console.WriteLine(second);
```

Не запуская программу, предсказать обе строки вывода. Затем запустить и объяснить результат через неизменяемость строк.

## Ожидаемый результат
Предсказано `Алгоритм и язык` и `Алгоритм`; объяснено, что операция `+` создала новый объект, а переменная `second` продолжает ссылаться на прежний.
