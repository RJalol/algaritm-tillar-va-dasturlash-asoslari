# L11-ALG-030. Полный аудит программы работы со строками

**Тема:** Л11 — Объявление и работа со строками. Форматирование строк

## Условие
Дан код:

```
using System;

namespace StringAudit
{
    class Program
    {
        static void Main(string[] args)
        {
            string title = "Отчёт";
            Console.WriteLine("Итог: " + 2 + 3);

            string? note = null;
            Console.WriteLine(note.Length);

            for (int i = 0; i <= title.Length; i++)
            {
                Console.WriteLine(title[i]);
            }

            Console.WriteLine(string.Format("{0} за {1}", title));

            double share = 0.5;
            Console.WriteLine(share.ToString("D2"));
        }
    }
}
```

Провести полный аудит и разнести замечания по четырём категориям: логическая ошибка порядка операций; обращение к отсутствующему объекту; выход за границы строки; несоответствие между форматом и аргументами. Отдельно указать строку, в которой ошибка проявляется только во время выполнения из-за неприменимости описателя формата. Для каждого замечания назвать тип исключения либо код ошибки и привести исправленную версию.

## Ожидаемый результат
Категории разнесены верно: `"Итог: " + 2 + 3` даёт `Итог: 23` вместо `Итог: 5`; обращение `note.Length` даёт `NullReferenceException`; знак `<=` в цикле даёт `IndexOutOfRangeException`; элемент `{1}` без второго аргумента даёт `FormatException`; описатель `D2`, применённый к `double`, также даёт `FormatException`, поскольку `D` применим только к целочисленным типам. Ни одно из пяти нарушений не обнаруживается компилятором. Приведён исправленный код.
