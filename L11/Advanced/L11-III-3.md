# L11 · Задание III · №3. Проверка паролей

**Тема:** Л11 — Символьные типы и работа с массивами символов. Стандартные методы обработки символов

## Условие
Проверить пароль по правилам: длина не менее 8, есть заглавная и строчная буквы, цифра и спецсимвол. Вывести перечень нарушенных правил.

## Ожидаемый результат
Для `"Abc12345"` нарушено требование спецсимвола; для `"Abc123!x"` нарушений нет.
