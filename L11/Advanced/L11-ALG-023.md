# L11-ALG-023. Шифр Цезаря

**Тема:** Л11 — Объявление и работа со строками. Форматирование строк

## Условие
Написать программу, которая шифрует строку из строчных латинских букв, заменяя каждую букву на отстоящую от неё на три позиции вперёд по алфавиту, причём после `z` счёт продолжается с `a`. Затем расшифровать полученную строку и убедиться, что исходная восстановлена. Проверить на строке `"attackatdawn"`. Циклический переход обеспечить операцией взятия остатка, а не проверками условий.

## Ожидаемый результат
Зашифрованная строка — `dwwdfndwgdzq`, расшифрованная совпадает с исходной `attackatdawn`; смещение вычислено выражением вида `(s[i] - 'a' + 3) % 26`.
