# Разбор решения. L11 · Задание I · №1. Тип char

## Условие
Объявить переменные типа `char` с буквой, цифрой и знаком препинания. Вывести каждый символ и его числовой код (приведением к `int`).

## Ожидаемый результат
Для `'A'` код 65, для `'0'` код 48, для `'!'` код 33; символы выведены в одинарных кавычках.

## Разбор условия
**Дано:** три символа — буква, цифра, знак препинания.
**Требуется:** вывести каждый символ и его числовой код.

## Теоретическая справка
Тип `char` хранит один символ в кодировке Unicode (UTF-16), занимает 16 бит. Символ — не число, но каждому символу соответствует целочисленный **код**; `char` неявно преобразуется в `int`, а обратное преобразование требует явного приведения.

Коды удобно запомнить: цифры идут подряд `'0'`=48 … `'9'`=57; прописные латинские буквы `'A'`=65 … `'Z'`=90; строчные `'a'`=97 … `'z'`=122. Разница кодов прописной и строчной буквы равна 32.

## Идея решения
Тип `char` хранит один символ Unicode (16 бит). Приведение к `int` даёт числовой код символа.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        char letter = 'A';
        char digit = '0';
        char sign = '!';

        Console.WriteLine(letter + " " + (int)letter);
        Console.WriteLine(digit + " " + (int)digit);
        Console.WriteLine(sign + " " + (int)sign);
    }
}
```

## Пошаговое объяснение
1. Литерал `char` записывается в одинарных кавычках.
2. `(int)letter` — явное приведение; код латинской `A` равен 65.
3. Цифра `'0'` имеет код 48, а не 0: это символ, а не число. Поэтому значение цифры получают вычитанием `'0'`.
4. Знак `!` имеет код 33.
5. Склейка `letter + " " + (int)letter` приводит всё к строке: сначала `char` превращается в строку, затем присоединяется число.

## Трассировка и проверка
| Символ | Тип | Код |
|:--:|---|--:|
| `'A'` | `char` | 65 |
| `'0'` | `char` | 48 |
| `'!'` | `char` | 33 |

Значение цифры получается вычитанием: `'7' - '0' = 7`. Выражение `'A' + 1` имеет тип `int` (66); чтобы получить `'B'`, нужно приведение `(char)('A' + 1)`.

## Результат
A 65 / 0 48 / ! 33

## Типичные ошибки
- Путать символ `'0'` и число 0.
- Записывать `char` в двойных кавычках (это строка).
- Складывать `char` и строку, ожидая арифметику.
- Забывать, что `char + int` даёт `int`.
