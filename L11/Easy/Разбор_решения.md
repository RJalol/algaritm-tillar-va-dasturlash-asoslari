# Разбор решения. L11-ALG-001. Длина строки и её крайние символы

## Условие
Написать программу, которая объявляет строку со значением `"Программирование"` и выводит её саму, её длину, первый символ и последний символ. Индекс последнего символа получить через свойство `Length`, а не записывать числом.

## Ожидаемый результат
Выведены строка, длина `16`, первый символ `П` и последний символ `е`; индекс последнего символа записан выражением `Length - 1`.

## Идея решения
Строка — последовательность символов с индексацией с нуля. Длину получаем свойством `Length`, последний символ — по индексу `Length - 1`.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        string word = "Программирование";

        Console.WriteLine(word);
        Console.WriteLine(word.Length);
        Console.WriteLine(word[0]);
        Console.WriteLine(word[word.Length - 1]);
    }
}
```

## Пошаговое объяснение
1. `word.Length` равно 16 — число символов.
2. `word[0]` — первый символ `П` (индексы начинаются с 0).
3. Последний индекс равен `Length - 1 = 15`, символ `е`.
4. Запись `Length - 1` вместо числа 15 работает для любой строки.

## Результат
Программирование / 16 / П / е
