# L11-ALG-005. Первое знакомство с интерполяцией

**Тема:** Л11 — Объявление и работа со строками. Форматирование строк

## Условие
Написать программу, которая объявляет строку с именем и целую переменную с возрастом, после чего одним оператором вывода с интерполяцией выводит предложение вида «Меня зовут …, мне … лет, через год будет …». Значение «через год» вычислить **внутри** интерполяции, не заводя отдельной переменной.

## Ожидаемый результат
Выведено одно предложение со всеми тремя значениями; третье получено выражением вида `{age + 1}` непосредственно в интерполированной строке.
