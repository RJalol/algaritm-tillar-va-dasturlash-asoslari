# Разбор решения. L35 · Задание I · №1. Первый обобщённый класс

## Условие
Объявить обобщённый класс «коробка» с одним параметром типа, хранящий одно значение, свойство только для чтения и метод вывода сведений. Создать три объекта с разными аргументами типа: целое число, строка и объект собственного класса. Вывести содержимое каждой коробки.

## Ожидаемый результат
Один и тот же класс обслужил три разных типа; ни одного приведения в вызывающем коде нет; попытка положить в коробку для чисел строку не компилируется и даёт `CS1503`.

## Разбор условия
**Дано:** три разных значения: число, строка, объект собственного класса.
**Требуется:** обобщённый класс `Box<T>` и три коробки с разными аргументами типа.

## Теоретическая справка
**Обобщения (generics)** позволяют писать код, параметризованный типом: `class Box<T>`. При использовании вместо `T` подставляется конкретный тип (`Box<int>`).

Преимущества перед хранением `object`:

- **безопасность типов** — ошибки обнаруживаются при компиляции (`CS1503`);
- **отсутствие приведений** и упаковки значимых типов;
- **повторное использование кода** — один класс вместо набора копий.

`typeof(T)` позволяет получить сведения о типе во время выполнения.

## Идея решения
Обобщённый класс `Box<T>` содержит параметр типа `T`; при создании объекта вместо `T` подставляется конкретный тип, и компилятор проверяет его на этапе компиляции.

## Решение
```csharp
using System;

class Box<T>
{
    public T Value { get; }
    public Box(T value) { Value = value; }

    public void Print() => Console.WriteLine($"Коробка<{typeof(T).Name}>: {Value}");
}

class Student
{
    public string Name { get; }
    public Student(string name) { Name = name; }
    public override string ToString() => "Студент " + Name;
}

class Program
{
    static void Main()
    {
        var numbers = new Box<int>(42);
        var text = new Box<string>("привет");
        var student = new Box<Student>(new Student("Азиз"));

        numbers.Print();
        text.Print();
        student.Print();

        int n = numbers.Value;           // приведение не требуется

        // numbers = new Box<int>("abc");   // CS1503: string нельзя преобразовать в int
    }
}
```

## Пошаговое объяснение
1. `class Box<T>` — «шаблон» класса; `T` в нём — заглушка для типа.
2. `Box<int>`, `Box<string>`, `Box<Student>` — три разных конструктивных типа, созданных из одного кода.
3. Свойство `Value` возвращает именно `T`, поэтому `int n = numbers.Value;` не требует приведения (в отличие от класса, хранящего `object`).
4. Попытка положить строку в коробку для чисел отвергается компилятором (`CS1503`) — безопасность типов проверяется до запуска.

## Трассировка и проверка
| Объект | Конструктивный тип | Вывод |
|---|---|---|
| `new Box<int>(42)` | Box<int> | Коробка<Int32>: 42 |
| `new Box<string>("привет")` | Box<string> | Коробка<String>: привет |
| `new Box<Student>(…)` | Box<Student> | Коробка<Student>: Студент Азиз |

Попытка `new Box<int>("abc")` — `CS1503` на этапе компиляции.

## Результат
Три коробки с разными типами выводят свои значения; присваивание строки в Box<int> не компилируется (CS1503).

## Типичные ошибки
- Использовать `object` вместо обобщения и терять безопасность типов.
- Забыть, что `Box<int>` и `Box<string>` — разные типы.
- Вызывать на значении `T` члены, не гарантированные ограничениями (`CS1061`).
- Создавать `T` через `new T()` без ограничения `where T : new()`.
