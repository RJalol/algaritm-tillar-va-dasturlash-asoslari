# L35 · Задание I · №3. Обобщённый метод и вывод типа

**Тема:** Л35 — Обобщённые типы и наследование в обобщённых типах. Обобщённые классы и работа с объектами классов

## Условие
Написать обобщённый метод обмена значений двух переменных и обобщённый метод вывода всех элементов массива. Вызвать оба для массивов трёх разных типов, один раз указав аргумент типа явно, остальные разы — положившись на вывод компилятором.

## Ожидаемый результат
Оба метода работают для всех трёх типов; показано, что явная и выводимая формы вызова дают одинаковый результат; объяснено, из чего компилятор вывел аргумент типа.
