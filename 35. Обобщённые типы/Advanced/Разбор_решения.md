# Разбор решения. L35 · Задание III · №1. Обобщённая библиотека структур данных

## Условие
Собрать библиотеку классов (тема №27) из трёх обобщённых структур данных — стек, очередь и упорядоченный набор без повторов — и приложение, проверяющее их работу не менее чем на трёх различных аргументах типа каждая. Для набора применить ограничение интерфейсом сравнения.

## Ожидаемый результат
Библиотека собрана отдельным проектом и подключена к приложению; все три структуры проверены; ограничения выбраны по правилу «максимально сильное из допустимых» и выбор обоснован для каждой структуры.

## Разбор условия
**Дано:** три структуры данных.
**Требуется:** библиотека из `MyStack<T>`, `MyQueue<T>` и `OrderedSet<T>`; приложение проверяет каждую не менее чем на трёх типах; для набора — ограничение интерфейсом сравнения; обоснование ограничений.

## Теоретическая справка
**Ограничения типа (`where`)** сообщают компилятору, что `T` обладает нужными членами: `where T : IComparable<T>`, `class`, `struct`, `new()`.

**Правило выбора:** налагать *минимально необходимые* ограничения — ровно те, без которых код не скомпилируется. Лишние ограничения сужают применимость; недостающие — не дают пользоваться нужными членами.

| Структура | Нужно ли сравнение? | Ограничение |
|---|:--:|---|
| стек | нет | нет |
| очередь | нет | нет |
| упорядоченный набор | да (порядок и повторы) | `IComparable<T>` |

Двоичный поиск места вставки даёт O(log n) на поиск и O(n) на вставку.

## Идея решения
Библиотека `DataStructures` содержит `MyStack<T>`, `MyQueue<T>` и `OrderedSet<T>`. Для набора, которому нужно сравнение, накладываем ограничение `where T : IComparable<T>` — «максимально сильное из допустимых» (только то, что действительно используется); для стека и очереди ограничения не нужны.

## Решение
```csharp
using System;
using System.Collections.Generic;

namespace DataStructures                                          // библиотека классов
{
    public class MyStack<T>                                       // без ограничений: хранит любые значения
    {
        private readonly List<T> _items = new List<T>();
        public int Count => _items.Count;
        public void Push(T x) => _items.Add(x);
        public T Pop()
        {
            if (_items.Count == 0) throw new InvalidOperationException("Стек пуст");
            T x = _items[^1]; _items.RemoveAt(_items.Count - 1); return x;
        }
    }

    public class MyQueue<T>                                       // без ограничений
    {
        private readonly LinkedList<T> _items = new LinkedList<T>();
        public int Count => _items.Count;
        public void Enqueue(T x) => _items.AddLast(x);
        public T Dequeue()
        {
            if (_items.Count == 0) throw new InvalidOperationException("Очередь пуста");
            T x = _items.First.Value; _items.RemoveFirst(); return x;
        }
    }

    public class OrderedSet<T> where T : IComparable<T>           // нужно сравнение элементов
    {
        private readonly List<T> _items = new List<T>();
        public int Count => _items.Count;

        public bool Add(T x)
        {
            int lo = 0, hi = _items.Count - 1;
            while (lo <= hi)                                      // двоичный поиск места вставки
            {
                int mid = (lo + hi) / 2;
                int c = x.CompareTo(_items[mid]);
                if (c == 0) return false;                         // повтор — не добавляем
                if (c < 0) hi = mid - 1; else lo = mid + 1;
            }
            _items.Insert(lo, x);
            return true;
        }

        public IEnumerable<T> Items => _items;
    }
}

class Program                                                      // приложение
{
    static void Main()
    {
        var si = new DataStructures.MyStack<int>(); si.Push(1); si.Push(2);
        var ss = new DataStructures.MyStack<string>(); ss.Push("a"); ss.Push("b");
        var sd = new DataStructures.MyStack<double>(); sd.Push(1.5);
        Console.WriteLine(si.Pop() + " " + ss.Pop() + " " + sd.Pop());

        var qi = new DataStructures.MyQueue<int>(); qi.Enqueue(7); qi.Enqueue(8);
        var qs = new DataStructures.MyQueue<string>(); qs.Enqueue("x"); qs.Enqueue("y");
        var qd = new DataStructures.MyQueue<DateTime>(); qd.Enqueue(new DateTime(2026, 1, 1));
        Console.WriteLine(qi.Dequeue() + " " + qs.Dequeue() + " " + qd.Dequeue().Year);

        var oi = new DataStructures.OrderedSet<int>();
        foreach (int x in new[] { 5, 1, 3, 3, 9, 1 }) oi.Add(x);
        var os = new DataStructures.OrderedSet<string>();
        foreach (string x in new[] { "ёлка", "арбуз", "мир", "арбуз" }) os.Add(x);
        var od = new DataStructures.OrderedSet<double>();
        foreach (double x in new[] { 2.5, 0.5, 2.5 }) od.Add(x);

        Console.WriteLine(string.Join(", ", oi.Items));    // 1, 3, 5, 9
        Console.WriteLine(string.Join(", ", os.Items));    // арбуз, ёлка, мир
        Console.WriteLine(string.Join(", ", od.Items));    // 0,5, 2,5
    }
}
```

## Пошаговое объяснение
1. Библиотека оформляется как отдельный проект («Библиотека классов»), а приложение добавляет на неё ссылку (тема №27); приведённый листинг показывает обе части.
2. `MyStack<T>` и `MyQueue<T>` ничего не делают со значениями, кроме хранения, — поэтому ограничения не нужны, и они работают с любым `T` (включая структуры и `DateTime`).
3. `OrderedSet<T>` должен упорядочивать и обнаруживать повторы, значит ему нужно сравнивать элементы: ограничение `where T : IComparable<T>` — минимальное необходимое. Более сильные ограничения (например, `class`) только сузили бы применимость.
4. Двоичный поиск находит позицию вставки за O(log n) и даёт отказ при повторе, сохраняя упорядоченность.
5. Каждая структура проверена на трёх разных аргументах типа (int, string, double/DateTime).

## Трассировка и проверка
Проверки приложения:

| Структура | Тип 1 | Тип 2 | Тип 3 |
|---|---|---|---|
| MyStack | int | string | double |
| MyQueue | int | string | DateTime |
| OrderedSet | int | string | double |

Результат для набора `{5,1,3,3,9,1}` — `1, 3, 5, 9` (повторы отброшены, порядок возрастающий).

## Результат
Выведено: «2 b 1,5», «7 x 2026», «1, 3, 5, 9», «арбуз, ёлка, мир», «0,5, 2,5».

## Типичные ошибки
- Требовать `IComparable<T>` у стека — лишнее ограничение.
- Использовать неабстрактный `IComparable` вместо `IComparable<T>` (упаковка).
- Сравнивать элементы операцией `<` (для `T` она недоступна).
- Забыть проверку повторов.
