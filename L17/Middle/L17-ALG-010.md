# L17-ALG-010. Цепочка конструкторов

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Переписать класс задания ALG-003 так, чтобы поля заполнялись **только** в конструкторе с двумя параметрами, а два остальных вызывали его записью `: this(...)`. Затем добавить в конструктор с двумя параметрами проверку «сторона положительна, иначе единица» и убедиться, что она действует при создании объекта любым из трёх способов.

## Ожидаемый результат
Все три способа создания дают прежние размеры; после добавления проверки объект `new Rect(-3, 5)` получил размеры `1x5`; проверка записана в одном месте.
