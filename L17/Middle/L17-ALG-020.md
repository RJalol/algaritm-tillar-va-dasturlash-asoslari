# L17-ALG-020. Рекурсивное свойство

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Дан код:

```
public int Score
{
    get { return Score; }
    set { Score = value; }
}
```

**Запускать не следует.** Определить, скомпилируется ли фрагмент, и предсказать, что произойдёт при первом обращении к свойству. Назвать вид ошибки и объяснить связь с темой №14. Привести исправление.

## Ожидаемый результат
Фрагмент компилируется без ошибок и предупреждений; при обращении процесс завершается сообщением `Stack overflow.`; ошибка — рекурсия без базового случая; в исправлении методы доступа обращаются к отдельному полю-хранилищу.
