# L17-ALG-018. Неоднозначный вызов

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Дан код:

```
public static void G(int a, double b) { }
public static void G(double a, int b) { }

G(1, 2);
```

Назвать код ошибки, объяснить, почему ни одна перегрузка не подходит лучше другой, и привести два исправления: явным приведением одного аргумента и удалением одной из перегрузок.

## Ожидаемый результат
Назван код `CS0121`; в первом исправлении один аргумент записан как `1.0` или `2.0`, что делает выбор однозначным.
