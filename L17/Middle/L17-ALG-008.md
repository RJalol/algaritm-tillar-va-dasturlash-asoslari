# L17-ALG-008. Свойство только для чтения

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Объявить класс с двумя свойствами, объявленными как `{ get; }`, и конструктором, задающим их. Создать объект и вывести оба свойства. Затем добавить строку, присваивающую одному из них новое значение вне класса, определить код ошибки и объяснить, почему конструктору присваивать разрешено.

## Ожидаемый результат
Оба свойства выведены; присваивание извне даёт `CS0200`; объяснено, что автоматическое свойство без `set` присваивается только из конструкторов типа.
