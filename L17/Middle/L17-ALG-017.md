# L17-ALG-017. Вызов метода экземпляра через имя класса

**Тема:** Л17 — Создание классов и их объектов. Принципы объектно-ориентированного программирования (ООП). Поля, методы и конструкторы классов и объектов

## Условие
Дан код:

```
Console.WriteLine(Student.IsExcellent());
```

где `IsExcellent` — метод экземпляра класса `Student`. Назвать код ошибки, объяснить причину и привести исправление. Указать, чем этот случай отличается от вызова `Math.Sqrt(2)`.

## Ожидаемый результат
Назван код `CS0120`; в исправлении метод вызывается на объекте; объяснено, что `Math.Sqrt` — статический метод, а тема статических членов — №20.
