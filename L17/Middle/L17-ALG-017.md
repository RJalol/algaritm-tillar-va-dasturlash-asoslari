# L17-ALG-017. Перегрузка по именам параметров

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Дан код:

```
public Ctor(int x) { X = x; }
public Ctor(int y) { X = y; }
```

Определить, скомпилируется ли класс, назвать код ошибки и объяснить, какие части объявления образуют то, чем различаются перегрузки.

## Ожидаемый результат
Назван код `CS0111`; объяснено, что различают перегрузки **типы** параметров и их число, но не имена.
