# L17-ALG-016. Перегрузка по типу результата

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Дан код:

```
public int F(int a)    { return a; }
public double F(int a) { return a; }
```

Назвать код ошибки и объяснить причину запрета, рассмотрев вызов, результат которого не используется. Привести два исправления: переименованием и изменением списка параметров.

## Ожидаемый результат
Назван код `CS0111`; объяснено, что по вызову `F(1);` без присваивания невозможно определить, какой метод имелся в виду.
