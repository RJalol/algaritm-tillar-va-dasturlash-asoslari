# L17-ALG-019. Присваивание свойству только для чтения

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Для класса со свойствами `public string Code { get; }` и `public int Computed => 42;` даны присваивания `d.Code = "Y";` и `d.Computed = 1;`. Назвать код ошибки для каждого и объяснить, чем эти два свойства различаются по внутреннему устройству, хотя ошибка одинакова.

## Ожидаемый результат
Оба присваивания дают `CS0200`; объяснено, что у первого свойства хранилище есть и присваивать его может конструктор, а у второго хранилища нет вовсе.
