# L17-ALG-014. Метод Main и аргументы командной строки

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Написать программу, выводящую число аргументов командной строки и каждый из них с порядковым номером. Запустить её без аргументов и с тремя аргументами (командой `dotnet run -- a b c`). Объяснить в комментарии, почему цикл по массиву `args` безопасен без проверки на `null`.

## Ожидаемый результат
Без аргументов выведено `0` и ни одной строки; с тремя — `3` и три пронумерованные строки; в комментарии указано, что `args` никогда не равен `null`, а при отсутствии аргументов его длина равна нулю.
