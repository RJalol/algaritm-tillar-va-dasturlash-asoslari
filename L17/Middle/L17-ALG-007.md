# L17-ALG-007. Вычисляемое свойство

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Дополнить класс задания ALG-006 двумя вычисляемыми свойствами: логическим «отличник ли» (балл не менее 90) и строковым «карточка» вида «Имя (группа): балл». Хранилища для них не заводить. Изменить имя и балл объекта и убедиться, что оба свойства отражают изменения.

## Ожидаемый результат
После изменения полей карточка содержит новые значения; вычисляемые свойства записаны в виде выражения через `=>` и хранилища не имеют.
