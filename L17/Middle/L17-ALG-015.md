# L17-ALG-015. Возвращаемое значение метода Main

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Переписать метод `Main` так, чтобы он возвращал `int`: нуль при успешной работе и единицу, если аргументов командной строки не передано. Проверить код завершения после каждого запуска (в PowerShell — переменная `$LastExitCode`).

## Ожидаемый результат
Запуск без аргументов даёт код завершения `1`, с аргументами — `0`; объяснено, что нулевое значение принято обозначать успешное завершение.
