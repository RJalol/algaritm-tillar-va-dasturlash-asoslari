# Разбор решения. L17-ALG-021. Пять нарушений в одном фрагменте

## Условие
Дан код:

```
class Student
{
    public string Name;
    public int Score;
    public Student(string name, int score) { Name = name; Score = score; }
    public bool IsExcellent() { return Score >= 90; }
}

Student a = new Student("Азиз");
Student b = new Student("Азиз", 87);
Console.WriteLine(b.Age);
Console.WriteLine(Student.IsExcellent());
Student c;
Console.WriteLine(c.Name);
Student d = new Student("A", 1);
d.Score = "много";
```

Найти все нарушения, назвать код ошибки для каждого и разнести их по трём группам: несоответствие вызова конструктора объявленному; обращение к члену класса неверным образом; ошибка при использовании переменной. Привести исправленный фрагмент.

## Ожидаемый результат
Названы коды `CS7036`, `CS1061`, `CS0120`, `CS0165` и `CS0029`; группы разнесены верно.

## Разбор условия
**Дано:** класс `Student` и девять строк использования.
**Требуется:** найти пять нарушений и назвать коды (`CS7036`, `CS1061`, `CS0120`, `CS0165`, `CS0029`), разнести по трём группам.

## Теоретическая справка
Группы ошибок:

1. **Вызов конструктора.** Должен соответствовать одному из объявленных: у `Student(string, int)` нельзя вызвать `Student("Азиз")` (`CS7036`).
2. **Обращение к члену.** Члена `Age` в классе нет (`CS1061`); метод экземпляра нельзя вызывать от имени класса (`CS0120`).
3. **Использование переменной.** Локальная ссылка должна быть присвоена до использования (`CS0165`); присваивание значения неверного типа полю — `CS0029`.

Различайте: ссылка *присвоена* (`Student c = null;`) и объект *создан* (`new`). Использование `null`-ссылки — ошибка времени выполнения (`NullReferenceException`), а использование неприсвоенной — ошибка компиляции.

## Идея решения
Проверяем вызовы конструктора, обращение к членам и использование переменных.

## Решение
```csharp
// Исправленный фрагмент
Student a = new Student("Азиз", 80);          // конструктор требует два аргумента
Student b = new Student("Азиз", 87);
Console.WriteLine(b.Score);                   // поля Age нет
Console.WriteLine(b.IsExcellent());           // метод экземпляра - у объекта
Student c = new Student("C", 0);              // переменную нужно инициализировать
Console.WriteLine(c.Name);
Student d = new Student("A", 1);
d.Score = 100;                                // число, а не строка
```

## Пошаговое объяснение
1. Конструктор: `new Student("Азиз")` — нет подходящего конструктора с одним аргументом (`CS7036`).
2. Обращение к членам: `b.Age` — такого поля нет (`CS1061`); `Student.IsExcellent()` — метод экземпляра вызван от имени класса (`CS0120`).
3. Использование переменных: `c` не инициализирована (`CS0165`); `d.Score = "много"` — присваивание строки в поле `int` (`CS0029`).

## Трассировка и проверка
| Строка | Группа | Код |
|---|---|---|
| `new Student("Азиз")` | вызов конструктора | CS7036 |
| `b.Age` | член не существует | CS1061 |
| `Student.IsExcellent()` | метод экземпляра от имени класса | CS0120 |
| `Console.WriteLine(c.Name)` для `Student c;` | неинициализированная переменная | CS0165 |
| `d.Score = "много"` | тип значения | CS0029 |

## Результат
Коды: CS7036, CS1061, CS0120, CS0165, CS0029.

## Типичные ошибки
- Путать вызов от имени класса и от имени объекта.
- Забывать, что при объявлении собственного конструктора пропадает конструктор по умолчанию.
- Присваивать поля несоответствующих типов.
- Не различать `CS0165` и `NullReferenceException`.
