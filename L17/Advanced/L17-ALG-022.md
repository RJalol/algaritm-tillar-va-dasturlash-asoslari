# L17-ALG-022. Класс «денежная сумма»

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Объявить класс `Money` с закрытым полем суммы, свойством `Amount` (отрицательные значения заменяются нулём) и свойством `Currency` только для чтения. Объявить **три** конструктора, связанных цепочкой `: this(...)`: без параметров (нуль и валюта `"UZS"`), с одной суммой и с суммой и валютой. Переопределить `ToString` в формате «сумма с двумя знаками, пробел, валюта». Проверить все три конструктора и присваивание отрицательной суммы.

## Ожидаемый результат
Выведено `0,00 UZS`, `1500,50 UZS` и `20,00 USD`; после присваивания −50 сумма стала `0,00 UZS`; заполнение полей записано только в конструкторе с двумя параметрами.
