# L17-ALG-027. Свойство с внутренним пересчётом

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Объявить класс `Time` с закрытым полем «число минут от начала суток» и свойствами `Hours` и `Minutes`, вычисляемыми из него, причём доступными и для записи: присваивание любому из них пересчитывает поле. Добавить свойство `TotalMinutes` только для чтения и переопределение `ToString` в формате `ЧЧ:ММ`. Проверить: создание со значением 23:50; присваивание `Minutes` значения 75; присваивание `Hours` значения 25.

## Ожидаемый результат
Выведено `23:50` при `TotalMinutes` равном `1430`; после присваивания `Minutes = 75` — `00:15` и `15`, поскольку 23 часа 75 минут выходят за пределы суток; после присваивания `Hours = 25` — `01:15` и `75`. Хранилище одно, и его значение всегда лежит в отрезке от 0 до 1439.
