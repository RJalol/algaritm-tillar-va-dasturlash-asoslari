# L17-ALG-026. Цепочка из трёх конструкторов

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Объявить класс с тремя конструкторами, связанными в цепочку так, чтобы первый вызывал второй, а второй — третий. В каждый конструктор добавить вывод строки, показывающей порядок выполнения. Создать объект первым конструктором и по выводу определить, в каком порядке выполняются тела.

## Ожидаемый результат
Сначала выполнено тело **третьего** конструктора, затем второго, затем первого; сделан вывод, что вызываемый конструктор отрабатывает **до** тела вызывающего.
