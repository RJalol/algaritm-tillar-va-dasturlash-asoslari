# L17-ALG-029. Предсказание выбора перегрузки

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Даны перегрузки:

```
static void H(int a) { Console.WriteLine("int"); }
static void H(long a) { Console.WriteLine("long"); }
static void H(double a) { Console.WriteLine("double"); }
static void H(object a) { Console.WriteLine("object"); }
```

Не запуская программу, предсказать вывод каждого из вызовов: `H(5)`, `H(5L)`, `H(5.0)`, `H(5.0f)`, `H('A')`, `H("текст")`. Затем проверить запуском и объяснить каждый выбор через цепочку неявных преобразований.

## Ожидаемый результат
Получено `int`, `long`, `double`, `double`, `int` и `object`; объяснено, что при отсутствии точного соответствия выбирается перегрузка с ближайшим расширяющим преобразованием, а перегрузка с `object` подходит любому аргументу и потому выбирается последней.
