# L17-ALG-023. Связанные свойства

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Объявить класс `Temperature` с единственным закрытым полем — температурой в градусах Цельсия — и **тремя** свойствами: `Celsius` (при записи значение не может быть ниже абсолютного нуля −273,15), `Fahrenheit` (и чтение, и запись через пересчёт) и `Kelvin` (только чтение). Переопределить `ToString`, выводящий все три величины с двумя знаками. Проверить: создание со значением 100; присваивание `Fahrenheit` значения 32; присваивание `Celsius` значения −500; создание конструктором без параметров.

## Ожидаемый результат
Выведено `100,00 C = 212,00 F = 373,15 K`, затем `0,00 C = 32,00 F = 273,15 K`, затем `-273,15 C = -459,67 F = 0,00 K` и снова `0,00 C = 32,00 F = 273,15 K`; хранилище одно, а согласованность трёх величин обеспечена методами доступа.
