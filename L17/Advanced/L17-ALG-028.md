# L17-ALG-028. Поле или свойство

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Для каждой из пяти ситуаций выбрать средство — открытое поле, автоматическое свойство, свойство с проверкой, свойство только для чтения или вычисляемое свойство — и обосновать выбор: (а) название книги, которое можно менять; (б) номер счёта, задаваемый при создании и неизменный; (в) возраст, который не может быть отрицательным; (г) полное имя, составляемое из имени и фамилии; (д) координата точки в программе обработки геометрии, где важна скорость и никаких проверок не требуется. Для трёх ситуаций написать код.

## Ожидаемый результат
Пять обоснованных пар; отмечено, что даже для случая (д) автоматическое свойство предпочтительнее открытого поля, поскольку позволяет добавить проверку впоследствии, не изменяя вызывающий код.
