# L17-ALG-024. Набор перегрузок для вывода отчёта

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Объявить класс с **четырьмя** перегрузками метода `Report`: без аргументов (полный отчёт); с одним целым (отчёт по номеру); с одной строкой (отчёт по имени); с целым и строкой. Вызвать все четыре и убедиться, что выбран нужный вариант. Затем добавить пятую перегрузку с параметром типа `long` и объяснить, изменится ли выбор при вызове с аргументом `5`.

## Ожидаемый результат
Четыре разных вывода; после добавления перегрузки с `long` вызов с аргументом `5` по-прежнему выбирает вариант с `int`, поскольку соответствие точное.
