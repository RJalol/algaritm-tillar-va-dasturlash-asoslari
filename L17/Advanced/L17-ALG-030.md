# L17-ALG-030. Полный аудит программы со свойствами

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Дан код:

```
using System;

namespace PropertyAudit
{
    class Employee
    {
        private decimal _salary;

        public string Name { get; set; }

        public decimal Salary
        {
            get { return Salary; }
            set { _salary = value; }
        }

        public int Age { get; }

        public Employee(string name, decimal salary)
        {
            Name = name;
            _salary = salary;
        }

        public Employee(string name, decimal pay)
        {
            Name = name;
            _salary = pay;
        }

        public decimal Bonus(decimal percent) { return _salary * percent / 100; }
        public double Bonus(double percent) { return (double)_salary * percent / 100; }
    }
}
```

**Запускать не следует.** Провести полный аудит и разнести замечания по четырём категориям: рекурсивное свойство; невозможность различить перегрузки; свойство, которое конструктор не заполняет; отсутствие проверки в методе доступа. Для каждого указать код ошибки либо объяснить, почему компилятор молчит, и назвать тест-кейс, выявляющий ошибку. Привести исправленную версию.

## Ожидаемый результат
Категории разнесены верно: метод `get` свойства `Salary` обращается к самому свойству и потому даёт переполнение стека при первом чтении, причём компилятор не сообщает об этом ничего; два конструктора имеют одинаковые списки параметров и дают `CS0111`, различаясь лишь именем второго параметра; свойство `Age` объявлено только для чтения, конструктор его не заполняет, и оно навсегда остаётся нулём; метод `set` свойства `Salary` не проверяет неотрицательность, из-за чего оклад может стать отрицательным.
