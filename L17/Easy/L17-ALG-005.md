# L17-ALG-005. Автоматические свойства

**Тема:** Л17 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства

## Условие
Объявить класс `Book` с тремя **автоматическими** свойствами: название, автор и год. Двум строковым свойствам задать начальные значения — пустую строку и текст `"не указан"`. Создать объект конструктором без параметров и вывести все три свойства в квадратных скобках.

## Ожидаемый результат
Первое свойство — пустые скобки, второе — `[не указан]`, третье — `[0]`; ни одно значение не равно `null`.
