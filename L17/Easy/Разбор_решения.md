# Разбор решения. L17-ALG-001. Класс «точка»

## Условие
Объявить класс `Point` с двумя вещественными полями — координатами — и конструктором, задающим их. Добавить метод, возвращающий расстояние от точки до начала координат. Создать две точки, (3; 4) и (0; 0), и вывести оба расстояния.

## Ожидаемый результат
Выведено `5` и `0`; расстояние вычислено методом `Math.Sqrt`, поля заполнены конструктором.

## Разбор условия
**Дано:** координаты (3; 4) и (0; 0).
**Требуется:** класс `Point` с двумя вещественными полями, конструктором и методом расстояния до начала координат; создать две точки и вывести расстояния.

## Теоретическая справка
**Класс** — описание типа объекта: поля (состояние), методы (поведение), конструкторы (начальное состояние). **Объект** — экземпляр класса, создаваемый оператором `new`.

Принципы ООП: инкапсуляция (данные и действия в одном месте), наследование, полиморфизм, абстракция.

**Конструктор** — особый метод без возвращаемого типа с именем класса; вызывается при `new` и записывает начальные значения полей. Если конструктор не объявлен, создаётся конструктор по умолчанию без параметров.

Класс — **ссылочный тип**: переменная хранит ссылку на объект в куче; присваивание `b = a` копирует ссылку, и обе переменные указывают на один объект.

## Идея решения
Класс — шаблон объекта: поля хранят состояние, конструктор задаёт начальные значения, метод вычисляет расстояние по формуле √(x² + y²).

## Решение
```csharp
using System;

class Point
{
    public double X;
    public double Y;

    public Point(double x, double y)
    {
        X = x;
        Y = y;
    }

    public double DistanceToOrigin()
    {
        return Math.Sqrt(X * X + Y * Y);
    }
}

class Program
{
    static void Main()
    {
        Point a = new Point(3, 4);
        Point o = new Point(0, 0);
        Console.WriteLine(a.DistanceToOrigin());
        Console.WriteLine(o.DistanceToOrigin());
    }
}
```

## Пошаговое объяснение
1. Конструктор `Point(double x, double y)` записывает аргументы в поля.
2. `new Point(3, 4)` создаёт объект в памяти и вызывает конструктор.
3. `Math.Sqrt(3² + 4²) = Math.Sqrt(25) = 5`; для начала координат — 0.

## Трассировка и проверка
| Выражение | Результат |
|---|---|
| `new Point(3, 4)` | объект с X = 3, Y = 4 |
| `a.DistanceToOrigin()` | √(9 + 16) = 5 |
| `new Point(0, 0)` | объект с X = 0, Y = 0 |
| `o.DistanceToOrigin()` | 0 |

Каждый `new` создаёт независимый объект со своими полями.

## Результат
5 и 0

## Типичные ошибки
- Забыть `new` при создании объекта (переменная останется `null`).
- Обратиться к полю до создания объекта (`NullReferenceException`).
- Назвать параметры конструктора так же, как поля, и не использовать `this.` — присваивание «само себе».
- Вызывать метод от имени класса, а не объекта (`CS0120`).
