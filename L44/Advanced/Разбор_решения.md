# Разбор решения. L44 · Задание III · №1. Часы со стрелками

## Условие
Нарисовать аналоговые часы с циферблатом, делениями и тремя стрелками, обновляемыми таймером.

## Ожидаемый результат
Часы показывают текущее время.

## Идея решения
Часы — окружность, 12 делений и три стрелки. Угол стрелки считается от направления «вверх» по часовой стрелке: для секунд и минут — 6° на деление, для часов — 30° плюс поправка на минуты.

## Решение
```csharp
using System;
using System.Drawing;
using System.Drawing.Drawing2D;
using System.Windows.Forms;

public class Form1 : Form
{
    private readonly Timer _timer = new Timer { Interval = 1000 };

    public Form1()
    {
        Text = "Часы";
        ClientSize = new Size(360, 360);
        DoubleBuffered = true;
        ResizeRedraw = true;
        _timer.Tick += (s, e) => Invalidate();
        _timer.Start();
    }

    private static PointF Hand(PointF c, double angleDeg, float length)
    {
        double a = (angleDeg - 90) * Math.PI / 180;        // 0° = вверх
        return new PointF(c.X + (float)(Math.Cos(a) * length), c.Y + (float)(Math.Sin(a) * length));
    }

    protected override void OnPaint(PaintEventArgs e)
    {
        base.OnPaint(e);
        var g = e.Graphics;
        g.SmoothingMode = SmoothingMode.AntiAlias;

        var c = new PointF(ClientSize.Width / 2f, ClientSize.Height / 2f);
        float r = Math.Min(ClientSize.Width, ClientSize.Height) / 2f - 15;

        using (var face = new Pen(Color.Black, 3))
            g.DrawEllipse(face, c.X - r, c.Y - r, 2 * r, 2 * r);

        using (var tick = new Pen(Color.Black, 2))
            for (int i = 0; i < 12; i++)
                g.DrawLine(tick, Hand(c, i * 30, r - 12), Hand(c, i * 30, r));

        var t = DateTime.Now;
        double sec = t.Second, min = t.Minute + sec / 60, hour = t.Hour % 12 + min / 60;

        using (var h = new Pen(Color.Black, 6) { EndCap = LineCap.Round })
            g.DrawLine(h, c, Hand(c, hour * 30, r * 0.5f));
        using (var m = new Pen(Color.DarkBlue, 4) { EndCap = LineCap.Round })
            g.DrawLine(m, c, Hand(c, min * 6, r * 0.75f));
        using (var s = new Pen(Color.Red, 2))
            g.DrawLine(s, c, Hand(c, sec * 6, r * 0.9f));
    }
}
```

## Пошаговое объяснение
1. Метод `Hand` переводит угол (отсчёт от направления «вверх» по часовой стрелке) и длину в точку на экране: от угла отнимается 90°, так как стандартный тригонометрический ноль направлен вправо.
2. Деления проводятся 12 раз с шагом 30°; радиус циферблата зависит от меньшей стороны окна.
3. Секундная стрелка поворачивается на 6° за секунду, минутная — на 6° за минуту плюс поправка на секунды, часовая — на 30° за час плюс поправка на минуты (плавное движение).
4. Таймер раз в секунду вызывает `Invalidate()`, что приводит к перерисовке в `OnPaint`; `DoubleBuffered` убирает мерцание.
5. Ресурсы пера освобождаются оператором `using`.

## Результат
Аналоговые часы с циферблатом, делениями и тремя стрелками показывают текущее время и обновляются каждую секунду.
