# Разбор решения. L44 · Задание II · №4. График функции

## Условие
Построить график функции `y = sin(x)` на отрезке [-2π; 2π] с масштабированием по размеру формы.

## Ожидаемый результат
График корректен и масштабируется.

## Разбор условия
**Дано:** функция y = sin(x) на [−2π; 2π].
**Требуется:** построить график с осями, масштабируемый вместе с окном.

## Теоретическая справка
**Отображение координат.** Математическая система (x, y) переводится в пиксельную (px, py) линейным преобразованием:

```
px = cx + x · scaleX
py = cy − y · scaleY
```

где (cx, cy) — центр окна, `scaleX`/`scaleY` — число пикселей на единицу. Знак «минус» у y нужен, потому что ось Y экрана направлена вниз.

Гладкая кривая получается из достаточно частой сетки точек, соединённых `DrawLines`.

## Идея решения
Функция задана математически в координатах (x, y), а на экране нужны пиксели. Переход: `px = cx + x·scaleX`, `py = cy − y·scaleY` (ось Y экрана направлена вниз).

## Решение
```csharp
using System;
using System.Drawing;
using System.Drawing.Drawing2D;
using System.Windows.Forms;

public class Form1 : Form
{
    public Form1()
    {
        Text = "y = sin(x)";
        Size = new Size(640, 400);
        ResizeRedraw = true;
        DoubleBuffered = true;
    }

    protected override void OnPaint(PaintEventArgs e)
    {
        base.OnPaint(e);
        var g = e.Graphics;
        g.SmoothingMode = SmoothingMode.AntiAlias;

        float w = ClientSize.Width, h = ClientSize.Height;
        float cx = w / 2, cy = h / 2;
        float scaleX = (w - 40) / (4 * (float)Math.PI);     // отрезок [-2π; 2π]
        float scaleY = (h - 40) / 3;                        // по Y показываем [-1,5; 1,5]

        using var axis = new Pen(Color.Gray, 1);
        g.DrawLine(axis, 0, cy, w, cy);
        g.DrawLine(axis, cx, 0, cx, h);

        var points = new PointF[400];
        for (int i = 0; i < points.Length; i++)
        {
            double x = -2 * Math.PI + 4 * Math.PI * i / (points.Length - 1);
            points[i] = new PointF(cx + (float)x * scaleX, cy - (float)Math.Sin(x) * scaleY);
        }

        using var graph = new Pen(Color.Crimson, 2);
        g.DrawLines(graph, points);
    }
}
```

## Пошаговое объяснение
1. Центр экрана принимаем за начало координат, ось X ведём вправо, ось Y — вверх (поэтому для пикселя используется вычитание).
2. Масштаб по X подбирается так, чтобы отрезок длиной 4π поместился в ширину окна; по Y — чтобы значения от −1,5 до 1,5 поместились в высоту.
3. Строим 400 точек кривой и соединяем их ломаной `DrawLines`; при такой частоте разбиения кривая выглядит гладкой.
4. `ResizeRedraw` и пересчёт масштаба внутри `OnPaint` делают график масштабируемым при изменении размера окна.

## Трассировка и проверка
Для окна 640×400: центр (320; 200); `scaleX ≈ (640−40)/(4π) ≈ 47,7`; `scaleY ≈ (400−40)/3 = 120`.

| x | sin x | px | py |
|--:|--:|--:|--:|
| −2π | 0 | 20 | 200 |
| −π/2 | −1 | ≈ 245 | 320 |
| 0 | 0 | 320 | 200 |
| π/2 | 1 | ≈ 395 | 80 |
| 2π | 0 | 620 | 200 |

## Результат
На форме нарисованы оси и синусоида на отрезке [−2π; 2π], масштабируемая вместе с окном.

## Типичные ошибки
- Забыть минус при пересчёте Y — график перевёрнут.
- Использовать малое число точек — ломаная заметна.
- Не пересчитывать масштаб при изменении размера.
- Рисовать оси поверх графика одним цветом.
