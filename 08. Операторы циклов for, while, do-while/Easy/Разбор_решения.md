# Разбор решения. L08-ALG-001. Числа от 1 до N

## Условие
Написать программу, которая запрашивает у пользователя целое положительное число N и выводит все числа от 1 до N включительно, разделяя их пробелами, с помощью цикла `for`.

## Ожидаемый результат
При вводе 5 выведено `1 2 3 4 5`; граница цикла задана так, чтобы значение N попадало в вывод.

## Разбор условия
**Дано:** целое положительное N.
**Требуется:** вывести числа от 1 до N включительно через пробел циклом `for`.

## Теоретическая справка
Цикл `for` состоит из трёх частей:

```
for (инициализация; условие; изменение)
    тело;
```

1. Инициализация выполняется один раз до цикла.
2. Условие проверяется перед каждой итерацией; ложное условие завершает цикл.
3. Изменение выполняется после тела на каждой итерации.

Для включения границы N нужно условие `i <= n`. Количество итераций цикла `for (i = 1; i <= n; i++)` равно N.

## Идея решения
Цикл `for` с переменной от 1 до N: условие `i <= N` включает границу.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите N: ");
        int n = int.Parse(Console.ReadLine());

        for (int i = 1; i <= n; i++)
        {
            Console.Write(i + " ");
        }
        Console.WriteLine();
    }
}
```

## Пошаговое объяснение
1. Инициализация `int i = 1` выполняется один раз перед циклом.
2. Условие `i <= n` проверяется перед каждой итерацией; знак `<=` (а не `<`) делает так, что `n` тоже выводится.
3. После каждой итерации выполняется `i++`.
4. Числа печатаем через `Write` с пробелом, чтобы они шли в одну строку.

## Трассировка и проверка
Для N = 5:

| Итерация | i до проверки | `i <= 5` | Вывод |
|---:|---:|:--:|---|
| 1 | 1 | да | 1 |
| 2 | 2 | да | 2 |
| 3 | 3 | да | 3 |
| 4 | 4 | да | 4 |
| 5 | 5 | да | 5 |
| — | 6 | нет | выход |

Граничные случаи: N = 1 — одна итерация; N = 0 — цикл не выполняется (вывод пуст).

## Результат
При N = 5 выводится: 1 2 3 4 5

## Типичные ошибки
- Записать условие `i < n` — число N не будет выведено.
- Начать с `i = 0` — вывод будет лишний 0.
- Забыть изменение счётчика — бесконечный цикл.
- Использовать `WriteLine` и получить числа в столбик, а не через пробел.

## Задания для закрепления
- Вывести числа от N до 1 в обратном порядке.
- Вывести только чётные числа до N, используя шаг 2.
- Найти сумму чисел от 1 до N и проверить формулу N(N+1)/2.
