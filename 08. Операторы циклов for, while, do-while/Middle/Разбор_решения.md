# Разбор решения. L08-ALG-006. Таблица умножения на заданное число

## Условие
Написать программу, которая запрашивает целое число и выводит таблицу умножения на него от 1 до 10 в виде строк «N x K = P», каждая на отдельной строке.

## Ожидаемый результат
Десять строк вида `7 x 1 = 7`, `7 x 2 = 14` и так далее до `7 x 10 = 70` при вводе числа 7.

## Разбор условия
**Дано:** целое число n.
**Требуется:** вывести таблицу умножения на n от 1 до 10 строками вида «N x K = P».

## Теоретическая справка
Здесь число итераций заранее известно (10), поэтому естественный выбор — цикл `for`. Переменная цикла `k` одновременно служит множителем.

Для вывода используется **интерполяция строк**: `$"{n} x {k} = {n * k}"`. В фигурных скобках допускаются произвольные выражения; они вычисляются и подставляются в текст. Подстановка не меняет значения переменных.

## Идея решения
Цикл по множителю k от 1 до 10; в каждой итерации выводим строку вида «N x K = P».

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите число: ");
        int n = int.Parse(Console.ReadLine());

        for (int k = 1; k <= 10; k++)
        {
            Console.WriteLine($"{n} x {k} = {n * k}");
        }
    }
}
```

## Пошаговое объяснение
1. Считываем число `n`, на которое строим таблицу.
2. Цикл выполняется ровно 10 раз: `k` принимает значения 1…10.
3. В интерполированной строке `$"..."` выражения в фигурных скобках подставляются в текст, включая вычисление `n * k`.

## Трассировка и проверка
Для n = 7:

| k | Вывод |
|--:|---|
| 1 | 7 x 1 = 7 |
| 2 | 7 x 2 = 14 |
| … | … |
| 10 | 7 x 10 = 70 |

Контроль: последнее произведение равно 10·n, а каждое следующее больше предыдущего ровно на n.

## Результат
При n = 7: 7 x 1 = 7, 7 x 2 = 14, …, 7 x 10 = 70 (десять строк).

## Типичные ошибки
- Использовать `k < 10` — потеряется строка с множителем 10.
- Менять `n` внутри цикла — таблица искажается.
- Забыть пробелы в шаблоне вывода.
- Смешивать операции `x` (буква) и `*` (знак умножения) в шаблоне строки.

## Задания для закрепления
- Вывести таблицу умножения в виде матрицы 10×10 вложенными циклами.
- Вывести таблицу только для чётных множителей.
- Запросить диапазон множителей у пользователя.
