# Разбор решения. L45 · Задание I · №1. Заливка прямоугольника

## Условие
Закрасить прямоугольник одним цветом методом `FillRectangle` с `SolidBrush`.

## Ожидаемый результат
Прямоугольник залит заданным цветом.

## Идея решения
Контур рисуют методами `Draw...` с пером, заливку — методами `Fill...` с кистью (`Brush`). Для сплошного цвета используется `SolidBrush`.

## Решение
```csharp
using System;
using System.Drawing;
using System.Windows.Forms;

public class Form1 : Form
{
    public Form1()
    {
        Text = "Заливка";
        Size = new Size(320, 240);
        Paint += (s, e) =>
        {
            using var brush = new SolidBrush(Color.Orange);
            e.Graphics.FillRectangle(brush, 40, 40, 200, 100);
            using var pen = new Pen(Color.Black, 2);
            e.Graphics.DrawRectangle(pen, 40, 40, 200, 100);
        };
    }
}
```

## Пошаговое объяснение
1. `SolidBrush(Color.Orange)` — кисть сплошного цвета.
2. `FillRectangle(brush, x, y, width, height)` закрашивает прямоугольник; рамки у него нет.
3. Для рамки поверх заливки вызываем `DrawRectangle` с пером.
4. Кисть и перо — неуправляемые ресурсы, поэтому оборачиваем их в `using`.

## Результат
Оранжевый прямоугольник 200×100 с чёрной рамкой.
