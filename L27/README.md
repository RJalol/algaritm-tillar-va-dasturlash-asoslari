# L27. Вложенные классы. Их объявление и использование в пространствах имён. Создание библиотеки классов в среде Visual Studio

Практические задания к теме №27 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
L27/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
└── Advanced/   10 заданий  (Задание III)
```

## Формат задания

Каждый файл `L27-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. Для каждого уровня (`Easy/`, `Middle/`, `Advanced/`) приведён один образцовый разбор — файл `Разбор_решения.md`; остальные задания предназначены для самостоятельного выполнения.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.
