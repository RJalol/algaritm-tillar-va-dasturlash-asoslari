# L27 · Задание II · №15. Полный набор ошибок

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
Составить набор фрагментов, содержащий по одной ошибке каждого из изученных видов: обращение к закрытому вложенному типу извне; обращение содержащего типа к закрытому члену вложенного; обращение к `internal`-типу из другой сборки; использование типа библиотеки без ссылки на её проект; обращение к вложенному типу по простому имени. Для каждого записать код и причину.

## Ожидаемый результат
Получены коды `CS0122` (трижды, по разным причинам) и `CS0246` (дважды); для каждого случая причина сформулирована отдельно.
