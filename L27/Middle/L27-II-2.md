# L27 · Задание II · №2. Число вложенных типов

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
Для класса задания II.1 вывести средствами получения сведений о типе число открытых вложенных типов и число вложенных типов вообще. Затем сделать вложенный тип открытым и повторить вывод. Объяснить оба результата.

## Ожидаемый результат
До изменения открытых вложенных типов ноль, всего один; после изменения — по одному; объяснено, чем перечни различаются.
