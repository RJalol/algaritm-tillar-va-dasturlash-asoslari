# L27 · Задание II · №10. Три уровня сокрытия

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
Построить библиотеку, в которой присутствуют все три уровня сокрытия: открытый тип, тип `internal` и закрытый вложенный тип. Для каждого проверить опытом, откуда он доступен: из своего класса, из другого типа библиотеки, из приложения. Составить таблицу три на три.

## Ожидаемый результат
Таблица заполнена фактическими результатами; закрытый вложенный тип доступен только своему содержащему типу, `internal` — всей библиотеке, открытый — всем.
