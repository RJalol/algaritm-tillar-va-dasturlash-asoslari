# L27 · Задание II · №3. Уместность вложенного типа

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
Даны шесть типов: узел списка; перечисление состояний заказа, передаваемое в метод класса; форматировщик, используемый только одним классом; класс «адрес», применяемый несколькими классами; сравнитель, создаваемый только содержащим типом; класс настроек приложения. Для каждого решить, следует ли объявить его вложенным, и обосновать решение правилами проектирования. Реализовать все шесть.

## Ожидаемый результат
Вложенными объявлены три типа; для каждого невложенного указано нарушаемое правило.
