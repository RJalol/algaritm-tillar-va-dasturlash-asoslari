# L27 · Задание II · №8. Константа через границу сборки

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
В библиотеке объявить константу и поле `static readonly` с одинаковыми по смыслу значениями и вывести оба из приложения. Затем изменить оба значения в библиотеке, пересобрать **только** библиотеку, заменить её файл в каталоге приложения и запустить приложение **без** перекомпиляции. Записать оба выведенных значения.

## Ожидаемый результат
Константа сохранила старое значение, поле `static readonly` показало новое; результат объяснён подстановкой константы при компиляции.
