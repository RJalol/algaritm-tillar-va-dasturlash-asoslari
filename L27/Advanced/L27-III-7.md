# L27 · Задание III · №7. Экспертиза уместности вложенности

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
Дан набор из десяти типов с описанием их назначения и способа использования. Для каждого решить, следует ли объявить его вложенным, типом `internal` или открытым типом верхнего уровня, и обосновать решение правилами проектирования раздела 5.5. Оформить результат программой, выводящей таблицу решений с указанием применённого правила.

## Ожидаемый результат
Для каждого типа решение обосновано; правила «не применять вложенный тип для логической группировки» и «не применять вложенный тип, создаваемый внешним кодом» применены не менее чем по одному разу.
