# L27 · Задание III · №1. Библиотека учебного заведения

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
Разработать решение из библиотеки `Academy` и консольного приложения. Библиотека содержит иерархию из не менее чем пяти классов (темы №25—№26), не менее двух типов `internal` для внутренних проверок и не менее одного закрытого вложенного типа. Приложение выполняет ввод-вывод и печатает отчёты. Библиотека не должна содержать ни одного обращения к консоли.

## Ожидаемый результат
Приложение работает; в открытой части библиотеки только те типы, которые ему действительно нужны; попытка обратиться из приложения к любому `internal`-типу даёт `CS0122`.
