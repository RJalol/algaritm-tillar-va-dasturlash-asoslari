# L27 · Задание III · №3. Проектирование открытой части

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
Для библиотеки задания III.1 составить перечень всех типов и членов и решить для каждого, каким он должен быть: `public`, `internal`, закрытым вложенным или закрытым членом. Обосновать каждое решение вопросом «нужно ли это потребителю библиотеки». Реализовать принятые решения и убедиться, что приложение по-прежнему работает.

## Ожидаемый результат
Открытая часть библиотеки сократилась по сравнению с исходной; приложение работает без изменений; для каждого понижения доступности приведено обоснование.
