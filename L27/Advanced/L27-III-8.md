# L27 · Задание III · №8. Совместимость версий библиотеки

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
Составить перечень изменений библиотеки и для каждого определить опытом, требуется ли перекомпиляция приложения: изменение тела метода; изменение значения константы; изменение значения `static readonly`; добавление нового открытого члена; удаление открытого члена; изменение доступности типа с `public` на `internal`. Для каждого изменения провести замену файла библиотеки без перекомпиляции приложения и записать результат.

## Ожидаемый результат
Изменения, не затрагивающие открытых имён и констант, не требуют перекомпиляции; удаление члена и понижение доступности приводят к отказу при выполнении или при следующей сборке; таблица заполнена фактическими наблюдениями.
