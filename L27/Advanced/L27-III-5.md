# L27 · Задание III · №5. Библиотека структур данных

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
Разработать библиотеку с тремя структурами данных на связанных узлах — очередь, стек и односвязный список, — в каждой из которых узел объявлен закрытым вложенным типом. Общий вспомогательный код вынести в тип `internal`. Приложение проверяет все три структуры не менее чем на пятнадцати операциях.

## Ожидаемый результат
Все структуры работают; ни один тип узла не виден приложению; вспомогательный тип недоступен приложению, но используется всеми тремя структурами.
