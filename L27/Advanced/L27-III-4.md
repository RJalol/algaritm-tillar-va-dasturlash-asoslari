# L27 · Задание III · №4. Диагностика чужого решения

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
Подготовить решение из двух проектов, содержащее не менее семи внесённых ошибок: закрытый вложенный тип используется извне; содержащий тип обращается к закрытому члену вложенного; `internal`-тип используется из приложения; отсутствует ссылка на проект; вложенный тип назван простым именем; тип библиотеки не объявлен открытым; открытый вложенный тип создаётся внешним кодом. Составить таблицу «проект — строка — код — причина — исправление» и привести решение в рабочее состояние.

## Ожидаемый результат
Таблица содержит не менее семи строк; для случаев с одинаковым кодом причины указаны различные; исправленное решение собирается без ошибок и предупреждений.
