# Разбор решения. L27 · Задание III · №1. Библиотека учебного заведения

## Условие
Разработать решение из библиотеки `Academy` и консольного приложения. Библиотека содержит иерархию из не менее чем пяти классов (темы №25—№26), не менее двух типов `internal` для внутренних проверок и не менее одного закрытого вложенного типа. Приложение выполняет ввод-вывод и печатает отчёты. Библиотека не должна содержать ни одного обращения к консоли.

## Ожидаемый результат
Приложение работает; в открытой части библиотеки только те типы, которые ему действительно нужны; попытка обратиться из приложения к любому `internal`-типу даёт `CS0122`.

## Идея решения
Решение состоит из двух проектов: библиотеки классов `Academy` (без обращений к консоли) и консольного приложения. В библиотеке публичны только необходимые типы; проверки спрятаны в `internal` типах и закрытом вложенном типе.

## Решение
```csharp
// ===== Проект 1: библиотека классов Academy.dll =====
namespace Academy
{
    public class Person
    {
        public string Name { get; }
        public int BirthYear { get; }
        public Person(string name, int birthYear)
        {
            Validator.CheckName(name);                // internal-тип
            Validator.CheckYear(birthYear);
            Name = name; BirthYear = birthYear;
        }
        public virtual string Describe() => Name;
    }

    public class Student : Person
    {
        public int Course { get; }
        public Student(string name, int birthYear, int course) : base(name, birthYear)
        {
            Validator.CheckRange(course, 1, 6, nameof(course));
            Course = course;
        }
        public override string Describe() => $"{Name}, {Course} курс";
    }

    public class Teacher : Person
    {
        public string Department { get; }
        public Teacher(string name, int birthYear, string department) : base(name, birthYear)
        {
            Validator.CheckName(department);
            Department = department;
        }
        public override string Describe() => $"{Name}, кафедра {Department}";
    }

    public class Group
    {
        private class Entry                            // закрытый вложенный тип
        {
            public Person Person;
            public int Number;
        }
        private readonly System.Collections.Generic.List<Entry> _entries = new();

        public void Add(Person p) => _entries.Add(new Entry { Person = p, Number = _entries.Count + 1 });

        public string Report()
        {
            var sb = new System.Text.StringBuilder();
            foreach (Entry e in _entries) sb.AppendLine($"{e.Number}. {e.Person.Describe()}");
            return sb.ToString();
        }
    }

    public class Dean : Teacher
    {
        public Dean(string name, int birthYear, string department) : base(name, birthYear, department) { }
        public override string Describe() => "Декан " + base.Describe();
    }

    internal static class Validator                   // внутренний тип
    {
        public static void CheckName(string s)
        {
            if (string.IsNullOrWhiteSpace(s)) throw new System.ArgumentException("Пустое значение");
        }
        public static void CheckYear(int y)
        {
            CheckRange(y, 1900, 2026, nameof(y));
        }
        public static void CheckRange(int v, int min, int max, string name)
        {
            if (v < min || v > max) throw new System.ArgumentOutOfRangeException(name);
        }
    }

    internal class Counter { }                        // второй internal-тип
}

// ===== Проект 2: консольное приложение (ссылка на проект Academy) =====
using System;
using Academy;

class Program
{
    static void Main()
    {
        Group g = new Group();
        g.Add(new Student("Азиз", 2006, 2));
        g.Add(new Student("Малика", 2005, 3));
        g.Add(new Teacher("Нодира", 1985, "Информатика"));
        g.Add(new Dean("Саид", 1970, "Информатика"));
        Console.Write(g.Report());

        // Validator.CheckName("x");   // CS0122: Validator недоступен из-за его уровня защиты
    }
}
```

## Пошаговое объяснение
1. Создаём решение из двух проектов: библиотека классов и консольное приложение; приложение добавляет ссылку на проект библиотеки.
2. Иерархия библиотеки: Person → Student, Teacher → Dean (пять классов); все они `public`, потому что нужны приложению.
3. `Validator` и `Counter` — `internal`: видны только внутри сборки Academy. Приложение не может ими пользоваться — попытка даёт `CS0122`.
4. `Entry` — закрытый вложенный тип внутри `Group`, деталь реализации хранения.
5. В библиотеке нет ни одного обращения к `Console`: она возвращает строку отчёта (`Report`), а печатает её приложение — разделение ответственности.

## Результат
Приложение печатает пронумерованный отчёт по группе; любые обращения к internal-типам из приложения дают CS0122.
