# Разбор решения. L27 · Задание I · №1. Первый вложенный тип

## Условие
Объявить класс «счёт» с закрытым полем остатка и вложенным типом «форматировщик», выводящим остаток в виде строки с обозначением валюты. Вложенный тип объявить без модификатора доступа и обратиться к нему из открытого метода содержащего класса. Затем попытаться обратиться к нему из `Main` и записать код ошибки.

## Ожидаемый результат
Метод содержащего класса работает; обращение из `Main` даёт `CS0122`; в комментарии указано, что вложенный тип по умолчанию закрыт.

## Разбор условия
**Дано:** класс «счёт» и вложенный тип «форматировщик».
**Требуется:** вложенный тип без модификатора, использовать его из открытого метода содержащего класса; обратиться из `Main` и записать код ошибки.

## Теоретическая справка
**Вложенный тип** объявляется внутри другого. Особенности:

- по умолчанию вложенный тип `private` (в отличие от обычного типа верхнего уровня, который `internal`);
- вложенный тип видит закрытые члены содержащего класса, а содержащий класс видит открытые члены вложенного;
- внешний код обращается к вложенному типу через имя содержащего (`Account.Formatter`), если он не закрыт.

Применение: детали реализации (узлы списка, перечислители, вспомогательные классы).

## Идея решения
Вложенный тип без модификатора доступа по умолчанию `private`, поэтому он виден только содержащему классу.

## Решение
```csharp
using System;

class Account
{
    private decimal _balance;

    public Account(decimal balance) { _balance = balance; }

    class Formatter                              // без модификатора = private
    {
        public static string Format(decimal value) => value.ToString("N2") + " сум";
    }

    public string Report() => Formatter.Format(_balance);   // доступ изнутри содержащего класса
}

class Program
{
    static void Main()
    {
        Account a = new Account(1234.5m);
        Console.WriteLine(a.Report());

        // Account.Formatter.Format(1);   // CS0122: Formatter недоступен из-за его уровня защиты
    }
}
```

## Пошаговое объяснение
1. `Formatter` объявлен внутри `Account` без модификатора доступа — значит, закрыт.
2. Открытый метод `Report` содержащего класса использует вложенный тип — внутри класса это разрешено.
3. Обращение из `Main` (закомментированная строка) не компилируется: ошибка `CS0122`.
4. Таким образом, вложенный тип — деталь реализации, скрытая от внешнего кода.

## Трассировка и проверка
| Действие | Результат |
|---|---|
| `a.Report()` | «1 234,50 сум» (форматирование через вложенный тип) |
| `Account.Formatter.Format(1)` в `Main` | CS0122 — недоступен из-за уровня защиты |

Тип по умолчанию закрыт, поэтому внешний мир о нём не знает — это деталь реализации.

## Результат
1 234,50 сум; обращение из Main к Account.Formatter даёт CS0122.

## Типичные ошибки
- Объявлять вложенные типы открытыми без необходимости.
- Ожидать, что вложенный тип доступен как обычный.
- Путать вложенный тип и пространство имён.
- Забывать, что вложенный статический член требует имени содержащего класса.
