# L27 · Задание I · №2. Составное имя

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
Объявить класс «журнал» с **открытым** вложенным типом «запись». Создать объект вложенного типа из `Main` и вывести его полное имя, а также имя содержащего типа средствами получения сведений о типе. Попытаться обратиться к вложенному типу по простому имени и записать код ошибки.

## Ожидаемый результат
Обращение по составному имени работает; полное имя выведено с разделителем, принятым в метаданных; обращение по простому имени даёт `CS0246`.
