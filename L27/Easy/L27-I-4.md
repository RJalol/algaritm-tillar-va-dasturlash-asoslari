# L27 · Задание I · №4. Первая библиотека классов

**Тема:** Л27 — Вложенные классы. Их объявление и использование в пространстве имён. Создание библиотеки классов в Visual Studio

## Условие
Создать решение из двух проектов: библиотеки классов с открытым классом, содержащим один метод расчёта, и консольного приложения. Добавить приложению ссылку на проект библиотеки и вызвать метод. Вывести имена сборок, которым принадлежат тип библиотеки и класс `Program`, и перечислить файлы в каталоге сборки библиотеки.

## Ожидаемый результат
Метод библиотеки вызван успешно; имена сборок различны; в каталоге библиотеки присутствует файл с расширением `.dll` и отсутствует файл с расширением `.exe`.
