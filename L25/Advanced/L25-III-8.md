# L25 · Задание III · №8. Каталог иерархии

**Тема:** Л25 — Наследование. Базовые и производные классы

## Условие
Написать статический метод, который для заданного набора типов строит и печатает дерево наследования: каждый класс выводится с отступом, соответствующим глубине, а рядом указывается число собственных открытых членов и признак запечатанности. Проверить метод на иерархии задания III.1.

## Ожидаемый результат
Дерево выведено с верными отступами; корнем всех ветвей оказывается общий базовый класс библиотеки; числа членов соответствуют объявлениям.
