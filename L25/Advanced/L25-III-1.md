# L25 · Задание III · №1. Иерархия учебного заведения

**Тема:** Л25 — Наследование. Базовые и производные классы

## Условие
Разработать иерархию из шести классов: «человек» — «студент», «преподаватель», «сотрудник»; «студент» — «выпускник»; «преподаватель» — «заведующий кафедрой». Общие члены объявить в базовом классе, доступ разграничить модификаторами `private`, `protected` и `public` осмысленно. Классы разместить по файлам согласно теме №21. Программа заполняет массив базового типа не менее чем десятью объектами и печатает отчёт с указанием фактического класса каждого.

## Ожидаемый результат
Отчёт выведен; ни один член не продублирован в производных классах; для каждого поля обоснован выбор модификатора доступа.
