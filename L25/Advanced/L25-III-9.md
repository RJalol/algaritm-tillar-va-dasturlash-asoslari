# L25 · Задание III · №9. Безопасная обработка разнородного массива

**Тема:** Л25 — Наследование. Базовые и производные классы

## Условие
Разработать обработчик массива базового типа, который для каждого элемента выполняет действие, зависящее от его фактического класса, и **не может** завершиться исключением `Invalid``Cast``Exception` ни при каком составе массива. Добавить в массив объект класса, для которого действие не предусмотрено, и убедиться, что программа отрабатывает корректно. Сравнить с вариантом, использующим приведение без проверки.

## Ожидаемый результат
Первый вариант обрабатывает любой состав массива без исключений; второй завершается исключением на неучтённом объекте, что подтверждено запуском.
