# L25 · Задание III · №3. Статистика по иерархии

**Тема:** Л25 — Наследование. Базовые и производные классы

## Условие
Для массива объектов иерархии задания III.1 построить отчёт: для каждого из шести классов — число объектов, совместимых с этим типом, и число объектов, имеющих его **точно**. Вывести таблицу и объяснить соотношение чисел в каждой строке.

## Ожидаемый результат
Для базового класса число совместимых равно длине массива; сумма точных совпадений по всем классам равна длине массива; расхождения объяснены наследованием.
