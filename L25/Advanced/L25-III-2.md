# L25 · Задание III · №2. Разбор по типам

**Тема:** Л25 — Наследование. Базовые и производные классы

## Условие
Для иерархии задания III.1 написать метод, принимающий параметр базового типа и возвращающий подробное описание, различающееся для всех шести классов. Учесть порядок проверок: производные классы должны проверяться **раньше** своих базовых. Показать опытом, что произойдёт при обратном порядке.

## Ожидаемый результат
При правильном порядке описание соответствует фактическому классу каждого объекта; при обратном порядке все объекты получают описание базового класса, что подтверждено выводом.
