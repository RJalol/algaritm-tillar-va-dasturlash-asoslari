# Разбор решения. L25 · Задание I · №1. Первый производный класс

## Условие
Объявить базовый класс «сотрудник» с именем, годом приёма на работу и методом стажа, а также производный класс «преподаватель», добавляющий кафедру и учёную степень. Создать по объекту каждого класса и вывести сведения, вызвав для преподавателя как унаследованный, так и собственный метод.

## Ожидаемый результат
Унаследованные члены доступны объекту производного класса наравне с собственными; стаж вычислен верно для обоих объектов.

## Идея решения
Производный класс объявляется через двоеточие и получает все доступные члены базового. Стаж считается от года приёма.

## Решение
```csharp
using System;

class Employee
{
    public string Name;
    public int HireYear;

    public Employee(string name, int hireYear)
    {
        Name = name; HireYear = hireYear;
    }

    public int Experience(int currentYear) => currentYear - HireYear;
}

class Teacher : Employee
{
    public string Department;
    public string Degree;

    public Teacher(string name, int hireYear, string department, string degree)
        : base(name, hireYear)
    {
        Department = department; Degree = degree;
    }

    public string Info() => $"{Name}, кафедра {Department}, {Degree}";
}

class Program
{
    static void Main()
    {
        Employee e = new Employee("Азиз", 2015);
        Teacher t = new Teacher("Дилноза", 2010, "Информатика", "доцент");

        Console.WriteLine(e.Name + ", стаж " + e.Experience(2026));
        Console.WriteLine(t.Info());
        Console.WriteLine("Стаж: " + t.Experience(2026));    // унаследованный метод
    }
}
```

## Пошаговое объяснение
1. `class Teacher : Employee` — Teacher наследует поля `Name`, `HireYear` и метод `Experience`.
2. Собственные члены — `Department`, `Degree` и `Info`.
3. Объект производного класса вызывает унаследованный `Experience` так же, как собственный `Info`.
4. Стаж: 2026 − 2015 = 11 для сотрудника; 2026 − 2010 = 16 для преподавателя.

## Результат
Азиз, стаж 11 / Дилноза, кафедра Информатика, доцент / Стаж: 16
