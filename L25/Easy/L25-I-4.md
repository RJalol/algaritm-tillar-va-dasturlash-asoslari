# L25 · Задание I · №4. Преобразование к базовому типу

**Тема:** Л25 — Наследование. Базовые и производные классы

## Условие
Создать массив базового типа из задания I.1 и поместить в него объекты базового и производного классов. Пройти массив циклом, для каждого элемента вывести результат унаследованного метода и фактический тип объекта. Затем попытаться обратиться через элемент массива к члену производного класса и записать код ошибки.

## Ожидаемый результат
Массив содержит объекты обоих классов, фактический тип каждого выведен верно; обращение к члену производного класса даёт `CS1061`.
