# L25 · Задание II · №7. Оператор `is` против `typeof`

**Тема:** Л25 — Наследование. Базовые и производные классы

## Условие
Для иерархии из трёх уровней вывести таблицу: для каждого из трёх объектов и каждого из трёх типов — результаты `объект is Тип` и `объект. GetType() == typeof(Тип)`. Объяснить все расхождения между двумя столбцами.

## Ожидаемый результат
Таблица девять на два заполнена; объяснено, что `is` учитывает наследование, а сравнение типов требует точного совпадения.
