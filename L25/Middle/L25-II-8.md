# L25 · Задание II · №8. Сокрытие члена

**Тема:** Л25 — Наследование. Базовые и производные классы

## Условие
В производном классе объявить метод с тем же именем и подписью, что и в базовом, сначала без слова `new`, затем с ним. Записать реакцию компилятора в обоих случаях. Вызвать метод через переменную производного типа и через переменную базового типа для одного и того же объекта.

## Ожидаемый результат
Без слова `new` получено предупреждение `CS0108`; вызовы через переменные разных типов дают **разные** результаты для одного объекта, что подтверждено проверкой тождественности ссылок.
