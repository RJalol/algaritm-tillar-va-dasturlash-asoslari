# L25 · Задание II · №4. Классификация объектов

**Тема:** Л25 — Наследование. Базовые и производные классы

## Условие
Для иерархии задания II.1 написать метод, принимающий параметр базового типа и возвращающий строку описания, различающуюся для каждого производного класса. Использовать оператор `is` с шаблоном объявления. Проверить метод на массиве из шести объектов.

## Ожидаемый результат
Для каждого объекта выведено описание, соответствующее его фактическому классу; ни одного явного приведения в тексте метода нет.
