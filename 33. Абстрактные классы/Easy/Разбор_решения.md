# Разбор решения. L33 · Задание I · №1. Первый абстрактный класс

## Условие
Объявить абстрактный класс «сотрудник» с абстрактным методом расчёта заработной платы и абстрактным свойством должности. Реализовать три производных класса с разными правилами расчёта. Заполнить массив базового типа и вывести сведения о каждом. Попытаться создать объект абстрактного класса и записать код ошибки.

## Ожидаемый результат
Все три расчёта верны; попытка создать объект абстрактного класса даёт `CS0144`.

## Разбор условия
**Дано:** «сотрудник» с разными правилами оплаты.
**Требуется:** абстрактный класс с абстрактным методом зарплаты и абстрактным свойством должности; три наследника; попытка создания объекта абстрактного класса.

## Теоретическая справка
**Абстрактный класс** (`abstract class`) — класс, не предназначенный для создания объектов: он определяет общий «договор» и часть реализации. **Абстрактные члены** не имеют тела и обязаны быть реализованы (`override`) в первом неабстрактном потомке.

Сравнение с интерфейсом (тема №34): абстрактный класс может содержать поля, конструкторы, реализованные методы и хранит общее состояние; наследовать можно только один класс. Интерфейс — чистый договор, реализовывать можно сколько угодно.

Попытка `new Employee(...)` — ошибка `CS0144`.

## Идея решения
Абстрактный класс объявляет члены без реализации (`abstract`) — «обязательства» для наследников. Создать объект абстрактного класса нельзя.

## Решение
```csharp
using System;

abstract class Employee
{
    public string Name { get; }
    protected Employee(string name) { Name = name; }

    public abstract string Position { get; }
    public abstract decimal CalculateSalary();

    public void Print() => Console.WriteLine($"{Name}, {Position}: {CalculateSalary():N0}");
}

class FixedSalaryEmployee : Employee
{
    private readonly decimal _salary;
    public FixedSalaryEmployee(string name, decimal salary) : base(name) { _salary = salary; }
    public override string Position => "Сотрудник с окладом";
    public override decimal CalculateSalary() => _salary;
}

class HourlyEmployee : Employee
{
    private readonly decimal _rate; private readonly int _hours;
    public HourlyEmployee(string name, decimal rate, int hours) : base(name) { _rate = rate; _hours = hours; }
    public override string Position => "Почасовик";
    public override decimal CalculateSalary() => _rate * _hours;
}

class Manager : Employee
{
    private readonly decimal _base; private readonly decimal _bonus;
    public Manager(string name, decimal baseSalary, decimal bonus) : base(name) { _base = baseSalary; _bonus = bonus; }
    public override string Position => "Руководитель";
    public override decimal CalculateSalary() => _base + _bonus;
}

class Program
{
    static void Main()
    {
        Employee[] staff =
        {
            new FixedSalaryEmployee("Азиз", 5_000_000),
            new HourlyEmployee("Дилноза", 40_000, 120),
            new Manager("Рустам", 7_000_000, 1_500_000)
        };
        foreach (Employee e in staff) e.Print();

        // Employee x = new Employee("Тест");   // CS0144: нельзя создать экземпляр абстрактного класса
    }
}
```

## Пошаговое объяснение
1. `abstract class` не может иметь экземпляров; `abstract`-члены не содержат тела и обязаны быть реализованы (`override`) в неабстрактных наследниках.
2. Три класса реализуют расчёт зарплаты по-разному: оклад, почасовая ставка × часы, оклад + премия.
3. Метод `Print` реализован в базовом классе и обращается к абстрактным членам — шаблонный метод.
4. Попытка `new Employee(...)` даёт ошибку компиляции `CS0144`.

## Трассировка и проверка
| Класс | Расчёт | Результат |
|---|---|--:|
| FixedSalaryEmployee | оклад | 5 000 000 |
| HourlyEmployee | 40 000 × 120 | 4 800 000 |
| Manager | 7 000 000 + 1 500 000 | 8 500 000 |

Метод `Print` реализован в базовом классе и обращается к абстрактным `Position` и `CalculateSalary()` — он работает для любых наследников.

## Результат
Вывод: Азиз — 5 000 000; Дилноза — 4 800 000; Рустам — 8 500 000; создание Employee невозможно (CS0144).

## Типичные ошибки
- Создавать экземпляр абстрактного класса (`CS0144`).
- Не реализовать абстрактный член в наследнике (`CS0534`).
- Оставлять в абстрактных членах тело (`CS0500`).
- Делать абстрактным то, что имеет разумную реализацию по умолчанию (лучше `virtual`).
