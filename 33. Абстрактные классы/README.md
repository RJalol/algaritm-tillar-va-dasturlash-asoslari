# Тема 33. Абстрактные классы. Абстрактные данные и абстрактные методы. Переопределение абстрактных методов в производных классах

Практические задания к теме №33 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
33. Абстрактные классы/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
└── Advanced/   10 заданий  (Задание III)
```

## Формат задания

Каждый файл `L33-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. Для каждого уровня (`Easy/`, `Middle/`, `Advanced/`) приведён один образцовый разбор — файл `Разбор_решения.md`; остальные задания предназначены для самостоятельного выполнения.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.
