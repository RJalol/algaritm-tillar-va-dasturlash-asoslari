# L34 · Задание III · №3. Полный набор порядков сортировки

**Тема:** Л34 — Интерфейсы. Использование методов в интерфейсах и их реализация. Копирование и сортировка объектов интерфейсных типов

## Условие
Для класса из решения III.1 реализовать естественный порядок интерфейсом `IComparable` и не менее четырёх дополнительных порядков отдельными классами `IComparer`, включая два составных (по двум полям) и один обратный. Написать метод, принимающий массив и объект сравнения и печатающий отсортированную таблицу. Проверить все пять порядков.

## Ожидаемый результат
Пять таблиц упорядочены по-разному; сортируемый класс содержит ровно один метод сравнения; обратный порядок получен без дублирования логики прямого.
