# L34 · Задание II · №8. Три значения результата

**Тема:** Л34 — Интерфейсы. Использование методов в интерфейсах и их реализация. Копирование и сортировка объектов интерфейсных типов

## Условие
Для класса задания II.7 вывести значение метода сравнения для трёх пар объектов: первый предшествует второму, второй предшествует первому, объекты равны. Записать знак результата в каждом случае и сопоставить с правилом «меньше нуля — предшествует».

## Ожидаемый результат
Три значения имеют разные знаки; сопоставление с правилом выполнено.
