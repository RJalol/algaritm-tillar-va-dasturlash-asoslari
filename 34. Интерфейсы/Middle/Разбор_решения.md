# Разбор решения. L34 · Задание II · №1. Договор для несвязанных типов

## Условие
Объявить интерфейс «занимает место» с одним свойством, возвращающим объём, и реализовать его четырьмя классами из разных областей: книга, автомобиль, коробка, аквариум. Написать метод, вычисляющий суммарный объём массива типа интерфейса, и проверить его.

## Ожидаемый результат
Суммарный объём вычислен верно; между четырьмя классами нет ни одного отношения наследования.

## Разбор условия
**Дано:** книга, автомобиль, коробка, аквариум.
**Требуется:** интерфейс «занимает место» со свойством `Volume`; метод суммарного объёма по массиву интерфейса.

## Теоретическая справка
Интерфейс выражает **роль** («занимает место»), а не происхождение. Четыре класса из разных областей не имеют общего предка, но все умеют сообщать объём — этого достаточно для общей функции.

Это пример принципа «**программируй на уровне интерфейсов**»: метод `TotalVolume` зависит только от свойства `Volume`, поэтому новые типы подключаются без изменения метода.

Единицы измерения — часть договора; в примере везде кубические метры.

## Идея решения
Интерфейс с одним свойством `Volume` объединяет четыре совершенно разных класса; суммирование объёмов работает для любого из них.

## Решение
```csharp
using System;
using System.Linq;

interface IOccupiesSpace
{
    double Volume { get; }          // в кубических метрах
}

class Book : IOccupiesSpace
{
    public double Width { get; set; } = 0.15, Height { get; set; } = 0.22, Thickness { get; set; } = 0.03;
    public double Volume => Width * Height * Thickness;
}

class Car : IOccupiesSpace
{
    public double Length { get; set; } = 4.2, Width { get; set; } = 1.8, Height { get; set; } = 1.5;
    public double Volume => Length * Width * Height;
}

class Box : IOccupiesSpace
{
    public double Side { get; set; } = 0.5;
    public double Volume => Side * Side * Side;
}

class Aquarium : IOccupiesSpace
{
    public double Length { get; set; } = 1.0, Width { get; set; } = 0.4, Height { get; set; } = 0.5;
    public double Volume => Length * Width * Height;
}

class Program
{
    static double TotalVolume(IOccupiesSpace[] items) => items.Sum(i => i.Volume);

    static void Main()
    {
        IOccupiesSpace[] things = { new Book(), new Car(), new Box(), new Aquarium() };
        Console.WriteLine($"Суммарный объём: {TotalVolume(things):F4} м³");
    }
}
```

## Пошаговое объяснение
1. Классы `Book`, `Car`, `Box`, `Aquarium` ничего не наследуют друг от друга — общего предка, кроме `object`, у них нет.
2. Единственное, что их объединяет, — свойство `Volume`, поэтому именно оно вынесено в интерфейс.
3. `TotalVolume` принимает массив интерфейса и суммирует `Volume` через LINQ; конкретные типы не упоминаются.
4. Расчёт: книга 0,0010 + автомобиль 11,3400 + коробка 0,1250 + аквариум 0,2000 ≈ 11,6660 м³ (книга ≈ 0,00099).

## Трассировка и проверка
| Объект | Volume, м³ |
|---|--:|
| Book 0,15×0,22×0,03 | 0,00099 |
| Car 4,2×1,8×1,5 | 11,34 |
| Box 0,5³ | 0,125 |
| Aquarium 1×0,4×0,5 | 0,2 |
| **Сумма** | **≈ 11,67** |

## Результат
Суммарный объём ≈ 11,67 м³; между четырьмя классами нет наследования.

## Типичные ошибки
- Смешивать единицы измерения.
- Создавать общий базовый класс ради одного свойства.
- Забыть реализовать свойство в одном из классов.
- Хранить объём в поле вместо вычисления из размеров.
