# Разбор решения. L29 · Задание I · №1. Список дисков

## Условие
С помощью `DriveInfo.GetDrives()` вывести имена всех дисков компьютера, их тип и признак готовности.

## Ожидаемый результат
Выведен список дисков с именем, типом и состоянием.

## Разбор условия
**Дано:** компьютер с дисками.
**Требуется:** вывести имя, тип и готовность каждого диска через `DriveInfo.GetDrives()`.

## Теоретическая справка
Пространство имён `System.IO` содержит классы работы с файловой системой:

| Класс | Назначение |
|---|---|
| `DriveInfo` | сведения о дисках |
| `Directory`, `DirectoryInfo` | каталоги |
| `File`, `FileInfo` | файлы |
| `Path` | операции с путями |

Статические методы (`File`, `Directory`) удобны для разовых операций; экземплярные классы (`FileInfo`, `DirectoryInfo`) — при многократном обращении к одному объекту.

У неготового диска (`IsReady == false`) большинство свойств недоступно — обращение вызывает `IOException`.

## Идея решения
Класс `DriveInfo` описывает логические диски. Статический метод `GetDrives()` возвращает их массив.

## Решение
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        foreach (DriveInfo d in DriveInfo.GetDrives())
        {
            Console.WriteLine("Диск: " + d.Name);
            Console.WriteLine("  Тип: " + d.DriveType);
            Console.WriteLine("  Готов: " + d.IsReady);
        }
    }
}
```

## Пошаговое объяснение
1. `DriveInfo.GetDrives()` возвращает `DriveInfo[]` для всех дисков системы.
2. `Name` — имя диска (например, `C:\` или `/`), `DriveType` — тип (Fixed, Removable, Network…).
3. `IsReady` показывает, готов ли диск: у неготового (например, пустой привод) остальные свойства недоступны и вызывают `IOException`.

## Трассировка и проверка
Пример вывода:

```
Диск: C:\
  Тип: Fixed
  Готов: True
Диск: D:\
  Тип: CDRom
  Готов: False
```

Для неготового диска дополнительные свойства (`TotalSize`, `AvailableFreeSpace`) читать нельзя — сначала проверяют `IsReady`.

## Результат
Для каждого диска выведены имя, тип и признак готовности.

## Типичные ошибки
- Читать `TotalSize` у неготового диска.
- Предполагать наличие буквы диска (в Linux/macOS диски выглядят иначе).
- Жёстко записывать путь `C:\\` в программе, рассчитанной на разные системы.
- Забывать подключить `using System.IO;`.
