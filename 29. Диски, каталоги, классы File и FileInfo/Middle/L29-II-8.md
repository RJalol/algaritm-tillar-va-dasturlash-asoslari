# L29 · Задание II · №8. Размер каталога

**Тема:** Л29 — Работа с дисками и каталогами. Работа с файлами. Классы File и FileInfo. Файлы и потоки

## Условие
Вычислить суммарный размер всех файлов каталога, включая подкаталоги.

## Ожидаемый результат
Результат совпадает с размером, сообщаемым файловым менеджером (с точностью до округления).
