# Тема 29. Работа с дисками и каталогами. Работа с файлами. Классы File и FileInfo. Файлы и потоки

Практические задания к теме №29 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
29. Диски, каталоги, классы File и FileInfo/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
└── Advanced/   10 заданий  (Задание III)
```

## Формат задания

Каждый файл `L29-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. Для каждого уровня (`Easy/`, `Middle/`, `Advanced/`) приведён один образцовый разбор — файл `Разбор_решения.md`; остальные задания предназначены для самостоятельного выполнения.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.
