# Разбор решения. L40 · Задание II · №1. Обращение строки стеком

## Условие
Обратить строку с помощью стека символов.

## Ожидаемый результат
`"алгоритм"` превращается в `мтирогла`.

## Разбор условия
**Дано:** строка.
**Требуется:** обратить её с помощью стека символов.

## Теоретическая справка
Стек **обращает порядок**: элементы входят в порядке 1, 2, 3, а выходят в порядке 3, 2, 1. Это единственное свойство, нужное для задачи.

Алгоритм: пройти по строке, кладя символы в `Stack<char>`; затем извлекать символы, накапливая результат в `StringBuilder` (не в `string`, чтобы не создавать новую строку на каждой итерации).

Сложность: O(n) по времени и по памяти.

## Идея решения
Стек обращает порядок: символы кладём в стек по очереди, а извлекаем в обратном порядке.

## Решение
```csharp
using System;
using System.Collections.Generic;
using System.Text;

class Program
{
    static string Reverse(string s)
    {
        Stack<char> stack = new Stack<char>();
        foreach (char c in s)
            stack.Push(c);

        StringBuilder sb = new StringBuilder();
        while (stack.Count > 0)
            sb.Append(stack.Pop());
        return sb.ToString();
    }

    static void Main()
    {
        Console.WriteLine(Reverse("алгоритм"));
    }
}
```

## Пошаговое объяснение
1. Каждый символ строки кладётся в `Stack<char>`: первым — `а`, последним — `м`.
2. Из стека символы выходят в обратном порядке: сначала `м`, затем `т` и т. д.
3. Результат накапливаем в `StringBuilder`, чтобы не создавать новую строку на каждой итерации.
4. Сложность решения линейная — O(n).

## Трассировка и проверка
Для «алгоритм»:

| Этап | Содержимое стека (вершина слева) |
|---|---|
| после `Push` всех | м, и, р, о, г, л, а |
| `Pop` ×7 | м, и, р, о, г, л, а |

Результат: «мтирогла» — символы извлечены в обратном порядке.

## Результат
мтирогла

## Типичные ошибки
- Конкатенировать результат в `string` в цикле.
- Забыть привести `char` к строке при выводе.
- Не обработать пустую строку.
- Использовать массив и индексы там, где требуется показать стек.
