# Разбор решения. L43 · Задание I · №1. TextBox и Label

## Условие
Ввести имя в `TextBox` и по нажатию кнопки вывести приветствие в `Label`.

## Ожидаемый результат
Приветствие содержит введённое имя.

## Разбор условия
**Дано:** поле ввода, кнопка, метка.
**Требуется:** по нажатию кнопки вывести в метку приветствие с введённым именем.

## Теоретическая справка
Основные элементы:

| Элемент | Назначение | Ключевое свойство |
|---|---|---|
| `Label` | вывод текста | `Text` |
| `TextBox` | ввод текста | `Text` |
| `Button` | команда | событие `Click` |

**Событие** — сообщение элемента о действии пользователя; **обработчик** — метод, вызываемый при событии. Подписка: `button.Click += (s, e) => …;`.

Значение `TextBox.Text` — строка; пустое поле даёт пустую строку (не `null`).

## Идея решения
Свойство `Text` у `TextBox` содержит введённый текст; присваиваем строку приветствия свойству `Text` метки.

## Решение
```csharp
using System;
using System.Drawing;
using System.Windows.Forms;

public class Form1 : Form
{
    public Form1()
    {
        Text = "Приветствие";
        Size = new Size(320, 160);

        var name = new TextBox { Left = 10, Top = 10, Width = 200 };
        var button = new Button { Text = "Поприветствовать", Left = 10, Top = 45, Width = 200 };
        var result = new Label { Left = 10, Top = 85, AutoSize = true };

        button.Click += (s, e) => result.Text = "Здравствуйте, " + name.Text + "!";

        Controls.AddRange(new Control[] { name, button, result });
    }
}
```

## Пошаговое объяснение
1. Создаём три элемента: поле ввода, кнопку и метку для вывода.
2. Обработчик `Click` формирует строку из введённого имени и записывает её в `result.Text`.
3. Для пустого поля получится «Здравствуйте, !»; в улучшенной версии стоит проверять `string.IsNullOrWhiteSpace(name.Text)`.

## Трассировка и проверка
| Ввод в `TextBox` | Текст в `Label` |
|---|---|
| Азиз | Здравствуйте, Азиз! |
| (пусто) | Здравствуйте, ! |

Для пустого ввода уместно проверить `string.IsNullOrWhiteSpace(name.Text)` и вывести подсказку.

## Результат
При вводе «Азиз» метка показывает: Здравствуйте, Азиз!

## Типичные ошибки
- Забыть подписаться на событие.
- Обратиться к элементу до его создания.
- Не проверить пустой ввод.
- Использовать `Label.Text` для ввода данных.
