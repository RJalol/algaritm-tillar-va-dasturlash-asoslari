# Разбор решения. L43 · Задание II · №1. Меню с подменю

## Условие
Создать меню «Правка» с пунктами «Копировать», «Вставить», «Вырезать» и разделителем, работающими с `TextBox`.

## Ожидаемый результат
Операции выполняются над выделенным текстом.

## Разбор условия
**Дано:** `TextBox`.
**Требуется:** меню «Правка» с пунктами «Копировать», «Вставить», «Вырезать» и разделителем; горячие клавиши.

## Теоретическая справка
`MenuStrip` содержит пункты `ToolStripMenuItem`; вложенные пункты хранятся в `DropDownItems`. Для пункта задают:

- `Text` (амперсанд `&` подчёркивает букву для быстрого доступа `Alt+буква`);
- `ShortcutKeys` — сочетание клавиш (`Keys.Control | Keys.C`);
- `Click` — обработчик.

`TextBox` уже имеет методы `Copy`, `Cut`, `Paste`, `SelectAll`, `Undo`, работающие с буфером обмена и текущим выделением.

## Идея решения
`MenuStrip` содержит пункты `ToolStripMenuItem`. Операции правки реализуются готовыми методами `TextBox`: `Copy`, `Paste`, `Cut`.

## Решение
```csharp
using System;
using System.Windows.Forms;

public class Form1 : Form
{
    public Form1()
    {
        Text = "Меню «Правка»";
        Width = 480; Height = 320;

        var text = new TextBox { Dock = DockStyle.Fill, Multiline = true };

        var menu = new MenuStrip();
        var edit = new ToolStripMenuItem("Правка");

        var copy  = new ToolStripMenuItem("Копировать", null, (s, e) => text.Copy())  { ShortcutKeys = Keys.Control | Keys.C };
        var paste = new ToolStripMenuItem("Вставить",   null, (s, e) => text.Paste()) { ShortcutKeys = Keys.Control | Keys.V };
        var cut   = new ToolStripMenuItem("Вырезать",   null, (s, e) => text.Cut())   { ShortcutKeys = Keys.Control | Keys.X };

        edit.DropDownItems.Add(copy);
        edit.DropDownItems.Add(paste);
        edit.DropDownItems.Add(new ToolStripSeparator());
        edit.DropDownItems.Add(cut);
        menu.Items.Add(edit);

        Controls.Add(text);
        Controls.Add(menu);
        MainMenuStrip = menu;
    }
}
```

## Пошаговое объяснение
1. `MenuStrip` добавляется на форму и назначается главным меню (`MainMenuStrip`).
2. Пункт «Правка» содержит выпадающие подпункты (`DropDownItems`) и разделитель `ToolStripSeparator`.
3. Каждый подпункт получает обработчик, вызывающий соответствующий метод `TextBox` — работает с текущим выделением.
4. Свойство `ShortcutKeys` назначает горячие клавиши; они отображаются в меню справа от названия.

## Трассировка и проверка
| Пункт | Сочетание | Действие |
|---|---|---|
| Копировать | Ctrl+C | `text.Copy()` |
| Вставить | Ctrl+V | `text.Paste()` |
| Вырезать | Ctrl+X | `text.Cut()` |

Разделитель `ToolStripSeparator` группирует пункты визуально. Сочетания выводятся справа от названия пункта.

## Результат
Пункты меню копируют, вставляют и вырезают выделенный текст; сочетания Ctrl+C/V/X работают.

## Типичные ошибки
- Не назначить `MainMenuStrip` форме.
- Назначить `ShortcutKeys`, которые конфликтуют со стандартными сочетаниями `TextBox`.
- Добавить пункты в `Items` меню, а не в `DropDownItems`.
- Забыть проверку, есть ли выделение.
