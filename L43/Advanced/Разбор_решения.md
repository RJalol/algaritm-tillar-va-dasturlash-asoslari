# Разбор решения. L43 · Задание III · №9. Привязка данных

## Условие
Использовать `BindingSource` и `BindingList<T>` для связи списка объектов с элементами управления.

## Ожидаемый результат
Изменения объектов отображаются автоматически.

## Идея решения
`BindingList<T>` уведомляет связанные элементы управления об изменениях. Через `BindingSource` связываем список объектов с `DataGridView` и `TextBox` — правка в одном месте сразу видна в другом.

## Решение
```csharp
using System;
using System.ComponentModel;
using System.Windows.Forms;

public class Student
{
    public string Name { get; set; }
    public string Group { get; set; }
    public int Score { get; set; }
}

public class Form1 : Form
{
    public Form1()
    {
        Text = "Привязка данных";
        Width = 520; Height = 340;

        var students = new BindingList<Student>
        {
            new Student { Name = "Азиз", Group = "ТТ-11", Score = 87 },
            new Student { Name = "Дилноза", Group = "ТТ-11", Score = 92 },
            new Student { Name = "Рустам", Group = "ТТ-12", Score = 78 }
        };

        var source = new BindingSource { DataSource = students };

        var grid = new DataGridView { Dock = DockStyle.Fill, DataSource = source };
        var name = new TextBox { Dock = DockStyle.Top };
        name.DataBindings.Add("Text", source, nameof(Student.Name));

        var add = new Button { Text = "Добавить", Dock = DockStyle.Bottom };
        add.Click += (s, e) => students.Add(new Student { Name = "Новый", Group = "ТТ-13", Score = 60 });

        Controls.Add(grid);
        Controls.Add(name);
        Controls.Add(add);
    }
}
```

## Пошаговое объяснение
1. `BindingList<Student>` — коллекция, генерирующая события при добавлении и удалении элементов.
2. `BindingSource` — посредник между данными и элементами: хранит текущую запись и перенаправляет изменения.
3. `DataGridView.DataSource = source` строит столбцы по свойствам `Student`.
4. `DataBindings.Add("Text", source, "Name")` привязывает текстовое поле к полю `Name` текущей записи: при выборе строки в таблице оно показывает имя, при редактировании меняет таблицу.
5. Кнопка «Добавить» меняет только коллекцию — таблица обновляется сама, без ручной перерисовки.

## Результат
Таблица и текстовое поле синхронизированы; добавление в коллекцию мгновенно отображается в таблице.
