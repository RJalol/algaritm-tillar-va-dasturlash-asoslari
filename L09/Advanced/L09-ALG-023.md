# L09-ALG-023. Поиск пары с заданным произведением

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Написать программу, которая запрашивает целое число и ищет пару натуральных множителей из диапазона от 2 до 100, произведение которых равно введённому. Перебор должен прекращаться **полностью** сразу после находки. Если пары нет, сообщить об этом. Проверить работу на числах 91 и 97.

## Ожидаемый результат
Для 91 выведена пара `7` и `13`, для 97 — сообщение об отсутствии пары; выход из обоих циклов выполнен одним из двух изученных приёмов.
