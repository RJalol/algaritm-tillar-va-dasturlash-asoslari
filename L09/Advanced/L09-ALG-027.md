# L09-ALG-027. Оценка выигрыша от досрочного выхода

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Написать программу, которая для каждого числа от 2 до 100 определяет, простое ли оно, двумя способами: с оператором `break` и без него. Подсчитать суммарное число итераций внутреннего цикла в каждом случае и вывести оба числа. Объяснить в комментарии, для каких чисел выигрыш максимален, а для каких отсутствует.

## Ожидаемый результат
Два числа: `236` итераций с оператором `break` против `525` без него — выигрыш более чем вдвое; в комментарии указано, что для составных чисел с малым делителем выигрыш наибольший, а для простых чисел выигрыша нет, поскольку цикл в обоих случаях проходит до конца.
