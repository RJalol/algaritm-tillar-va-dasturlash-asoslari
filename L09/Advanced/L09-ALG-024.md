# L09-ALG-024. Два приёма выхода из вложенных циклов

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Решить задачу ALG-023 **дважды**: сначала с логической переменной-признаком, затем оператором `goto`. Убедиться, что оба варианта дают одинаковый результат. В комментарии сравнить их по трём признакам: объём кода, сложность условия внешнего цикла и наглядность намерения.

## Ожидаемый результат
Два работающих варианта с совпадающим выводом; в комментарии отмечено, что признак усложняет условие внешнего цикла, а `goto` короче, но вводит метку.
