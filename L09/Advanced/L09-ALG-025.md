# L09-ALG-025. Первое простое число, большее заданного

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Написать программу, которая запрашивает целое число и находит наименьшее простое число, строго большее введённого. Использовать два цикла: внешний перебирает кандидатов, внутренний проверяет их на простоту; оба должны завершаться досрочно, как только результат определён.

## Ожидаемый результат
Для 100 выведено `101`, для 90 — `97`; внутренний цикл прекращается при первом найденном делителе, внешний — при первом найденном простом числе.
