# L09-ALG-026. Досрочный выход при превышении

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Написать программу, которая проверяет, является ли введённое число совершенным (тема №8), суммируя его делители. Добавить досрочный выход: как только накопленная сумма делителей превысит само число, продолжать перебор бессмысленно. Вывести результат проверки и число выполненных итераций. Сравнить в комментарии число итераций с решением без досрочного выхода для числа 9999.

## Ожидаемый результат
Ответ о совершенности совпадает с решением темы №8; для чисел с большой суммой делителей число итераций заметно меньше; сравнение приведено в комментарии.
