# L09-ALG-022. Предсказание вывода при вложенных переходах

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Даны три фрагмента с одинаковой структурой вложенных циклов, различающиеся только оператором перехода: (A) `break` при `j == 2`; (B) `continue` при `j == 2`; (C) признак `stop` и `break` при `i == 2 && j == 2`, причём условие внешнего цикла дополнено проверкой `!stop`.

Внешний и внутренний циклы перебирают значения от 1 до 3, в теле выводится пара `(i,j)`. Не запуская программы, определить вывод каждого фрагмента и объяснить различия. Проверить ответы запуском.

## Ожидаемый результат
Предсказаны выводы `(1,1) (2,1) (3,1)`, `(1,1) (1,3) (2,1) (2,3) (3,1) (3,3)` и `(1,1) (1,2) (1,3) (2,1)`; для каждого объяснено, какой цикл затронут переходом.
