# L09-ALG-030. Полный аудит фрагмента с операторами перехода

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Дан код:

```
using System;

namespace AuditDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            int i = 0;
            while (i < 10)
            {
                if (i % 2 == 0) { continue; }
                Console.WriteLine(i);
                i++;
            }

            for (int k = 1; k <= 5; k++)
            {
                break;
                Console.WriteLine(k);
            }

            for (int a = 1; a <= 3; a++)
            {
                for (int b = 1; b <= 3; b++)
                {
                    if (a * b > 4) { break; }
                }
            }
            Console.WriteLine("Поиск завершён");
        }
    }
}
```

Провести полный аудит и разнести замечания по трём категориям: предупреждение компилятора; логическая ошибка, приводящая к тому, что программа не завершится; логическая ошибка, при которой оператор перехода действует не на тот цикл, на который рассчитывал автор. Для каждой указать конкретную строку и назвать код там, где он есть. Привести исправленную версию.

**Внимание:** запускать исходный фрагмент не следует — он содержит бесконечный цикл.

## Ожидаемый результат
Категории разнесены верно: предупреждение `CS0162` на строке после безусловного `break`; бесконечный цикл `while` из-за `continue`, расположенного до увеличения счётчика; `break` во внутреннем цикле, прерывающий только его, тогда как по смыслу задачи поиск следовало прекратить полностью. Приведён исправленный код.
