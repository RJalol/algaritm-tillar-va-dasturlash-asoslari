# L09-ALG-021. Три нарушения в одном фрагменте

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Дан код:

```
int x = 5;
if (x > 0)
{
    break;
}

for (int i = 1; i <= 3; i++)
{
    goto Finish;
}

for (int i = 1; i <= 5; i++)
{
    break;
    Console.WriteLine(i);
}
```

Найти все нарушения, для каждого назвать код сообщения компилятора и объяснить причину отдельно. Указать, какие два из них являются ошибками, а какое — предупреждением, и почему различие существенно. Привести исправленный фрагмент.

## Ожидаемый результат
Три сообщения: ошибки `CS0139` и `CS0159`, предупреждение `CS0162`; отмечено, что предупреждение не препятствует сборке, из-за чего соответствующая ошибка проявляется только в поведении программы.
