# L09-ALG-029. Взаимная замена goto и признака

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Дана программа с оператором `goto`, выходящим из двух вложенных циклов. Переписать её без `goto`, используя логическую переменную-признак. Затем выполнить обратное преобразование для программы, написанной с признаком. Для каждого преобразования указать, что именно пришлось изменить, помимо самого оператора перехода.

## Ожидаемый результат
Оба преобразования выполнены, выводы совпадают; отмечено, что при замене `goto` на признак потребовалось дополнить условие внешнего цикла, а при обратной замене — ввести метку и удалить проверку признака.
