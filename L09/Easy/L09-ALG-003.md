# L09-ALG-003. Первый делитель числа

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Написать программу, которая запрашивает целое число больше единицы и находит его наименьший делитель, больший единицы, перебирая числа по возрастанию и прекращая перебор сразу после находки.

## Ожидаемый результат
Для 30 выведено `2`, для 91 — `7`, для 29 — само число 29 как наименьший делитель простого числа; после находки цикл прекращает работу.
