# L09-ALG-004. Сумма чётных чисел

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Написать программу, которая вычисляет сумму всех чётных чисел от 1 до 100, перебирая все числа подряд и пропуская нечётные с помощью оператора `continue`. Вывести результат.

## Ожидаемый результат
Выведено `2550`; цикл перебрал все сто значений, а накопление выполнялось только для чётных.
