# Разбор решения. L09-ALG-001. Вывод до первого кратного семи

## Условие
Написать программу, которая выводит числа от 1 до 30, но прекращает вывод, как только встретится число, кратное семи. Само это число не выводить. Использовать оператор `break`.

## Ожидаемый результат
Выведено `1 2 3 4 5 6`; цикл завершился досрочно, не дойдя до значения 30.

## Идея решения
Цикл `for` от 1 до 30; как только число кратно 7 (остаток от деления на 7 равен нулю), выходим из цикла оператором `break`, не выводя это число.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        for (int i = 1; i <= 30; i++)
        {
            if (i % 7 == 0)
                break;
            Console.Write(i + " ");
        }
        Console.WriteLine();
    }
}
```

## Пошаговое объяснение
1. Проверка кратности стоит *перед* выводом, поэтому число 7 не печатается.
2. `break` немедленно прекращает ближайший охватывающий цикл.
3. Выведены только числа 1…6; итерации 8…30 не выполняются.

## Результат
Выведено: 1 2 3 4 5 6
