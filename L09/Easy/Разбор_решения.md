# Разбор решения. L09-ALG-001. Вывод до первого кратного семи

## Условие
Написать программу, которая выводит числа от 1 до 30, но прекращает вывод, как только встретится число, кратное семи. Само это число не выводить. Использовать оператор `break`.

## Ожидаемый результат
Выведено `1 2 3 4 5 6`; цикл завершился досрочно, не дойдя до значения 30.

## Разбор условия
**Дано:** числа 1…30.
**Требуется:** вывести их, но прекратить, как только встретится число, кратное 7; само число не выводить; использовать `break`.

## Теоретическая справка
Оператор **`break`** немедленно прекращает выполнение ближайшего охватывающего цикла (или `switch`) и передаёт управление первому оператору после него.

Порядок операторов в теле цикла важен: условие выхода проверяется **до** вывода, поэтому число 7 не печатается. Если сначала вывести, а затем проверить, 7 появилось бы в выводе.

## Идея решения
Цикл `for` от 1 до 30; как только число кратно 7 (остаток от деления на 7 равен нулю), выходим из цикла оператором `break`, не выводя это число.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        for (int i = 1; i <= 30; i++)
        {
            if (i % 7 == 0)
                break;
            Console.Write(i + " ");
        }
        Console.WriteLine();
    }
}
```

## Пошаговое объяснение
1. Проверка кратности стоит *перед* выводом, поэтому число 7 не печатается.
2. `break` немедленно прекращает ближайший охватывающий цикл.
3. Выведены только числа 1…6; итерации 8…30 не выполняются.

## Трассировка и проверка
| i | `i % 7 == 0` | Действие |
|--:|:--:|---|
| 1…6 | нет | вывод |
| 7 | да | `break` — выход, 7 не выводится |
| 8…30 | — | не выполняются |

Итог: `1 2 3 4 5 6`. Всего выполнено 7 итераций, из них 6 с выводом.

## Результат
Выведено: 1 2 3 4 5 6

## Типичные ошибки
- Поставить проверку после вывода — получится `1 … 7`.
- Использовать `continue` вместо `break` — цикл продолжится и выведет остальные числа.
- Вызвать `break` вне цикла — ошибка `CS0139`.
- Выход из вложенного цикла `break`-ом прерывает только внутренний цикл.

## Задания для закрепления
- Выводить числа до первого числа, кратного и 3, и 5.
- Найти первое число от 1000, делящееся на 17, и вывести его.
- Решить задачу без `break` с условием цикла.
