# L09-ALG-005. Первое число с квадратом больше заданного

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Написать программу, которая запрашивает целое положительное число и находит наименьшее натуральное число, квадрат которого превышает введённое. Перебор прекратить сразу после находки.

## Ожидаемый результат
Для 7 выведено `3`, для 100 — `11`; после присваивания результата цикл завершается оператором `break`.
