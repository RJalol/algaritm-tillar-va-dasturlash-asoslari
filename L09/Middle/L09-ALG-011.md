# L09-ALG-011. break во вложенных циклах

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Дан код:

```
for (int i = 1; i <= 3; i++)
{
    for (int j = 1; j <= 3; j++)
    {
        if (j == 2) { break; }
        Console.Write("(" + i + "," + j + ") ");
    }
}
```

Не запуская программу, определить вывод. Объяснить, на какой цикл подействовал `break`, и указать, каким был бы вывод, если бы он прерывал оба цикла. Проверить ответ запуском.

## Ожидаемый результат
Предсказан вывод `(1,1) (2,1) (3,1)`; объяснено, что прерван только внутренний цикл; указано, что при выходе из обоих вывелась бы единственная пара `(1,1)`.
