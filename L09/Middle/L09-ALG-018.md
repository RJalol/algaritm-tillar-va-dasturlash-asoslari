# L09-ALG-018. Форма goto case

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Написать программу, которая по номеру дня недели выводит его название, а для субботы и воскресенья дополнительно выводит строку «Выходной день». Для субботы использовать переход `goto case` в секцию воскресенья, чтобы не повторять вывод дважды.

## Ожидаемый результат
Для номера 6 выведены две строки — название дня и сообщение о выходном; переход записан явно оператором `goto case`.
