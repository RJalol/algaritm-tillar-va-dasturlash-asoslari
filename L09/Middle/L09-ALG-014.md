# L09-ALG-014. Недостижимый код

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Дан код:

```
for (int i = 1; i <= 5; i++)
{
    break;
    Console.WriteLine(i);
}
```

Определить, что выведет программа, назвать сообщение компилятора и объяснить, почему это предупреждение, а не ошибка. Указать, сколько раз выполнится тело цикла.

## Ожидаемый результат
Программа не выводит ничего; названо предупреждение `CS0162`; указано, что тело выполнилось один раз, но до строки вывода управление не дошло.
