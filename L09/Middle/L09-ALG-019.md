# L09-ALG-019. Несуществующая метка

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Дан код:

```
for (int i = 1; i <= 3; i++)
{
    goto Finish;
}
Console.WriteLine("Готово");
```

Объяснить, почему фрагмент не компилируется, назвать код ошибки и привести исправление. Дополнительно указать, был бы допустим переход **внутрь** тела цикла, если бы метка находилась там.

## Ожидаемый результат
Назван код `CS0159`; в исправлении метка добавлена после цикла; указано, что переход внутрь вложенной области запрещён.
