# L09-ALG-015. continue до изменения счётчика

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Дан код:

```
int i = 0;
while (i < 10)
{
    if (i % 2 == 0) { continue; }
    i++;
}
```

Определить, что произойдёт при выполнении этого фрагмента, и объяснить механизм. Указать, какое значение сохранит переменная `i`. Привести два исправления: перестановкой операторов и заменой вида цикла.

**Внимание:** этот фрагмент запускать не следует — он содержит бесконечный цикл.

## Ожидаемый результат
Установлено, что цикл бесконечен, а `i` остаётся равным нулю; объяснено, что `continue` передаёт управление к проверке условия, минуя увеличение счётчика; приведены оба исправления — перенос `i++` в начало тела и переход к циклу `for`.
