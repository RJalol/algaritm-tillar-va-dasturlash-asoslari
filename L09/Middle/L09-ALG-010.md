# L09-ALG-010. Цикл с командой выхода

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Написать программу, которая в бесконечном цикле запрашивает у пользователя строку и выводит её в верхнем регистре, а при вводе слова `выход` завершает работу оператором `break`. Заголовок цикла записать в форме `while (true)`.

## Ожидаемый результат
Программа обрабатывает произвольное число строк и корректно завершается по команде; условие выхода проверяется до обработки строки.
