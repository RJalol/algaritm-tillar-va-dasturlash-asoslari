# L09-ALG-008. Накопление до превышения порога

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Написать программу, которая складывает числа 1, 2, 3 и так далее до тех пор, пока накопленная сумма не превысит 100. Вывести полученную сумму и последнее прибавленное число. Выход из цикла выполнить оператором `break`.

## Ожидаемый результат
Выведены сумма `105` и последнее слагаемое `14`; проверка порога выполняется после прибавления.
