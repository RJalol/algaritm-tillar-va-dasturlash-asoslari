# L09-ALG-013. Оператор break вне цикла

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Дан код:

```
int x = 5;
if (x > 0)
{
    break;
}
```

Объяснить, почему фрагмент не компилируется, и назвать код ошибки. Указать, в каких двух конструкциях языка оператор `break` допустим.

## Ожидаемый результат
Назван код `CS0139`; указано, что `break` допустим только внутри цикла и внутри оператора `switch`.
