# L09-ALG-016. break в операторе switch внутри цикла

**Тема:** Л9 — Оператор break для выхода из цикла. Оператор continue и его применение. Оператор перехода goto

## Условие
Написать программу, которая в цикле перебирает числа от 1 до 5 и для каждого с помощью оператора `switch` выводит «мало» для 1 и 2, «средне» для 3 и «много» для остальных. Определить, прерывает ли цикл оператор `break`, завершающий секции `switch`, и подтвердить ответ фактическим выводом.

## Ожидаемый результат
Выведены пять строк — по одной на каждое число; подтверждено, что `break` относится к `switch` и на цикл не влияет.
