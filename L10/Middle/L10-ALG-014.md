# L10-ALG-014. Бинарный поиск

**Тема:** Л10 — Одномерные и многомерные массивы. Двумерные прямоугольные и нерегулярные массивы. Оператор итерации foreach

## Условие
Написать программу, которая выполняет бинарный поиск заданного значения в упорядоченном массиве `3, 7, 12, 18, 25, 31, 40`. Вывести индекс найденного элемента и число выполненных шагов. Проверить работу для значений 31, 3 и 100.

## Ожидаемый результат
Для 31 — индекс `5` за `2` шага, для 3 — индекс `0` за `3` шага, для 100 — сообщение об отсутствии; область поиска на каждом шаге сокращается вдвое.
