# L10-ALG-015. Выход за границы массива

**Тема:** Л10 — Одномерные и многомерные массивы. Двумерные прямоугольные и нерегулярные массивы. Оператор итерации foreach

## Условие
Дан код:

```
int[] numbers = { 10, 20, 30 };
for (int i = 0; i <= numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}
```

Определить, скомпилируется ли фрагмент и что произойдёт при выполнении. Назвать тип исключения, указать, на какой итерации оно возникнет, и объяснить, почему компилятор не обнаруживает эту ошибку. Привести исправление.

## Ожидаемый результат
Указано, что фрагмент компилируется, выводит три значения и завершается исключением `IndexOutOfRangeException` на четвёртой итерации; в исправлении знак `<=` заменён на `<`.
