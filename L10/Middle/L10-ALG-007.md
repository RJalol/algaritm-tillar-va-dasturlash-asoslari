# L10-ALG-007. Линейный поиск

**Тема:** Л10 — Массивы. Одномерные и многомерные массивы. Двумерные прямоугольные и ступенчатые массивы. Оператор цикла foreach

## Условие
Написать программу, которая ищет заданное значение в массиве `12, 7, 25, 3, 18` и выводит индекс первого совпадения либо сообщение об отсутствии. Поиск прекратить сразу после находки. Проверить работу для значений 25 и 99.

## Ожидаемый результат
Для 25 выведен индекс `2`, для 99 — сообщение об отсутствии; переменная результата инициализирована значением −1 до цикла.
