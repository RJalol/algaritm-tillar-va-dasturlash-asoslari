# Разбор решения. L10-ALG-006. Ввод массива с клавиатуры

## Условие
Написать программу, которая запрашивает количество элементов, создаёт массив такого размера, заполняет его введёнными с клавиатуры числами и выводит сумму и среднее арифметическое. Среднее вывести с сохранением дробной части.

## Ожидаемый результат
Программа работает при любом введённом количестве; среднее вычислено вещественным делением (тема №4), а не целочисленным.

## Разбор условия
**Дано:** количество элементов, вводимое пользователем, затем сами элементы.
**Требуется:** найти сумму и среднее арифметическое (с дробной частью).

## Теоретическая справка
Массив создаётся оператором `new T[n]`, где `n` может быть переменной — размер определяется во время выполнения.

**Среднее арифметическое** = сумма / количество. Если сумма и количество — целые, деление целочисленное и дробная часть теряется. Чтобы сохранить её, нужен хотя бы один вещественный операнд: либо массив `double[]`, либо приведение `(double)sum / n`.

Для пустого массива среднее не определено; при `n = 0` деление вещественных чисел даст `NaN`, а целых — исключение.

## Идея решения
Размер массива заранее неизвестен, поэтому сначала считываем его, затем создаём массив и заполняем. Для среднего используем вещественное деление.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Количество элементов: ");
        int n = int.Parse(Console.ReadLine());

        double[] a = new double[n];
        double sum = 0;

        for (int i = 0; i < n; i++)
        {
            Console.Write($"a[{i}] = ");
            a[i] = double.Parse(Console.ReadLine());
            sum += a[i];
        }

        Console.WriteLine("Сумма: " + sum);
        Console.WriteLine("Среднее: " + sum / n);
    }
}
```

## Пошаговое объяснение
1. Размер массива задаётся переменной `n` во время выполнения.
2. Сумма накапливается прямо при вводе.
3. Элементы и сумма — `double`, поэтому `sum / n` — вещественное деление и сохраняет дробную часть (при целых числах `7 / 2` дало бы 3).

## Трассировка и проверка
Ввод: n = 4; элементы 3, 5, 8, 2.

| Шаг | sum |
|--:|--:|
| после a[0] = 3 | 3 |
| после a[1] = 5 | 8 |
| после a[2] = 8 | 16 |
| после a[3] = 2 | 18 |

Среднее: 18 / 4 = 4,5 (при целочисленном делении получилось бы 4).

## Результат
Для 1, 2, 4 сумма = 7, среднее = 2,3333…

## Типичные ошибки
- Делить сумму целых на целое количество и получать усечённый результат.
- Начинать суммирование с ненулевого начального значения.
- Не проверять `n > 0` перед созданием массива и делением.
- Использовать `int` для вводимых значений, если допускаются дробные оценки.
