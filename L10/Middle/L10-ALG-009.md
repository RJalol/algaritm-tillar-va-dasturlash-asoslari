# L10-ALG-009. Подсчёт по нескольким условиям

**Тема:** Л10 — Одномерные и многомерные массивы. Двумерные прямоугольные и нерегулярные массивы. Оператор итерации foreach

## Условие
Написать программу, которая для массива `-5, 12, 0, -3, 7, 0, 25` подсчитывает отдельно количество положительных, отрицательных и нулевых элементов. Вывести все три числа.

## Ожидаемый результат
Положительных `3`, отрицательных `2`, нулевых `2`; сумма трёх чисел равна длине массива `7`, что служит проверкой правильности.
