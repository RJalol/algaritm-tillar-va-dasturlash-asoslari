# L10-ALG-012. Сортировка выбором

**Тема:** Л10 — Одномерные и многомерные массивы. Двумерные прямоугольные и нерегулярные массивы. Оператор итерации foreach

## Условие
Написать программу, которая сортирует массив `12, 7, 25, 3, 18` по возрастанию методом выбора: на каждом шаге находить наименьший элемент оставшейся части и менять его местами с текущим. Выводить массив после каждого прохода.

## Ожидаемый результат
Четыре промежуточные строки и итоговый массив `3 7 12 18 25`; обмен выполняется один раз за проход, вне внутреннего цикла.
