# L10-ALG-016. Изменение переменной цикла foreach

**Тема:** Л10 — Одномерные и многомерные массивы. Двумерные прямоугольные и нерегулярные массивы. Оператор итерации foreach

## Условие
Дан код:

```
int[] numbers = { 1, 2, 3 };
foreach (int value in numbers)
{
    value = value * 2;
}
```

Объяснить, почему фрагмент не компилируется, назвать код ошибки и переписать его так, чтобы элементы массива действительно удвоились. Объяснить, почему потребовалась замена вида цикла.

## Ожидаемый результат
Назван код `CS1656`; в исправленном варианте применён цикл `for` с обращением по индексу; объяснено, что переменная `foreach` содержит копию значения.
