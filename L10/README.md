# L10. Одномерные и многомерные массивы. Двумерные прямоугольные и нерегулярные массивы. Оператор итерации foreach

Практические задания к теме №10 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Особенность этой темы

До темы №10 каждое значение требовало собственной переменной, поэтому обработка ста чисел означала сто объявлений. Массив снимает это ограничение: набор элементов одного типа хранится под одним именем, а доступ к элементу выполняется по индексу — то есть **вычисляемому** выражению. Именно это делает цикл и массив естественной парой.

Вторая новая идея темы — **алгоритмы над набором данных**: линейный и бинарный поиск, сортировка выбором и пузырьком. Задание ALG-023 измеряет разницу численно: поиск значения 997 в упорядоченном массиве из 1000 элементов требует **997** шагов линейным методом против **8** шагов бинарным.

Не используются: **собственные методы** (тема №13), **строковые методы** (темы №11–12). Тип `List<int>` вводится только как средство хранения набора переменной длины; обобщённые коллекции подробно рассматриваются позднее.

## Ключевые идеи темы, проверяемые заданиями

- Индексация начинается с нуля, поэтому последний индекс равен `Length - 1`; знак `<=` в условии цикла даёт `IndexOutOfRangeException` **во время выполнения**, а не ошибку компиляции (ALG-015, ALG-021, ALG-030).
- Переменная цикла `foreach` доступна только для чтения — попытка присвоить ей значение даёт `CS1656`; изменение элементов требует цикла `for` (ALG-016, ALG-021).
- Поиск максимума с начальным значением `0` даёт неверный результат на массиве из одних отрицательных чисел; начинать следует с первого элемента (ALG-003, ALG-030).
- Бинарный поиск применим **только** к упорядоченному массиву и в неупорядоченном молча возвращает неверный результат (ALG-014, ALG-023).
- Для прямоугольного массива `Length` даёт **произведение** размеров, а число строк — `GetLength(0)`; смешение этих величин снова приводит к выходу за границы (ALG-022, ALG-030).
- Обращение вида `table[i][j]` к массиву `int[,]` — ошибка `CS0022`: у прямоугольного и нерегулярного массивов разный синтаксис (ALG-021).
- Размер массива фиксируется при создании; когда число элементов заранее неизвестно, применяется `List<int>` (ALG-020, ALG-029).

## О диагностических заданиях

Задания Middle ALG-015, ALG-016 и Advanced ALG-021, ALG-022, ALG-030 содержат код для анализа: найти ошибку, назвать её код либо предсказать результат до запуска.

Все коды сообщений (`CS1586`, `CS1656`, `CS0022`), тип исключения `IndexOutOfRangeException` и **все числовые ответы** (997 против 8 шагов; 5 обменов в сортировке пузырьком; 3 положительных, 2 отрицательных и 2 нулевых элемента; `Length` = 12, `GetLength(0)` = 3, `GetLength(1)` = 4, `Rank` = 2) проверены фактической компиляцией и запуском на .NET 8.

Каждый файл `L10-ALG-XXX.md` содержит только два поля: **Условие** и **Ожидаемый результат**. **Готовые решения не приводятся.**
