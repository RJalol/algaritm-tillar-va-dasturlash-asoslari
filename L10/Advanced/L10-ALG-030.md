# L10-ALG-030. Полный аудит программы работы с массивом

**Тема:** Л10 — Одномерные и многомерные массивы. Двумерные прямоугольные и нерегулярные массивы. Оператор итерации foreach

## Условие
Дан код:

```
using System;

namespace AuditDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            int[] numbers = { 12, 7, 25, 3, 18 };

            for (int i = 0; i <= numbers.Length; i++)
            {
                Console.WriteLine(numbers[i]);
            }

            int max = 0;
            foreach (int value in numbers)
            {
                if (value > max) { max = value; }
            }
            Console.WriteLine(max);

            int[,] table = new int[3, 4];
            for (int i = 0; i < table.Length; i++)
            {
                Console.WriteLine(table[i, 0]);
            }
        }
    }
}
```

Провести полный аудит и разнести замечания по трём категориям: ошибка времени выполнения из-за неверной границы цикла; логическая ошибка, которая проявляется только на определённых данных; ошибка, вызванная смешением `Length` и `GetLength`. Для каждой указать конкретную строку и объяснить последствия. Привести исправленную версию.

## Ожидаемый результат
Категории разнесены верно: `IndexOutOfRangeException` из-за знака `<=` в первом цикле; поиск максимума с начальным значением `0` даёт неверный результат для массива из одних отрицательных чисел; в третьем цикле `Length` равно 12, тогда как строк всего 3, что снова приводит к выходу за границы.
