# Разбор решения. L10-ALG-021. Четыре нарушения в одном фрагменте

## Условие
Дан код:

```
int[] noSize = new int[];

int[] numbers = { 1, 2, 3 };
foreach (int value in numbers)
{
    value = value * 2;
}

int[,] table = new int[2, 3];
Console.WriteLine(table[0][1]);

Console.WriteLine(numbers[3]);
```

Найти все нарушения. Для трёх из них назвать код ошибки компилятора; четвёртое **компилируется** — указать, что произойдёт при выполнении и почему компилятор его не обнаруживает. Привести исправленный фрагмент.

## Ожидаемый результат
Три ошибки компиляции — `CS1586`, `CS1656` и `CS0022`; четвёртое нарушение даёт `IndexOutOfRangeException` во время выполнения, поскольку значение индекса компилятору неизвестно.

## Идея решения
Проверяем размеры массивов, изменяемость переменной `foreach`, синтаксис многомерных индексов и границы индексов.

## Решение
```csharp
// Исправленный фрагмент
int[] noSize = new int[3];

int[] numbers = { 1, 2, 3 };
for (int i = 0; i < numbers.Length; i++)
{
    numbers[i] = numbers[i] * 2;          // изменяем элементы через for
}

int[,] table = new int[2, 3];
Console.WriteLine(table[0, 1]);           // индексы через запятую

Console.WriteLine(numbers[numbers.Length - 1]);
```

## Пошаговое объяснение
1. `new int[]` без размера и без инициализатора — ошибка `CS1586`: нужен размер или список значений.
2. В `foreach` переменная цикла доступна только для чтения; присваивание `value = value * 2` — ошибка `CS1656`. Для изменения элементов используем `for`.
3. `table[0][1]` — для двумерного массива индексы пишутся через запятую; запись `[0][1]` даёт `CS0022` (неверное число индексов).
4. `numbers[3]` компилируется (значение индекса компилятору неизвестно), но при выполнении выбросит `IndexOutOfRangeException`: допустимы индексы 0…2.

## Результат
Ошибки компиляции: CS1586, CS1656, CS0022; четвёртое нарушение проявляется при выполнении как IndexOutOfRangeException.
