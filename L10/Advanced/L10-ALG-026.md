# L10-ALG-026. Максимальный элемент каждой строки

**Тема:** Л10 — Одномерные и многомерные массивы. Двумерные прямоугольные и нерегулярные массивы. Оператор итерации foreach

## Условие
Написать программу, которая для двумерного массива находит наибольший элемент в каждой строке и выводит его вместе с номером столбца. Затем определить, в какой строке наибольший элемент оказался максимальным среди всех строк. Проверить на массиве `{{3,7,2},{9,1,5},{4,4,8}}`.

## Ожидаемый результат
Максимумы строк `7`, `9` и `8` со столбцами `1`, `0` и `2`; наибольший из них — `9` во второй строке.
