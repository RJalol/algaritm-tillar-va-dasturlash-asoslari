# Разбор решения. L10-ALG-001. Заполнение и вывод массива

## Условие
Написать программу, которая создаёт массив из десяти целых чисел, заполняет его квадратами номеров позиций (элемент с индексом `i` получает значение (i+1)²) и выводит все элементы в одну строку через пробел, используя цикл `for`.

## Ожидаемый результат
Выведено `1 4 9 16 25 36 49 64 81 100`; границей цикла служит свойство `Length`, а не записанное числом десять.

## Идея решения
Создаём массив `int[10]` и в цикле записываем в элемент с индексом `i` значение (i+1)². Границу цикла берём из `Length`.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        int[] squares = new int[10];

        for (int i = 0; i < squares.Length; i++)
            squares[i] = (i + 1) * (i + 1);

        for (int i = 0; i < squares.Length; i++)
            Console.Write(squares[i] + " ");
        Console.WriteLine();
    }
}
```

## Пошаговое объяснение
1. Индексы массива идут от 0 до 9, поэтому условие цикла `i < squares.Length`.
2. Элемент `i` получает `(i + 1)²`: при `i = 0` — 1, при `i = 9` — 100.
3. `Length` вместо числа 10 делает код устойчивым к изменению размера.
4. Второй цикл печатает элементы через пробел.

## Результат
Выведено: 1 4 9 16 25 36 49 64 81 100
