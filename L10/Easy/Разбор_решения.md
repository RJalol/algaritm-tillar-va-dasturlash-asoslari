# Разбор решения. L10-ALG-001. Заполнение и вывод массива

## Условие
Написать программу, которая создаёт массив из десяти целых чисел, заполняет его квадратами номеров позиций (элемент с индексом `i` получает значение (i+1)²) и выводит все элементы в одну строку через пробел, используя цикл `for`.

## Ожидаемый результат
Выведено `1 4 9 16 25 36 49 64 81 100`; границей цикла служит свойство `Length`, а не записанное числом десять.

## Разбор условия
**Дано:** массив из 10 целых.
**Требуется:** заполнить квадратами номеров позиций (элемент с индексом `i` — (i+1)²), вывести в строку через пробел; граница цикла — `Length`.

## Теоретическая справка
**Массив** — упорядоченный набор элементов одного типа, доступных по индексу. Индексы начинаются с 0, последний допустимый индекс равен `Length - 1`. Размер задаётся при создании и не меняется.

Выход индекса за границы вызывает `IndexOutOfRangeException` во время выполнения.

Свойство `Length` возвращает число элементов; использование его вместо константы делает код устойчивым к изменению размера.

## Идея решения
Создаём массив `int[10]` и в цикле записываем в элемент с индексом `i` значение (i+1)². Границу цикла берём из `Length`.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        int[] squares = new int[10];

        for (int i = 0; i < squares.Length; i++)
            squares[i] = (i + 1) * (i + 1);

        for (int i = 0; i < squares.Length; i++)
            Console.Write(squares[i] + " ");
        Console.WriteLine();
    }
}
```

## Пошаговое объяснение
1. Индексы массива идут от 0 до 9, поэтому условие цикла `i < squares.Length`.
2. Элемент `i` получает `(i + 1)²`: при `i = 0` — 1, при `i = 9` — 100.
3. `Length` вместо числа 10 делает код устойчивым к изменению размера.
4. Второй цикл печатает элементы через пробел.

## Трассировка и проверка
| i | (i+1)² | Элемент `squares[i]` |
|--:|--:|--:|
| 0 | 1 | 1 |
| 1 | 4 | 4 |
| 2 | 9 | 9 |
| … | … | … |
| 9 | 100 | 100 |

Вывод: `1 4 9 16 25 36 49 64 81 100`. Сумма элементов равна 385 (проверка по формуле n(n+1)(2n+1)/6 при n = 10).

## Результат
Выведено: 1 4 9 16 25 36 49 64 81 100

## Типичные ошибки
- Использовать `i <= squares.Length` — выход за границу массива.
- Записывать `i * i` — получатся квадраты индексов 0…9, а не позиций 1…10.
- Задать размер числом 10 в нескольких местах и забыть изменить одно из них.
- Выводить без пробела между числами.
