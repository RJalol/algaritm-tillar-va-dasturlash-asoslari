# L13-ALG-020. Первые проверки Debug.Assert

**Тема:** Л13 — Методы, возвращающие и не возвращающие значения. Методы с параметрами и без параметров. Локальные переменные и методы

## Условие
Написать метод `Square` и не менее пяти проверок `Debug.Assert` для него, включая проверки для аргументов 0 и отрицательного числа. Каждой проверке дать поясняющее сообщение вторым аргументом. После проверок вывести подтверждающую строку. Не забыть директиву `using System.Diagnostics;`.

## Ожидаемый результат
Программа выводит только подтверждающую строку; сами проверки при истинных условиях ничего не выводят.
