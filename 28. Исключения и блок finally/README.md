# Тема 28. Исключения и их обработка. Виды исключений и способы их генерации. Блок finally

Практические задания к теме №28 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
28. Исключения и блок finally/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
└── Advanced/   10 заданий  (Задание III)
```

## Формат задания

Каждый файл `L28-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. Для каждого уровня (`Easy/`, `Middle/`, `Advanced/`) приведён один образцовый разбор — файл `Разбор_решения.md`; остальные задания предназначены для самостоятельного выполнения.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.
