# Разбор решения. L28 · Задание II · №1. Несколько блоков catch

## Условие
Написать метод, который читает два числа из строк и делит одно на другое. Использовать три блока `catch` для `FormatException`, `DivideByZeroException` и `OverflowException` с разными сообщениями.

## Ожидаемый результат
Для каждого типа ошибки выводится своё сообщение; порядок блоков корректен.

## Разбор условия
**Дано:** строки с двумя числами.
**Требуется:** метод деления с тремя `catch` — `FormatException`, `DivideByZeroException`, `OverflowException` — с разными сообщениями.

## Теоретическая справка
**Несколько блоков `catch`:** исключение попадает в **первый подходящий** блок сверху вниз. Поэтому блоки с более общими типами (`Exception`) размещают **последними**; иначе компилятор сообщит `CS0160` (предыдущий блок уже перехватывает этот тип).

Источники исключений:

| Исключение | Причина |
|---|---|
| `FormatException` | строка не является числом |
| `OverflowException` | число не помещается в `int` |
| `DivideByZeroException` | деление целого на 0 |

Типы не связаны наследованием друг с другом (все наследуют `SystemException`), поэтому их взаимный порядок несущественен.

## Идея решения
Несколько блоков `catch` позволяют обрабатывать разные исключения по-разному. Исключение попадает в первый подходящий блок.

## Решение
```csharp
using System;

class Program
{
    static void Divide(string sa, string sb)
    {
        try
        {
            int a = int.Parse(sa);          // FormatException, OverflowException
            int b = int.Parse(sb);
            Console.WriteLine(a / b);       // DivideByZeroException
        }
        catch (FormatException)
        {
            Console.WriteLine("Ошибка формата: введено не число");
        }
        catch (DivideByZeroException)
        {
            Console.WriteLine("Ошибка: деление на ноль");
        }
        catch (OverflowException)
        {
            Console.WriteLine("Ошибка: число вне диапазона int");
        }
    }

    static void Main()
    {
        Divide("20", "4");
        Divide("abc", "4");
        Divide("20", "0");
        Divide("99999999999", "4");
    }
}
```

## Пошаговое объяснение
1. `int.Parse("abc")` выбрасывает `FormatException` — строка не число.
2. `a / b` при `b == 0` выбрасывает `DivideByZeroException`.
3. `int.Parse("99999999999")` выбрасывает `OverflowException` — число не помещается в `int`.
4. Каждый тип обрабатывается своим блоком со своим сообщением. Эти типы не связаны наследованием друг с другом, поэтому порядок блоков здесь не критичен (в отличие от общего `Exception`, который должен быть последним).

## Трассировка и проверка
| Вызов | Исключение | Блок |
|---|---|---|
| `Divide("20", "4")` | — | вывод 5 |
| `Divide("abc", "4")` | FormatException | первый |
| `Divide("20", "0")` | DivideByZeroException | второй |
| `Divide("99999999999", "4")` | OverflowException | третий |

## Результат
5; «Ошибка формата…»; «Ошибка: деление на ноль»; «Ошибка: число вне диапазона int».

## Типичные ошибки
- Поставить `catch (Exception)` перед конкретными типами (`CS0160`).
- Перехватывать `Exception` везде без разбора.
- Использовать исключения для обычного управления потоком.
- Выводить одинаковое сообщение для разных ошибок.
