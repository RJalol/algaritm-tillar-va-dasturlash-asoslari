# Разбор решения. L28 · Задание I · №1. Деление на ноль

## Условие
Прочитать два целых числа и вывести результат деления первого на второе. Обернуть деление в `try`-`catch`, перехватывающий `DivideByZeroException`, и вывести понятное сообщение вместо аварийного завершения.

## Ожидаемый результат
При вводе 10 и 2 выводится 5; при вводе 10 и 0 выводится сообщение об ошибке, программа завершается штатно.

## Разбор условия
**Дано:** два целых числа, вводимые пользователем.
**Требуется:** вывести результат деления первого на второе; деление обернуть в `try`-`catch`, перехватывающий `DivideByZeroException`.

## Теоретическая справка
**Исключение** — объект, описывающий ошибку времени выполнения; он «всплывает» вверх по стеку вызовов, пока не будет перехвачен обработчиком.

Конструкция:

```
try        { потенциально опасный код }
catch (Тип){ обработка }
```

- `try` — защищаемый блок;
- `catch (T)` — перехватывает исключения типа `T` и его наследников;
- после блока `catch` выполнение продолжается обычным образом.

`DivideByZeroException` возникает при делении **целых** чисел на ноль. Деление вещественных на ноль исключения не вызывает (результат — бесконечность или `NaN`).

## Идея решения
Исключение возникает при выполнении операции, которую нельзя выполнить (деление целого числа на ноль). Блок `try` содержит опасный код, блок `catch` его обрабатывает.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите делимое: ");
        int a = int.Parse(Console.ReadLine());
        Console.Write("Введите делитель: ");
        int b = int.Parse(Console.ReadLine());

        try
        {
            int result = a / b;
            Console.WriteLine("Результат: " + result);
        }
        catch (DivideByZeroException)
        {
            Console.WriteLine("Ошибка: делить на ноль нельзя");
        }

        Console.WriteLine("Программа завершена штатно");
    }
}
```

## Пошаговое объяснение
1. Числа читаются вне `try`: вопросы корректности ввода — отдельная тема (`FormatException`).
2. Деление помещено в `try`. Если `b == 0`, среда выполнения создаёт объект `DivideByZeroException` и прерывает выполнение блока.
3. Управление передаётся в `catch (DivideByZeroException)`, где выводится понятное сообщение.
4. После блока `catch` выполнение продолжается обычным образом — программа не завершается аварийно.

## Трассировка и проверка
| Ввод | Что происходит | Вывод |
|---|---|---|
| 10 и 2 | деление выполнено | Результат: 5 |
| 10 и 0 | `DivideByZeroException` → `catch` | Ошибка: делить на ноль нельзя |

В обоих случаях далее выводится «Программа завершена штатно» — исключение не привело к аварийному завершению.

## Результат
10 и 2 → «Результат: 5»; 10 и 0 → «Ошибка: делить на ноль нельзя»; в обоих случаях выводится «Программа завершена штатно».

## Типичные ошибки
- Помещать в `try` слишком много кода — трудно понять, что вызвало ошибку.
- Пустой `catch` («проглатывание» исключения) — ошибка скрывается.
- Проверять делитель условием и одновременно ловить исключение, не понимая, что нужно (достаточно одного).
- Ожидать исключения при делении вещественных чисел.
