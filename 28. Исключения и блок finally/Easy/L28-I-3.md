# L28 · Задание I · №3. Выход за границы массива

**Тема:** Л28 — Исключения и их обработка. Виды исключений и способы их генерации. Блок finally

## Условие
Создать массив из пяти элементов и запросить у пользователя индекс. Вывести элемент по индексу, перехватывая `IndexOutOfRangeException`.

## Ожидаемый результат
Для индексов 0–4 выводится элемент; для 7 или -1 — сообщение о недопустимом индексе.
