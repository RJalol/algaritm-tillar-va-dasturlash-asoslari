# L14-ALG-019. Рекурсия без базового случая

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Дан код:

```
static int Bad(int n)
{
    return Bad(n - 1);
}
```

**Запускать не следует.** Определить, компилируется ли метод, и объяснить, что произойдёт при вызове. Назвать возникающее исключение и указать, чего в методе не хватает. Привести исправленный вариант с базовым случаем.

## Ожидаемый результат
Метод компилируется; при вызове возбуждается `StackOverflowException` из-за отсутствия базового случая; в исправленном варианте добавлено условие, прекращающее рекурсию.
