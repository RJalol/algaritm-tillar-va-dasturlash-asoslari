# L14-ALG-014. Рекурсивный поиск максимума

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Написать рекурсивный метод, возвращающий наибольший элемент массива: он принимает массив и индекс, с которого начинать. Базовым случаем считать последний элемент. Проверить на массивах `{3, 17, 9}`, `{-5, -12, -3}` и на массиве из одного элемента.

## Ожидаемый результат
Выведено `17`, `-3` и сам единственный элемент; начальное значение нулём не задаётся ни разу.
