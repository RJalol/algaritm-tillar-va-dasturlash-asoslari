# L14-ALG-017. Неконстантное значение по умолчанию

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Дан код:

```
static void Bad(int n = DateTime.Now.Year)
{
    Console.WriteLine(n);
}
```

Назвать код ошибки и объяснить причину запрета. Переписать метод так, чтобы текущий год всё же использовался при отсутствии аргумента.

## Ожидаемый результат
Назван код `CS1736`; в исправленном варианте значением по умолчанию взята константа (например, `0`), а подстановка текущего года выполняется внутри метода проверкой этого значения.
