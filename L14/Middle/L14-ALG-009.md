# L14-ALG-009. Обращение строки рекурсивно

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Написать рекурсивный метод `Rev`, возвращающий строку с символами в обратном порядке. Использовать метод `Substring` (тема №12). Проверить на строке `"алгоритм"`, на строке из одного символа и на пустой строке.

## Ожидаемый результат
Выведено `мтирогла`, тот же единственный символ и пустая строка; базовый случай записан условием `Length <= 1`, охватывающим оба граничных случая.
