# L14-ALG-016. Необязательный параметр перед обязательным

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Дан код:

```
static void Bad(int a = 1, int b)
{
    Console.WriteLine(a + b);
}
```

Объяснить, почему объявление не компилируется, назвать код ошибки и привести два исправления: перестановкой параметров и превращением обоих в необязательные.

## Ожидаемый результат
Назван код `CS1737`; оба исправленных варианта компилируются, и указано, чем они различаются при вызове с одним аргументом.
