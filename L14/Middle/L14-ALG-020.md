# L14-ALG-020. Недостижимый базовый случай

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Дан код:

```
static int Countdown(int n)
{
    if (n == 0) return 0;
    return Countdown(n - 2);
}
```

**Запускать не следует.** Определить, для каких значений аргумента метод завершится, а для каких — нет, и объяснить причину. Привести исправление, работающее при любом целом аргументе.

## Ожидаемый результат
Метод завершается для чётных неотрицательных аргументов и не завершается для нечётных и отрицательных, поскольку базовый случай проверяет точное равенство нулю; в исправленном варианте условие заменено на `n <= 0`.
