# L14-ALG-018. Позиционный аргумент после именованного

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Для метода `Show(string name, int num, string prod)` даны три вызова:

```
Show(prod: "X", 31, "Y");
Show("A", 1, wrongName: "Z");
Show("A", num: 1, name: "B");
```

Определить код ошибки для каждого и объяснить различие. Для каждого привести исправленный вызов.

## Ожидаемый результат
Названы коды `CS8323` (позиционный аргумент следует за именованным не на своём месте), `CS1739` (параметра с таким именем нет) и `CS1744` (параметр уже задан позиционно).
