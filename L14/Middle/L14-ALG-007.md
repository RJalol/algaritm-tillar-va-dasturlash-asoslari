# L14-ALG-007. Наибольший общий делитель рекурсивно

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Написать рекурсивный метод `Gcd`, реализующий алгоритм Евклида. Тело метода записать одним оператором с условным оператором (тема №7). Проверить на парах (48, 18), (17, 5), (0, 7) и (12, 0).

## Ожидаемый результат
Выведено `6`, `1`, `7` и `12`; базовым случаем служит равенство второго аргумента нулю.
