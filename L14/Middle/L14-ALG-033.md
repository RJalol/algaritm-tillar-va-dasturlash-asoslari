# L14-ALG-033. Применение к массиву

**Тема:** Л14 — Модификаторы параметров в методах. Определение рекурсивных методов. Функции высшего порядка

## Условие
Написать метод `Map(int[] a, Func<int,int> f)`, возвращающий новый массив, элементы которого получены применением `f` к элементам `a`. Вызвать с квадратом и удвоением для массива {1, 2, 3, 4}.

## Ожидаемый результат
Получены {1, 4, 9, 16} и {2, 4, 6, 8}; исходный массив не изменён.
