# Разбор решения. L14-ALG-001. Метод с необязательными параметрами

## Условие
Написать метод `Greet`, принимающий имя, необязательное приветствие со значением по умолчанию `"Здравствуйте"` и необязательный знак препинания со значением по умолчанию `'!'`. Вызвать его тремя способами: с одним аргументом, с двумя и с тремя.

## Ожидаемый результат
Выведено `Здравствуйте, Азиз!`, `Привет, Азиз!` и `Привет, Азиз.`; необязательные параметры расположены после обязательного.

## Разбор условия
**Дано:** метод приветствия с обязательным именем и двумя необязательными параметрами.
**Требуется:** вызвать его тремя способами — с одним, двумя и тремя аргументами.

## Теоретическая справка
**Необязательные параметры** имеют значение по умолчанию, указанное при объявлении: `string greeting = "Здравствуйте"`. При вызове их можно опустить.

Правила:

- необязательные параметры располагаются **после** обязательных (`CS1737` иначе);
- значение по умолчанию — константное выражение (`CS1736` иначе);
- опускать можно только конечные параметры, если не использованы именованные аргументы.

## Идея решения
Необязательные параметры получают значение по умолчанию прямо в объявлении и обязаны стоять после обязательных.

## Решение
```csharp
using System;

class Program
{
    static void Greet(string name, string greeting = "Здравствуйте", char mark = '!')
    {
        Console.WriteLine(greeting + ", " + name + mark);
    }

    static void Main()
    {
        Greet("Азиз");
        Greet("Азиз", "Привет");
        Greet("Азиз", "Привет", '.');
    }
}
```

## Пошаговое объяснение
1. `name` обязателен и стоит первым.
2. `greeting` и `mark` необязательны — при пропуске подставляются значения по умолчанию.
3. Первый вызов использует оба умолчания, второй — только знак по умолчанию, третий задаёт всё явно.

## Трассировка и проверка
| Вызов | name | greeting | mark | Вывод |
|---|---|---|:--:|---|
| `Greet("Азиз")` | Азиз | Здравствуйте | ! | Здравствуйте, Азиз! |
| `Greet("Азиз", "Привет")` | Азиз | Привет | ! | Привет, Азиз! |
| `Greet("Азиз", "Привет", '.')` | Азиз | Привет | . | Привет, Азиз. |

Значения по умолчанию подставляются на этапе компиляции в место вызова.

## Результат
Здравствуйте, Азиз! / Привет, Азиз! / Привет, Азиз.

## Типичные ошибки
- Поставить необязательный параметр перед обязательным.
- Задать значение по умолчанию, вычисляемое во время выполнения.
- Забыть, что строка и символ записываются в разных кавычках.
- Менять порядок аргументов, не используя именованные.

## Задания для закрепления
- Вызвать метод, пропустив средний параметр с помощью именованного аргумента.
- Заменить необязательные параметры перегрузками (тема №18) и сравнить.
- Добавить параметр «язык» со значением по умолчанию.
