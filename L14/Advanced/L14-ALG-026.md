# L14-ALG-026. Ханойские башни с выводом ходов

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Дополнить метод задания ALG-012 выводом каждого перекладывания в виде «диск `k`: A → C». Вывести полную последовательность ходов для трёх дисков и подсчитать их число. Затем, не выводя ходов, подсчитать их число для 10 дисков.

## Ожидаемый результат
Для трёх дисков выведено `7` ходов, первый и последний из которых перемещают наименьший диск; для десяти дисков число ходов равно `1023`.
