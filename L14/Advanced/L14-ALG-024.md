# L14-ALG-024. Три ошибки в рекурсивных методах

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Даны три метода:

```
static int A(int n) { return n * A(n - 1); }
static int B(int n) { if (n == 0) return 0; return B(n - 2); }
static int C(int n) { if (n <= 1) return 1; return C(n); }
```

**Запускать не следует.** Для каждого определить, какое из двух условий правильности рекурсии нарушено: отсутствие базового случая, недостижимость базового случая или отсутствие приближения к нему. Указать, при каких аргументах каждый метод завершится, если такие аргументы есть. Привести исправленный вариант каждого.

## Ожидаемый результат
У метода `A` базовый случай отсутствует вовсе; у `B` базовый случай недостижим для нечётных и отрицательных аргументов; у `C` базовый случай есть, но аргумент не изменяется, поэтому при `n > 1` рекурсия не прекращается.
