# L14-ALG-027. Рекурсивный бинарный поиск

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Написать рекурсивный метод бинарного поиска в упорядоченном массиве: метод принимает массив, искомое значение, левую и правую границы. Обе границы задать необязательными параметрами так, чтобы при первом вызове их можно было не указывать. Проверить на массиве `{3, 7, 12, 18, 25, 31, 40}` для значений 31, 3 и 100.

## Ожидаемый результат
Для 31 возвращён индекс `5`, для 3 — `0`, для 100 — −1; первый вызов записан в виде, не требующем указания границ; базовым случаем служит пересечение границ.
