# L14-ALG-030. Полный аудит программы с рекурсией

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Дан код:

```
using System;

namespace RecursionAudit
{
    class Program
    {
        static void Log(int level = 0, string message)
        {
            Console.WriteLine(new string(' ', level) + message);
        }

        static long Fact(int n)
        {
            return n * Fact(n - 1);
        }

        static int Sum(int n)
        {
            if (n == 0) return 0;
            return n + Sum(n - 2);
        }

        static void Main(string[] args)
        {
            Log(message: "старт", 0);
            Console.WriteLine(Fact(5));
            Console.WriteLine(Sum(7));
        }
    }
}
```

**Запускать не следует.** Провести полный аудит и разнести замечания по трём категориям: ошибка объявления необязательного параметра; ошибка записи аргументов при вызове; нарушение правильности рекурсии. Для каждой указать код ошибки либо объяснить, почему компилятор молчит, и назвать значение аргумента, при котором ошибка проявится. Привести исправленную версию.

## Ожидаемый результат
Категории разнесены верно: объявление `Log` даёт `CS1737`, поскольку необязательный параметр стоит перед обязательным; вызов `Log(message: "старт", 0)` даёт `CS8323`; метод `Fact` не имеет базового случая и приводит к `StackOverflowException` при любом аргументе; метод `Sum` имеет недостижимый базовый случай для нечётных аргументов и потому переполняет стек при `Sum(7)`, хотя при `Sum(6)` работает верно. Приведён исправленный код.
