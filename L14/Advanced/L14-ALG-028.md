# L14-ALG-028. Рекурсия и цикл для одной задачи

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Для каждой из пяти задач — факториал, сумма цифр, наибольший общий делитель, обход элементов массива, ханойские башни — реализовать решение и рекурсивно, и циклом, если это возможно. Для каждой задачи письменно указать, какое решение предпочтительнее и почему. Отдельно объяснить, для какой из пяти задач итеративное решение существенно сложнее рекурсивного.

## Ожидаемый результат
Пять пар обоснованных решений; отмечено, что для обхода массива и факториала предпочтителен цикл, а для ханойских башен рекурсивное решение существенно проще итеративного.
