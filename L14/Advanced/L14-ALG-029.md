# L14-ALG-029. Предсказание вывода при взаимной рекурсии

**Тема:** Л14 — Модификаторы параметров в методах. Рекурсивные методы

## Условие
Дан код:

```
static bool IsEven(int n)
{
    if (n == 0) return true;
    return IsOdd(n - 1);
}

static bool IsOdd(int n)
{
    if (n == 0) return false;
    return IsEven(n - 1);
}
```

Не запуская программу, предсказать результаты вызовов `IsEven(4)`, `IsOdd(4)` и `IsEven(0)`, а также число выполненных вызовов для `IsEven(4)`. Затем проверить запуском. Отдельно ответить, что произойдёт при вызове `IsEven(-1)` и почему.

## Ожидаемый результат
Получено `True`, `False` и `True`; вызов `IsEven(4)` порождает пять вызовов, чередующихся между двумя методами; при отрицательном аргументе базовый случай недостижим, и возникает переполнение стека.
