# L01-ALG-003. Средний балл по трём оценкам

**Тема:** Л1 — Этапы решения поставленной задачи в программировании: модель — метод решения — алгоритм — программа. Понятие алгоритма, способы его представления, свойства, виды и эффективность

## Условие
Даны три оценки студента за экзамен. Составить алгоритм вычисления среднего балла.

## Ожидаемый результат
Среднее арифметическое трёх оценок (например, при 7, 8, 9 результат — 8).
