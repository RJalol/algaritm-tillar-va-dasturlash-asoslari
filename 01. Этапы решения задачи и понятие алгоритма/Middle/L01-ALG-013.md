# L01-ALG-013. Вычисление факториала числа

**Тема:** Л1 — Этапы решения поставленной задачи в программировании: модель — метод решения — алгоритм — программа. Понятие алгоритма, способы его представления, свойства, виды и эффективность

## Условие
Дано целое неотрицательное число N. Составить алгоритм вычисления N! (факториала).

## Ожидаемый результат
Верное значение факториала как минимум для N = 0, N = 1 и произвольного N (например, при N = 5 — F = 120).
