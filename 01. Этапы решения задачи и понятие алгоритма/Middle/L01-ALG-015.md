# L01-ALG-015. Проверка числа на простоту

**Тема:** Л1 — Этапы решения поставленной задачи в программировании: модель — метод решения — алгоритм — программа. Понятие алгоритма, способы его представления, свойства, виды и эффективность

## Условие
Дано целое число N (N > 1). Составить алгоритм, определяющий, является ли оно простым.

## Ожидаемый результат
Верный ответ «простое»/«составное» (например, для N = 7 — «простое», для N = 8 — «составное»).
