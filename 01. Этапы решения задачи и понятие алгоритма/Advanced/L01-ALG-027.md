# L01-ALG-027. Анализ алгоритма деления двух чисел

**Тема:** Л1 — Этапы решения поставленной задачи в программировании: модель — метод решения — алгоритм — программа. Понятие алгоритма, способы его представления, свойства, виды и эффективность

## Условие
Дан алгоритм:
```
начало
  ввод a, b
  result := a / b
  вывод result
конец
```
Определить, при каком значении входных данных этот алгоритм неприменим, и объяснить, почему.

## Ожидаемый результат
Конкретное проблемное значение входных данных с логическим и математическим обоснованием, почему именно оно проблематично.
