# Разбор решения. L42 · Задание I · №1. Panel

## Условие
Разместить на форме `Panel` с цветным фоном и тремя кнопками внутри. Отключать все кнопки панели одним присваиванием `panel.Enabled = false`.

## Ожидаемый результат
Все дочерние элементы отключаются вместе с панелью.

## Разбор условия
**Дано:** форма, панель с тремя кнопками.
**Требуется:** отключить все кнопки одним действием `panel.Enabled = false`.

## Теоретическая справка
**Контейнер** — элемент, содержащий другие элементы (`Panel`, `GroupBox`, `TabControl`, `FlowLayoutPanel`, `TableLayoutPanel`). Особенности:

- дочерние элементы лежат в коллекции `Controls` контейнера;
- координаты дочернего элемента отсчитываются от верхнего левого угла контейнера;
- свойства `Enabled`, `Visible` распространяются на все дочерние элементы;
- удаление контейнера удаляет дочерние.

Контейнер удобен для группировки: показать/скрыть, включить/выключить, переместить целую область одним действием.

## Идея решения
`Panel` — контейнер: дочерние элементы привязаны к нему, а свойства `Enabled` и `Visible` панели распространяются на всех потомков.

## Решение
```csharp
using System;
using System.Drawing;
using System.Windows.Forms;

public class Form1 : Form
{
    public Form1()
    {
        Text = "Panel";
        Size = new Size(320, 220);

        var panel = new Panel { Left = 10, Top = 10, Width = 280, Height = 70, BackColor = Color.LightSteelBlue };
        for (int i = 0; i < 3; i++)
            panel.Controls.Add(new Button { Text = "Кнопка " + (i + 1), Left = 10 + i * 90, Top = 20, Width = 80 });

        var toggle = new Button { Text = "Отключить панель", Left = 10, Top = 100, Width = 160 };
        toggle.Click += (s, e) =>
        {
            panel.Enabled = !panel.Enabled;
            toggle.Text = panel.Enabled ? "Отключить панель" : "Включить панель";
        };

        Controls.Add(panel);
        Controls.Add(toggle);
    }
}
```

## Пошаговое объяснение
1. `Panel` создаётся с цветным фоном, три кнопки добавляются в `panel.Controls`, а не в `Controls` формы.
2. Положение дочернего элемента отсчитывается от верхнего левого угла панели.
3. `panel.Enabled = false` отключает все три кнопки сразу — каждую по отдельности перебирать не нужно.
4. Кнопка-переключатель сама остаётся на форме, поэтому ею можно вернуть панель в рабочее состояние.

## Трассировка и проверка
| `panel.Enabled` | Кнопки на панели | Кнопка-переключатель (вне панели) |
|:--:|---|---|
| true | активны | активна |
| false | отключены (серые) | активна |

Кнопку-переключатель размещают вне панели, иначе после отключения панели её нельзя включить.

## Результат
Нажатие кнопки «Отключить панель» блокирует все три кнопки панели; повторное нажатие их включает.

## Типичные ошибки
- Добавлять кнопки в `Controls` формы, а не панели.
- Помещать переключатель внутрь отключаемой панели.
- Считать координаты кнопок относительно формы.
- Не вызывать `Dispose` при динамическом удалении элементов.

## Задания для закрепления
- Показать и скрыть панель свойством `Visible`.
- Перебрать `panel.Controls` и изменить цвет всех кнопок.
- Вложить одну панель в другую.
