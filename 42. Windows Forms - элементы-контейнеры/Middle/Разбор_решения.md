# Разбор решения. L42 · Задание II · №3. SplitContainer

## Условие
Разместить `SplitContainer` с двумя панелями, в левой `ListBox`, в правой `TextBox`. Выбранный элемент списка отображается в текстовом поле.

## Ожидаемый результат
Разделитель можно перемещать; выбор синхронизирован.

## Разбор условия
**Дано:** `SplitContainer` с `ListBox` слева и `TextBox` справа.
**Требуется:** выбор в списке отображается в текстовом поле.

## Теоретическая справка
`SplitContainer` делит область на две панели (`Panel1`, `Panel2`) подвижным разделителем. Элементы добавляются в панели: `split.Panel1.Controls.Add(list)`.

**Свойство `Dock`** прикрепляет элемент к краям контейнера: `Fill` растягивает на всю область. Благодаря `Dock` и `Anchor` интерфейс адаптируется к изменению размеров.

Событие `SelectedIndexChanged` у `ListBox` возникает при смене выбора; `SelectedItem` может быть `null` (ничего не выбрано), поэтому используют `?.` и `??`.

## Идея решения
`SplitContainer` делит область на две панели с подвижным разделителем. Слева `ListBox`, справа `TextBox`; выбор в списке копируется в текстовое поле.

## Решение
```csharp
using System;
using System.Windows.Forms;

public class Form1 : Form
{
    public Form1()
    {
        Text = "SplitContainer";
        Width = 500; Height = 300;

        var split = new SplitContainer { Dock = DockStyle.Fill, SplitterDistance = 150 };
        var list = new ListBox { Dock = DockStyle.Fill };
        list.Items.AddRange(new object[] { "Алгоритмы", "Структуры данных", "C#", "Сети" });
        var text = new TextBox { Dock = DockStyle.Fill, Multiline = true };

        list.SelectedIndexChanged += (s, e) => text.Text = list.SelectedItem?.ToString() ?? "";

        split.Panel1.Controls.Add(list);
        split.Panel2.Controls.Add(text);
        Controls.Add(split);
    }
}
```

## Пошаговое объяснение
1. `SplitContainer` с `Dock = Fill` занимает всё окно; разделитель можно перетаскивать мышью.
2. Элементы добавляются в `Panel1` и `Panel2`, а не в форму.
3. `Dock = Fill` растягивает `ListBox` и `TextBox` на всю свою панель, поэтому они подстраиваются при перемещении разделителя.
4. Событие `SelectedIndexChanged` срабатывает при выборе элемента; `SelectedItem` может быть `null` (нет выбора), поэтому используется `?.` и `??`.

## Трассировка и проверка
| Действие | Результат |
|---|---|
| выбрать «C#» | в правой панели текст «C#» |
| снять выбор | поле очищается |
| перетащить разделитель | панели меняют ширину, элементы подстраиваются |

## Результат
При выборе пункта списка текст пункта появляется в правой панели; разделитель перемещается.

## Типичные ошибки
- Забыть `Dock = Fill` — элементы остаются фиксированного размера.
- Обращаться к `SelectedItem.ToString()` без проверки на `null`.
- Добавить элементы в форму, а не в панели `SplitContainer`.
- Привязывать обработчик несколько раз.
