# L06-ALG-015. Объявление и проверка значения, допускающего null

**Тема:** Л6 — Типы данных и правила их преобразования. Класс Convert и метод Parse. Перечисляемые типы

## Условие
Написать программу, которая объявляет две переменные типа «целое, допускающее отсутствие значения»: одну без значения, другую со значением 42. Для каждой вывести результат проверки `HasValue` и результат сравнения с `null`.

## Ожидаемый результат
Четыре строки; для переменной без значения `HasValue` даёт `False`, а сравнение с `null` — `True`; для переменной со значением — наоборот.
