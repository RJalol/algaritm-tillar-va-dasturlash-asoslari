# L06-ALG-008. Приведение против Convert

**Тема:** Л6 — Типы данных и правила их преобразования. Иерархия типов данных. Класс Convert и его методы. Использование класса Convert и метода Parse для преобразования строковых данных. Перечисляемые типы

## Условие
Написать программу, которая для значения 7,9 выводит результат приведения к типу `int` и результат вызова `Convert.ToInt32`, а затем делает то же для значения −7,9. Объяснить в комментарии, в чём состоит различие двух способов.

## Ожидаемый результат
Четыре строки: `7`, `8`, `-7`, `-8`; в комментарии указано, что приведение отбрасывает дробную часть, а `Convert` округляет.
