# L06-ALG-017. Поднятые операции

**Тема:** Л6 — Типы данных и правила их преобразования. Класс Convert и метод Parse. Перечисляемые типы

## Условие
Написать программу, которая объявляет переменную «целое, допускающее отсутствие значения» без значения и вторую такую же со значением 7, а затем к каждой прибавляет 5 и выводит результат: для первой — результат проверки `HasValue`, для второй — само значение. Объяснить в комментарии наблюдаемое правило.

## Ожидаемый результат
Две строки: `False` и `12`; в комментарии сформулировано правило поднятых операций — отсутствие значения в любом операнде даёт отсутствие значения в результате.
