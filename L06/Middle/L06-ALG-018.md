# L06-ALG-018. Сравнение с отсутствующим значением

**Тема:** Л6 — Типы данных и правила их преобразования. Класс Convert и метод Parse. Перечисляемые типы

## Условие
Написать программу, которая для переменной без значения выводит результаты сравнений «меньше 10» и «больше или равно 10», а затем результаты сравнения двух переменных без значения операциями `==` и `!=`. Объяснить в комментарии, почему первые два результата не противоположны друг другу, и сопоставить это с поведением значения `NaN` из темы №5.

## Ожидаемый результат
Четыре строки: `False`, `False`, `True`, `False`; в комментарии отмечено, что операции отношения при участии отсутствующего значения дают `False`, тогда как `==` для двух отсутствующих значений даёт `True`.
