# L06-ALG-019. Некорректная строка при преобразовании

**Тема:** Л6 — Типы данных и правила их преобразования. Класс Convert и метод Parse. Перечисляемые типы

## Условие
Дан код:

```
string text = "сорок два";
int number = int.Parse(text);
Console.WriteLine(number);
```

Определить, скомпилируется ли фрагмент и что произойдёт при его выполнении. Назвать тип возникающего исключения и указать, в какой теме курса изучается механизм, позволяющий обработать такую ситуацию.

## Ожидаемый результат
Указано, что фрагмент компилируется, но при выполнении возникает `FormatException`; названа тема №38 как место изучения обработки исключений и упомянут метод `TryParse` (тема №15) как безопасная альтернатива.
