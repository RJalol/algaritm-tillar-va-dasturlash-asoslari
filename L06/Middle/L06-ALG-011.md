# L06-ALG-011. Два числа с клавиатуры

**Тема:** Л6 — Типы данных и правила их преобразования. Класс Convert и метод Parse. Перечисляемые типы

## Условие
Написать программу, которая запрашивает у пользователя два целых числа (каждое с отдельным приглашением) и выводит их сумму, разность, произведение и частное. Частное вывести так, чтобы дробная часть сохранялась.

## Ожидаемый результат
Четыре строки с результатами; частное вычислено с сохранением дробной части, для чего выражение сделано вещественным приёмом темы №4.
