# Разбор решения. L06-ALG-006. Потеря старших битов

## Условие
Написать программу, которая объявляет переменную типа `int` со значением 500 и переменную типа `int` со значением 70000, а затем приводит первую к типу `byte`, вторую — к типу `short`, и выводит оба результата. Объяснить в комментарии, почему полученные числа не совпадают с исходными и почему компилятор не выдал предупреждения.

## Ожидаемый результат
Две строки: `244` и `4464`; в комментарии объяснено, что не поместившиеся старшие биты отбрасываются молча, а операция приведения означает принятие этого риска программистом.

## Идея решения
При явном приведении к более узкому типу старшие биты, не поместившиеся в целевой тип, отбрасываются (в контексте `unchecked`, действующем по умолчанию).

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        int a = 500;
        int c = 70000;

        byte  b = (byte)a;    // 500 mod 256 = 244
        short s = (short)c;   // 70000 - 65536 = 4464

        Console.WriteLine(b);
        Console.WriteLine(s);

        // Старшие биты, не поместившиеся в целевой тип, отбрасываются молча.
        // Явная операция приведения означает, что программист принимает риск,
        // поэтому компилятор не выдаёт ни ошибки, ни предупреждения.
    }
}
```

## Пошаговое объяснение
1. 500 в двоичном виде — `1 1111 0100`; в `byte` помещаются младшие 8 бит `1111 0100` = 244.
2. 70000 = 65536 + 4464; в `short` (16 бит) остаётся младшая часть 4464 (значение лежит в диапазоне −32768…32767, поэтому знак не меняется).
3. Приведение — явная команда программиста, поэтому компилятор доверяет ему и не предупреждает о потере.
4. Если нужен контроль, используют `checked` — тогда вместо молчаливой потери возникнет `OverflowException`.

## Результат
Выводятся 244 и 4464.
