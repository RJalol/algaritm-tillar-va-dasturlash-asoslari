# L06-ALG-021. Три нарушения в одном фрагменте

**Тема:** Л6 — Типы данных и правила их преобразования. Класс Convert и метод Parse. Перечисляемые типы

## Условие
Дан код:

```
double real = 3.9;
int whole = real;
int? maybe = 42;
int definite = maybe;
byte small = (byte)500;
```

Найти все нарушения, для каждого назвать код ошибки компилятора и объяснить причину отдельно. Для третьего нарушения дополнительно указать, при каком изменении кода оно исчезнет, хотя проблема по существу останется. Привести исправленный фрагмент.

## Ожидаемый результат
Три нарушения с кодами `CS0266`, `CS0266` и `CS0221`; для третьего указано, что замена литерала на переменную того же значения снимает ошибку компиляции, но приводит к молчаливой потере данных.
