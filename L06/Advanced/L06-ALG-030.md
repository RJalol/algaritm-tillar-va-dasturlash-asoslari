# L06-ALG-030. Полный аудит фрагмента с преобразованиями

**Тема:** Л6 — Типы данных и правила их преобразования. Класс Convert и метод Parse. Перечисляемые типы

## Условие
Дан код:

```
using System;

namespace AuditDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.Write("Введите количество: ");
            string countText = Console.ReadLine();
            int count = Convert.ToInt32(countText);

            double price = 199.99;
            int wholePrice = price;

            int? discount = null;
            int finalDiscount = discount;

            byte packages = (byte)count;

            Console.WriteLine(wholePrice);
            Console.WriteLine(finalDiscount);
            Console.WriteLine(packages);
        }
    }
}
```

Провести полный аудит и разнести замечания по четырём категориям: ошибка компиляции; предупреждение компилятора; ошибка времени выполнения, возможная при некоторых входных данных; логическая опасность, не вызывающая ни того ни другого. Для каждой указать конкретную строку и назвать код там, где он есть. Привести исправленную версию.

## Ожидаемый результат
Категории разнесены верно: два случая `CS0266` (присваивание `double` переменной `int` и `int?` переменной `int`); предупреждения `CS8600` на присваивании результата `ReadLine` переменной типа `string` и `CS8629` на использовании значения, которое может отсутствовать; `FormatException` при вводе нечислового значения; молчаливая потеря данных при приведении `count` к типу `byte`, если введено число больше 255.
