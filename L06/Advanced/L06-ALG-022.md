# L06-ALG-022. Цепочка преобразований

**Тема:** Л6 — Типы данных и правила их преобразования. Класс Convert и метод Parse. Перечисляемые типы

## Условие
Дан код:

```
double d = 9.99;
int i = (int)d;
byte b = (byte)i;
double back = b;
```

Не запуская программу, определить значения всех четырёх переменных и указать, на каком шаге произошла потеря данных, а на каком — нет. Объяснить, почему обратное преобразование не восстановило исходное значение. Проверить ответ запуском.

## Ожидаемый результат
Значения `9,99`, `9`, `9`, `9`; указано, что потеря произошла только на первом приведении, а последний шаг является неявным расширяющим преобразованием и потерь не вносит; объяснено, что отброшенная дробная часть невосстановима.
