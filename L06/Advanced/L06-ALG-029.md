# L06-ALG-029. Выбор способа преобразования под задачу

**Тема:** Л6 — Типы данных и правила их преобразования. Класс Convert и метод Parse. Перечисляемые типы

## Условие
Для каждой из ситуаций выбрать наиболее подходящий способ преобразования — неявное, приведение, `Convert` или `Parse` — и обосновать выбор: (а) присвоить значение типа `int` переменной типа `long`; (б) получить целое число из введённой пользователем строки; (в) отбросить дробную часть цены, оставив только целые единицы; (г) получить целое количество, округлив измеренное вещественное значение; (д) получить элемент перечисления из номера варианта.

## Ожидаемый результат
Пять пар «ситуация — способ» с обоснованием; для (в) и (г) выбраны разные способы именно потому, что в одном случае требуется отбрасывание, а в другом — округление.
