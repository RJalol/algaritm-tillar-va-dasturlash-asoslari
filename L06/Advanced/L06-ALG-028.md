# L06-ALG-028. Определение типа результата преобразования

**Тема:** Л6 — Типы данных и правила их преобразования. Класс Convert и метод Parse. Перечисляемые типы

## Условие
Для каждого из выражений определить тип его результата, не запуская программу:

```
Convert.ToInt32("5")     Convert.ToDouble("5")     (int)3.9
n ?? 0    (где n объявлена как int?)
Math.Floor(7.5)          (Grade)4    (где Grade - перечисление)
```

Ответ по каждому обосновать: чем определяется тип результата метода `Convert`, чем — тип результата приведения, и что даёт операция `??`. Проверить ответы с помощью `GetType()`.

## Ожидаемый результат
Шесть пар «выражение — тип»; отмечено, что `Math.Floor` возвращает вещественное значение, несмотря на целый результат, а `(Grade)4` даёт тип перечисления с указанием пространства имён.
