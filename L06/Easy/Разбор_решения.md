# Разбор решения. L06-ALG-001. Цепочка неявных преобразований

## Условие
Написать программу, которая объявляет переменную типа `byte` со значением 150 и последовательно, **без операции приведения**, присваивает её значение переменным типов `short`, `int`, `long` и `double`. Вывести все пять значений.

## Ожидаемый результат
Пять одинаковых строк со значением `150`; программа компилируется без единой операции приведения типа.

## Разбор условия
**Дано:** переменная `byte` со значением 150.
**Требуется:** без операции приведения присвоить её значение переменным `short`, `int`, `long`, `double` и вывести пять значений.

## Теоретическая справка
**Неявное (расширяющее) преобразование** выполняется автоматически, если любое значение исходного типа помещается в целевой тип без потери:

```
byte → short → int → long → float → double
 8      16      32     64      32      64   (бит)
```

Исключение — `long → float` и `long → double`: преобразование допустимо, но может потерять младшие разряды (точность), хотя диапазон при этом не нарушается.

Явное приведение `(тип)значение` нужно для обратных (сужающих) преобразований.

## Идея решения
Неявные (расширяющие) преобразования допустимы, когда диапазон целевого типа охватывает диапазон исходного: byte → short → int → long → double.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        byte  b = 150;
        short s = b;
        int   i = s;
        long  l = i;
        double d = l;

        Console.WriteLine(b);
        Console.WriteLine(s);
        Console.WriteLine(i);
        Console.WriteLine(l);
        Console.WriteLine(d);
    }
}
```

## Пошаговое объяснение
1. Каждое присваивание идёт от «узкого» типа к «широкому», потеря данных исключена.
2. Поэтому явный оператор приведения `(тип)` не требуется.
3. Значение 150 сохраняется на каждом шаге; в `double` оно выводится как `150`.

## Трассировка и проверка
| Присваивание | Тип результата | Значение |
|---|---|---:|
| `byte b = 150;` | `byte` | 150 |
| `short s = b;` | `short` | 150 |
| `int i = s;` | `int` | 150 |
| `long l = i;` | `long` | 150 |
| `double d = l;` | `double` | 150 |

Все пять выводов равны 150. Операции приведения `(тип)` в коде отсутствуют, что и требовалось.

## Результат
Пять строк со значением 150.

## Типичные ошибки
- Добавлять ненужное приведение `(short)b` — условие запрещает.
- Пытаться присвоить `double` переменной `int` без приведения (`CS0266`).
- Считать, что `double` 150 выведется как `150,0` — по умолчанию лишний нуль не печатается.
- Путать `byte` (0…255) со знаковым `sbyte` (−128…127).
