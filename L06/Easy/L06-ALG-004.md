# L06-ALG-004. Числовой ввод с клавиатуры

**Тема:** Л6 — Типы данных и правила их преобразования. Класс Convert и метод Parse. Перечисляемые типы

## Условие
Написать программу, которая запрашивает у пользователя целое число (с приглашением, без перевода строки), преобразует введённое значение в число и выводит это число, увеличенное втрое.

## Ожидаемый результат
При вводе значения 12 выведено `36`; преобразование выполнено явно, поскольку `Console.ReadLine` возвращает строку.
