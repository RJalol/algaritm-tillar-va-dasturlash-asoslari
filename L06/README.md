# L06. Типы данных и правила их преобразования. Класс Convert и метод Parse. Перечисляемые типы

Практические задания к теме №6 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Особенность этой темы

Тема №5 дала ввод с клавиатуры, но только **строковый**. Тема №6 снимает это ограничение: строку можно превратить в число, и программа наконец получает возможность вычислять по данным пользователя.

Одновременно тема отвечает на вопрос, откуда взялась запись `string?` в теме №5, — это тип, допускающий отсутствие значения.

Не используются: **управляющие конструкции** `if`, `switch` и циклы (темы №7–9), **метод `TryParse`** и модификатор `out` (тема №15), **обработка исключений** (тема №38). В заданиях предполагается корректный ввод, а поведение при некорректном разбирается аналитически.

## Ключевые идеи темы, проверяемые заданиями

- Неявное преобразование выполняется, только когда потеря данных **невозможна** (ALG-001).
- Приведение типа **отбрасывает** дробную часть, `Convert` — **округляет**, причём к ближайшему чётному (ALG-008, ALG-009, ALG-020, ALG-027).
- Приведение константы вне диапазона — ошибка `CS0221`; приведение **переменной** того же значения проходит молча (ALG-006, ALG-007).
- Даже **расширяющее** преобразование `long → float` может потерять точность (ALG-025).
- `Convert.ToInt32(null)` возвращает `0`, а `int.Parse(null)` возбуждает исключение — два метода расходятся именно в граничном случае (ALG-026).
- Отсутствие значения «заражает» вычисление: `null + 10` даёт `null` (ALG-017).
- Явное приведение обходит защиту перечисления: `(Grade)99` компилируется и работает (ALG-024).

## О диагностических заданиях

Часть заданий (Middle: ALG-007, ALG-019; Advanced: ALG-021, ALG-022, ALG-024, ALG-026, ALG-030) содержит код, который требуется проанализировать: найти ошибку и назвать её код либо предсказать результат до запуска.

Все коды ошибок (`CS0221`, `CS0266`), предупреждения (`CS8600`, `CS8629`), исключения (`FormatException`, `ArgumentNullException`, `InvalidOperationException`) и **все числовые ответы** проверены фактической компиляцией и запуском на .NET 8 (`TargetFramework=net8.0`, `LangVersion=12.0`).
