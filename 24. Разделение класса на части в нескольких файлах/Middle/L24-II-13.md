# L24 · Задание II · №13. Точка расширения для проверки данных

**Тема:** Л24 — Разделение класса на части, хранение его в нескольких файлах и работа с такими файлами

## Условие
Разработать частичный класс «регистрация», в шаблонной части которого объявлена точка расширения «проверить дополнительно», вызываемая после основных проверок. Реализовать её во второй части так, чтобы добавились правила конкретного учебного заведения. Показать поведение программы с реализацией и без неё.

## Ожидаемый результат
Без реализации действуют только основные проверки, с реализацией — дополнительные; ни в одном случае шаблонная часть не изменялась.
