# Разбор решения. L24 · Задание III · №1. Учебный «конструктор форм»

## Условие
Разработать учебную имитацию конструктора форм: программа-генератор по описанию формы (заголовок, ширина, перечень полей) создаёт текст файла с суффиксом `.Designer. cs`, содержащего одну часть класса с полями и методом их настройки. Вторая часть класса написана вручную и содержит конструктор и вывод. Показать, что повторный запуск генератора перезаписывает только первый файл.

## Ожидаемый результат
После повторного запуска генератора с изменённым описанием форма выводится по-новому, а код второй части остался нетронутым.

## Разбор условия
**Дано:** описание формы (заголовок, ширина, перечень полей).
**Требуется:** генератор создаёт файл `Form.Designer.cs` с первой частью класса; вторая часть написана вручную; повторный запуск перезаписывает только первый файл.

## Теоретическая справка
Принцип «машинной» и «ручной» частей: генерируемый код хранится отдельно, чтобы его можно было перегенерировать без потери правок человека. Так устроены Windows Forms (`.Designer.cs`), WPF (`.g.cs`), Entity Framework.

Признаки хорошего разделения:

- в генерируемом файле предупреждающий комментарий (`<auto-generated>`);
- ручная часть не зависит от внутреннего устройства генерируемой, кроме согласованных членов (`InitializeComponent`, `Fields`);
- генератор записывает файл целиком (`File.WriteAllText`), не пытаясь «сливать» изменения.

## Идея решения
Генератор по описанию формы пишет только файл `Form.Designer.cs` (часть класса с полями и методом настройки); вручную написанная часть `Form.cs` не трогается. Повторный запуск перезаписывает лишь первый файл.

## Решение
```csharp
// ---- Generator.cs (программа-генератор) ----
using System;
using System.IO;
using System.Text;

static class Generator
{
    public static void Generate(string title, int width, string[] fields)
    {
        StringBuilder sb = new StringBuilder();
        sb.AppendLine("// <auto-generated> Не редактируйте вручную </auto-generated>");
        sb.AppendLine("public partial class Form");
        sb.AppendLine("{");
        foreach (string f in fields)
            sb.AppendLine($"    private string _{f};");
        sb.AppendLine("    private void InitializeComponent()");
        sb.AppendLine("    {");
        sb.AppendLine($"        Title = \"{title}\"; Width = {width};");
        sb.AppendLine("    }");
        sb.AppendLine($"    private static readonly string[] Fields = {{ {string.Join(", ", Array.ConvertAll(fields, f => "\"" + f + "\""))} }};");
        sb.AppendLine("}");
        File.WriteAllText("Form.Designer.cs", sb.ToString());   // только этот файл
    }
}

// ---- Form.cs (ручная часть, не перезаписывается) ----
using System;
public partial class Form
{
    public string Title; public int Width;

    public Form() { InitializeComponent(); }

    public void Print()
    {
        Console.WriteLine($"Форма «{Title}», ширина {Width}, поля: {string.Join(", ", Fields)}");
    }
}

// ---- Program.cs ----
class Program
{
    static void Main()
    {
        Generator.Generate("Вход", 300, new[] { "login", "password" });
        // повторный запуск с другим описанием:
        // Generator.Generate("Регистрация", 400, new[] { "login", "email", "password" });
        new Form().Print();
    }
}
```

## Пошаговое объяснение
1. Файл `.Designer.cs` — «машинная» часть класса: поля, массив имён полей и метод `InitializeComponent`, заданный описанием формы.
2. Ручная часть `Form.cs` содержит конструктор, вызывающий `InitializeComponent`, и метод вывода.
3. Генератор записывает **только** `Form.Designer.cs`, поэтому код `Form.cs` остаётся нетронутым при любом количестве запусков.
4. После изменения описания и повторного запуска генератора форма выводится по-новому (другой заголовок, ширина, набор полей), а ручной код тот же.

## Трассировка и проверка
Запуск 1: `Generate("Вход", 300, {"login","password"})` → `Form.Designer.cs`; вывод: «Форма «Вход», ширина 300, поля: login, password».

Запуск 2: `Generate("Регистрация", 400, {"login","email","password"})` → файл перезаписан; ручной файл `Form.cs` не менялся, но вывод стал: «Форма «Регистрация», ширина 400, поля: login, email, password».

Проверка: время изменения `Form.cs` не изменилось.

## Результат
Форма «Вход», ширина 300, поля: login, password; после повторной генерации — «Регистрация», 400, login, email, password; Form.cs не изменялся.

## Типичные ошибки
- Править сгенерированный файл вручную — правки пропадут.
- Хранить конструктор в генерируемой части.
- Не учитывать экранирование кавычек при генерации строк.
- Требовать от ручной части знания деталей генерации.
