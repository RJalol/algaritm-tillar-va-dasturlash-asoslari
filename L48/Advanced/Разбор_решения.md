# Разбор решения. L48 · Задание III · №3. Левое внешнее соединение

## Условие
Реализовать левое внешнее соединение (`GroupJoin` + `DefaultIfEmpty`) списков клиентов и заказов.

## Ожидаемый результат
Клиенты без заказов присутствуют в результате.

## Идея решения
Левое внешнее соединение возвращает все элементы левой последовательности, даже если для них нет пары справа. В LINQ его выражают через `GroupJoin` и `DefaultIfEmpty`.

## Решение
```csharp
using System;
using System.Collections.Generic;
using System.Linq;

record Customer(int Id, string Name);
record Order(int Id, int CustomerId, decimal Total);

class Program
{
    static void Main()
    {
        var customers = new List<Customer> { new(1, "Азиз"), new(2, "Дилноза"), new(3, "Рустам") };
        var orders = new List<Order> { new(10, 1, 100), new(11, 1, 250), new(12, 3, 80) };

        var report = from c in customers
                     join o in orders on c.Id equals o.CustomerId into customerOrders
                     from o in customerOrders.DefaultIfEmpty()
                     select new { c.Name, OrderId = o?.Id, Total = o?.Total ?? 0 };

        foreach (var r in report)
            Console.WriteLine($"{r.Name}: заказ {(r.OrderId.HasValue ? r.OrderId.ToString() : "нет")}, сумма {r.Total}");
    }
}
```

## Пошаговое объяснение
1. `join ... into customerOrders` (в методах — `GroupJoin`) собирает для каждого клиента группу его заказов — она может быть пустой.
2. `from o in customerOrders.DefaultIfEmpty()` разворачивает группу обратно в элементы, а для пустой группы подставляет один `null` — так клиент без заказов не пропадает.
3. Значения заказа читаются через `o?.Id` и `o?.Total ?? 0`, так как `o` может быть `null`.
4. Обычный внутренний `join` исключил бы клиента «Дилноза», у которого заказов нет.

## Результат
Азиз — два заказа (10 и 11), Дилноза — «нет» (сумма 0), Рустам — заказ 12 на 80.
