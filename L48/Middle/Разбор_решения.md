# Разбор решения. L48 · Задание II · №3. Группировка

## Условие
Сгруппировать студентов по группам оператором `group by` и вывести количество в каждой группе.

## Ожидаемый результат
Количества верны.

## Разбор условия
**Дано:** список студентов (имя, группа, балл).
**Требуется:** сгруппировать по группам и вывести число студентов в каждой.

## Теоретическая справка
`group x by ключ` формирует последовательность групп. Каждая группа — объект `IGrouping<TKey, TElement>`: свойство `Key` — общий ключ, сама группа — последовательность элементов.

Продолжение запроса после группировки — `into g`: дальше можно упорядочивать группы, считать агрегаты (`g.Count()`, `g.Average(…)`) и проецировать результат в анонимный тип.

Метод-вариант: `students.GroupBy(s => s.Group).Select(g => new { g.Key, Count = g.Count() })`.

## Идея решения
`group by` разбивает последовательность на группы с одинаковым ключом; каждая группа — объект `IGrouping<TKey,TElement>` с ключом `Key` и элементами.

## Решение
```csharp
using System;
using System.Collections.Generic;
using System.Linq;

record Student(string Name, string Group, int Score);

class Program
{
    static void Main()
    {
        var students = new List<Student>
        {
            new("Азиз", "ТТ-11", 87), new("Дилноза", "ТТ-11", 92),
            new("Рустам", "ТТ-12", 78), new("Малика", "ТТ-12", 95), new("Тимур", "ТТ-13", 60)
        };

        var groups = from s in students
                     group s by s.Group into g
                     orderby g.Key
                     select new { Group = g.Key, Count = g.Count() };

        foreach (var g in groups)
            Console.WriteLine($"{g.Group}: {g.Count}");
    }
}
```

## Пошаговое объяснение
1. `group s by s.Group into g` создаёт группы по значению поля `Group`; `into g` позволяет продолжить запрос над группами.
2. `g.Key` — общее значение ключа группы, `g.Count()` — число студентов в ней.
3. `select new { ... }` создаёт анонимный тип с двумя свойствами.
4. `orderby g.Key` упорядочивает группы по названию.

## Трассировка и проверка
Для пяти студентов:

| Группа | Студенты | Count |
|---|---|--:|
| ТТ-11 | Азиз, Дилноза | 2 |
| ТТ-12 | Рустам, Малика | 2 |
| ТТ-13 | Тимур | 1 |

Порядок групп по умолчанию — порядок первого появления ключа; `orderby g.Key` упорядочивает по названию.

## Результат
ТТ-11: 2 / ТТ-12: 2 / ТТ-13: 1

## Типичные ошибки
- Путать `group by` с `orderby`.
- Забыть `into g` и пытаться использовать группу после `select`.
- Обращаться к элементам группы без перебора.
- Считать, что `GroupBy` сортирует ключи.
