# L36 · Задание II · №8. Возвращаемое значение многоадресного делегата

**Тема:** Л36 — Делегаты. Обобщённые делегаты. Делегаты Func и Action

## Условие
Составить многоадресный делегат `Func<int>` из трёх методов, возвращающих 1, 2, 3. Выяснить, какое значение возвращает вызов, и получить все три значения через список вызова.

## Ожидаемый результат
Вызов возвращает значение последнего метода (3); через список вызова получены 1, 2, 3.
