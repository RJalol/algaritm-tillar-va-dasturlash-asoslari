# L36 · Задание II · №3. Метод возвращает делегат

**Тема:** Л36 — Делегаты. Обобщённые делегаты. Делегаты Func и Action

## Условие
Написать метод `GetOperation(char sign)`, возвращающий делегат по знаку (`+`, `-`, `*`, `/`). Для неизвестного знака вернуть `null` и обработать это.

## Ожидаемый результат
Для `'*'` и чисел (6, 7) получено 42; для `'%'` выведено сообщение об ошибке.
