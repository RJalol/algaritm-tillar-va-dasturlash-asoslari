# Разбор решения. L36 · Задание II · №1. Делегат как параметр

## Условие
Написать метод `Calculate(int a, int b, Operation op)`, возвращающий результат операции, и вызвать его с четырьмя разными операциями (сложение, вычитание, умножение, деление).

## Ожидаемый результат
Результаты для (12, 4): 16, 8, 48, 3.

## Разбор условия
**Дано:** четыре операции.
**Требуется:** метод `Calculate(int a, int b, Operation op)` и вызов с четырьмя разными операциями.

## Теоретическая справка
**Делегат как параметр** — способ передать *поведение* в метод. Метод `Calculate` не знает, какая именно операция будет выполнена; он лишь применяет переданный делегат. Так устроены `Array.Sort(…, Comparison)`, `List.RemoveAll(Predicate)`, LINQ.

Сигнатура лямбда-выражения должна соответствовать типу делегата: `(x, y) => x + y` подходит для `Operation`.

Принцип: **отделение алгоритма от политики** — общий алгоритм (применить операцию к двум числам) не зависит от конкретной политики (какая именно операция).

## Идея решения
Делегат передаётся в метод как параметр — так поведение (операция) выбирает вызывающий код, а метод только применяет его.

## Решение
```csharp
using System;

delegate int Operation(int a, int b);

class Program
{
    static int Calculate(int a, int b, Operation op) => op(a, b);

    static void Main()
    {
        Console.WriteLine(Calculate(12, 4, (x, y) => x + y));
        Console.WriteLine(Calculate(12, 4, (x, y) => x - y));
        Console.WriteLine(Calculate(12, 4, (x, y) => x * y));
        Console.WriteLine(Calculate(12, 4, (x, y) => x / y));
    }
}
```

## Пошаговое объяснение
1. `Calculate` ничего не знает о конкретных операциях: он просто вызывает переданный делегат.
2. Четыре лямбда-выражения реализуют сложение, вычитание, умножение и деление.
3. Сигнатура лямбды `(x, y) => ...` совпадает с типом `Operation`, поэтому преобразование допустимо.
4. Результаты для (12, 4): 16, 8, 48, 3 (деление целочисленное).

## Трассировка и проверка
Для (12, 4):

| Передано | Вычисление | Результат |
|---|---|--:|
| `(x, y) => x + y` | 12 + 4 | 16 |
| `(x, y) => x - y` | 12 − 4 | 8 |
| `(x, y) => x * y` | 12 · 4 | 48 |
| `(x, y) => x / y` | 12 / 4 | 3 |

При делении на нуль (b = 0) произойдёт `DivideByZeroException` — защита должна быть либо в лямбде, либо в `Calculate`.

## Результат
16, 8, 48, 3

## Типичные ошибки
- Забыть проверку на `null`.
- Передать лямбду с другим числом параметров (`CS1593`).
- Игнорировать деление на нуль.
- Захватывать изменяемую внешнюю переменную и получать неожиданный результат.
