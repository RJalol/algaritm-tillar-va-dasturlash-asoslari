# Разбор решения. L36 · Задание I · №1. Первый делегат

## Условие
Объявить тип делегата `delegate int Operation(int a, int b);` и два метода `Add` и `Multiply` с подходящими сигнатурами. Присвоить методы переменной делегата и вызвать для чисел 6 и 7.

## Ожидаемый результат
Выведены 13 и 42; одна и та же переменная вызывает разные методы.

## Разбор условия
**Дано:** два метода — `Add` и `Multiply`.
**Требуется:** объявить тип делегата, присвоить методы переменной делегата и вызвать для 6 и 7.

## Теоретическая справка
**Делегат** — ссылочный тип, описывающий сигнатуру метода (типы параметров и результата). Переменная делегата хранит ссылку на любой метод с такой сигнатурой и позволяет вызвать его как функцию.

```
delegate int Operation(int a, int b);
Operation op = Add;     // присваивание метода
int r = op(6, 7);       // вызов
```

Делегаты — основа обратных вызовов (callbacks), событий (тема №38) и лямбда-выражений (тема №37). Сигнатура метода должна **точно** (с учётом ковариантности и контравариантности) соответствовать делегату.

## Идея решения
Делегат — тип, описывающий сигнатуру метода. Переменная типа делегата хранит ссылку на любой метод с такой сигнатурой.

## Решение
```csharp
using System;

delegate int Operation(int a, int b);

class Program
{
    static int Add(int a, int b) => a + b;
    static int Multiply(int a, int b) => a * b;

    static void Main()
    {
        Operation op = Add;
        Console.WriteLine(op(6, 7));      // 13

        op = Multiply;
        Console.WriteLine(op(6, 7));      // 42
    }
}
```

## Пошаговое объяснение
1. `delegate int Operation(int a, int b);` задаёт тип: метод с двумя `int` и результатом `int`.
2. `Add` и `Multiply` подходят по сигнатуре, поэтому их можно присвоить переменной `op`.
3. Вызов `op(6, 7)` выполняет тот метод, на который указывает переменная в данный момент.
4. Переприсваивание `op = Multiply` меняет поведение без изменения кода вызова — основа «стратегий» и обратных вызовов.

## Трассировка и проверка
| Присваивание | Вызов `op(6, 7)` | Результат |
|---|---|--:|
| `op = Add` | 6 + 7 | 13 |
| `op = Multiply` | 6 · 7 | 42 |

Код вызова не изменился — поведение определяется тем, на какой метод указывает переменная в данный момент.

## Результат
13 и 42

## Типичные ошибки
- Присвоить методу с неподходящей сигнатурой (`CS0123`).
- Вызвать делегат, равный `null` (`NullReferenceException`).
- Путать объявление типа делегата и объявление переменной.
- Передавать метод со скобками (`op = Add()`), а не его имя.
