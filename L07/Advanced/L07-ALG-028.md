# L07-ALG-028. Поиск недостижимых ветвей

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Дан код:

```
if (n > 0)
    Console.WriteLine("положительное");
else if (n > 100)
    Console.WriteLine("большое");
else if (n != 0)
    Console.WriteLine("ненулевое");
else
    Console.WriteLine("нуль");
```

Определить, какие ветви недостижимы ни при каком значении `n`, а какие достижимы, и для каждой указать множество значений, при которых она выполняется. Объяснить, почему компилятор не сообщает об этой проблеме. Привести исправленный вариант, сохраняющий очевидное намерение автора.

## Ожидаемый результат
Установлено, что вторая ветвь недостижима полностью; для остальных указаны множества значений; отмечено, что все условия синтаксически корректны и компилятор проверяет только типы, но не логическую совместимость условий.
