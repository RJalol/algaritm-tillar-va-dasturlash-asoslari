# L07-ALG-029. Число дней в месяце

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Написать программу, которая запрашивает номер месяца и год и выводит количество дней в этом месяце. Для месяцев с фиксированным числом дней использовать оператор `switch` с объединёнными метками, а для февраля — дополнительную проверку високосности года (ALG-009). Предусмотреть обработку недопустимого номера месяца.

## Ожидаемый результат
Верное число дней для всех двенадцати месяцев; для февраля 2024 года выведено 29, для февраля 1900 года — 28; недопустимый номер обработан меткой `default`.
