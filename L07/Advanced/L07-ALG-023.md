# L07-ALG-023. Перевод между конструкциями

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Дана программа, которая по номеру месяца (1–12) определяет время года цепочкой `if-else-if`. Переписать её с использованием оператора `switch` с объединёнными метками. Затем выполнить обратное преобразование для программы из ALG-007 (оценка по баллу) и объяснить, почему второе преобразование оказывается неудобным.

## Ожидаемый результат
Работающий вариант со `switch` для месяцев, использующий объединённые метки; при обратном переводе показано, что диапазоны баллов требуют перечисления множества констант, из-за чего `switch` здесь неуместен.
