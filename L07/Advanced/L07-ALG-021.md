# L07-ALG-021. Три нарушения в одном фрагменте

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Дан код:

```
int x = 3;
if (x = 5) { Console.WriteLine("равно"); }

var label = x > 0 ? "положительное" : 0;

switch (x)
{
    case 1:
        Console.WriteLine("один");
    case 2:
        Console.WriteLine("два");
        break;
}
```

Найти все нарушения, для каждого назвать код ошибки компилятора и объяснить причину отдельно. Указать, какое из них связано с типом условия, какое — с типами ветвей, а какое — со структурой оператора выбора. Привести исправленный фрагмент.

## Ожидаемый результат
Три нарушения с кодами `CS0029`, `CS0173` и `CS0163`, каждое с отдельным обоснованием и правильным отнесением к категории.
