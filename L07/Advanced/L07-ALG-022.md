# L07-ALG-022. Предсказание вывода вложенных условий

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Дан код:

```
int a = 10;
int b = 0;

if (a > 5)
    if (b > 0)
        Console.WriteLine("первое");
    else
        Console.WriteLine("второе");
else
    Console.WriteLine("третье");
```

Не запуская программу, определить, что она выведет, и объяснить, к какому `if` относится каждая из двух частей `else`. Затем расставить фигурные скобки так, чтобы структура стала однозначной, не изменив поведения. Проверить ответ запуском.

## Ожидаемый результат
Предсказано «второе»; показано, что первый `else` принадлежит внутреннему `if`, а второй — внешнему; приведён вариант со скобками, дающий тот же вывод.
