# Разбор решения. L07-ALG-021. Три нарушения в одном фрагменте

## Условие
Дан код:

```
int x = 3;
if (x = 5) { Console.WriteLine("равно"); }

var label = x > 0 ? "положительное" : 0;

switch (x)
{
    case 1:
        Console.WriteLine("один");
    case 2:
        Console.WriteLine("два");
        break;
}
```

Найти все нарушения, для каждого назвать код ошибки компилятора и объяснить причину отдельно. Указать, какое из них связано с типом условия, какое — с типами ветвей, а какое — со структурой оператора выбора. Привести исправленный фрагмент.

## Ожидаемый результат
Три нарушения с кодами `CS0029`, `CS0173` и `CS0163`, каждое с отдельным обоснованием и правильным отнесением к категории.

## Разбор условия
**Дано:** три фрагмента: условие `if` с присваиванием, условный оператор с разными типами ветвей, `switch` без завершения раздела.
**Требуется:** найти три нарушения, назвать коды (`CS0029`, `CS0173`, `CS0163`), отнести к категориям, привести исправленный вариант.

## Теоретическая справка
1. **Условие `if` обязано быть `bool`.** Выражение `x = 5` — присваивание, его значение имеет тип `int`; в C бы это скомпилировалось, в C# — ошибка `CS0029`.
2. **Тернарный оператор `?:`** требует, чтобы типы второй и третьей частей имели общий тип. Для `string` и `int` общего типа нет (`CS0173`, начиная с C# 9 сообщение уточняется, но смысл тот же).
3. **Оператор `switch`:** каждый раздел `case` должен завершаться `break`, `return`, `throw`, `goto` или `continue`. «Проваливаться» в следующий раздел нельзя (`CS0163`), поскольку это частый источник ошибок в C/C++.

## Идея решения
Проверяем тип условия, согласованность типов двух ветвей `?:` и обязательность завершения каждого раздела `switch`.

## Решение
```csharp
// Исправленный фрагмент
int x = 3;
if (x == 5) { Console.WriteLine("равно"); }

var label = x > 0 ? "положительное" : "неположительное";

switch (x)
{
    case 1:
        Console.WriteLine("один");
        break;
    case 2:
        Console.WriteLine("два");
        break;
}
```

## Пошаговое объяснение
1. `if (x = 5)` — `x = 5` является присваиванием и имеет тип `int`, а условие `if` обязано быть `bool` (`CS0029`). Нужно сравнение `==`. Нарушение, связанное с типом условия.
2. `x > 0 ? "положительное" : 0` — ветви имеют несовместимые типы `string` и `int`, общего типа нет (`CS0173`). Нарушение, связанное с типами ветвей.
3. `case 1:` без `break` — в C# провал в следующий раздел запрещён: каждый раздел должен завершаться `break`, `return`, `goto` и т. п. (`CS0163`). Нарушение структуры оператора выбора.

## Трассировка и проверка
| Фрагмент | Категория | Код | Исправление |
|---|---|---|---|
| `if (x = 5)` | тип условия | CS0029 | `if (x == 5)` |
| `x > 0 ? "…" : 0` | типы ветвей | CS0173 | обе ветви — строки |
| `case 1: …` без `break` | структура `switch` | CS0163 | добавить `break;` |

Дополнительная проверка: после исправления `x = 3`: `x == 5` ложно (вывода нет), `label = "положительное"`, `switch` не находит совпадений и ничего не печатает.

## Результат
Нарушения: CS0029 (тип условия), CS0173 (типы ветвей), CS0163 (раздел switch без завершения).

## Типичные ошибки
- Считать, что `if (x = 5)` присваивает и сравнивает одновременно.
- Объединять строки и числа в ветвях `?:`, надеясь на неявное преобразование.
- Не знать, что несколько меток подряд допустимы для пустых разделов: `case 1: case 2: …` — общий раздел для двух значений.
- Забывать раздел `default`, когда нужны сообщения о неожиданных значениях.
