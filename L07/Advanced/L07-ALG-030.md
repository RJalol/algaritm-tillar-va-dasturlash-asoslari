# L07-ALG-030. Полный аудит фрагмента с ветвлениями

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Дан код:

```
using System;

namespace AuditDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.Write("Введите балл: ");
            int score = Convert.ToInt32(Console.ReadLine());

            if (score >= 60);
            {
                Console.WriteLine("Зачёт");
            }

            if (score >= 60)
                Console.WriteLine("Удовлетворительно");
            else if (score >= 90)
                Console.WriteLine("Отлично");

            switch (score)
            {
                case 100:
                    Console.WriteLine("Максимум");
                default:
                    Console.WriteLine("Обычный балл");
                    break;
            }
        }
    }
}
```

Провести полный аудит и разнести замечания по трём категориям: ошибка компиляции; предупреждение компилятора, за которым скрывается неверное поведение; логическая ошибка, не вызывающая ни того ни другого. Для каждой указать конкретную строку, назвать код там, где он есть, и описать, что именно программа сделает неправильно. Привести исправленную версию.

## Ожидаемый результат
Категории разнесены верно: `CS0163` в операторе `switch` (секция `case 100` без завершающего оператора); предупреждение `CS0642` на первом `if`, из-за которого «Зачёт» выводится при любом балле; логически недостижимая ветвь «Отлично» из-за неверного порядка условий. Приведён исправленный код.
