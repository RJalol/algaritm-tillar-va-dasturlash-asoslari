# L07-ALG-025. Цепочка тернарных операторов

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Написать программу, которая по введённому баллу определяет оценку («отлично», «хорошо», «удовлетворительно», «неудовлетворительно») **одним выражением** с цепочкой тернарных операторов, присвоив результат строковой переменной. Затем расставить в этом выражении скобки в соответствии с правилом ассоциативности и убедиться, что результат не изменился. Сравнить в комментарии читаемость этой записи с цепочкой `if-else-if`.

## Ожидаемый результат
Одно выражение, дающее правильную оценку; приведён вариант со скобками, показывающий правоассоциативность; в комментарии сделан обоснованный вывод о границах применимости такой записи.
