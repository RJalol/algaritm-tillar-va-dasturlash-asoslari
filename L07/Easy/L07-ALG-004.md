# L07-ALG-004. Знак числа

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Написать программу, которая запрашивает у пользователя целое число и сообщает, является оно положительным, отрицательным или нулём. Использовать цепочку `if-else-if` с завершающей частью `else`.

## Ожидаемый результат
Три взаимоисключающих исхода; завершающая часть `else` обрабатывает случай нуля без отдельной проверки на равенство нулю.
