# L07-ALG-002. Больший из двух

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Написать программу, которая запрашивает у пользователя два целых числа и выводит большее из них, используя оператор `if-else`. Предусмотреть случай равенства чисел, сообщив о нём отдельно.

## Ожидаемый результат
Три различных исхода в зависимости от введённых данных; случай равенства обработан отдельной ветвью, а не отнесён к одному из двух неравенств.
