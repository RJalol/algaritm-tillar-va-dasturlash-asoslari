# L07-ALG-003. Больший из двух через тернарный оператор

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Решить задачу поиска большего из двух чисел ещё раз, но записать выбор **одним выражением** с тернарным оператором, присвоив результат переменной. Вывести значение этой переменной. Сравнить в комментарии объём этой записи с записью через `if-else` из предыдущего задания.

## Ожидаемый результат
Выведено большее из двух чисел; выбор выполнен единственным выражением, результат сохранён в переменной.
