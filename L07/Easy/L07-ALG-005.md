# L07-ALG-005. День недели по номеру

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Написать программу, которая запрашивает у пользователя номер дня недели от 1 до 7 и выводит его название, используя оператор `switch`. Предусмотреть метку `default` для недопустимых значений.

## Ожидаемый результат
При вводе 3 выведено «Среда», при вводе 9 — сообщение о недопустимом значении; каждая секция завершается оператором `break`.
