# Разбор решения. L07-ALG-001. Чётность числа

## Условие
Написать программу, которая запрашивает у пользователя целое число и сообщает, чётное оно или нечётное. Использовать оператор `if-else` и операцию взятия остатка (тема №4).

## Ожидаемый результат
При вводе 14 выведено сообщение о чётности, при вводе 7 — о нечётности; в условии применена проверка остатка от деления на 2.

## Разбор условия
**Дано:** целое число, вводимое пользователем.
**Требуется:** определить, чётное оно или нечётное, и сообщить об этом.
**Ограничение по условию:** оператор `if-else` и операция взятия остатка.

## Теоретическая справка
**Оператор ветвления `if-else`** выполняет одну из двух ветвей:

```
if (условие)
    ветвь_если_истинно;
else
    ветвь_если_ложно;
```

Условие обязано иметь тип `bool`. Чётность определяется остатком от деления на 2: число чётное, если `n % 2 == 0`. Для отрицательных нечётных чисел остаток равен `-1`, а не `1`, поэтому проверять лучше именно равенство нулю, а не единице.

Метод `int.Parse` преобразует введённую строку в число; при неверном формате вызывает `FormatException` (обработка ошибок — тема №28).

## Идея решения
Число чётно, если остаток от деления на 2 равен нулю.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите целое число: ");
        int n = int.Parse(Console.ReadLine());

        if (n % 2 == 0)
            Console.WriteLine("Число чётное");
        else
            Console.WriteLine("Число нечётное");
    }
}
```

## Пошаговое объяснение
1. Считываем строку и преобразуем её в `int` методом `int.Parse`.
2. Условие `n % 2 == 0` проверяет, делится ли число на 2 без остатка.
3. Если условие истинно, выполняется ветвь `if`, иначе — `else`.
4. Для отрицательных чисел остаток может быть `-1`, но сравнение с нулём остаётся верным, поэтому проверка работает и для них.

## Трассировка и проверка
| n | n % 2 | Условие `n % 2 == 0` | Вывод |
|---:|---:|:--:|---|
| 14 | 0 | да | чётное |
| 7 | 1 | нет | нечётное |
| 0 | 0 | да | чётное |
| −3 | −1 | нет | нечётное |

Ноль — чётное число; программа относит его к чётным без особых случаев.

## Результат
14 → «Число чётное»; 7 → «Число нечётное».

## Типичные ошибки
- Проверять `n % 2 == 1` — для отрицательных нечётных чисел остаток равен −1, и они попадут в «чётные».
- Использовать `=` вместо `==` в условии (`if (n % 2 = 0)` — ошибка компиляции).
- Поставить после `if (...)` точку с запятой — ветвь окажется пустой.
- Не обработать ввод нечислового текста (при `int.Parse` возникнет исключение).
