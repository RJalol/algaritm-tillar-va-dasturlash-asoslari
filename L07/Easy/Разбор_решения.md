# Разбор решения. L07-ALG-001. Чётность числа

## Условие
Написать программу, которая запрашивает у пользователя целое число и сообщает, чётное оно или нечётное. Использовать оператор `if-else` и операцию взятия остатка (тема №4).

## Ожидаемый результат
При вводе 14 выведено сообщение о чётности, при вводе 7 — о нечётности; в условии применена проверка остатка от деления на 2.

## Идея решения
Число чётно, если остаток от деления на 2 равен нулю.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите целое число: ");
        int n = int.Parse(Console.ReadLine());

        if (n % 2 == 0)
            Console.WriteLine("Число чётное");
        else
            Console.WriteLine("Число нечётное");
    }
}
```

## Пошаговое объяснение
1. Считываем строку и преобразуем её в `int` методом `int.Parse`.
2. Условие `n % 2 == 0` проверяет, делится ли число на 2 без остатка.
3. Если условие истинно, выполняется ветвь `if`, иначе — `else`.
4. Для отрицательных чисел остаток может быть `-1`, но сравнение с нулём остаётся верным, поэтому проверка работает и для них.

## Результат
14 → «Число чётное»; 7 → «Число нечётное».
