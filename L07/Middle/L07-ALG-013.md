# L07-ALG-013. Присваивание вместо сравнения

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Дан код:

```
int x = 3;
if (x = 5)
{
    Console.WriteLine("равно");
}
```

Определить, скомпилируется ли фрагмент. Назвать код ошибки, объяснить причину и указать, почему в языках семейства C такая запись компилируется, а в C# — нет. Привести исправленный вариант.

## Ожидаемый результат
Назван код `CS0029`; объяснено, что результатом присваивания является число, а условие обязано иметь тип `bool`; отмечено, что это ограничение защищает от распространённой ошибки.
