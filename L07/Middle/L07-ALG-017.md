# L07-ALG-017. Несовместимые ветви тернарного оператора

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Дан код:

```
int n = 5;
var result = n > 0 ? "положительное" : 0;
```

Объяснить, почему фрагмент не компилируется, назвать код ошибки и сформулировать требование, предъявляемое к типам ветвей тернарного оператора. Предложить два разных исправления.

## Ожидаемый результат
Назван код `CS0173`; сформулировано требование совместимости типов; предложены исправления — привести обе ветви к строке либо обе к числу.
