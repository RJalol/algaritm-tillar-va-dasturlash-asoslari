# L07-ALG-010. Наибольшее из трёх чисел

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Написать программу, которая запрашивает три целых числа и выводит наибольшее из них. Задачу решить **вложенными** операторами `if`, не применяя методы класса `Math`.

## Ожидаемый результат
Выведено наибольшее из трёх введённых значений при любом их порядке; решение использует вложенные условия, а не `Math.Max`.
