# L07-ALG-018. Недостижимая ветвь

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Дан код:

```
if (score >= 60)
    Console.WriteLine("Удовлетворительно");
else if (score >= 90)
    Console.WriteLine("Отлично");
```

Определить, при каком значении балла программа работает неверно, и объяснить причину. Указать, обнаружит ли ошибку компилятор. Привести исправленный вариант.

## Ожидаемый результат
Указано, что при балле 90 и выше выводится «Удовлетворительно», поскольку первое условие истинно и вторая ветвь недостижима; отмечено, что компилятор ошибку не обнаруживает; в исправленном варианте условия расположены в порядке убывания границ.
