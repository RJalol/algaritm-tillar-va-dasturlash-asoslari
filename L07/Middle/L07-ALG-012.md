# L07-ALG-012. Калькулятор на четыре действия

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Написать программу, которая запрашивает два числа и знак операции (строку из одного символа: `+`, `-`, `*` или `/`) и выводит результат соответствующего действия, используя оператор `switch`. Для деления предусмотреть проверку делителя на нуль до выполнения операции.

## Ожидаемый результат
Четыре работающие операции и метка `default` для неизвестного знака; при делении на нуль выведено сообщение вместо аварийного завершения программы.
