# Разбор решения. L07-ALG-006. Проверка допустимости данных

## Условие
Написать программу, которая запрашивает у пользователя балл и, прежде чем что-либо вычислять, проверяет, лежит ли он в пределах от 0 до 100. При недопустимом значении вывести сообщение об ошибке, при допустимом — вывести сам балл и его долю от максимума в процентах.

## Ожидаемый результат
При вводе 150 выведено сообщение об ошибке и никаких вычислений не выполнено; при вводе 45 выведены балл и доля; условие допустимости записано одним выражением с логической операцией.

## Разбор условия
**Дано:** балл, вводимый пользователем.
**Требуется:** сначала проверить допустимость (0…100), при недопустимом значении вывести ошибку и ничего не вычислять; иначе вывести балл и его долю от максимума в процентах.
**Требование:** условие допустимости записано одним выражением.

## Теоретическая справка
Проверка входных данных до вычисления — приём **защитного программирования**: недопустимые данные отсекаются сразу.

Условие «значение вне отрезка [0; 100]» записывается как `score < 0 || score > 100`. Эквивалентная запись допустимости: `score >= 0 && score <= 100`. Законы де Моргана связывают эти формы: `!(A && B) == !A || !B`.

Доля от максимума в процентах: `score / max * 100`. При максимуме 100 процент совпадает с баллом, но запись формулы с константой `max` делает код понятнее и устойчивее к изменению шкалы.

## Идея решения
Сначала проверяем допустимость данных одним логическим выражением, и только потом вычисляем долю от максимума (100) в процентах.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите балл: ");
        double score = double.Parse(Console.ReadLine());

        if (score < 0 || score > 100)
        {
            Console.WriteLine("Ошибка: балл должен быть от 0 до 100");
        }
        else
        {
            double percent = score / 100 * 100;
            Console.WriteLine($"Балл: {score}, доля от максимума: {percent}%");
        }
    }
}
```

## Пошаговое объяснение
1. Недопустимое значение — вне отрезка [0; 100]: `score < 0 || score > 100` (одно выражение с логической операцией «или»).
2. Если условие истинно, выводим ошибку, и вычисления не выполняются.
3. В противном случае считаем долю: `score / 100 * 100` (при максимуме 100 процент совпадает с баллом) и выводим результат с помощью интерполяции строк.

## Трассировка и проверка
| Ввод | Условие ошибки | Вывод |
|---:|:--:|---|
| 150 | `150 > 100` — истина | сообщение об ошибке |
| −5 | `−5 < 0` — истина | сообщение об ошибке |
| 45 | ложь | «Балл: 45, доля: 45%» |
| 0 | ложь | «Балл: 0, доля: 0%» |
| 100 | ложь | «Балл: 100, доля: 100%» |

Проверка границ показывает, что 0 и 100 допустимы: знаки сравнения строгие (`<`, `>`).

## Результат
150 → сообщение об ошибке без вычислений; 45 → «Балл: 45, доля от максимума: 45%».

## Типичные ошибки
- Использовать нестрогие сравнения (`<=`, `>=`) в условии ошибки — исключит допустимые границы.
- Использовать `&&` вместо `||` в условии ошибки: ни одно число не может быть одновременно меньше 0 и больше 100.
- Выполнять вычисление до проверки.
- Читать число типом `int` и терять дробную часть баллов вроде 87,5.
