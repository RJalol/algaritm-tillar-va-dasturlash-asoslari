# L07-ALG-019. Обработка текстовой команды

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Написать программу, которая запрашивает у пользователя команду в виде строки (`старт`, `стоп` или `пауза`) и выводит соответствующее сообщение, используя оператор `switch` по строковому значению. Предусмотреть обработку неизвестной команды.

## Ожидаемый результат
Три распознаваемые команды и сообщение о неизвестной команде для остальных значений; оператор `switch` применён к строке.
