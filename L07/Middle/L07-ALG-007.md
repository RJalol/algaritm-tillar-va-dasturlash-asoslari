# L07-ALG-007. Оценка по баллу цепочкой условий

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Написать программу, которая по введённому баллу выводит оценку: 90 и выше — «отлично», 70–89 — «хорошо», 60–69 — «удовлетворительно», ниже 60 — «неудовлетворительно». Использовать цепочку `if-else-if`, в каждом условии проверяя **только нижнюю** границу.

## Ожидаемый результат
Четыре взаимоисключающих исхода; условия расположены в порядке убывания границ, благодаря чему верхние границы диапазонов проверять не требуется.
