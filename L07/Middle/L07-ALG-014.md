# L07-ALG-014. Забытый break

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Дан код:

```
switch (day)
{
    case 1:
        Console.WriteLine("Понедельник");
    case 2:
        Console.WriteLine("Вторник");
        break;
}
```

Определить, скомпилируется ли фрагмент, назвать код ошибки и объяснить, что произошло бы в языке C при той же записи. Привести два корректных варианта: с раздельной обработкой и с объединением меток.

## Ожидаемый результат
Назван код `CS0163`; объяснено, что в C выполнились бы обе секции подряд, а C# такой переход запрещает; приведены оба исправления.
