# L07-ALG-020. switch по перечислению

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Написать программу, которая объявляет перечисляемый тип «Время года» (тема №6), создаёт переменную этого типа и с помощью оператора `switch` выводит характерное для этого сезона сообщение. Объяснить в комментарии, чем такой `switch` лучше `switch` по числу.

## Ожидаемый результат
Четыре секции по числу элементов перечисления; в комментарии отмечено, что метки читаются как осмысленные имена, а не как числа.
