# L07-ALG-016. Привязка else

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Дан код:

```
int x = 5;
int y = 20;

if (x > 0)
    if (y > 100)
        Console.WriteLine("A");
    else
        Console.WriteLine("B");
```

Не запуская программу, определить, что она выведет. Объяснить ответ через правило привязки `else`. Затем переписать фрагмент так, чтобы `else` относился к внешнему `if`, и указать, что выведет изменённый вариант.

## Ожидаемый результат
Предсказано `B`, ответ обоснован правилом привязки к ближайшему `if`; в переписанном варианте с фигурными скобками не выводится ничего.
