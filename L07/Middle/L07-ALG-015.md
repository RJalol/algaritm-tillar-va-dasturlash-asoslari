# L07-ALG-015. Лишняя точка с запятой

**Тема:** Л7 — Тернарный оператор. Операторы ветвления if, if-else, if-else-if. Оператор выбора переключателя

## Условие
Дан код:

```
int score = 30;
if (score >= 60);
{
    Console.WriteLine("Зачёт");
}
```

Определить, что выведет программа, и объяснить причину. Указать, какое сообщение выдаст компилятор и почему это сообщение является предупреждением, а не ошибкой. Объяснить, почему эта ситуация опаснее ошибок из ALG-013 и ALG-014.

## Ожидаемый результат
Указано, что выводится «Зачёт» несмотря на балл 30; названо предупреждение `CS0642`; объяснено, что точка с запятой образует пустой оператор, ставший телом `if`, а блок выполняется безусловно; отмечено, что программа собирается и ошибка проявляется только в поведении.
