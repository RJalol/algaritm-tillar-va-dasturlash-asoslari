# Разбор решения. L38 · Задание I · №1. Первое событие

## Условие
Объявить класс `Button` с событием `Click` типа `EventHandler`. Подписать на него метод и вызвать событие методом `OnClick`.

## Ожидаемый результат
Метод-обработчик выводит сообщение при вызове события.

## Разбор условия
**Дано:** класс «кнопка».
**Требуется:** объявить событие `Click` типа `EventHandler`, подписать метод и вызвать событие.

## Теоретическая справка
**Событие** — механизм уведомления: класс-**издатель** (publisher) сообщает о происшествии, а **подписчики** (subscribers) реагируют. Объявляется ключевым словом `event`:

```
public event EventHandler Click;
```

Тип `EventHandler` — делегат `void (object sender, EventArgs e)`.

Ограничения события (отличие от открытого делегата):

- снаружи класса можно только подписаться (`+=`) и отписаться (`-=`);
- вызвать событие или присвоить ему значение может только сам издатель.

Безопасный вызов: `Click?.Invoke(this, EventArgs.Empty);` — оператор `?.` защищает от `null`, когда подписчиков нет.

## Идея решения
Событие — особый член класса-издателя, на который подписываются обработчики. Тип события `EventHandler` — стандартный делегат `void (object sender, EventArgs e)`.

## Решение
```csharp
using System;

class Button
{
    public event EventHandler Click;

    public void OnClick()
    {
        Click?.Invoke(this, EventArgs.Empty);
    }
}

class Program
{
    static void Handler(object sender, EventArgs e)
    {
        Console.WriteLine("Кнопка нажата");
    }

    static void Main()
    {
        Button b = new Button();
        b.Click += Handler;     // подписка
        b.OnClick();            // вызов события
    }
}
```

## Пошаговое объяснение
1. `public event EventHandler Click;` объявляет событие: снаружи на него можно только подписываться (`+=`) и отписываться (`-=`).
2. Вызывает событие только сам класс-издатель, здесь — метод `OnClick`.
3. Запись `Click?.Invoke(...)` безопасна, если подписчиков нет (тогда `Click` равно `null`).
4. Метод `Handler` совпадает по сигнатуре с `EventHandler` и подписан оператором `+=`.

## Трассировка и проверка
| Действие | Результат |
|---|---|
| `b.Click += Handler;` | подписчик добавлен |
| `b.OnClick();` | вызов события → `Handler` выводит «Кнопка нажата» |
| вызов без подписчиков | ничего не происходит (благодаря `?.`) |

## Результат
Кнопка нажата

## Типичные ошибки
- Вызвать событие без проверки `null`.
- Попытаться вызвать событие снаружи класса (`CS0070`).
- Использовать `=` вместо `+=` для подписки (`CS0070`).
- Забыть отписаться и удерживать подписчиков в памяти.
