# Разбор решения. L47 · Задание II · №1. Несколько кривых

## Условие
Построить на одном графике синус и косинус с легендой.

## Ожидаемый результат
Две кривые разных цветов и легенда.

## Идея решения
Каждая кривая — отдельный вызов добавления ряда данных; легенда включается и подписывается через свойства ряда.

## Решение
```csharp
using System;
using System.Linq;
using System.Windows.Forms;
using ScottPlot.WinForms;

public class Form1 : Form
{
    public Form1()
    {
        Text = "sin и cos";
        Width = 700; Height = 450;

        double[] x = Enumerable.Range(0, 200).Select(i => i * 2 * Math.PI / 199).ToArray();
        double[] sin = x.Select(Math.Sin).ToArray();
        double[] cos = x.Select(Math.Cos).ToArray();

        var plot = new FormsPlot { Dock = DockStyle.Fill };
        var s1 = plot.Plot.Add.Scatter(x, sin);
        s1.LegendText = "sin(x)";
        var s2 = plot.Plot.Add.Scatter(x, cos);
        s2.LegendText = "cos(x)";
        plot.Plot.ShowLegend();
        plot.Plot.Title("Синус и косинус");
        plot.Refresh();

        Controls.Add(plot);
    }
}
```

## Пошаговое объяснение
1. Сетка x содержит 200 точек на отрезке [0; 2π]; значения функций вычисляются массивами.
2. Метод добавления ряда возвращает объект, у которого можно задать подпись (`LegendText`), цвет, толщину.
3. `ShowLegend()` включает легенду; цвета рядов библиотека подбирает автоматически.
4. Подробности API зависят от версии библиотеки (в ScottPlot 5 — `Plot.Add.Scatter`); при другой версии нужно сверяться с документацией.

## Результат
На графике две кривые разных цветов — синусоида и косинусоида — с легендой.
