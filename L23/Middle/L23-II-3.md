# L23 · Задание II · №3. Статический конструктор для полей только для чтения

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Объявить класс с тремя статическими полями только для чтения, значения которых вычисляются согласованно (например, нижняя граница, верхняя граница и их разность). Присвоить значения в статическом конструкторе, выведя из него сообщение. Обратиться к типу дважды и определить по выводу, сколько раз выполнился статический конструктор.

## Ожидаемый результат
Сообщение статического конструктора выведено **один** раз и до первого использования значений; все три поля согласованы.
