# L23 · Задание II · №8. Выбор средства

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Даны величины: число $$; номер зачётной книжки; название учебного заведения, считываемое при запуске; максимальная длина имени, зафиксированная в требованиях; дата создания объекта; коды состояний заказа. Для каждой выбрать `const`, `readonly` либо `static readonly` и обосновать выбор. Реализовать классы, содержащие все шесть величин.

## Ожидаемый результат
Выбор для каждой величины обоснован моментом получения значения и принадлежностью типу или объекту; все классы компилируются.
