# Разбор решения. L23 · Задание II · №1. Класс настроек

## Условие
Объявить класс настроек приложения, содержащий одновременно: константу с названием и версией программы, статическое поле только для чтения, вычисляемое при запуске (например, момент запуска или имя платформы), и экземплярное поле только для чтения с моментом создания объекта. Вывести все значения и пояснить в комментарии, почему для каждого выбрано именно это средство.

## Ожидаемый результат
Все три группы значений выведены; в комментарии для каждого поля указано, когда именно оно получает значение.

## Идея решения
Три способа хранить «неизменяемое»: `const` — значение известно при компиляции; `static readonly` — вычисляется при запуске (инициализация типа); `readonly` экземпляра — задаётся при создании каждого объекта.

## Решение
```csharp
using System;

class AppSettings
{
    // const: значение известно на этапе компиляции и одинаково везде
    public const string Title = "Учёт студентов v1.0";

    // static readonly: вычисляется один раз при первом обращении к типу
    public static readonly DateTime StartedAt = DateTime.Now;
    public static readonly string Platform = Environment.OSVersion.Platform.ToString();

    // readonly-поле экземпляра: значение фиксируется при создании объекта
    public readonly DateTime CreatedAt;

    public AppSettings()
    {
        CreatedAt = DateTime.Now;
    }
}

class Program
{
    static void Main()
    {
        AppSettings s1 = new AppSettings();
        System.Threading.Thread.Sleep(100);
        AppSettings s2 = new AppSettings();

        Console.WriteLine(AppSettings.Title);
        Console.WriteLine(AppSettings.StartedAt);
        Console.WriteLine(AppSettings.Platform);
        Console.WriteLine(s1.CreatedAt);
        Console.WriteLine(s2.CreatedAt);   // отличается от s1
    }
}
```

## Пошаговое объяснение
1. `const Title` — название и версия известны заранее, компилятор подставляет значение в код.
2. `static readonly StartedAt`/`Platform` — значения зависят от среды выполнения, поэтому `const` невозможен; они вычисляются один раз при загрузке типа и общие для всех объектов.
3. `readonly CreatedAt` — у каждого объекта своё значение, присваиваемое только в конструкторе.
4. Вывод показывает, что `CreatedAt` у двух объектов различается, а `StartedAt` один.

## Результат
Выведены название, момент запуска, платформа и два разных момента создания объектов.
