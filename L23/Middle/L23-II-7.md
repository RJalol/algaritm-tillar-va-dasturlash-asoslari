# L23 · Задание II · №7. Внешняя ссылка на «защищённый» объект

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Показать на классе задания II.5, что объект, переданный в конструктор извне, остаётся доступным для изменения через исходную переменную. Вывести состояние журнала до и после изменения через внешнюю ссылку. Предложить исправление, при котором конструктор создаёт собственную копию объекта.

## Ожидаемый результат
До исправления изменение через внешнюю переменную отражается на журнале; после исправления — не отражается.
