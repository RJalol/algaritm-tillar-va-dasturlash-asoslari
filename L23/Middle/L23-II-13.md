# L23 · Задание II · №13. Неизменяемый класс

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Разработать класс «денежная сумма», у которого **все** поля объявлены только для чтения, а все операции возвращают новый объект, не изменяя существующий. Реализовать сложение и вычитание перегруженными операторами (тема №22). Проверить, что после серии операций исходный объект не изменился.

## Ожидаемый результат
Исходный объект после всех операций сохранил своё значение; каждая операция вернула новый объект.
