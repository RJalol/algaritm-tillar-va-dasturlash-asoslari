# L23 · Задание II · №1. Класс настроек

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Объявить класс настроек приложения, содержащий одновременно: константу с названием и версией программы, статическое поле только для чтения, вычисляемое при запуске (например, момент запуска или имя платформы), и экземплярное поле только для чтения с моментом создания объекта. Вывести все значения и пояснить в комментарии, почему для каждого выбрано именно это средство.

## Ожидаемый результат
Все три группы значений выведены; в комментарии для каждого поля указано, когда именно оно получает значение.
