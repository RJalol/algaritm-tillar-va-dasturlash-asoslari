# L23 · Задание II · №11. Части в разных пространствах имён

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Объявить две части с одинаковым именем в **разных** пространствах имён и попытаться использовать члены обеих через один объект. Определить, сообщает ли компилятор об ошибке, и объяснить полученный результат, опираясь на тему №21.

## Ожидаемый результат
Компилятор об ошибке не сообщает; установлено, что получились два разных типа с разными полными именами, а не две части одного типа.
