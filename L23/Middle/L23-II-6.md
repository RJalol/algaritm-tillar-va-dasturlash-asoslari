# L23 · Задание II · №6. Массив только для чтения

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Дополнить класс задания II.5 полем только для чтения — массивом оценок. Показать, что элементы массива изменяются свободно, а замена массива целиком запрещена. Предложить и реализовать способ действительно защитить содержимое от изменения извне класса, не прибегая к средствам последующих тем.

## Ожидаемый результат
Изменение элемента выполнено, замена массива даёт `CS0191`; предложенная защита — скрыть поле и выдавать наружу копию массива либо отдельные значения через методы.
