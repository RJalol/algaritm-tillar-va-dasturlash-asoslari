# L23 · Задание II · №5. `readonly` и ссылочный тип

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Объявить класс «журнал», хранящий поле только для чтения ссылочного типа (объект группы с изменяемым названием) и поле только для чтения значимого типа. Написать метод, изменяющий название группы через это поле, и попытку присвоить полю новый объект группы. Проверить, что первое разрешено, а второе — нет.

## Ожидаемый результат
Название группы изменено успешно; присваивание нового объекта даёт `CS0191`; в комментарии сформулировано, что модификатор защищает ссылку, а не объект.
