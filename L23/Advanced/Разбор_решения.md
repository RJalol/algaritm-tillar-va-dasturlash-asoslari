# Разбор решения. L23 · Задание III · №1. Полностью неизменяемый тип

## Условие
Разработать неизменяемый класс «дата занятия», хранящий год, месяц, день и номер пары. Все поля — только для чтения, все проверки корректности — в конструкторе, все операции (сдвиг на несколько дней, смена пары) возвращают новый объект. Добавить перегруженные операторы равенства и сравнения (тема №22) с согласованными `Equals` и `GetHashCode`. Проверить не менее чем на десяти операциях, включая переход через границу месяца.

## Ожидаемый результат
Ни одна операция не изменила исходный объект; сравнения дают верные результаты; некорректные аргументы конструктора отвергнуты.

## Разбор условия
**Дано:** требования к неизменяемому классу «дата занятия».
**Требуется:** поля только для чтения, проверки в конструкторе, операции возвращают новые объекты, перегруженные `==`, `!=`, `<`, `>` и согласованные `Equals`/`GetHashCode`; не менее десяти проверок.

## Теоретическая справка
**Неизменяемый (immutable) тип:** состояние задаётся при создании и далее не меняется. Преимущества: безопасность при использовании из нескольких потоков, отсутствие скрытых побочных эффектов, возможность использовать как ключ словаря.

**Контракт равенства:**

1. `Equals(a, b)` и `a == b` согласованы;
2. равные объекты имеют равные `GetHashCode()`;
3. хэш неизменяемого объекта не меняется в течение жизни.

Сравнение строится на одном методе (`CompareTo`), от которого выражаются `<`, `>`, `Equals`. Хэш считается по тем же полям, что участвуют в сравнении.

## Идея решения
Неизменяемый тип: все поля `readonly`, проверки в конструкторе, операции возвращают новые объекты. Равенство и сравнение согласованы между собой и с `GetHashCode`.

## Решение
```csharp
using System;

sealed class LessonDate : IEquatable<LessonDate>, IComparable<LessonDate>
{
    public readonly int Year, Month, Day, Period;

    public LessonDate(int year, int month, int day, int period)
    {
        if (month < 1 || month > 12) throw new ArgumentOutOfRangeException(nameof(month));
        if (day < 1 || day > DateTime.DaysInMonth(year, month)) throw new ArgumentOutOfRangeException(nameof(day));
        if (period < 1 || period > 6) throw new ArgumentOutOfRangeException(nameof(period));
        Year = year; Month = month; Day = day; Period = period;
    }

    public LessonDate AddDays(int n)
    {
        DateTime d = new DateTime(Year, Month, Day).AddDays(n);
        return new LessonDate(d.Year, d.Month, d.Day, Period);
    }

    public LessonDate WithPeriod(int period) => new LessonDate(Year, Month, Day, period);

    public int CompareTo(LessonDate o)
    {
        int c = new DateTime(Year, Month, Day).CompareTo(new DateTime(o.Year, o.Month, o.Day));
        return c != 0 ? c : Period.CompareTo(o.Period);
    }

    public bool Equals(LessonDate o) => o is not null && CompareTo(o) == 0;
    public override bool Equals(object obj) => obj is LessonDate o && Equals(o);
    public override int GetHashCode() => HashCode.Combine(Year, Month, Day, Period);

    public static bool operator ==(LessonDate a, LessonDate b) => a is null ? b is null : a.Equals(b);
    public static bool operator !=(LessonDate a, LessonDate b) => !(a == b);
    public static bool operator <(LessonDate a, LessonDate b) => a.CompareTo(b) < 0;
    public static bool operator >(LessonDate a, LessonDate b) => a.CompareTo(b) > 0;

    public override string ToString() => $"{Day:00}.{Month:00}.{Year}, пара {Period}";
}

class Program
{
    static void Main()
    {
        LessonDate a = new LessonDate(2026, 1, 30, 2);
        LessonDate b = a.AddDays(3);                       // переход через границу месяца
        LessonDate c = a.WithPeriod(4);
        Console.WriteLine(a);                              // не изменился
        Console.WriteLine(b);                              // 02.02.2026
        Console.WriteLine(c);
        Console.WriteLine(a == new LessonDate(2026, 1, 30, 2));
        Console.WriteLine(a < b);
        Console.WriteLine(b > c);
        Console.WriteLine(a.GetHashCode() == new LessonDate(2026, 1, 30, 2).GetHashCode());
        try { new LessonDate(2026, 2, 30, 1); }
        catch (ArgumentOutOfRangeException e) { Console.WriteLine("Отвергнуто: " + e.ParamName); }
    }
}
```

## Пошаговое объяснение
1. Все поля объявлены `readonly` и присваиваются только в конструкторе, где выполняются и проверки (месяц, день с учётом длины месяца, номер пары).
2. `AddDays` и `WithPeriod` не меняют текущий объект, а создают новый — отсюда неизменяемость.
3. `CompareTo` сравнивает дату, затем номер пары; на нём построены `Equals`, `<`, `>`, а `GetHashCode` вычисляется по тем же четырём полям — равные объекты дают равные хэши.
4. Переход через границу месяца: 30.01 + 3 дня = 02.02.
5. Некорректный аргумент (30 февраля) отвергается исключением из конструктора.

## Трассировка и проверка
Выборка проверок:

| Операция | Результат |
|---|---|
| `a = (2026-01-30, пара 2)` | создан |
| `a.AddDays(3)` | 02.02.2026 (переход через границу месяца) |
| `a.WithPeriod(4)` | новая дата с парой 4; `a` не изменён |
| `a == new LessonDate(2026,1,30,2)` | true |
| `a < b` | true |
| хэши равных | совпадают |
| `new LessonDate(2026,2,30,1)` | `ArgumentOutOfRangeException` |

## Результат
Исходный объект не изменяется; сравнения и хэши согласованы; 30.02.2026 отвергнуто исключением.

## Типичные ошибки
- Менять поля внутри методов вместо возврата нового объекта.
- Переопределить `Equals`, но не `GetHashCode` (предупреждение и неверная работа в словарях).
- Реализовать `==` без обработки `null` (`NullReferenceException`).
- Проверять день по константе 31 без учёта длины месяца.
