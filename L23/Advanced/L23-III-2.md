# L23 · Задание III · №2. Защита содержимого от внешнего изменения

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Разработать класс «ведомость», хранящий поле только для чтения — массив оценок — и объект группы. Показать тремя опытами, что модификатор `readonly` не защищает содержимое: изменение элемента массива изнутри; изменение состояния объекта группы изнутри; изменение через сохранённую снаружи ссылку. Затем реализовать защищённую версию, копирующую данные в конструкторе и выдающую наружу только копии, и повторить те же три опыта.

## Ожидаемый результат
В первой версии все три опыта изменяют состояние ведомости; во второй — ни один; объяснено, чем защита копированием отличается от модификатора `readonly`.
