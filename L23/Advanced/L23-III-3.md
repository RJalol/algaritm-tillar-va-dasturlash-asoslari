# L23 · Задание III · №3. Учебный проект из шести файлов

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Разработать проект «библиотека» из двух частичных классов, каждый разделён на три файла (данные, операции, вывод), размещённых по папкам согласно теме №21. Номера читательских билетов и инвентарные номера книг — поля только для чтения; предельные значения (максимум книг на руки, срок выдачи) — константы. Программа выдаёт и принимает книги и печатает отчёт.

## Ожидаемый результат
Проект компилируется; все операции работают; ни одно поле только для чтения не изменяется после создания объекта; предельные значения заданы константами и использованы, в том числе, как метки `case` либо значения параметров по умолчанию.
