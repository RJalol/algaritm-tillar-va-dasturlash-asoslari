# L23 · Задание III · №1. Полностью неизменяемый тип

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Разработать неизменяемый класс «дата занятия», хранящий год, месяц, день и номер пары. Все поля — только для чтения, все проверки корректности — в конструкторе, все операции (сдвиг на несколько дней, смена пары) возвращают новый объект. Добавить перегруженные операторы равенства и сравнения (тема №22) с согласованными `Equals` и `Get``Hash``Code`. Проверить не менее чем на десяти операциях, включая переход через границу месяца.

## Ожидаемый результат
Ни одна операция не изменила исходный объект; сравнения дают верные результаты; некорректные аргументы конструктора отвергнуты.
