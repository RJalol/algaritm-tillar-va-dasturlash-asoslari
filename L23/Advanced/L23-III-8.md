# L23 · Задание III · №8. Инвентаризация неизменяемости

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Написать статический метод, который для заданного типа выводит перечень его полей с указанием: константа, поле только для чтения, статическое поле только для чтения либо обычное поле. Список полей получить средствами получения сведений о типе. Проверить метод на классе задания III.3 и сопоставить результат с исходным текстом.

## Ожидаемый результат
Каждое поле отнесено к верной категории; итог полностью соответствует объявлениям в исходном тексте.
