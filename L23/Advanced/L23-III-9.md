# L23 · Задание III · №9. Части и порядок инициализации

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Разделить класс на две части так, чтобы инициализаторы полей только для чтения были объявлены в одной части, а статический конструктор — в другой. Вывести из инициализаторов и из конструкторов сообщения и по фактическому выводу установить порядок выполнения. Объяснить, зависит ли этот порядок от того, в какой части объявлен каждый член.

## Ожидаемый результат
Установлен фактический порядок: инициализаторы статических полей выполняются раньше статического конструктора; порядок не зависит от распределения членов по частям, поскольку части соединяются при компиляции.
