# L23 · Задание III · №5. Цена подстановки константы

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Объяснить на примере, почему величину, способную измениться в следующей версии программы, не следует объявлять константой, если она используется за пределами объявляющей сборки. Смоделировать ситуацию в пределах одного проекта: показать, в каких местах кода значение константы оказывается «вписанным» (метка `case`, значение параметра по умолчанию, инициализатор другой константы), и переписать класс так, чтобы величина стала изменяемой между версиями.

## Ожидаемый результат
Перечислены места, где константа не может быть заменена полем `static readonly`, и объяснено, почему; переписанный вариант использует `static readonly` и не требует перекомпиляции потребителей при смене значения.
