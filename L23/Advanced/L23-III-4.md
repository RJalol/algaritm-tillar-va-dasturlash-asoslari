# L23 · Задание III · №4. Диагностика чужого класса

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Подготовить класс, содержащий не менее семи внесённых ошибок из числа изученных: присваивание константе; неконстантный инициализатор; константа ссылочного типа; `static` у константы; присваивание `readonly` вне конструктора; присваивание `static readonly` в конструкторе экземпляра; поле `static readonly` в метке `case`. Составить таблицу «строка — код — причина — исправление» и привести класс в рабочее состояние.

## Ожидаемый результат
Таблица содержит не менее семи строк с фактически полученными кодами; исправленный класс компилируется без ошибок и предупреждений.
