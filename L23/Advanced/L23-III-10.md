# L23 · Задание III · №10. Полный аудит

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Дан проект, в котором одновременно: величины, которые должны быть константами, объявлены обычными полями; величины, способные измениться, объявлены константами; поле только для чтения ссылочного типа выдаётся наружу открытым; части одного класса объявлены с разной доступностью; в одной части забыт модификатор `partial`. Провести аудит, разнести замечания по трём категориям (неверный выбор средства; мнимая защита ссылочного поля; нарушение правил частичного типа) и привести исправленную версию.

## Ожидаемый результат
Все замечания названы с обоснованием и, где применимо, с кодом ошибки (`CS0260`, `CS0262`); исправленный проект компилируется, а его поведение совпадает с исходным во всём, кроме устранённой мнимой защиты.
