# L23 · Задание I · №1. Первые константы

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Объявить класс «физические величины» с константами: ускорение свободного падения, число дней в неделе и обозначение единицы измерения длины. Одну из констант объявить через другую константным выражением. Вывести все значения и вычислить путь свободного падения за заданное число секунд.

## Ожидаемый результат
Все константы выведены по имени класса; вычисленный путь верен; константа, объявленная через другую, имеет ожидаемое значение.
