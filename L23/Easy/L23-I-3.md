# L23 · Задание I · №3. Поле только для чтения

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Объявить класс «читатель библиотеки» с полем только для чтения — номером билета, задаваемым в конструкторе, — полем только для чтения с названием библиотеки, присвоенным в объявлении, и обычным изменяемым свойством с именем читателя. Создать два объекта, вывести карточки, затем изменить имя одного из них и вывести карточку снова.

## Ожидаемый результат
Номера билетов различны, название библиотеки одинаково; имя изменилось, а номер билета остался прежним.
