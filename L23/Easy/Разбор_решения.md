# Разбор решения. L23 · Задание I · №1. Первые константы

## Условие
Объявить класс «физические величины» с константами: ускорение свободного падения, число дней в неделе и обозначение единицы измерения длины. Одну из констант объявить через другую константным выражением. Вывести все значения и вычислить путь свободного падения за заданное число секунд.

## Ожидаемый результат
Все константы выведены по имени класса; вычисленный путь верен; константа, объявленная через другую, имеет ожидаемое значение.

## Идея решения
Константа `const` вычисляется при компиляции и подставляется в код; её значение может определяться другой константой, если выражение константное. Путь свободного падения: h = g·t²/2.

## Решение
```csharp
using System;

class Physics
{
    public const double G = 9.81;
    public const int DaysInWeek = 7;
    public const string LengthUnit = "м";
    public const double HalfG = G / 2;     // константа через другую константу
}

class Program
{
    static void Main()
    {
        Console.WriteLine(Physics.G);
        Console.WriteLine(Physics.DaysInWeek);
        Console.WriteLine(Physics.LengthUnit);
        Console.WriteLine(Physics.HalfG);

        double t = 3;
        double h = Physics.HalfG * t * t;
        Console.WriteLine("Путь за " + t + " с: " + h + " " + Physics.LengthUnit);
    }
}
```

## Пошаговое объяснение
1. Константы объявлены в классе и доступны по имени класса (неявно статические).
2. `HalfG = G / 2` — допустимо, потому что правая часть — константное выражение.
3. Формула h = (g/2)·t²: 4,905 · 9 = 44,145 м.
4. Присвоить константе другое значение после объявления нельзя.

## Результат
9,81 / 7 / м / 4,905 / Путь за 3 с: 44,145 м
