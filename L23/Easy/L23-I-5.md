# L23 · Задание I · №5. Первый частичный класс

**Тема:** Л23 — Поля-константы. Поля только для чтения. Частичные классы

## Условие
Разделить объявление класса «прямоугольник» на два файла: в первом — закрытые поля и конструктор, во втором — методы вычисления площади и периметра и переопределение `ToString`. Создать объект и вывести все три результата. Убедиться, что методы второго файла читают закрытые поля первого.

## Ожидаемый результат
Программа компилируется и работает; методы из второго файла обращаются к закрытым полям первого без каких-либо дополнительных объявлений; полное имя типа выведено одно.
