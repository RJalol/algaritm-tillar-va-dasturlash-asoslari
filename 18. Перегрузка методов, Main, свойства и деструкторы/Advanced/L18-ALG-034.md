# L18-ALG-034. Шаблон Dispose

**Тема:** Л18 — Перегрузка методов и конструкторов. Класс Program и метод Main. Свойства. Деструкторы

## Условие
Реализовать полный шаблон `Dispose(bool disposing)` с вызовом `GC.SuppressFinalize(this)` и убедиться, что при явном `Dispose` деструктор уже не выполняется.

## Ожидаемый результат
Сообщение деструктора не выводится, если `Dispose` был вызван.
