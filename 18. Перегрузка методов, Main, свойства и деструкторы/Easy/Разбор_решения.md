# Разбор решения. L18-ALG-001. Первая перегрузка

## Условие
Объявить класс с тремя перегрузками метода `Show`: для целого числа, для вещественного и для строки. Каждая выводит значение с указанием типа. Вызвать все три и убедиться, что выбран нужный вариант.

## Ожидаемый результат
Три строки вывода с разными пометками типов; все три метода имеют одинаковое имя и различаются типом единственного параметра.

## Разбор условия
**Дано:** потребность выводить значения разных типов.
**Требуется:** класс с тремя перегрузками метода `Show` (для `int`, `double`, `string`) и вызовы всех трёх.

## Теоретическая справка
**Перегрузка** — несколько методов с одним именем и **разными списками параметров** (число или типы). Компилятор выбирает метод по аргументам во время компиляции (**статическое связывание**).

Правила:

- возвращаемый тип в сигнатуру не входит: методы, различающиеся лишь им, — ошибка `CS0111`;
- имена параметров в сигнатуру не входят;
- при неоднозначности (`CS0121`) нужно привести аргумент к нужному типу.

Порядок выбора перегрузки: точное соответствие типов лучше неявного преобразования (`int` → `double`).

## Идея решения
Перегрузка — несколько методов с одним именем и разными списками параметров; компилятор выбирает подходящий по типу аргумента.

## Решение
```csharp
using System;

class Printer
{
    public void Show(int x)    { Console.WriteLine("int: " + x); }
    public void Show(double x) { Console.WriteLine("double: " + x); }
    public void Show(string x) { Console.WriteLine("string: " + x); }
}

class Program
{
    static void Main()
    {
        Printer p = new Printer();
        p.Show(5);
        p.Show(2.5);
        p.Show("текст");
    }
}
```

## Пошаговое объяснение
1. Имя метода одно, а типы параметров различаются — это допустимая перегрузка.
2. Для `5` выбирается `Show(int)`, для `2.5` — `Show(double)`, для строки — `Show(string)`.
3. Различие *только* в возвращаемом типе перегрузкой не является.

## Трассировка и проверка
| Вызов | Выбранная перегрузка | Вывод |
|---|---|---|
| `p.Show(5)` | `Show(int)` | int: 5 |
| `p.Show(2.5)` | `Show(double)` | double: 2,5 |
| `p.Show("текст")` | `Show(string)` | string: текст |

Если удалить `Show(int)`, вызов `Show(5)` выберет `Show(double)` (неявное преобразование) — результат изменится.

## Результат
int: 5 / double: 2,5 / string: текст

## Типичные ошибки
- Пытаться перегрузить метод, изменив только возвращаемый тип.
- Ожидать, что перегрузка выбирается во время выполнения.
- Создавать перегрузки с неоднозначными вызовами.
- Дублировать код в перегрузках вместо делегирования одной перегрузке другой.
