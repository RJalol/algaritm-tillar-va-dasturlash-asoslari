# Разбор решения. L13-ALG-001. Первый метод

## Условие
Написать метод `Square`, принимающий целое число и возвращающий его квадрат. Вызвать его из `Main` для значений 7, 0 и −3, а также в записи `Square(Square(3))`. Вывести все четыре результата.

## Ожидаемый результат
Выведено `49`, `0`, `9` и `81`; последний результат получен вложенным вызовом без промежуточной переменной.

## Разбор условия
**Дано:** числа 7, 0, −3 и выражение `Square(Square(3))`.
**Требуется:** написать метод `Square` и вывести четыре результата.

## Теоретическая справка
**Метод** — именованный блок кода, который можно вызывать многократно.

Объявление: `static int Square(int x) { return x * x; }`

- `static` — метод принадлежит классу (пока объекты не изучены, все методы статические);
- `int` — тип возвращаемого значения; оператор `return` возвращает результат и завершает метод;
- `x` — параметр, локальная переменная метода, получающая значение аргумента.

Вызов можно использовать как значение в выражении, в том числе вложенный: `Square(Square(3))` — сначала вычисляется внутренний вызов.

## Идея решения
Метод — именованный блок кода; принимает параметры, возвращает значение оператором `return`. Вызовы можно вкладывать друг в друга.

## Решение
```csharp
using System;

class Program
{
    static int Square(int x)
    {
        return x * x;
    }

    static void Main()
    {
        Console.WriteLine(Square(7));
        Console.WriteLine(Square(0));
        Console.WriteLine(Square(-3));
        Console.WriteLine(Square(Square(3)));
    }
}
```

## Пошаговое объяснение
1. `Square` принимает `int` и возвращает `int`.
2. `Square(7) = 49`, `Square(0) = 0`, `Square(-3) = 9` (квадрат отрицательного числа неотрицателен).
3. `Square(Square(3))`: внутренний вызов даёт 9, внешний — 81; промежуточная переменная не нужна.

## Трассировка и проверка
| Вызов | Вычисление | Результат |
|---|---|--:|
| `Square(7)` | 7·7 | 49 |
| `Square(0)` | 0·0 | 0 |
| `Square(-3)` | (−3)·(−3) | 9 |
| `Square(Square(3))` | Square(9) | 81 |

Параметры передаются **по значению**: изменение `x` внутри метода не затрагивает аргумент.

## Результат
49, 0, 9, 81

## Типичные ошибки
- Не вернуть значение из метода (`CS0161` при отсутствии `return` на каком-либо пути).
- Забыть `static` у метода, вызываемого из статического `Main` (`CS0120`).
- Вызвать метод, не использовав результат — значение пропадёт.
- Путать параметры (при объявлении) и аргументы (при вызове).
