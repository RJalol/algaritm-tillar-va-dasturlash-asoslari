# L13-ALG-003. Метод типа void

**Тема:** Л13 — Собственные методы. Основы тестирования программ

## Условие
Написать метод `PrintLine`, принимающий символ и число повторений и выводящий строку из указанного числа этих символов. Вызвать его трижды с разными аргументами. Объяснить в комментарии, почему тип возвращаемого значения — `void`.

## Ожидаемый результат
Три строки-разделителя разной длины и из разных символов; в комментарии указано, что метод выполняет действие и значения не возвращает.
