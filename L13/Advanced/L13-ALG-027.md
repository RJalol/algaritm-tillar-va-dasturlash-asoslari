# L13-ALG-027. Метод обработки строки и его граничные случаи

**Тема:** Л13 — Собственные методы. Основы тестирования программ

## Условие
Написать метод `CountVowels`, возвращающий число гласных букв в строке; регистр не учитывать, список гласных задать строкой. Составить не менее шести тест-кейсов, из которых не менее трёх — граничные, и оформить каждый вызовом `Debug.Assert` с поясняющим сообщением. Обязательно включить случаи пустой строки и строки без единой гласной.

## Ожидаемый результат
Для строки `"Программирование"` метод даёт `7`, для пустой строки и строки `"бвгд"` — `0`, для строки `"Hello"` — `2`; все проверки истинны, и программа доходит до конца.
