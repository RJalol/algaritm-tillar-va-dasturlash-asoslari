# L13-ALG-026. Проверка предположения и проверка ввода

**Тема:** Л13 — Собственные методы. Основы тестирования программ

## Условие
Написать метод, вычисляющий среднее арифметическое элементов массива. Защитить его **двумя** разными способами: вызовом `Debug.Assert` для проверки того, что массив не пуст, и оператором `if`, выводящим сообщение при пустом массиве. Запустить программу с пустым массивом в конфигурациях Debug и Release. Объяснить письменно, какая из двух защит сработала в каждой конфигурации и какая из них пригодна для проверки данных, введённых пользователем.

## Ожидаемый результат
В конфигурации Debug сработали обе защиты, в конфигурации Release — только оператор `if`; сделан вывод, что `Debug.Assert` проверяет предположения разработчика, а данные пользователя следует проверять оператором `if`.
