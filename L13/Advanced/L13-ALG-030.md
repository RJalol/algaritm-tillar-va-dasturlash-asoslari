# L13-ALG-030. Полный аудит программы с методами

**Тема:** Л13 — Собственные методы. Основы тестирования программ

## Условие
Дан код:

```
using System;

namespace MethodAudit
{
    class Program
    {
        static int Divide(int a, int b)
        {
            if (b != 0) return a / b;
        }

        static void Swap(int a, int b)
        {
            int t = a;
            a = b;
            b = t;
        }

        static int Max(int[] numbers)
        {
            int max = 0;
            foreach (int v in numbers) if (v > max) max = v;
            return max;
        }

        static void Main(string[] args)
        {
            int x = 3, y = 8;
            Swap(x, y);
            Console.WriteLine(x + " " + y);

            Divide(10, 2);

            int[] data = { -5, -12, -3 };
            Console.WriteLine(Max(data));
        }
    }
}
```

Провести полный аудит и разнести замечания по четырём категориям: нарушение контракта возврата; метод, не выполняющий заявленного действия из-за передачи по значению; отброшенный результат вызова; логическая ошибка, проявляющаяся только на определённых данных. Для каждого указать код ошибки либо объяснить, почему компилятор молчит, и назвать тест-кейс, выявляющий ошибку. Привести исправленную версию, отметив, какое из исправлений требует средств темы №14 и потому здесь может быть только описано словами.

## Ожидаемый результат
Категории разнесены верно: метод `Divide` не компилируется — `CS0161`; метод `Swap` компилируется, но значений не меняет, и вывод остаётся `3 8`, поскольку параметры получены по значению — исправление требует модификатора `ref` из темы №14; вызов `Divide(10, 2);` отбрасывает результат; метод `Max` с начальным значением `0` даёт `0` вместо `-3` на массиве из одних отрицательных чисел, и именно этот тест-кейс выявляет ошибку.
