# L13-ALG-025. Разбиение программы на методы

**Тема:** Л13 — Собственные методы. Основы тестирования программ

## Условие
Дана программа, целиком записанная в методе `Main`: она вводит массив чисел, находит наибольший и наименьший элементы, вычисляет среднее арифметическое, подсчитывает число положительных элементов и выводит отчёт. Переписать её, выделив **не менее четырёх** методов, каждый из которых получает массив параметром и возвращает результат. Метод `Main` после переработки должен состоять только из ввода, вызовов и вывода.

## Ожидаемый результат
Программа даёт тот же вывод, что и исходная; в `Main` не осталось ни одного цикла обработки, а каждый выделенный метод имеет имя, обозначающее вычисляемую величину.
