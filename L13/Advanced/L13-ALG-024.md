# L13-ALG-024. Проверка Debug.Assert в двух конфигурациях

**Тема:** Л13 — Собственные методы. Основы тестирования программ

## Условие
Написать метод `Square` с **намеренной** ошибкой — возвращающий `x + x` вместо `x * x`, — и проверку `Debug.Assert(Square(4) == 16, "...")`, между двумя выводами на консоль. Запустить программу в конфигурации Debug и в конфигурации Release (`dotnet run -c Release`). Сравнить оба вывода и объяснить различие.

## Ожидаемый результат
В конфигурации Debug выведена только первая строка, после чего программа прервана сообщением `Process terminated. Assertion failed.` с указанным текстом; в конфигурации Release выведены обе строки, так как вызовы `Assert` удалены компилятором из-за атрибута `Conditional("DEBUG")`.
