# Разбор решения. L13-ALG-021. Шесть нарушений в объявлениях и вызовах

## Условие
Дан код:

```
static int Sign(int x)
{
    if (x > 0) return 1;
    if (x < 0) return -1;
}

static void Show(int x)
{
    return x;
}

static int Add(int a, int b) { return a + b; }

int NotStatic() { return 2; }

static void Main(string[] args)
{
    Console.WriteLine(Add(1));
    Console.WriteLine(Add("1", "2"));
    Console.WriteLine(local);
    Console.WriteLine(NotStatic());
    Add(1, 2);
}
```

Найти все нарушения. Для шести из них назвать код ошибки компилятора и разнести их по трём группам: нарушение контракта возврата; несоответствие аргументов параметрам; нарушение видимости. Отдельно указать оператор, который **компилируется без предупреждений**, и объяснить, почему он тем не менее является ошибкой. Привести исправленный фрагмент.

## Ожидаемый результат
Названы коды `CS0161`, `CS0127`, `CS7036`, `CS1503`, `CS0103` и `CS0120`; группы разнесены верно; отдельно указан оператор `Add(1, 2);`, вычисляющий сумму и отбрасывающий её.

## Идея решения
Проверяем контракт возврата, соответствие аргументов параметрам и видимость статических/нестатических членов.

## Решение
```csharp
// Исправленный фрагмент
static int Sign(int x)
{
    if (x > 0) return 1;
    if (x < 0) return -1;
    return 0;                          // все пути возвращают значение
}
static void Show(int x)
{
    Console.WriteLine(x);              // void-метод ничего не возвращает
}
static int Add(int a, int b) { return a + b; }
static int NotStatic() { return 2; }   // статический, чтобы вызвать из Main
static void Main(string[] args)
{
    int local = 0;
    Console.WriteLine(Add(1, 2));
    Console.WriteLine(Add(1, 2));
    Console.WriteLine(local);
    Console.WriteLine(NotStatic());
    Console.WriteLine(Add(1, 2));      // результат использован
}
```

## Пошаговое объяснение
1. Контракт возврата: в `Sign` не все пути возвращают значение (`CS0161`); `Show` объявлен `void`, но возвращает `x` (`CS0127`).
2. Аргументы и параметры: `Add(1)` — не хватает аргумента (`CS7036`); `Add("1", "2")` — строки вместо чисел (`CS1503`).
3. Видимость: `local` нигде не объявлена (`CS0103`); `NotStatic()` — нестатический метод вызывается из статического `Main` без объекта (`CS0120`).
4. Оператор `Add(1, 2);` компилируется без предупреждений, но сумма вычисляется и отбрасывается — вызов бесполезен; результат надо вывести или сохранить.

## Результат
Коды: CS0161, CS0127, CS7036, CS1503, CS0103, CS0120; отдельно отмечен оператор Add(1, 2);
