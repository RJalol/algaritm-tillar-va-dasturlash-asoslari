# L13-ALG-029. Предсказание вывода: видимость и копии

**Тема:** Л13 — Собственные методы. Основы тестирования программ

## Условие
Дан код:

```
static int Next(int start)
{
    start = start + 1;
    return start;
}

static void Main(string[] args)
{
    int start = 10;
    Console.WriteLine(Next(start));
    Console.WriteLine(start);
    Console.WriteLine(Next(Next(start)));
    Console.WriteLine(start);
}
```

Не запуская программу, предсказать все четыре строки вывода. Затем запустить и объяснить каждую. Отдельно ответить: почему переменная с именем `start` существует в программе дважды и не приводит ли это к ошибке.

## Ожидаемый результат
Предсказано `11`, `10`, `12` и `10`; объяснено, что параметр метода и локальная переменная `Main` — разные переменные, каждая видна только в своём методе, и совпадение имён ошибкой не является.
