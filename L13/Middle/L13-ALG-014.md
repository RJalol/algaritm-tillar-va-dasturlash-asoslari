# L13-ALG-014. Предсказание вывода: передача по значению

**Тема:** Л13 — Собственные методы. Основы тестирования программ

## Условие
Дан код:

```
static void TryModify(int x)
{
    x = 100;
    Console.WriteLine("внутри метода x = " + x);
}

int value = 5;
TryModify(value);
Console.WriteLine("после вызова value = " + value);
```

Не запуская программу, предсказать обе строки вывода. Затем запустить и объяснить результат.

## Ожидаемый результат
Предсказано `внутри метода x = 100` и `после вызова value = 5`; объяснено, что в метод передана копия значения.
