# L13-ALG-016. Не все пути возвращают значение

**Тема:** Л13 — Методы, возвращающие и не возвращающие значения. Методы с параметрами и без параметров. Локальные переменные и методы

## Условие
Дан код:

```
static int Sign(int x)
{
    if (x > 0) return 1;
    if (x < 0) return -1;
}
```

Объяснить, почему метод не компилируется, назвать код ошибки и привести **два** исправления: добавлением завершающего `return` и заменой второго условия на `else`.

## Ожидаемый результат
Назван код `CS0161`; оба варианта компилируются и дают `1`, `-1` и `0` для положительного, отрицательного и нулевого аргумента.
