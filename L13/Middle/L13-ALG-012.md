# L13-ALG-012. Метод с вещественными параметрами

**Тема:** Л13 — Методы, возвращающие и не возвращающие значения. Методы с параметрами и без параметров. Локальные переменные и методы

## Условие
Написать метод `CircleArea`, принимающий радиус типа `double` и возвращающий площадь круга. Использовать константу `Math.PI`. Вывести площадь для радиусов 1, 2 и 0 с четырьмя знаками после разделителя.

## Ожидаемый результат
Для радиуса 1 выведено `3,1416`, для радиуса 2 — `12,5664`, для радиуса 0 — `0,0000`; форматирование выполнено описателем `F4` (тема №12).
