# Разбор решения. L13-ALG-006. Проверка простоты числа

## Условие
Написать метод `IsPrime`, возвращающий `true`, если число простое. Делители проверять до корня из числа, пользуясь условием `d * d <= n`, а не вызовом `Math.Sqrt`. Вывести все простые числа от 1 до 20, а затем отдельно результаты для 0, 1, 2, 97 и 100.

## Ожидаемый результат
Выведено `2 3 5 7 11 13 17 19`; отдельные результаты — `False`, `False`, `True`, `True`, `False`; случаи 0 и 1 отсечены отдельной проверкой в начале метода.

## Идея решения
Простое число — натуральное, большее 1, без делителей кроме 1 и себя. Перебираем делители d, пока d*d <= n.

## Решение
```csharp
using System;

class Program
{
    static bool IsPrime(int n)
    {
        if (n < 2) return false;           // 0 и 1 не простые
        for (int d = 2; d * d <= n; d++)
        {
            if (n % d == 0) return false;
        }
        return true;
    }

    static void Main()
    {
        for (int i = 1; i <= 20; i++)
            if (IsPrime(i)) Console.Write(i + " ");
        Console.WriteLine();

        foreach (int n in new[] { 0, 1, 2, 97, 100 })
            Console.WriteLine(n + ": " + IsPrime(n));
    }
}
```

## Пошаговое объяснение
1. Первая проверка отсекает числа меньше 2.
2. Условие `d * d <= n` заменяет вызов `Math.Sqrt` и работает только с целыми числами.
3. Найден делитель — сразу `return false`; цикл закончился без делителей — `return true`.
4. Для 100 найдётся делитель 2; для 97 делителей до 9 нет.

## Результат
2 3 5 7 11 13 17 19; затем False, False, True, True, False.
