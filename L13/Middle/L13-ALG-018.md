# L13-ALG-018. Несоответствие аргументов

**Тема:** Л13 — Собственные методы. Основы тестирования программ

## Условие
Для метода `static int Add(int a, int b)` даны три вызова:

```
Add(1);
Add(1, 2, 3);
Add("1", "2");
```

Определить код ошибки для каждого и объяснить различие между ними. Привести правильный вызов для каждого случая.

## Ожидаемый результат
Названы коды `CS7036` (недостаёт аргумента), `CS1501` (аргументов слишком много) и `CS1503` (несовместимый тип аргумента); для третьего случая правильный вызов предполагает преобразование строк в числа (тема №6).
