# L13-ALG-019. Область видимости локальной переменной

**Тема:** Л13 — Собственные методы. Основы тестирования программ

## Условие
Написать метод, объявляющий внутри себя локальную переменную, и попытаться обратиться к ней из метода `Main`. Назвать код ошибки. Затем переписать программу так, чтобы значение этой переменной стало доступно в `Main`, не объявляя её вне метода.

## Ожидаемый результат
Назван код `CS0103`; в исправленном варианте значение передано в `Main` через возвращаемое значение метода.
