# L13-ALG-015. Предсказание вывода: массив как аргумент

**Тема:** Л13 — Собственные методы. Основы тестирования программ

## Условие
Дан код:

```
static void TryModifyArray(int[] a)
{
    a[0] = 100;
}

int[] arr = { 1, 2, 3 };
TryModifyArray(arr);
Console.WriteLine(arr[0]);
```

Не запуская программу, предсказать вывод. Сравнить с результатом задания ALG-014 и объяснить, почему результаты различаются, хотя в обоих случаях аргумент передан одинаково.

## Ожидаемый результат
Выведено `100`; объяснено, что массив — ссылочный тип, поэтому в метод передана ссылка на тот же объект, и изменение его элемента видно вызывающему коду.
