# L13-ALG-017. Возврат значения из метода void

**Тема:** Л13 — Собственные методы. Основы тестирования программ

## Условие
Дан код:

```
static void Show(int x)
{
    return x;
}
```

Назвать код ошибки и привести **два** исправления: сохранив тип `void` и изменив тип возвращаемого значения. Объяснить, в каком случае уместен каждый вариант.

## Ожидаемый результат
Назван код `CS0127`; в первом варианте `return` заменён выводом, во втором тип метода изменён на `int`; объяснено, что `void` выбирают, когда метод выполняет действие, а не вычисляет значение.
