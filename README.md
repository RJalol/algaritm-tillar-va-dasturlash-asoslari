# Практические задания курса «Алгоритмические языки и программирование»

Репозиторий содержит практические задания к учебному пособию по дисциплине «Алгоритмические языки и программирование» (язык программирования — C#, целевая аудитория — студенты ОТМ Республики Узбекистан).

**Версия структуры: V3** (30 заданий на тему, компактный 2-польный формат).

## Статус подготовки

На данный момент подготовлены темы **Л1**–**Л20** из 51 запланированной, все — в структуре V3. Остальные темы (Л21–Л51) будут добавляться по мере готовности, каждая — в отдельной папке `L10/`, `L11/` и т.\,д., с той же внутренней структурой.

Последовательность тем определяется файлом `Course Structure (approved v1).md` (утверждён автором 28.08.2026).

## Правила нумерации

- Внутри каждой темы используется собственная нумерация `ALG-001`–`ALG-030` (30 заданий на тему: 5 Easy, 15 Middle, 10 Advanced).
- Для уникальности имени файла в общем репозитории используется префикс темы, например: `L01-ALG-001.md`, `L02-ALG-001.md` и т.\,д. — то есть один и тот же локальный номер `ALG-001` существует в каждой теме, но полные идентификаторы файлов не пересекаются.

## Формат задания (V3)

Каждое задание содержит только два поля: **Условие** и **Ожидаемый результат**. Все необходимые ограничения и уточнения включены непосредственно в условие — отдельных полей «Цель», «Требования», «Входные/Выходные данные», «Ограничения», «Пример», «Критерии корректности» больше нет.

## Академическая добросовестность

Готовые решения заданий в репозитории не публикуются. Каждое задание содержит чёткое условие и описание ожидаемого результата, достаточные для самостоятельного выполнения.
