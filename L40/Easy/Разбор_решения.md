# Разбор решения. L40 · Задание I · №1. Первый стек

## Условие
Создать `Stack<int>`, добавить числа 1, 2, 3 методом `Push`, вывести верхний элемент методом `Peek` и извлечь все элементы методом `Pop`.

## Ожидаемый результат
Верхний элемент 3; элементы извлекаются в порядке 3, 2, 1.

## Разбор условия
**Дано:** числа 1, 2, 3.
**Требуется:** `Stack<int>`: `Push` трёх чисел, `Peek`, затем `Pop` до опустошения.

## Теоретическая справка
**Стек** — структура данных по принципу **LIFO** («последним пришёл — первым вышел»). Операции:

| Операция | Смысл | Сложность |
|---|---|---|
| `Push(x)` | положить на вершину | O(1) |
| `Pop()` | снять вершину и вернуть | O(1) |
| `Peek()` | прочитать вершину | O(1) |
| `Count` | число элементов | O(1) |

Применение: вызовы методов (стек вызовов), отмена действий, разбор выражений, обход в глубину.

## Идея решения
Стек работает по принципу LIFO: последним пришёл — первым вышел. `Push` кладёт элемент на вершину, `Peek` читает вершину, `Pop` извлекает.

## Решение
```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        Stack<int> stack = new Stack<int>();
        stack.Push(1);
        stack.Push(2);
        stack.Push(3);

        Console.WriteLine("Вершина: " + stack.Peek());

        while (stack.Count > 0)
            Console.WriteLine(stack.Pop());
    }
}
```

## Пошаговое объяснение
1. Три вызова `Push` помещают числа 1, 2, 3; вершиной становится 3.
2. `Peek()` возвращает вершину, не удаляя её.
3. Цикл `while (stack.Count > 0)` извлекает элементы `Pop()` до опустошения стека.
4. Порядок извлечения обратен порядку добавления.

## Трассировка и проверка
| Операция | Стек (вершина слева) |
|---|---|
| `Push(1)` | 1 |
| `Push(2)` | 2, 1 |
| `Push(3)` | 3, 2, 1 |
| `Peek()` → 3 | 3, 2, 1 |
| `Pop()` → 3 | 2, 1 |
| `Pop()` → 2 | 1 |
| `Pop()` → 1 | пусто |

## Результат
Вершина: 3, затем 3, 2, 1

## Типичные ошибки
- `Pop()` на пустом стеке (`InvalidOperationException`).
- Путать `Peek` и `Pop`.
- Перебирать стек `foreach` и ожидать порядок добавления (перебор идёт от вершины).
- Изменять стек во время перебора.
