# Разбор решения. L40 · Задание I · №1. Первый стек

## Условие
Создать `Stack<int>`, добавить числа 1, 2, 3 методом `Push`, вывести верхний элемент методом `Peek` и извлечь все элементы методом `Pop`.

## Ожидаемый результат
Верхний элемент 3; элементы извлекаются в порядке 3, 2, 1.

## Идея решения
Стек работает по принципу LIFO: последним пришёл — первым вышел. `Push` кладёт элемент на вершину, `Peek` читает вершину, `Pop` извлекает.

## Решение
```csharp
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        Stack<int> stack = new Stack<int>();
        stack.Push(1);
        stack.Push(2);
        stack.Push(3);

        Console.WriteLine("Вершина: " + stack.Peek());

        while (stack.Count > 0)
            Console.WriteLine(stack.Pop());
    }
}
```

## Пошаговое объяснение
1. Три вызова `Push` помещают числа 1, 2, 3; вершиной становится 3.
2. `Peek()` возвращает вершину, не удаляя её.
3. Цикл `while (stack.Count > 0)` извлекает элементы `Pop()` до опустошения стека.
4. Порядок извлечения обратен порядку добавления.

## Результат
Вершина: 3, затем 3, 2, 1
