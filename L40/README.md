# L40. Структуры данных «стек» (Stack) и «очередь» (Queue) в языке программирования C#

Практические задания к теме №40 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
L40/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
└── Advanced/   10 заданий  (Задание III)
```

## Формат задания

Каждый файл `L40-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. В каждой из папок `Easy/`, `Middle/`, `Advanced/` приведён один образцовый разбор — файл `Разбор_решения.md`.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.
