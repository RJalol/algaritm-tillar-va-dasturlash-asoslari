# Разбор решения. L45 · Задание I · №1. Заливка прямоугольника

## Условие
Закрасить прямоугольник одним цветом методом `FillRectangle` с `SolidBrush`.

## Ожидаемый результат
Прямоугольник залит заданным цветом.

## Разбор условия
**Дано:** форма.
**Требуется:** закрасить прямоугольник методом `FillRectangle` и добавить рамку.

## Теоретическая справка
Рисование фигур делится на два семейства:

| Контур | Заливка |
|---|---|
| `DrawRectangle(Pen, …)` | `FillRectangle(Brush, …)` |
| `DrawEllipse(Pen, …)` | `FillEllipse(Brush, …)` |
| `DrawPolygon(Pen, points)` | `FillPolygon(Brush, points)` |

Виды кистей: `SolidBrush` (сплошной цвет), `HatchBrush` (штриховка), `LinearGradientBrush` (градиент), `TextureBrush` (рисунок), `PathGradientBrush`.

Порядок: сначала заливка, затем контур — иначе заливка закроет рамку.

## Идея решения
Контур рисуют методами `Draw...` с пером, заливку — методами `Fill...` с кистью (`Brush`). Для сплошного цвета используется `SolidBrush`.

## Решение
```csharp
using System;
using System.Drawing;
using System.Windows.Forms;

public class Form1 : Form
{
    public Form1()
    {
        Text = "Заливка";
        Size = new Size(320, 240);
        Paint += (s, e) =>
        {
            using var brush = new SolidBrush(Color.Orange);
            e.Graphics.FillRectangle(brush, 40, 40, 200, 100);
            using var pen = new Pen(Color.Black, 2);
            e.Graphics.DrawRectangle(pen, 40, 40, 200, 100);
        };
    }
}
```

## Пошаговое объяснение
1. `SolidBrush(Color.Orange)` — кисть сплошного цвета.
2. `FillRectangle(brush, x, y, width, height)` закрашивает прямоугольник; рамки у него нет.
3. Для рамки поверх заливки вызываем `DrawRectangle` с пером.
4. Кисть и перо — неуправляемые ресурсы, поэтому оборачиваем их в `using`.

## Трассировка и проверка
| Вызов | Результат |
|---|---|
| `FillRectangle(brush, 40, 40, 200, 100)` | оранжевый прямоугольник |
| `DrawRectangle(pen, 40, 40, 200, 100)` | чёрная рамка поверх |

Общие координаты и размеры должны совпадать, иначе рамка «сместится».

## Результат
Оранжевый прямоугольник 200×100 с чёрной рамкой.

## Типичные ошибки
- Нарисовать контур раньше заливки.
- Не освободить кисть.
- Перепутать ширину/высоту и вторую точку.
- Использовать стандартные кисти `Brushes.*` и вызывать у них `Dispose` (нельзя).
