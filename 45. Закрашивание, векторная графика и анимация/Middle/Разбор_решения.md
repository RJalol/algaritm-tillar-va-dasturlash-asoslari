# Разбор решения. L45 · Задание II · №7. Анимация движения

## Условие
Анимировать шар, движущийся по форме и отскакивающий от стенок, с помощью `Timer`.

## Ожидаемый результат
Шар отражается от границ.

## Разбор условия
**Дано:** шар и стенки окна.
**Требуется:** анимация шара, отскакивающего от границ, на основе `Timer`.

## Теоретическая справка
**Анимация** — повторяющийся цикл «изменить состояние → перерисовать».

Модель шара: положение (x, y), скорость (vx, vy). На каждом тике: `x += vx; y += vy;`. При касании стенки знак соответствующей скорости меняется: `vx = -vx`. Метод `Math.Clamp` возвращает шар внутрь области, если за шаг он «проскочил» границу.

`Timer` (Windows Forms) вызывается в потоке интерфейса; интервал 16 мс даёт ~60 кадров/с. `Invalidate()` ставит запрос на перерисовку, `DoubleBuffered = true` убирает мерцание.

## Идея решения
Мяч — это положение (x, y) и скорость (vx, vy). По таймеру положение изменяется на скорость; при касании стенки знак соответствующей составляющей скорости меняется на противоположный.

## Решение
```csharp
using System;
using System.Drawing;
using System.Windows.Forms;

public class Form1 : Form
{
    private float _x = 50, _y = 50, _vx = 4, _vy = 3;
    private const int R = 15;
    private readonly Timer _timer = new Timer { Interval = 16 };   // ≈ 60 кадров/с

    public Form1()
    {
        Text = "Отскок";
        ClientSize = new Size(500, 350);
        DoubleBuffered = true;

        _timer.Tick += (s, e) =>
        {
            _x += _vx; _y += _vy;
            if (_x - R < 0 || _x + R > ClientSize.Width)  { _vx = -_vx; _x = Math.Clamp(_x, R, ClientSize.Width - R); }
            if (_y - R < 0 || _y + R > ClientSize.Height) { _vy = -_vy; _y = Math.Clamp(_y, R, ClientSize.Height - R); }
            Invalidate();
        };
        _timer.Start();
    }

    protected override void OnPaint(PaintEventArgs e)
    {
        base.OnPaint(e);
        e.Graphics.FillEllipse(Brushes.SteelBlue, _x - R, _y - R, 2 * R, 2 * R);
    }
}
```

## Пошаговое объяснение
1. Состояние анимации хранится в полях: координаты центра и скорость по осям.
2. Таймер с интервалом около 16 мс даёт примерно 60 кадров в секунду; на каждом тике положение сдвигается и вызывается `Invalidate`, т. е. перерисовка.
3. Отражение от стенки — смена знака скорости; `Math.Clamp` возвращает шар внутрь области, если за один шаг он «проскочил» границу.
4. `DoubleBuffered = true` убирает мерцание при частой перерисовке.
5. `Brushes.SteelBlue` — стандартная кисть, освобождать её не нужно.

## Трассировка и проверка
Для поля 500×350, шара радиуса 15 и скорости (4; 3):

| Тик | x | y | событие |
|--:|--:|--:|---|
| 0 | 50 | 50 | старт |
| 1 | 54 | 53 | — |
| … | … | … | … |
| k | 485 | … | касание правой стенки: vx = −4 |

Далее x уменьшается, пока шар не коснётся левой стенки.

## Результат
Шар движется по форме и отскакивает от всех четырёх стенок.

## Типичные ошибки
- Рисовать в обработчике `Tick` через `CreateGraphics` вместо `Invalidate`.
- Не учитывать радиус шара при проверке границ.
- Не задать `DoubleBuffered` — мерцание.
- Блокировать поток интерфейса длительными вычислениями.
