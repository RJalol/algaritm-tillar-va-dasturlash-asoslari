# Разбор решения. L45 · Задание III · №3. Солнечная система

## Условие
Анимировать модель из Солнца и трёх планет с разными орбитами и периодами.

## Ожидаемый результат
Планеты движутся по орбитам.

## Разбор условия
**Дано:** модель Солнечной системы.
**Требуется:** Солнце и три планеты с разными орбитами и периодами; анимация движения.

## Теоретическая справка
**Орбитальное движение.** Планета движется по окружности радиуса R с угловой скоростью ω = 2π / T (T — период). Угол изменяется на ω·Δt за кадр, положение:

```
x = cx + R · cos θ
y = cy + R · sin θ
```

**Объектная модель:** класс `Planet` хранит параметры (орбита, размер, период, цвет, текущий угол); список планет обходится одним циклом и при обновлении, и при рисовании — это пример полиморфной обработки однотипных объектов.

Полупрозрачное перо (`Color.FromArgb(70, …)`) делает орбиты ненавязчивыми.

## Идея решения
Планета движется по окружности радиуса R вокруг Солнца с угловой скоростью ω = 2π/T. Угол каждой планеты увеличивается на ω·Δt на каждом кадре.

## Решение
```csharp
using System;
using System.Collections.Generic;
using System.Drawing;
using System.Drawing.Drawing2D;
using System.Windows.Forms;

public class Planet
{
    public float Orbit, Size, Angle, Period;       // Period - условных секунд на оборот
    public Color Color;
}

public class Form1 : Form
{
    private readonly List<Planet> _planets = new List<Planet>
    {
        new Planet { Orbit = 70,  Size = 8,  Period = 4,  Color = Color.Gray },
        new Planet { Orbit = 120, Size = 12, Period = 10, Color = Color.DeepSkyBlue },
        new Planet { Orbit = 180, Size = 10, Period = 19, Color = Color.OrangeRed }
    };
    private readonly Timer _timer = new Timer { Interval = 16 };

    public Form1()
    {
        Text = "Солнечная система";
        ClientSize = new Size(500, 500);
        BackColor = Color.Black;
        DoubleBuffered = true;

        _timer.Tick += (s, e) =>
        {
            foreach (var p in _planets)
                p.Angle += (float)(2 * Math.PI / p.Period * 0.016);    // ω·Δt, Δt = 16 мс
            Invalidate();
        };
        _timer.Start();
    }

    protected override void OnPaint(PaintEventArgs e)
    {
        base.OnPaint(e);
        var g = e.Graphics;
        g.SmoothingMode = SmoothingMode.AntiAlias;
        float cx = ClientSize.Width / 2f, cy = ClientSize.Height / 2f;

        g.FillEllipse(Brushes.Gold, cx - 20, cy - 20, 40, 40);                 // Солнце

        using var orbitPen = new Pen(Color.FromArgb(70, Color.White));
        foreach (var p in _planets)
        {
            g.DrawEllipse(orbitPen, cx - p.Orbit, cy - p.Orbit, 2 * p.Orbit, 2 * p.Orbit);
            float x = cx + (float)Math.Cos(p.Angle) * p.Orbit;
            float y = cy + (float)Math.Sin(p.Angle) * p.Orbit;
            using var brush = new SolidBrush(p.Color);
            g.FillEllipse(brush, x - p.Size, y - p.Size, 2 * p.Size, 2 * p.Size);
        }
    }
}
```

## Пошаговое объяснение
1. Каждая планета описывается орбитой, размером, периодом и текущим углом.
2. На каждом тике таймера угол увеличивается на ω·Δt, где ω = 2π/период, Δt = 0,016 с; чем меньше период, тем быстрее движение.
3. Положение вычисляется через тригонометрию: x = cx + R·cos θ, y = cy + R·sin θ.
4. Орбиты рисуются полупрозрачным пером (`Color.FromArgb(70, ...)`), Солнце — золотым кругом в центре.
5. Одна общая логика обновляет все планеты в цикле, поэтому добавление новой планеты — одна строка в списке.

## Трассировка и проверка
При Δt = 0,016 с:

| Планета | T, с | ω, рад/с | Приращение угла за кадр |
|---|--:|--:|--:|
| 1 | 4 | 1,571 | 0,0251 |
| 2 | 10 | 0,628 | 0,0101 |
| 3 | 19 | 0,331 | 0,0053 |

Чем меньше период, тем быстрее планета.

## Результат
Три планеты вращаются по своим орбитам вокруг Солнца с разной скоростью.

## Типичные ошибки
- Использовать градусы в `Math.Cos`/`Math.Sin` (нужны радианы).
- Складывать приращение углов без нормировки (при длительной работе угол растёт неограниченно — для `float` это терять точность).
- Хранить положение планеты, а не угол (накопление ошибок).
- Создавать новые перья и кисти в каждом кадре без освобождения.
