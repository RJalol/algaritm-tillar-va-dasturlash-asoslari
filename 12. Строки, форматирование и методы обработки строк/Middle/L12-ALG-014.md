# L12-ALG-014. Накопление текста в StringBuilder

**Тема:** Л12 — Объявление строк и работа с ними. Форматирование строк. Стандартные методы обработки строковых данных

## Условие
Написать программу, которая с помощью `StringBuilder` строит текст из трёх частей: слова, символа-пробела и числа, затем переводит строку методом `AppendLine` и добавляет форматированную запись методом `AppendFormat` с указанием ширины полей. Вывести результат и значение `Length`.

## Ожидаемый результат
Выведен двухстрочный текст и его длина; объект `StringBuilder` создан один раз, нового объекта ни один из вызовов не порождает.
