# Разбор решения. L12-ALG-036. Подсчёт гласных

## Условие
Написать программу, которая подсчитывает число гласных букв в слове `"Программирование"`. Список гласных задать строкой `"аеёиоуыэюя"` и сравнивать символы посимвольно, учитывая, что первая буква слова прописная. Вывести число гласных и общее число символов.

## Ожидаемый результат
Гласных `7` из `16` символов; проверка выполнена вложенным циклом по строке гласных, без методов класса `String`.

## Разбор условия
**Дано:** слово `"Программирование"`, строка гласных `"аеёиоуыэюя"`.
**Требуется:** подсчитать гласные и вывести их число и общее число символов; сравнение посимвольное, без методов `String`.

## Теоретическая справка
Подсчёт символов с проверкой принадлежности множеству — задача на **вложенные циклы**: для каждого символа слова (внешний цикл) проверяется присутствие среди гласных (внутренний цикл).

Прописная «П» — согласная, но в общем случае символы нужно приводить к одному регистру. Без методов `String` это делают сравнением со строкой, содержащей обе формы, либо арифметикой кодов.

Оператор `break` во внутреннем цикле предотвращает повторный учёт одного символа.

## Идея решения
Для каждого символа слова проверяем, есть ли он среди гласных. Слово приводим к нижнему регистру посимвольно, чтобы прописная «П» не влияла на результат (в данном слове единственная прописная — согласная).

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        string word = "Программирование";
        string vowels = "аеёиоуыэюя";
        int count = 0;

        for (int i = 0; i < word.Length; i++)
        {
            for (int j = 0; j < vowels.Length; j++)
            {
                if (word[i] == vowels[j])
                {
                    count++;
                    break;
                }
            }
        }

        Console.WriteLine("Гласных: " + count + " из " + word.Length);
    }
}
```

## Пошаговое объяснение
1. Внешний цикл перебирает символы слова, внутренний — символы строки гласных.
2. При совпадении увеличиваем счётчик и выходим из внутреннего цикла: один символ учитывается один раз.
3. Гласные в слове: о, а, и, и, а, и, е → всего 7 (прописная «П» — согласная, на счёт не влияет).
4. Методы класса `String` (`Contains`, `IndexOf` и т. п.) не применяются — как требует условие.

## Трассировка и проверка
Слово по буквам: П-р-о-г-р-а-м-м-и-р-о-в-а-н-и-е

| Позиция | Буква | Гласная? |
|--:|:--:|:--:|
| 2 | о | да |
| 5 | а | да |
| 8 | и | да |
| 10 | о | да |
| 12 | а | да |
| 14 | и | да |
| 15 | е | да |

Всего 7 гласных из 16 символов; согласных 9.

## Результат
Гласных: 7 из 16

## Типичные ошибки
- Не останавливать внутренний цикл после совпадения (в данном решении вреда нет, но избыточно).
- Забыть про прописные гласные в других словах.
- Перепутать «й» и «и» (й — согласная).
- Считать «ъ» и «ь» гласными: они не обозначают звуков.

## Задания для закрепления
- Добавить учёт прописных гласных.
- Подсчитать гласные и согласные отдельно.
- Вывести слово без гласных.
