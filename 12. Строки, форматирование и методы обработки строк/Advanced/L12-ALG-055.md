# L12-ALG-055. Форматированный отчёт

**Тема:** Л12 — Объявление строк и работа с ними. Форматирование строк. Стандартные методы обработки строковых данных

## Условие
Даны два массива: фамилии `"Азиз"`, `"Дилноза"`, `"Рустам"` и баллы `87.5`, `92.4`, `78.0`. Написать программу, которая выводит заголовок и три строки отчёта: имя — по левому краю в поле шириной 12, балл — по правому краю в поле шириной 8 с двумя знаками после разделителя, доля от ста баллов — по правому краю в поле шириной 10 в процентах с одним знаком. Использовать интерполяцию.

## Ожидаемый результат
Заголовок и три выровненные строки; первая строка данных — `Азиз` в левом поле, `87,50` и `87,5 %`; столбцы выровнены только описателями ширины, без пробелов в тексте.
