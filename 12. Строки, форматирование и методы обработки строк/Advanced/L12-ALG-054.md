# L12-ALG-054. Частота символов

**Тема:** Л12 — Объявление строк и работа с ними. Форматирование строк. Стандартные методы обработки строковых данных

## Условие
Написать программу, которая подсчитывает, сколько раз каждая строчная латинская буква встречается в строке `"abracadabra"`, используя массив из 26 счётчиков (тема №10). Вывести только те буквы, которые встретились хотя бы один раз, вместе с их количеством. Номер счётчика получать вычитанием кода буквы `'a'`.

## Ожидаемый результат
Выведено `a=5`, `b=2`, `c=1`, `d=1`, `r=2`; сумма всех счётчиков равна длине строки `11`, что служит проверкой правильности.
