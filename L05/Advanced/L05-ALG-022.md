# L05-ALG-022. Предсказание значений составных условий

**Тема:** Л5 — Работа с функциями ввода и вывода в консоли. Сравнение и логические операции. Порядок выполнения операций. Математические функции

## Условие
Даны переменные `a = 3`, `b = 7`, `c = 3`. Не запуская программу, определить значения пяти выражений:

```
a < b && b > c
a == c || a > b
!(a == c) && (b > c)
a != c ^ b > c
a + b > c * 3
```

Для каждого выражения указать порядок выполнения операций. Затем проверить ответы запуском.

## Ожидаемый результат
Предсказанные значения `True`, `True`, `False`, `True`, `True` совпали с фактическим выводом; для каждого выражения показано, какие операции выполнены раньше и почему.
