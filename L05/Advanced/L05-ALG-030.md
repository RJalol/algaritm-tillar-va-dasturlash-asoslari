# L05-ALG-030. Полный аудит фрагмента с условиями

**Тема:** Л5 — Работа с функциями ввода и вывода в консоли. Сравнение и логические операции. Порядок выполнения операций. Математические функции

## Условие
Дан код:

```
using System;

namespace AuditDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Введите город: ");
            string city = Console.ReadLine();

            int count = 0;
            bool valid = 0 < count < 50;
            bool safe = (100 / count > 1) && (count != 0);

            double total = 0.1 + 0.2;
            bool exact = total == 0.3;

            Console.WriteLine(valid);
            Console.WriteLine(safe);
            Console.WriteLine(exact);
        }
    }
}
```

Провести полный аудит и разнести замечания по четырём категориям: ошибка компиляции; предупреждение компилятора; ошибка времени выполнения; логическая ошибка, не вызывающая ни того ни другого. Для каждой указать конкретную строку, назвать код (там, где он есть) и объяснить последствия. Привести исправленную версию, свободную от всех четырёх.

## Ожидаемый результат
Четыре категории разнесены верно: `CS0019` на двойном неравенстве; предупреждение `CS8600` на присваивании результата `ReadLine` переменной типа `string`; `DivideByZeroException` из-за неверного порядка операндов в условии `safe` (проверка на ноль должна стоять первой); логически неверное сравнение вещественных значений операцией `==`. Отмечено также, что приглашение выведено методом `WriteLine` вместо `Write`. Приведён исправленный код.
