# L05-ALG-023. Приоритет условного И над условным ИЛИ

**Тема:** Л5 — Работа с функциями ввода и вывода в консоли. Сравнение и логические операции. Порядок выполнения операций. Математические функции

## Условие
Написать программу, которая вычисляет и выводит значения выражений `true || false && false` и `(true || false) && false`, а затем `false && true || true` и `false && (true || true)`. Для каждой пары объяснить в комментарии, как выражение разбирается по умолчанию, и записать первое выражение пары со скобками так, чтобы смысл не изменился.

## Ожидаемый результат
Четыре строки: `True`, `False`, `True`, `False`; для каждой пары приведена явная скобочная запись, эквивалентная поведению по умолчанию.
