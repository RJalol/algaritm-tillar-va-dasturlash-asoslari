# L05-ALG-028. Определение типа результата без запуска

**Тема:** Л5 — Работа с функциями ввода и вывода в консоли. Сравнение и логические операции. Порядок выполнения операций. Математические функции

## Условие
Для каждого из выражений определить тип его результата, не запуская программу:

```
7 > 3            Math.Sqrt(16)      Math.Abs(-5)
Math.Max(2, 9)   Math.Max(2.0, 9)   true && false
```

Ответ по каждому выражению обосновать: результатом сравнения и логической операции является одно, а тип результата метода `Math` определяется другим. Проверить ответы с помощью `GetType()`.

## Ожидаемый результат
Шесть пар «выражение — тип»; объяснено, почему `Math.Max(2, 9)` и `Math.Max(2.0, 9)` дают результаты разных типов, а `Math.Sqrt` возвращает вещественное значение даже для точного корня.
