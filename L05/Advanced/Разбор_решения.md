# Разбор решения. L05-ALG-021. Три нарушения в одном фрагменте

## Условие
Дан код:

```
int age = 25;
bool adult = 18 <= age <= 65;
int flag = 1;
bool inactive = !flag;
bool ready = true;
int total = ready + 1;
```

Найти все нарушения, для каждого назвать код ошибки компилятора и объяснить причину отдельно. Указать, какие из нарушений вызваны переносом математической записи в код, а какие — смешением логического и числового типов. Привести исправленный фрагмент.

## Ожидаемый результат
Три независимых нарушения с кодами `CS0019`, `CS0023` и `CS0019`; исправленный фрагмент использует `&&` для диапазона и не смешивает `bool` с числовыми типами.

## Идея решения
Проверяем, какие типы допускают операции сравнения, отрицания и сложения.

## Решение
```csharp
// Исправленный фрагмент
int age = 25;
bool adult = age >= 18 && age <= 65;   // двойное неравенство раскрыто через &&
int flag = 1;
bool inactive = flag == 0;             // вместо !flag
bool ready = true;
int total = ready ? 1 : 0;             // вместо ready + 1
```

## Пошаговое объяснение
1. `18 <= age <= 65` — сначала вычисляется `18 <= age` и получается `bool`, затем `bool <= 65` — сравнение логического значения с числом недопустимо (`CS0019`). Ошибка вызвана переносом математической записи двойного неравенства.
2. `!flag` — оператор логического отрицания определён только для `bool`, а `flag` — `int` (`CS0023`). Ошибка смешения числового и логического типов (в C# нет «ноль — ложь»).
3. `ready + 1` — сложение `bool` и `int` не определено (`CS0019`). Это тоже смешение логического и числового типов.
4. Исправления: объединить два условия через `&&`, сравнить число с нулём явно, использовать условный оператор `?:`.

## Результат
Три нарушения (CS0019, CS0023, CS0019); исправленный код использует && и не смешивает bool с числовыми типами.
