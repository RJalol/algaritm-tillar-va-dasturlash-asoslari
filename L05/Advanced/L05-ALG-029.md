# L05-ALG-029. Расстановка скобок без изменения смысла

**Тема:** Л5 — Работа с функциями ввода и вывода в консоли. Сравнение и логические операции. Порядок выполнения операций. Математические функции

## Условие
Даны четыре выражения без скобок:

```
a + b * c > d
!x && y || z
a < b == c < d
p || q && r || s
```

Переписать каждое, расставив скобки в полном соответствии с приоритетом и ассоциативностью операций, так чтобы смысл не изменился. Для каждого выражения указать, какое правило определило расстановку. Проверить эквивалентность запуском на конкретных значениях переменных, заданных в тексте программы.

## Ожидаемый результат
Четыре пары «исходное — со скобками», дающие одинаковые значения при проверке; для каждой указано применённое правило приоритета либо левой ассоциативности.
