# Разбор решения. L05-ALG-001. Приветствие по введённым данным

## Условие
Написать программу, которая последовательно запрашивает у пользователя имя и название города, выводя перед каждым вводом понятное приглашение, и затем выводит приветствие, содержащее оба введённых значения. Приглашения оформить так, чтобы ввод оказывался на той же строке.

## Ожидаемый результат
Программа дважды ожидает ввода с клавиатуры, каждый раз показав приглашение без перевода строки, и выводит приветствие с обоими введёнными значениями.

## Разбор условия
**Дано:** ничего (данные вводятся).
**Требуется:** запросить имя и город, выводя приглашения так, чтобы ввод шёл на той же строке, затем вывести приветствие с обоими значениями.

## Теоретическая справка
Основные методы консоли:

| Метод | Действие |
|---|---|
| `Console.Write(s)` | выводит текст, курсор остаётся в той же строке |
| `Console.WriteLine(s)` | выводит текст и переводит строку |
| `Console.ReadLine()` | читает строку до Enter и возвращает её (`string`) |

Приглашение выводят через `Write`, а не `WriteLine` — иначе ввод окажется на следующей строке. Возвращаемое значение `ReadLine` нужно сохранить в переменную, иначе оно потеряется. Если ввод закрыт (Ctrl+Z / Ctrl+D), `ReadLine` возвращает `null`.

## Идея решения
Приглашение выводим через `Console.Write` (без перевода строки), чтобы ввод пользователя оказался на той же строке. Ввод читаем `Console.ReadLine`.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите имя: ");
        string name = Console.ReadLine();

        Console.Write("Введите город: ");
        string city = Console.ReadLine();

        Console.WriteLine("Здравствуйте, " + name + " из города " + city + "!");
    }
}
```

## Пошаговое объяснение
1. `Console.Write` печатает приглашение и оставляет курсор в той же строке.
2. `Console.ReadLine()` ожидает ввода строки до нажатия Enter и возвращает её.
3. Повторяем для города.
4. Склеиваем строки операцией `+` и выводим приветствие через `WriteLine`.

## Трассировка и проверка
Диалог (ввод пользователя выделен скобками):

```
Введите имя: [Азиз]
Введите город: [Самарканд]
Здравствуйте, Азиз из города Самарканд!
```

Соединение строк оператором `+` создаёт новую строку; число операций склейки не влияет на результат. Для длинных строк удобнее интерполяция: `$"Здравствуйте, {name} из города {city}!"`.

## Результат
Программа дважды запрашивает ввод; при вводе «Азиз» и «Самарканд» выводит: Здравствуйте, Азиз из города Самарканд!

## Типичные ошибки
- Использовать `WriteLine` для приглашения — ввод окажется на следующей строке.
- Не сохранить результат `ReadLine()` — программа ничего не запомнит.
- Забыть пробелы при склейке: «Азизиз города» вместо «Азиз из города».
- Не предусмотреть пустой ввод (получится приветствие без имени).

## Задания для закрепления
- Добавить запрос возраста и вывести его в приветствии.
- Вывести приветствие с использованием интерполяции строк.
- Запросить имя повторно, если введена пустая строка.
