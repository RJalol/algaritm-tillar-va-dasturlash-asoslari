# L05-ALG-011. Предсказание результата по приоритетам

**Тема:** Л5 — Работа с функциями ввода и вывода в консоли. Сравнение и логические операции. Порядок выполнения операций. Математические функции

## Условие
Даны переменные `a = 5`, `b = 10`, `c = 15`. Не запуская программу, определить значения выражений `a + b > c`, `a + b >= c` и `a < b == true`, объяснив для каждого порядок выполнения операций. Затем написать программу, выводящую эти значения, и сверить результат.

## Ожидаемый результат
Предсказанные значения `False`, `True`, `True` совпали с фактическим выводом; для каждого выражения указано, какая операция выполняется первой и почему.
