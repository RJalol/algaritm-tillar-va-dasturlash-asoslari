# L05-ALG-013. Отрицание целого числа

**Тема:** Л5 — Работа с функциями ввода и вывода в консоли. Сравнение и логические операции. Порядок выполнения операций. Математические функции

## Условие
Дан код:

```
int flag = 1;
bool result = !flag;
Console.WriteLine(result);
```

Объяснить, почему фрагмент не компилируется, назвать код ошибки и указать, какое свойство системы типов C# является причиной. Привести корректный вариант, сохраняющий смысл «признак не установлен».

## Ожидаемый результат
Назван код `CS0023`; объяснено, что логические операции применимы только к `bool` и число не преобразуется в логическое значение автоматически; предложен вариант с переменной типа `bool` либо со сравнением `flag == 0`.
