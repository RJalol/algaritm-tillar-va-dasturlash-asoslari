# Разбор решения. L05-ALG-006. Три строки в обратном порядке

## Условие
Написать программу, которая последовательно запрашивает у пользователя три слова, выводя перед каждым вводом отдельное приглашение, и затем выводит их в порядке, обратном введённому, каждое на своей строке.

## Ожидаемый результат
Три введённых значения выведены в обратном порядке; перед каждым вводом показано собственное приглашение.

## Разбор условия
**Дано:** три слова, вводимые пользователем.
**Требуется:** вывести их в обратном порядке, каждое на своей строке; перед каждым вводом — отдельное приглашение.

## Теоретическая справка
Данные нужно **запомнить**: слова вводятся в одном порядке, а выводятся в другом. Для этого нужны три переменные (или массив/стек). Первое введённое слово необходимо сохранить до конца программы, поскольку выводиться оно будет последним.

Это простейший пример идеи «последним пришёл — первым вышел» (LIFO), которая в полном виде реализована в структуре данных «стек» (тема №40).

## Идея решения
Считываем три слова в три переменные (отдельное приглашение перед каждым вводом) и выводим их в обратном порядке.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Первое слово: ");
        string first = Console.ReadLine();
        Console.Write("Второе слово: ");
        string second = Console.ReadLine();
        Console.Write("Третье слово: ");
        string third = Console.ReadLine();

        Console.WriteLine(third);
        Console.WriteLine(second);
        Console.WriteLine(first);
    }
}
```

## Пошаговое объяснение
1. Для каждого слова — своё приглашение `Write` и своя переменная.
2. Значения нужно сохранить, поскольку выводить их мы будем позже и в другом порядке.
3. Выводим переменные в порядке `third`, `second`, `first`, каждую на новой строке (`WriteLine`).

## Трассировка и проверка
| Ввод | Переменная |
|---|---|
| «один» | `first` |
| «два» | `second` |
| «три» | `third` |

Вывод в обратном порядке: `third`, `second`, `first` → «три», «два», «один». Если по ошибке вывести в порядке ввода, результат не изменится относительно ввода — признак неверного решения при проверке.

## Результат
При вводе «один», «два», «три» выводится: три, два, один (каждое на своей строке).

## Типичные ошибки
- Перезаписывать одну переменную: останется только последнее слово.
- Вывести слова в порядке ввода.
- Не выводить отдельное приглашение перед каждым словом.
- Склеить слова в одну строку, тогда как условие требует вывод по строкам.
