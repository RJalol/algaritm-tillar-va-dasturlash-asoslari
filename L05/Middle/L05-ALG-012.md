# L05-ALG-012. Двойное неравенство

**Тема:** Л5 — Работа с функциями ввода и вывода в консоли. Сравнение и логические операции. Порядок выполнения операций. Математические функции

## Условие
Дан код:

```
int score = 75;
bool inRange = 0 < score < 100;
Console.WriteLine(inRange);
```

Определить, скомпилируется ли фрагмент. Назвать код ошибки, объяснить по тексту сообщения, как компилятор разобрал выражение, и привести корректную запись.

## Ожидаемый результат
Назван код `CS0019`; по упоминанию операндов типов `bool` и `int` восстановлен порядок разбора; приведена запись через `&&`.
