# L05-ALG-010. Исключающее ИЛИ

**Тема:** Л5 — Работа с функциями ввода и вывода в консоли. Сравнение и логические операции. Порядок выполнения операций. Математические функции

## Условие
Написать программу, которая объявляет две логические переменные, описывающие сдачу двух экзаменов, и вычисляет условие «сдан ровно один из двух экзаменов», используя операцию `^`. Проверить работу для всех четырёх сочетаний значений, выводя результат каждый раз. В комментарии указать, какой другой операцией можно заменить `^` для операндов типа `bool`.

## Ожидаемый результат
Четыре строки: `False`, `True`, `True`, `False`; в комментарии указана операция `!=`.
