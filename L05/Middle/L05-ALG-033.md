# L05-ALG-033. Проверка бита

**Тема:** Л5 — Работа с функциями ввода и вывода в консоли. Операции сравнения и логические операции. Поразрядные операции. Приоритет операций. Математические функции

## Условие
Написать программу, определяющую, установлен ли бит с номером k (считая с нуля) в числе n, выражением `(n & (1 << k)) != 0`. Проверить для n = 37 и k = 0, 1, 2, 5.

## Ожидаемый результат
37 = `100101`: биты 0, 2, 5 установлены, бит 1 — нет.
