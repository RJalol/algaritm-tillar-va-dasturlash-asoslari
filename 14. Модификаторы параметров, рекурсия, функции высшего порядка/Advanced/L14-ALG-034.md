# L14-ALG-034. Фильтрация и свёртка

**Тема:** Л14 — Модификаторы параметров в методах. Определение рекурсивных методов. Функции высшего порядка

## Условие
Реализовать собственные функции высшего порядка `Filter(int[], Func<int,bool>)` и `Reduce(int[], int, Func<int,int,int>)`. Найти сумму квадратов чётных чисел массива {1, 2, 3, 4, 5, 6}.

## Ожидаемый результат
Результат 56 (4 + 16 + 36).
