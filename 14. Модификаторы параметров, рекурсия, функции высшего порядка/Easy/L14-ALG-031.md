# L14-ALG-031. Метод как параметр: Func

**Тема:** Л14 — Модификаторы параметров в методах. Определение рекурсивных методов. Функции высшего порядка

## Условие
Объявить метод `Apply`, принимающий число и функцию `Func<int,int>`, и вызвать её. Передать метод `Square` (возведение в квадрат) и лямбда-выражение `x => x + 1`.

## Ожидаемый результат
`Apply(5, Square)` даёт 25, `Apply(5, x => x + 1)` даёт 6.
