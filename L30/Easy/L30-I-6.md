# L30 · Задание I · №6. Запись текста в файл

**Тема:** Л30 — Потоки данных. Использование объекта FileStream для записи байтовых потоков в файл и чтения из файла. Чтение данных из текстовых файлов и запись в них

## Условие
Записать в файл `notes.txt` три строки с помощью `File.WriteAllText` или `File.WriteAllLines`.

## Ожидаемый результат
Файл содержит три строки.
