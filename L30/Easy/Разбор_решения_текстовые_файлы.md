# Разбор решения. L30 · Задание I · №1. Запись текста в файл

## Условие
Записать в файл `notes.txt` три строки с помощью `File.WriteAllText` или `File.WriteAllLines`.

## Ожидаемый результат
Файл содержит три строки.

## Идея решения
Для небольших файлов удобны статические методы класса `File`: они сами открывают, записывают и закрывают файл.

## Решение
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string[] lines = { "Первая строка", "Вторая строка", "Третья строка" };
        File.WriteAllLines("notes.txt", lines);

        Console.WriteLine(File.ReadAllText("notes.txt"));
        Console.WriteLine("Строк в файле: " + File.ReadAllLines("notes.txt").Length);
    }
}
```

## Пошаговое объяснение
1. `File.WriteAllLines` записывает каждый элемент массива отдельной строкой и перезаписывает файл, если он существует.
2. Для записи единым текстом подходит `File.WriteAllText(path, text)`.
3. Проверка: чтение обратно возвращает три строки.

## Результат
Файл notes.txt содержит три строки; чтение показывает их и число 3.
