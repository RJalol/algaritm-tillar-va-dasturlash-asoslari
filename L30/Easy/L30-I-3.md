# L30 · Задание I · №3. Запись строки в байтах

**Тема:** Л30 — Поток данных. Объект FileStream для записи и чтения потоков байтов в файл и из файла

## Условие
Преобразовать строку в байты кодировкой UTF-8 (`Encoding.UTF8.GetBytes`) и записать её в файл через `FileStream`.

## Ожидаемый результат
Размер файла равен длине массива байтов; текст читается в любом редакторе.
