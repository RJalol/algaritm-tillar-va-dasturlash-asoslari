# L30 · Задание I · №1. Запись байтов в файл

**Тема:** Л30 — Поток данных. Объект FileStream для записи и чтения потоков байтов в файл и из файла

## Условие
Открыть `FileStream` в режиме `Create`, записать в него массив из пяти байтов и закрыть поток.

## Ожидаемый результат
Файл создан, его размер равен пяти байтам.
