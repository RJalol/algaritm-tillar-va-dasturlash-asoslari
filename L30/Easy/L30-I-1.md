# L30 · Задание I · №1. Первый интерфейс

**Тема:** Л30 — Интерфейсы. Использование методов в интерфейсах и их переопределение. Копирование и сортировка объектов

## Условие
Объявить интерфейс «вывод сведений» с одним методом и одним свойством только для чтения. Реализовать его двумя не связанными наследованием классами. Написать метод, принимающий параметр типа интерфейса, и вызвать его для объектов обоих классов через массив типа интерфейса.

## Ожидаемый результат
Метод отработал для обоих классов, ничего о них не зная; массив типа интерфейса содержит объекты обоих классов; попытка создать объект интерфейса даёт `CS0144`.
