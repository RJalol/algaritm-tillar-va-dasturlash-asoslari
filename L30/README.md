# L30. Потоки данных. Использование объекта FileStream для записи байтовых потоков в файл и чтения из файла. Чтение данных из текстовых файлов и запись в них

Практические задания к теме №30 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
L30/
├── README.md
├── Easy/       10 заданий  (Задание I: №1–10)
├── Middle/     30 заданий  (Задание II: №1–30)
└── Advanced/   20 заданий  (Задание III: №1–20)
```

## Формат задания

Каждый файл `L30-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. Для каждого уровня (`Easy/`, `Middle/`, `Advanced/`) приведён один образцовый разбор — файл `Разбор_решения.md`; остальные задания предназначены для самостоятельного выполнения.

Нумерация локальна для каждого блока: Задание I — 1..10, Задание II — 1..30, Задание III — 1..20.

## Состав объединённой темы

| Задания | Содержание |
|---|---|
| I-1…5, II-1…15, III-1…10 | `FileStream`: запись и чтение потоков байтов |
| I-6…10, II-16…30, III-11…20 | Чтение данных из текстовых файлов и запись текста в файл (`File.ReadAllText`, `WriteAllLines` и др.) |

Образцовые разборы: `Разбор_решения.md` (`FileStream`) и `Разбор_решения_текстовые_файлы.md` (текстовые файлы).
