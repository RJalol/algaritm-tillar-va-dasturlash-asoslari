# Разбор решения. L30 · Задание II · №1. Подсчёт слов и символов

## Условие
Для текстового файла подсчитать число слов, символов и символов без пробелов.

## Ожидаемый результат
Значения совпадают с ожидаемыми для тестового файла.

## Разбор условия
**Дано:** текстовый файл.
**Требуется:** подсчитать число слов, символов и символов без пробельных.

## Теоретическая справка
Подсчёт характеристик текста:

- **символы** — `text.Length`;
- **символы без пробелов** — число `c`, для которых `!char.IsWhiteSpace(c)`;
- **слова** — разбиение `Split` по набору разделителей с `StringSplitOptions.RemoveEmptyEntries`, чтобы подряд идущие разделители не порождали пустых «слов».

Определение слова — договорённость: здесь разделители — пробельные символы и знаки препинания.

## Идея решения
Слова разделяем по пробелам и знакам препинания; символы считаем двумя способами — с пробелами и без них.

## Решение
```csharp
using System;
using System.IO;
using System.Linq;

class Program
{
    static void Main()
    {
        string text = File.ReadAllText("text.txt");

        int chars = text.Length;
        int charsNoSpaces = text.Count(c => !char.IsWhiteSpace(c));
        int words = text.Split(new[] { ' ', '\n', '\r', '\t', ',', '.', ';', ':', '!', '?' },
                               StringSplitOptions.RemoveEmptyEntries).Length;

        Console.WriteLine("Слов: " + words);
        Console.WriteLine("Символов: " + chars);
        Console.WriteLine("Символов без пробелов: " + charsNoSpaces);
    }
}
```

## Пошаговое объяснение
1. Весь файл читается одной строкой `File.ReadAllText`.
2. Общее число символов — `Length`; без пробельных символов — количество `c`, для которых `char.IsWhiteSpace(c)` ложно.
3. `Split` по набору разделителей с параметром `RemoveEmptyEntries` не создаёт пустых «слов» при подряд идущих разделителях.
4. Пример: для текста «Привет, мир!» получим 2 слова, 11 символов, 10 без пробелов.

## Трассировка и проверка
Для текста «Привет, мир!»:

| Показатель | Значение |
|---|--:|
| символов | 11 |
| без пробелов | 10 |
| слов | 2 («Привет», «мир») |

Без `RemoveEmptyEntries` разделение «Привет, мир!» по набору `{' ', ','}` дало бы пустой элемент между запятой и пробелом.

## Результат
Для «Привет, мир!»: слов 2, символов 11, без пробелов 10.

## Типичные ошибки
- Не использовать `RemoveEmptyEntries`.
- Считать слова по количеству пробелов + 1 (ошибка при подряд идущих пробелах).
- Забыть знаки препинания и символы перевода строки.
- Читать файл построчно и пропускать переносы.
