# L30 · Задание II · №6. Интерфейс или абстрактный класс

**Тема:** Л30 — Интерфейсы. Использование методов в интерфейсах и их переопределение. Копирование и сортировка объектов

## Условие
Даны шесть требований: общее состояние у родственных типов; договор для типов из разных иерархий; необходимость конструктора с проверками; несколько независимых договоров у одного типа; поведение для структуры; развиваемая иерархия с общей реализацией. Для каждого решить, что применить — абстрактный класс или интерфейс, — и обосновать. Реализовать по одному примеру каждого решения.

## Ожидаемый результат
Для каждого требования выбор обоснован; в реализации присутствуют оба средства.
