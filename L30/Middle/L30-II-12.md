# L30 · Задание II · №12. Дозапись в конец файла

**Тема:** Л30 — Потоки данных. Использование объекта FileStream для записи байтовых потоков в файл и чтения из файла. Чтение данных из текстовых файлов и запись в них

## Условие
Реализовать журнал: каждое выполнение программы дописывает в конец файла строку с текущим временем.

## Ожидаемый результат
После трёх запусков файл содержит три записи.
