# L30 · Задание III · №1. Библиотека учебного заведения

**Тема:** Л30 — Интерфейсы. Использование методов в интерфейсах и их переопределение. Копирование и сортировка объектов

## Условие
Разработать библиотеку классов (тема №27), в которой присутствуют: абстрактный класс с иерархией из четырёх классов; не менее трёх интерфейсов, реализуемых типами из разных ветвей иерархии и одним типом вне её; один класс, реализующий два интерфейса сразу; одна структура, реализующая интерфейс. Приложение собирает объекты в массивы по интерфейсам и печатает отчёты.

## Ожидаемый результат
Каждый массив типа интерфейса содержит объекты не связанных наследованием типов; для каждого решения (наследование либо интерфейс) приведено обоснование.
