# L30 · Задание III · №9. Обработка разнородного набора

**Тема:** Л30 — Интерфейсы. Использование методов в интерфейсах и их переопределение. Копирование и сортировка объектов

## Условие
Разработать программу, обрабатывающую массив объектов, часть которых реализует один интерфейс, часть — другой, а часть — оба. Для каждого элемента выполнить те действия, договоры которых он поддерживает, определяя это оператором `is` (тема №25). Убедиться, что программа корректно работает при любом составе массива, включая объекты, не реализующие ни одного из интерфейсов.

## Ожидаемый результат
Для каждого элемента выполнены только допустимые действия; ни при каком составе массива исключения не возникают; итоговая сводка верна.
