# Разбор решения. L30 · Задание III · №1. Разбиение файла на части

## Условие
Разбить большой файл на части фиксированного размера и собрать обратно, проверив совпадение.

## Ожидаемый результат
Собранный файл идентичен исходному.

## Идея решения
Разбиваем файл на части фиксированного размера, а затем склеиваем их по порядку. Потоки обрабатываются порциями, поэтому память не зависит от размера файла.

## Решение
```csharp
using System;
using System.IO;

class Program
{
    const int PartSize = 1024 * 1024;     // 1 МБ

    static int Split(string path)
    {
        byte[] buffer = new byte[PartSize];
        int parts = 0;
        using (FileStream input = new FileStream(path, FileMode.Open, FileAccess.Read))
        {
            int read;
            while ((read = ReadFull(input, buffer)) > 0)
            {
                string partName = path + ".part" + (++parts).ToString("000");
                using (FileStream part = new FileStream(partName, FileMode.Create))
                    part.Write(buffer, 0, read);
            }
        }
        return parts;
    }

    static void Merge(string path, int parts)
    {
        using (FileStream output = new FileStream(path, FileMode.Create))
        {
            for (int i = 1; i <= parts; i++)
            {
                string partName = path + ".part" + i.ToString("000");
                using (FileStream part = new FileStream(partName, FileMode.Open))
                    part.CopyTo(output);
            }
        }
    }

    // Read может вернуть меньше запрошенного, поэтому дочитываем до полного буфера
    static int ReadFull(Stream s, byte[] buf)
    {
        int total = 0, n;
        while (total < buf.Length && (n = s.Read(buf, total, buf.Length - total)) > 0)
            total += n;
        return total;
    }

    static bool Same(string a, string b)
    {
        using FileStream fa = new FileStream(a, FileMode.Open);
        using FileStream fb = new FileStream(b, FileMode.Open);
        if (fa.Length != fb.Length) return false;
        int x, y;
        while ((x = fa.ReadByte()) != -1)
        {
            y = fb.ReadByte();
            if (x != y) return false;
        }
        return true;
    }

    static void Main()
    {
        string original = "big.bin";
        int parts = Split(original);
        Console.WriteLine("Частей: " + parts);

        Merge("restored.bin", parts);
        Console.WriteLine("Файлы идентичны: " + Same(original, "restored.bin"));
    }
}
```

## Пошаговое объяснение
1. `Split` читает исходный файл порциями по 1 МБ; каждая порция записывается в отдельный файл `имя.partNNN` с номером, дополненным нулями (чтобы порядок по имени совпадал с порядком частей).
2. `ReadFull` дочитывает буфер до конца, потому что `Stream.Read` имеет право вернуть меньше байтов, чем запрошено, и тогда части получились бы разного размера.
3. `Merge` открывает части по порядку и дописывает их в выходной файл методом `CopyTo`.
4. `Same` сравнивает размеры, а затем содержимое побайтово.
5. Все потоки открыты в `using` и закрываются автоматически.

## Результат
Для big.bin размером, например, 3,5 МБ создаются 4 части; восстановленный файл идентичен исходному («Файлы идентичны: True»).
