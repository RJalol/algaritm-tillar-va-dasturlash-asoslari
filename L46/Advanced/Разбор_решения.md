# Разбор решения. L46 · Задание III · №4. Сглаживание данных

## Условие
Построить график сырых данных и скользящего среднего (окно 5) на одной области.

## Ожидаемый результат
Скользящее среднее вычислено верно.

## Идея решения
Скользящее среднее с окном k в точке i — среднее последних k значений: avg(i) = (x[i−k+1] + … + x[i]) / k. Для первых k−1 точек среднее не определено (или считается по доступным).

## Решение
```csharp
using System;
using System.Drawing;
using System.Linq;
using System.Windows.Forms;
using System.Windows.Forms.DataVisualization.Charting;

public class Form1 : Form
{
    public Form1()
    {
        Text = "Скользящее среднее";
        Size = new Size(700, 420);

        var rnd = new Random(1);
        double[] data = new double[60];
        double v = 50;
        for (int i = 0; i < data.Length; i++)
        {
            v += rnd.NextDouble() * 10 - 5;
            data[i] = v;
        }

        const int k = 5;
        var chart = new Chart { Dock = DockStyle.Fill };
        chart.ChartAreas.Add(new ChartArea("main"));
        chart.Legends.Add(new Legend("legend"));

        var raw = new Series("Данные")  { ChartType = SeriesChartType.Line, ChartArea = "main", Color = Color.LightSteelBlue };
        var avg = new Series($"Среднее (окно {k})") { ChartType = SeriesChartType.Line, ChartArea = "main", Color = Color.Crimson, BorderWidth = 3 };

        for (int i = 0; i < data.Length; i++)
        {
            raw.Points.AddXY(i + 1, data[i]);
            if (i >= k - 1)
                avg.Points.AddXY(i + 1, data.Skip(i - k + 1).Take(k).Average());
        }

        chart.Series.Add(raw);
        chart.Series.Add(avg);
        Controls.Add(chart);
    }
}
```

## Пошаговое объяснение
1. Данные моделируются случайным блужданием (фиксированное зерно `Random(1)` делает результат воспроизводимым).
2. Для i ≥ k−1 берём окно из k элементов (`Skip(i−k+1).Take(k)`) и вычисляем `Average()`.
3. Два ряда в одной области построения: исходный (светлый, тонкий) и среднее (красный, толстый).
4. Среднее сглаживает колебания и «запаздывает» относительно данных — это видно на графике.
5. Для больших массивов вместо повторного суммирования эффективнее поддерживать скользящую сумму (O(n) вместо O(n·k)).

## Результат
На графике видны исходный шумный ряд и гладкая линия скользящего среднего, начинающаяся с 5-й точки.
