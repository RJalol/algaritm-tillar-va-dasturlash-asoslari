# Разбор решения. L46 · Задание II · №2. График функции

## Условие
Построить график функции `y = x²` на отрезке [-5; 5] с шагом 0,5, настроив диапазон осей и сетку.

## Ожидаемый результат
График параболы корректен.

## Идея решения
Для графика функции берём равномерную сетку значений x, вычисляем y = f(x) и добавляем пары в ряд. Диапазон оси настраиваем свойствами `Minimum`/`Maximum`.

## Решение
```csharp
using System;
using System.Drawing;
using System.Windows.Forms;
using System.Windows.Forms.DataVisualization.Charting;

public class Form1 : Form
{
    public Form1()
    {
        Text = "y = x²";
        Size = new Size(560, 380);

        var chart = new Chart { Dock = DockStyle.Fill };
        var area = new ChartArea("main");
        area.AxisX.Minimum = -5; area.AxisX.Maximum = 5; area.AxisX.Interval = 1;
        area.AxisY.Minimum = 0;  area.AxisY.Maximum = 25;
        area.AxisX.MajorGrid.LineColor = Color.LightGray;
        area.AxisY.MajorGrid.LineColor = Color.LightGray;
        chart.ChartAreas.Add(area);

        var series = new Series("y = x²") { ChartType = SeriesChartType.Spline, ChartArea = "main", BorderWidth = 2 };
        for (double x = -5; x <= 5; x += 0.5)
            series.Points.AddXY(x, x * x);

        chart.Series.Add(series);
        chart.Legends.Add(new Legend("legend"));
        Controls.Add(chart);
    }
}
```

## Пошаговое объяснение
1. Цикл от −5 до 5 с шагом 0,5 даёт 21 точку.
2. Тип `Spline` соединяет точки сглаженной кривой — парабола выглядит гладко.
3. Свойства осей `Minimum`, `Maximum`, `Interval` задают видимый диапазон и шаг подписей; `MajorGrid` включает сетку.
4. Легенда показывает название ряда.

## Результат
Гладкая парабола y = x² на отрезке [−5; 5] с сеткой и легендой; вершина в точке (0; 0).
