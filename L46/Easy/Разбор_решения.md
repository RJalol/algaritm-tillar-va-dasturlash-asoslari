# Разбор решения. L46 · Задание I · №1. Элемент Chart на форме

## Условие
Разместить на форме элемент `Chart` (пространство имён `System.Windows.Forms.DataVisualization.Charting`), добавить один ряд `Series` типа `Line` и три точки методом `Points.AddXY`.

## Ожидаемый результат
На форме отображается линия, соединяющая три точки.

## Идея решения
`Chart` содержит области построения (`ChartArea`) и ряды (`Series`). Для линейного графика у ряда задаётся тип `SeriesChartType.Line`, точки добавляются методом `Points.AddXY`.

## Решение
```csharp
using System;
using System.Drawing;
using System.Windows.Forms;
using System.Windows.Forms.DataVisualization.Charting;

public class Form1 : Form
{
    public Form1()
    {
        Text = "Первый график";
        Size = new Size(500, 350);

        var chart = new Chart { Dock = DockStyle.Fill };
        chart.ChartAreas.Add(new ChartArea("main"));

        var series = new Series("Данные") { ChartType = SeriesChartType.Line, ChartArea = "main" };
        series.Points.AddXY(1, 5);
        series.Points.AddXY(2, 8);
        series.Points.AddXY(3, 4);

        chart.Series.Add(series);
        Controls.Add(chart);
    }
}
```

## Пошаговое объяснение
1. Элемент `Chart` (пространство имён `System.Windows.Forms.DataVisualization.Charting`) в .NET 8 подключается пакетом, содержащим эту библиотеку (в .NET Framework входит в состав платформы).
2. Сначала создаётся область построения `ChartArea`, затем ряд `Series` с типом `Line` и привязкой к области.
3. Метод `Points.AddXY(x, y)` добавляет точку; три вызова дают три точки, соединённые линией.
4. Ряд добавляется в `chart.Series`, элемент — в `Controls` формы.

## Результат
На форме отображается линия через точки (1; 5), (2; 8), (3; 4).
