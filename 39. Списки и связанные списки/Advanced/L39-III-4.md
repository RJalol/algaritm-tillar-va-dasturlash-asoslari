# L39 · Задание III · №4. Шесть исключений

**Тема:** Л39 — Списки и связанные списки в языке программирования C#

## Условие
Поставить шесть опытов, вызвав по одному: `ArgumentOutOfRangeException` при обращении по неверному индексу; `KeyNotFoundException` при чтении отсутствующего ключа; `ArgumentException` при повторном ключе; `ArgumentNullException` при ключе `null`; `InvalidOperationException` при извлечении из пустой очереди и оно же при изменении коллекции во время перебора. Для каждого записать сообщение и способ избежать.

## Ожидаемый результат
Получены все шесть; составлена таблица «действие — исключение — как избежать»; отдельно отмечено, что два разных случая дают одно и то же исключение.
