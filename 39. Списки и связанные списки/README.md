# Тема 39. Списки и связанные списки в языке программирования C#

Практические задания к теме №39 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
39. Списки и связанные списки/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
└── Advanced/   10 заданий  (Задание III)
```

## Формат задания

Каждый файл `L39-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. Для каждого уровня (`Easy/`, `Middle/`, `Advanced/`) приведён один образцовый разбор — файл `Разбор_решения.md`; остальные задания предназначены для самостоятельного выполнения.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.

## Состав темы

Основной предмет темы — списки `List<T>` и связанные списки `LinkedList<T>`. Задания, подготовленные ранее для обобщённого обзора коллекций, сохранены полностью: они дополнительно затрагивают словари, множества, стеки и очереди. Стеки и очереди как самостоятельная тема рассматриваются в теме №40 (папка «40. Стек и очередь»).
