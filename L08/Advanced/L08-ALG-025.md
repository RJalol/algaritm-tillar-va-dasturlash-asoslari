# L08-ALG-025. Числа-палиндромы

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Написать программу, которая запрашивает целое неотрицательное число и определяет, является ли оно палиндромом, то есть читается ли одинаково слева направо и справа налево. Задачу решить арифметически, применив приём переворота числа из ALG-010, без преобразования в строку.

## Ожидаемый результат
Для 12321 — сообщение о палиндроме, для 12345 — об отсутствии этого свойства; сравнивается исходное число с перевёрнутым, для чего исходное значение сохраняется до цикла.
