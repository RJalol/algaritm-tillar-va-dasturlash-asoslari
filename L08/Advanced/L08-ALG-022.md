# L08-ALG-022. Подсчёт числа итераций

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Не запуская программу, определить, сколько раз выполнится тело каждого из циклов:

```
for (int i = 1; i <= 5; i++)          { }
for (int i = 1; i < 5; i++)           { }
for (int i = 0; i <= 5; i++)          { }
for (int i = 10; i >= 1; i -= 3)      { }
for (int i = 1; i <= 20; i *= 2)      { }
```

Для каждого цикла перечислить принимаемые счётчиком значения. Затем проверить ответы, добавив в тело каждого цикла счётчик итераций.

## Ожидаемый результат
Пять чисел: `5`, `4`, `6`, `4`, `5`; для каждого цикла перечислены фактические значения счётчика.
