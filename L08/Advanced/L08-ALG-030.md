# L08-ALG-030. Полный аудит фрагмента с циклами

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Дан код:

```
using System;

namespace AuditDemo
{
    class Program
    {
        static void Main(string[] args)
        {
            int sum = 0;
            for (int i = 1; i <= 5; i++);
            {
                sum += i;
            }

            int counter = 0;
            for (double x = 0; x < 1.0; x += 0.1)
            {
                counter++;
            }

            int n = 5;
            while (n > 0)
            {
                Console.WriteLine(n);
            }

            Console.WriteLine(sum);
            Console.WriteLine(counter);
        }
    }
}
```

Провести полный аудит и разнести замечания по трём категориям: ошибка компиляции; предупреждение компилятора, за которым скрывается неверное поведение; логическая ошибка, приводящая к тому, что программа не завершится. Для каждой указать конкретную строку и назвать код там, где он есть. Привести исправленную версию.

**Внимание:** запускать исходный фрагмент не следует — он содержит бесконечный цикл.

## Ожидаемый результат
Категории разнесены верно: `CS0103` на обращении к счётчику `i` внутри блока, оказавшегося за пределами цикла из-за точки с запятой; предупреждение `CS0642` на той же строке; вещественный счётчик, дающий 11 итераций вместо 10; бесконечный цикл `while`, в теле которого не изменяется `n`.
