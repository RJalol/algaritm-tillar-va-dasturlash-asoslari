# L08-ALG-029. Оценка числа выполнений

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Даны три фрагмента с вложенными циклами:

```
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= n; j++)          { }

for (int i = 1; i <= n; i++)
    for (int j = 1; j <= i; j++)          { }

for (int i = 1; i <= n; i++)
    for (int j = 1; j <= 10; j++)         { }
```

Для каждого определить, сколько раз выполнится тело внутреннего цикла при n = 100, и записать общую формулу через n. Проверить ответы, подсчитав итерации программно. Объяснить, какой из фрагментов сильнее всего замедлится при увеличении n вдесятеро.

## Ожидаемый результат
Числа `10000`, `5050` и `1000` с формулами n², n(n+1)/2 и 10n; указано, что первые два растут квадратично, а третий — линейно.
