# L08-ALG-023. Полная таблица умножения

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Написать программу, которая выводит таблицу умножения от 1 до 9 в виде квадратной таблицы: девять строк по девять чисел, выровненных по столбцам с помощью символа табуляции. Использовать вложенные циклы. В комментарии указать, сколько раз выполнилось тело внутреннего цикла.

## Ожидаемый результат
Девять строк по девять чисел с выравниванием по столбцам; в комментарии указано 81 выполнение тела внутреннего цикла.
