# Разбор решения. L08-ALG-021. Три нарушения в одном фрагменте

## Условие
Дан код:

```
int i = 0;
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine(i);
}

int count = 3;
while (count)
{
    count--;
}

for (int k = 1; k <= 3; k++)
{
    Console.WriteLine(k);
}
Console.WriteLine(k);
```

Найти все нарушения, для каждого назвать код ошибки компилятора и объяснить причину отдельно. Указать, какие из них связаны с областью видимости, а какое — с типом условия. Привести исправленный фрагмент.

## Ожидаемый результат
Три нарушения с кодами `CS0136`, `CS0029` и `CS0103`; первое и третье отнесены к области видимости, второе — к типу условия.

## Разбор условия
**Дано:** три фрагмента с циклами и областями видимости.
**Требуется:** найти три нарушения (`CS0136`, `CS0029`, `CS0103`), объяснить, отнести к областям видимости или типу условия, исправить.

## Теоретическая справка
**Область видимости** переменной — часть программы, где её имя доступно.

- Переменная, объявленная в заголовке `for`, живёт только внутри этого цикла.
- Вложенный блок не может объявлять переменную с именем, уже существующим во внешнем блоке того же метода (`CS0136`): даже если внешняя переменная объявлена до цикла, повторное объявление запрещено.
- Условие цикла `while`, как и `if`, должно быть типа `bool`; `while (count)` с `int` — ошибка `CS0029`.

## Идея решения
Ищем конфликты имён в области видимости, неверный тип условия цикла и обращение к переменной вне её блока.

## Решение
```csharp
// Исправленный фрагмент
int i = 0;
for (int j = 1; j <= 3; j++)      // другое имя счётчика
{
    Console.WriteLine(j);
}

int count = 3;
while (count > 0)                  // условие типа bool
{
    count--;
}

int k;
for (k = 1; k <= 3; k++)           // k объявлена снаружи
{
    Console.WriteLine(k);
}
Console.WriteLine(k);
```

## Пошаговое объяснение
1. `for (int i = 1; ...)` при уже объявленной выше `int i` — вложенная область не может переобъявлять имя из внешней (`CS0136`). Нарушение области видимости.
2. `while (count)` — условие должно быть `bool`, а `count` — `int` (`CS0029`). Нарушение типа условия.
3. `Console.WriteLine(k)` после цикла — переменная `k`, объявленная в заголовке `for`, существует только внутри цикла (`CS0103`). Нарушение области видимости.
4. Исправления: переименовать счётчик, записать условие `count > 0`, объявить `k` до цикла.

## Трассировка и проверка
| Фрагмент | Причина | Код |
|---|---|---|
| `int i = 0;` и `for (int i = 1; …)` | имя `i` уже объявлено во внешней области | CS0136 |
| `while (count)` | `int` не преобразуется в `bool` | CS0029 |
| `Console.WriteLine(k)` после цикла | `k` существовала только внутри `for` | CS0103 |

Три исправления: другое имя счётчика, условие `count > 0`, объявление `k` до цикла (если нужно использовать после него).

## Результат
Нарушения: CS0136 (область видимости), CS0029 (тип условия), CS0103 (имя вне области видимости).

## Типичные ошибки
- Объявлять счётчик внутри цикла и пользоваться им после.
- Считать, что в C# ноль — «ложь», а ненулевое — «истина».
- Дублировать имена переменных во вложенных циклах (`i` во внутреннем и внешнем).
- Модифицировать счётчик в теле цикла `for`, нарушая предсказуемость числа итераций.
