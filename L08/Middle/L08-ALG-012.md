# L08-ALG-012. Наибольший общий делитель

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Написать программу, которая запрашивает два целых положительных числа и находит их наибольший общий делитель алгоритмом Евклида: пока второе число не равно нулю, заменять пару «первое, второе» парой «второе, остаток от деления первого на второе». Использовать цикл `while`.

## Ожидаемый результат
Для чисел 48 и 18 выведено `6`; для чисел 17 и 5 — `1`; обмен значений выполняется через вспомогательную переменную.
