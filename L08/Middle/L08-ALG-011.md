# L08-ALG-011. Возведение в степень

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Написать программу, которая запрашивает основание и целый неотрицательный показатель степени и вычисляет степень с помощью цикла, **не используя** метод `Math.Pow`. Проверить работу для показателя, равного нулю.

## Ожидаемый результат
Для основания 2 и показателя 10 выведено `1024`; для показателя 0 выведено `1`, что обеспечивается начальным значением накопителя.
