# L08-ALG-016. Счётчик за пределами цикла

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Дан код:

```
for (int i = 1; i <= 3; i++)
{
    Console.WriteLine(i);
}
Console.WriteLine(i);
```

Объяснить, почему фрагмент не компилируется, назвать код ошибки и привести два способа исправления, дающих разный результат последней строки.

## Ожидаемый результат
Назван код `CS0103`; приведены оба исправления — объявить счётчик до цикла либо убрать последнюю строку; указано, какое значение будет выведено в первом случае.
