# L08-ALG-008. Количество цифр числа

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Написать программу, которая запрашивает целое неотрицательное число и определяет количество цифр в нём, последовательно деля число на 10. Использовать цикл `do-while`. Проверить работу на числах 12345, 7 и **0**.

## Ожидаемый результат
Соответственно `5`, `1` и `1`; выбор `do-while` обеспечивает правильный ответ для нуля без отдельной проверки.
