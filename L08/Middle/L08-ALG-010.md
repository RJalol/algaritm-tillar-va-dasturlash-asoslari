# L08-ALG-010. Переворот числа

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Написать программу, которая запрашивает целое неотрицательное число и выводит число, записанное теми же цифрами в обратном порядке. Задачу решить арифметически, с помощью цикла, не преобразуя число в строку.

## Ожидаемый результат
При вводе 4728 выведено `8274`; результат накапливается умножением на 10 и прибавлением очередной цифры.
