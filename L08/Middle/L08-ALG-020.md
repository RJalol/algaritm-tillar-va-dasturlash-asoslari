# L08-ALG-020. Треугольник из символов

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Написать программу, которая по введённой высоте выводит прямоугольный треугольник из звёздочек: в первой строке одна звёздочка, во второй две и так далее. Использовать вложенные циклы, связав границу внутреннего цикла со счётчиком внешнего.

## Ожидаемый результат
При высоте 4 выведены строки из 1, 2, 3 и 4 звёздочек; граница внутреннего цикла зависит от текущего значения счётчика внешнего.
