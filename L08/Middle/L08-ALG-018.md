# L08-ALG-018. Вещественный счётчик

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Написать программу, которая подсчитывает число итераций цикла `for (double x = 0; x < 1.0; x += 0.1)`. Вывести полученное число и объяснить в комментарии расхождение с ожидаемым. Затем переписать цикл с целочисленным счётчиком так, чтобы значение шага оставалось равным 0,1, и убедиться, что число итераций стало правильным.

## Ожидаемый результат
Первый цикл даёт `11`, второй — `10`; в комментарии причина связана с накоплением погрешности вещественных вычислений (тема №4).
