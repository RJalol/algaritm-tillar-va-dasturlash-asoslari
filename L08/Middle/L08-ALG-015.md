# L08-ALG-015. Точка с запятой после заголовка

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Дан код:

```
int sum = 0;
for (int i = 1; i <= 5; i++);
{
    sum += 10;
}
Console.WriteLine(sum);
```

Определить, что выведет программа, и объяснить причину. Назвать сообщение компилятора. Затем указать, что произошло бы при той же ошибке в цикле `while`, и объяснить, почему последствия там серьёзнее.

## Ожидаемый результат
Указано, что выводится `10`, а не `50`; названо предупреждение `CS0642`; объяснено, что телом цикла стал пустой оператор, а блок выполнился однократно; для `while` отмечено возникновение бесконечного цикла.
