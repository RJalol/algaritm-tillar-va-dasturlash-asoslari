# L08-ALG-017. Число как условие цикла

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Дан код:

```
int count = 3;
while (count)
{
    count--;
}
```

Объяснить, почему фрагмент не компилируется, назвать код ошибки и записать корректный вариант, сохраняющий очевидное намерение автора.

## Ожидаемый результат
Назван код `CS0029`; объяснено, что условие обязано иметь тип `bool`; в исправленном варианте записано явное сравнение с нулём.
