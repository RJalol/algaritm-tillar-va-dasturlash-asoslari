# L08-ALG-002. Сумма чисел от 1 до N

**Тема:** Л8 — Операторы повторения for, while, do-while. Различные формы оператора for в процессе повторения

## Условие
Написать программу, которая запрашивает целое положительное число N и вычисляет сумму всех целых чисел от 1 до N с помощью цикла `for`. Вывести результат.

## Ожидаемый результат
При вводе 100 выведено `5050`; переменная-накопитель обнулена **до** цикла.
