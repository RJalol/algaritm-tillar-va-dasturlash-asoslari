# Разбор решения. L08-ALG-001. Числа от 1 до N

## Условие
Написать программу, которая запрашивает у пользователя целое положительное число N и выводит все числа от 1 до N включительно, разделяя их пробелами, с помощью цикла `for`.

## Ожидаемый результат
При вводе 5 выведено `1 2 3 4 5`; граница цикла задана так, чтобы значение N попадало в вывод.

## Идея решения
Цикл `for` с переменной от 1 до N: условие `i <= N` включает границу.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Введите N: ");
        int n = int.Parse(Console.ReadLine());

        for (int i = 1; i <= n; i++)
        {
            Console.Write(i + " ");
        }
        Console.WriteLine();
    }
}
```

## Пошаговое объяснение
1. Инициализация `int i = 1` выполняется один раз перед циклом.
2. Условие `i <= n` проверяется перед каждой итерацией; знак `<=` (а не `<`) делает так, что `n` тоже выводится.
3. После каждой итерации выполняется `i++`.
4. Числа печатаем через `Write` с пробелом, чтобы они шли в одну строку.

## Результат
При N = 5 выводится: 1 2 3 4 5
