# Разбор решения. L50 · Задание I · №1. Первое WPF-приложение

## Условие
Создать проект WPF (`net8.0-windows`), изучить файлы `App.xaml` и `MainWindow.xaml` и изменить заголовок, размер и положение окна атрибутами `Title`, `Width`, `Height`, `WindowStartupLocation`.

## Ожидаемый результат
Окно открывается по центру с заданными параметрами.

## Разбор условия
**Дано:** проект WPF (.NET 8).
**Требуется:** изучить файлы проекта, задать заголовок, размер и положение окна атрибутами XAML.

## Теоретическая справка
**WPF (Windows Presentation Foundation)** — платформа для создания интерфейсов с разделением разметки (**XAML**) и кода. XAML — декларативный язык на основе XML: элементы соответствуют классам, атрибуты — свойствам.

Структура проекта:

| Файл | Назначение |
|---|---|
| `App.xaml` / `App.xaml.cs` | приложение (класс `Application`), ресурсы, `StartupUri` |
| `MainWindow.xaml` | разметка главного окна (`Window`) |
| `MainWindow.xaml.cs` | код окна (`partial class`) |

Пространства имён XAML: основное `xmlns=".../presentation"` (элементы WPF) и `xmlns:x` (служебные атрибуты `x:Class`, `x:Name`). Устройство независимо от разрешения: размеры задаются в **аппаратно-независимых единицах** (1/96 дюйма).

## Идея решения
В проекте WPF окно описывается разметкой XAML (`MainWindow.xaml`) и классом-наследником `Window` (`MainWindow.xaml.cs`). Начальные параметры окна задаются атрибутами корневого элемента.

## Решение
```xml
<!-- MainWindow.xaml -->
<Window x:Class="FirstWpf.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="Мой первый проект WPF"
        Width="420" Height="260"
        WindowStartupLocation="CenterScreen">
    <Grid>
        <TextBlock Text="Привет, WPF!" FontSize="24"
                   HorizontalAlignment="Center" VerticalAlignment="Center"/>
    </Grid>
</Window>
```

## Пошаговое объяснение
1. Создаём проект «Приложение WPF» (.NET 8). В нём `App.xaml` описывает приложение, а `MainWindow.xaml` — главное окно.
2. Корневой элемент `Window` с атрибутами `Title`, `Width`, `Height`, `WindowStartupLocation` задаёт заголовок, размер и положение окна.
3. Пространства имён: `xmlns` — элементы WPF, `xmlns:x` — служебные атрибуты XAML (`x:Class`, `x:Name`).
4. `x:Class` связывает разметку с классом `MainWindow` в коде; внутри окна находится `Grid` с надписью.
5. Запуск (F5) показывает окно по центру экрана.

## Трассировка и проверка
| Атрибут | Значение | Эффект |
|---|---|---|
| `Title` | «Мой первый проект WPF» | заголовок |
| `Width`/`Height` | 420/260 | размер |
| `WindowStartupLocation` | `CenterScreen` | по центру экрана |

Запуск (F5) показывает окно с надписью «Привет, WPF!» в центре.

## Результат
Окно 420×260 с заголовком «Мой первый проект WPF» по центру экрана; в центре — надпись «Привет, WPF!».

## Типичные ошибки
- Путать `Width` и `ActualWidth` (последняя — фактическая).
- Забыть закрывающий тег или кавычку в XAML (ошибка разметки).
- Менять `x:Class` в одном файле и не менять в другом.
- Писать логику в XAML вместо кода/ViewModel.
