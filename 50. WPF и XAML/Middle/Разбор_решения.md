# Разбор решения. L50 · Задание II · №6. Привязка данных

## Условие
Связать `TextBox` и `TextBlock` привязкой `{Binding ElementName=..., Path=Text}`.

## Ожидаемый результат
Текст в `TextBlock` обновляется при вводе.

## Разбор условия
**Дано:** текстовое поле и текстовый блок.
**Требуется:** связать их привязкой данных в XAML без кода.

## Теоретическая справка
**Привязка данных (data binding)** связывает свойство-приёмник с источником. Выражение разметки: `{Binding Path=Text, ElementName=Input}`.

Основные параметры:

| Параметр | Значение |
|---|---|
| `Path` | свойство источника |
| `ElementName` | имя элемента-источника |
| `Mode` | `OneWay`, `TwoWay`, `OneTime` |
| `UpdateSourceTrigger` | когда обновлять источник: `PropertyChanged`, `LostFocus` |

Для `TextBox.Text` по умолчанию обновление источника происходит при потере фокуса; `UpdateSourceTrigger=PropertyChanged` делает обновление «на лету».

## Идея решения
Привязка (`Binding`) связывает свойство одного элемента со свойством другого: изменение источника автоматически обновляет получатель без кода-обработчика.

## Решение
```xml
<!-- MainWindow.xaml -->
<Window x:Class="BindingDemo.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="Привязка" Width="360" Height="160">
    <StackPanel Margin="15">
        <TextBox x:Name="Input"
                 Text="" Margin="0,0,0,10"/>
        <TextBlock FontSize="18"
                   Text="{Binding ElementName=Input, Path=Text, UpdateSourceTrigger=PropertyChanged}"/>
    </StackPanel>
</Window>
```

## Пошаговое объяснение
1. `x:Name="Input"` даёт текстовому полю имя, по которому на него можно сослаться.
2. Выражение `{Binding ElementName=Input, Path=Text}` означает: взять свойство `Text` элемента с именем `Input`.
3. По умолчанию источник `TextBox` обновляется при потере фокуса; режим `UpdateSourceTrigger=PropertyChanged` обновляет его при каждом нажатии клавиши.
4. Кода в `MainWindow.xaml.cs` не требуется — вся связь задана декларативно.

## Трассировка и проверка
| Ввод | Текст в `TextBlock` |
|---|---|
| «A» | A |
| «Ал» | Ал |
| «Алго» | Алго |

Привязка работает без обработчиков событий и кода в `MainWindow.xaml.cs`.

## Результат
Текст в нижней надписи изменяется синхронно с вводом в текстовое поле.

## Типичные ошибки
- Забыть `x:Name` у источника.
- Опечататься в `Path` (WPF не выдаёт ошибки компиляции — только предупреждение в окне вывода).
- Не указать `UpdateSourceTrigger` и ждать обновления при каждом символе.
- Использовать привязку к свойству, не реализующему уведомления.
