# Разбор решения. L48 · Задание I · №1. Первый запрос LINQ

## Условие
Дан массив чисел {5, 12, 8, 3, 20, 7}. Выбрать числа больше 6 запросом `where` и вывести.

## Ожидаемый результат
Выведены 12, 8, 20, 7.

## Разбор условия
**Дано:** массив {5, 12, 8, 3, 20, 7}.
**Требуется:** выбрать числа больше 6 запросом LINQ.

## Теоретическая справка
**LINQ (Language Integrated Query)** — язык запросов, встроенный в C#. Источник — любая коллекция, реализующая `IEnumerable<T>`.

Две формы записи:

| Синтаксис запросов | Синтаксис методов |
|---|---|
| `from n in a where n > 6 select n` | `a.Where(n => n > 6)` |

Обе формы компилируются в вызовы методов расширения (`Where`, `Select`, `OrderBy`, …).

**Отложенное выполнение:** запрос не выполняется в момент объявления, а лишь описывается; вычисление происходит при переборе (`foreach`) или при вызове агрегата/`ToList()`.

## Идея решения
LINQ-запрос состоит из источника (`from`), условия (`where`) и результата (`select`). Запрос можно записать и методами: `numbers.Where(...)`.

## Решение
```csharp
using System;
using System.Linq;

class Program
{
    static void Main()
    {
        int[] numbers = { 5, 12, 8, 3, 20, 7 };

        var result = from n in numbers
                     where n > 6
                     select n;

        foreach (int n in result)
            Console.Write(n + " ");
        Console.WriteLine();

        // эквивалент в синтаксисе методов
        Console.WriteLine(string.Join(" ", numbers.Where(n => n > 6)));
    }
}
```

## Пошаговое объяснение
1. `from n in numbers` задаёт источник и переменную диапазона `n`.
2. `where n > 6` — фильтр; `select n` — какие значения попадают в результат.
3. Запрос не выполняется в момент объявления (отложенное выполнение): вычисление идёт при переборе `foreach`.
4. Вторая строка — тот же запрос в синтаксисе методов расширения; оба варианта компилируются в один и тот же код.

## Трассировка и проверка
| n | n > 6 | В результате |
|--:|:--:|:--:|
| 5 | нет | — |
| 12 | да | 12 |
| 8 | да | 8 |
| 3 | нет | — |
| 20 | да | 20 |
| 7 | да | 7 |

Результат: 12 8 20 7 (порядок исходной последовательности сохранён).

## Результат
12 8 20 7

## Типичные ошибки
- Забыть `using System.Linq;`.
- Считать, что запрос выполняется сразу.
- Перепутать порядок: в синтаксисе запросов `select` пишется в конце.
- Изменять источник, пока запрос ещё не выполнен, и удивляться результату.
