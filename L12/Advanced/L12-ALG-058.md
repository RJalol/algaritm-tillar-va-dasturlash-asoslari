# L12-ALG-058. Разбор строки на слова

**Тема:** Л12 — Объявление строк и работа с ними. Форматирование строк. Стандартные методы обработки строковых данных

## Условие
Написать программу, которая выделяет из строки `"язык программирования C Sharp"` отдельные слова и выводит каждое с порядковым номером. Метод `Split` не использовать: слово накапливается посимвольно и завершается при встрече пробела либо конца строки. Предусмотреть, чтобы последнее слово не потерялось.

## Ожидаемый результат
Четыре пронумерованные строки: `1. язык`, `2. программирования`, `3. C`, `4. Sharp`; условие завершения слова проверяется в том числе за последним символом строки.
