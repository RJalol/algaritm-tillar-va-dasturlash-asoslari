# L12-ALG-030. Полный аудит программы обработки строк

**Тема:** Л12 — Методы работы со строками. Класс StringBuilder

## Условие
Дан код:

```
using System;

namespace TextAudit
{
    class Program
    {
        static void Main(string[] args)
        {
            string line = "  Азиз ; 87  ";

            line.Trim();

            string[] fields = line.Split(';');
            Console.WriteLine(fields[0]);

            int pos = line.IndexOf("балл");
            Console.WriteLine(line.Substring(pos));

            if (fields[0] == "Азиз")
            {
                Console.WriteLine("найден");
            }

            Console.WriteLine(line.Substring(0, 20));
        }
    }
}
```

Провести полный аудит и разнести замечания по четырём категориям: отброшенный результат метода; использование результата поиска без проверки; сравнение, нарушаемое незамеченными пробелами; выход за границы при извлечении. Для каждого замечания назвать тип исключения либо объяснить, почему ошибка не обнаруживается ни компилятором, ни средой выполнения. Привести исправленную версию.

## Ожидаемый результат
Категории разнесены верно: вызов `line.Trim()` без присваивания не делает ничего и не вызывает ни ошибки, ни предупреждения; `IndexOf("балл")` возвращает −1, и последующий `Substring` даёт `ArgumentOutOfRangeException`; сравнение `fields[0] == "Азиз"` даёт `False` из-за пробелов, оставшихся вокруг поля; `Substring(0, 20)` выходит за пределы строки длиной `13` и также даёт `ArgumentOutOfRangeException`. Приведён исправленный код, в котором результат `Trim` присвоен, поля дополнительно очищены, а результат поиска проверен на −1.
