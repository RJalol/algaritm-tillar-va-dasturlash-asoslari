# Разбор решения. L12-ALG-051. Шесть нарушений в одном фрагменте

## Условие
Дан код:

```
string s = "abc";
s[0] = 'X';
int n = s.Length();
char c = s;
string k = 'x';
string bad = "C:\Users";
Console.WriteLine($ "значение {n}");
```

Найти все нарушения и назвать код ошибки компилятора для каждого. Разнести их по трём группам: нарушение неизменяемости; несовпадение типов; лексическая ошибка записи. Привести исправленный фрагмент.

## Ожидаемый результат
Названы коды `CS0200`, `CS1955`, `CS0029` (дважды — в обе стороны между `char` и `string`), `CS1009` и `CS1056`; группы разнесены верно, приведён компилирующийся вариант.

## Разбор условия
**Дано:** семь строк кода со строками.
**Требуется:** найти нарушения и назвать коды (`CS0200`, `CS1955`, `CS0029` ×2, `CS1009`, `CS1056`), разнести по трём группам: неизменяемость, несовпадение типов, лексическая ошибка.

## Теоретическая справка
- **Неизменяемость:** индексатор строки только для чтения (`CS0200`); `Length` — свойство, вызывать как метод нельзя (`CS1955`).
- **Несовпадение типов:** `char` и `string` — разные типы. `char c = s;` и `string k = 'x';` — `CS0029`.
- **Лексика:** в обычной строке `\` начинает escape-последовательность; `\U` — начало 8-значного кода Unicode, а здесь он неполон (`CS1009`). Интерполяция записывается `$"…"` без пробела между `$` и кавычкой (`CS1056`).

Способы записи пути: `"C:\\Users"` (экранирование) или `@"C:\Users"` (буквальная строка).

## Идея решения
Анализируем семь строк: строки неизменяемы, `Length` — свойство, `char` и `string` — разные типы, нужен экранированный `\`, интерполяция записывается как `$"..."` без пробела.

## Решение
```csharp
// Исправленный фрагмент
string s = "abc";
s = "X" + s.Substring(1);              // строку не изменить - создаём новую
int n = s.Length;                      // свойство без скобок
char c = s[0];                         // char берётся из строки по индексу
string k = "x";                        // строка в двойных кавычках
string bad = "C:\\Users";              // обратная косая черта экранируется
Console.WriteLine($"значение {n}");    // нет пробела между $ и кавычкой
```

## Пошаговое объяснение
1. Группа «неизменяемость»: `s[0] = 'X'` — индексатор строки только для чтения (`CS0200`); `s.Length()` — `Length` свойство, а не метод (`CS1955`).
2. Группа «несовпадение типов»: `char c = s;` (`string` → `char`) и `string k = 'x';` (`char` → `string`) — оба `CS0029`.
3. Группа «лексические ошибки»: `"C:\Users"` содержит нераспознанную escape-последовательность `\U` (`CS1009`); `$ "..."` с пробелом после `$` нарушает запись интерполяции (`CS1056`).
4. Исправленный код компилируется: изменение строки заменено созданием новой, типы согласованы, `\` экранирована.

## Трассировка и проверка
| Строка | Группа | Код |
|---|---|---|
| `s[0] = 'X';` | неизменяемость | CS0200 |
| `s.Length()` | неизменяемость/свойство | CS1955 |
| `char c = s;` | несовпадение типов | CS0029 |
| `string k = 'x';` | несовпадение типов | CS0029 |
| `"C:\Users"` | лексическая | CS1009 |
| `$ "…"` | лексическая | CS1056 |

Исправленный фрагмент использует `s.Substring`, `s.Length`, `s[0]`, `"x"`, `@"C:\Users"` и `$"значение {n}"`.

## Результат
Коды: CS0200, CS1955, CS0029 (дважды), CS1009 и CS1056; группы разнесены, приведён компилирующийся вариант.

## Типичные ошибки
- Путать одинарные и двойные кавычки.
- Забывать экранирование обратной косой черты в путях.
- Ставить пробел между `$` и кавычкой.
- Пытаться изменять символы строки на месте.
