# Разбор решения. L12-ALG-021. Пять нарушений в одном фрагменте

## Условие
Дан код:

```
string s = "abc";
string u = s.ToUpper;
int i = s.IndexOf("b").Length;
string w = s.Substring("1");
StringBuilder sb = new StringBuilder("x");
string v = sb.ToString;
s.Replace("a", "z");
Console.WriteLine(s + u + i + w + v);
```

Найти все нарушения. Для четырёх из них назвать код ошибки компилятора; пятое **компилируется без предупреждений** — объяснить, что оно делает и почему это опаснее ошибки компиляции. Привести исправленный фрагмент.

## Ожидаемый результат
Названы коды `CS0428` (дважды — `ToUpper` и `ToString` без скобок), `CS1061` (у типа `int` нет члена `Length`) и `CS1503` (аргумент `Substring` должен быть целым); пятое нарушение — отброшенный результат `Replace`, из-за которого строка молча остаётся прежней.

## Идея решения
Проверяем вызовы методов (скобки), типы результата и аргументов, а также использование результата метода.

## Решение
```csharp
// Исправленный фрагмент
string s = "abc";
string u = s.ToUpper();                  // скобки при вызове метода
int i = s.IndexOf("b");                  // IndexOf уже возвращает int
string w = s.Substring(1);               // аргумент - целое число
StringBuilder sb = new StringBuilder("x");
string v = sb.ToString();
s = s.Replace("a", "z");                 // результат Replace сохранён
Console.WriteLine(s + u + i + w + v);
```

## Пошаговое объяснение
1. `s.ToUpper` и `sb.ToString` без скобок — это группа методов, а не вызов; присвоить её строке нельзя (`CS0428`, два случая).
2. `s.IndexOf("b").Length` — `IndexOf` возвращает `int`, у `int` нет члена `Length` (`CS1061`).
3. `s.Substring("1")` — параметр метода целый, строка не подходит (`CS1503`).
4. `s.Replace("a", "z");` компилируется без предупреждений, но возвращаемое значение отбрасывается — строка `s` остаётся прежней. Это опаснее ошибки компиляции: программа работает, но не делает нужного.
5. Исправление: сохранять результат `s = s.Replace(...)`.

## Результат
Коды: CS0428 (×2), CS1061, CS1503; пятое нарушение — отброшенный результат Replace.
