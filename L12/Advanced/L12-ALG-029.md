# L12-ALG-029. Предсказание результатов сравнения

**Тема:** Л12 — Методы работы со строками. Класс StringBuilder

## Условие
Не запуская программу, предсказать значение каждого из шести выражений:

```
string.Compare("abc", "ABC", StringComparison.Ordinal)
string.Compare("abc", "ABC", StringComparison.OrdinalIgnoreCase)
"abc".Equals("ABC")
"abc".Equals("ABC", StringComparison.OrdinalIgnoreCase)
string.Compare("a", "b", StringComparison.Ordinal)
string.Compare("b", "a", StringComparison.Ordinal)
```

Затем проверить запуском. Для тех выражений, где предсказание не совпало, объяснить причину. Отдельно ответить: почему первое выражение даёт не единицу?

## Ожидаемый результат
Получено `32`, `0`, `False`, `True`, −1 и `1`; объяснено, что `Compare` возвращает величину, у которой значим только знак, и что 32 — разность кодов символов `'a'` и `'A'`.
