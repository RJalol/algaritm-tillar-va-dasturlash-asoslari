# L12-ALG-025. Проверка анаграммы

**Тема:** Л12 — Методы работы со строками. Класс StringBuilder

## Условие
Написать программу, которая определяет, составлены ли два слова из одних и тех же букв в разном порядке. Регистр не учитывать — привести оба слова к нижнему регистру методом `ToLower`. Использовать массив из 26 счётчиков (тема №10): для первого слова счётчики увеличиваются, для второго — уменьшаются; слова являются анаграммами, если все счётчики обнулились. Метод `Array.Sort` не использовать. Проверить на парах `"listen"`/`"silent"`, `"Listen"`/`"Silent"` и `"hello"`/`"world"`.

## Ожидаемый результат
Получено `True`, `True` и `False`; перед подсчётом выполнена проверка равенства длин, отсекающая заведомо неподходящие пары.
