# L12-ALG-051. Шесть нарушений в одном фрагменте

**Тема:** Л12 — Объявление строк и работа с ними. Форматирование строк. Стандартные методы обработки строковых данных

## Условие
Дан код:

```
string s = "abc";
s[0] = 'X';
int n = s.Length();
char c = s;
string k = 'x';
string bad = "C:\Users";
Console.WriteLine($ "значение {n}");
```

Найти все нарушения и назвать код ошибки компилятора для каждого. Разнести их по трём группам: нарушение неизменяемости; несовпадение типов; лексическая ошибка записи. Привести исправленный фрагмент.

## Ожидаемый результат
Названы коды `CS0200`, `CS1955`, `CS0029` (дважды — в обе стороны между `char` и `string`), `CS1009` и `CS1056`; группы разнесены верно, приведён компилирующийся вариант.
