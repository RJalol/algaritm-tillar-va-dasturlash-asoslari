# Разбор решения. L12-ALG-031. Длина строки и её крайние символы

## Условие
Написать программу, которая объявляет строку со значением `"Программирование"` и выводит её саму, её длину, первый символ и последний символ. Индекс последнего символа получить через свойство `Length`, а не записывать числом.

## Ожидаемый результат
Выведены строка, длина `16`, первый символ `П` и последний символ `е`; индекс последнего символа записан выражением `Length - 1`.

## Разбор условия
**Дано:** строка `"Программирование"`.
**Требуется:** вывести строку, её длину, первый и последний символы; индекс последнего получить через `Length`.

## Теоретическая справка
Строка — последовательность символов `char`, к которой можно обращаться по индексу `s[i]` (только чтение). Индексы идут от 0 до `Length - 1`.

Индексатор строки возвращает `char`, поэтому `Console.WriteLine(word[0])` выводит символ, а не число. Попытка обращения к индексу `Length` и далее — `IndexOutOfRangeException`.

## Идея решения
Строка — последовательность символов с индексацией с нуля. Длину получаем свойством `Length`, последний символ — по индексу `Length - 1`.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        string word = "Программирование";

        Console.WriteLine(word);
        Console.WriteLine(word.Length);
        Console.WriteLine(word[0]);
        Console.WriteLine(word[word.Length - 1]);
    }
}
```

## Пошаговое объяснение
1. `word.Length` равно 16 — число символов.
2. `word[0]` — первый символ `П` (индексы начинаются с 0).
3. Последний индекс равен `Length - 1 = 15`, символ `е`.
4. Запись `Length - 1` вместо числа 15 работает для любой строки.

## Трассировка и проверка
| Выражение | Значение |
|---|---|
| `word` | Программирование |
| `word.Length` | 16 |
| `word[0]` | П |
| `word[word.Length - 1]` | е (индекс 15) |

Количество букв: П-р-о-г-р-а-м-м-и-р-о-в-а-н-и-е = 16.

## Результат
Программирование / 16 / П / е

## Типичные ошибки
- Использовать `word[16]` — выход за границу.
- Записать индекс последнего символа числом 15 вместо `Length - 1`.
- Пытаться записать `word[0] = 'п'` (`CS0200`).
- Считать длину с единицы.
