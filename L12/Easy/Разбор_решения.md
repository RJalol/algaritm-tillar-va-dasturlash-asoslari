# Разбор решения. L12-ALG-001. Регистр и длина

## Условие
Написать программу, которая объявляет строку `"Turbo Pascal"` и выводит её в верхнем регистре, в нижнем регистре, а затем ещё раз в исходном виде вместе с длиной. Объяснить в комментарии, почему третий вывод не изменился.

## Ожидаемый результат
Выведено `TURBO PASCAL`, `turbo pascal`, затем `Turbo Pascal` и длина `12`; в комментарии указано, что методы возвращают новую строку и не изменяют исходную.

## Разбор условия
**Дано:** строка `"Turbo Pascal"`.
**Требуется:** вывести её в верхнем и нижнем регистре, затем в исходном виде вместе с длиной; объяснить в комментарии, почему третий вывод не изменился.

## Теоретическая справка
**Неизменяемость строк.** Объект `string` в .NET нельзя изменить после создания. Все методы, «изменяющие» строку (`ToUpper`, `ToLower`, `Trim`, `Replace`, `Substring`, `Insert`, `Remove`), **возвращают новую строку**, а исходная остаётся прежней.

Следствие: результат метода необходимо сохранить или использовать. Оператор `s.ToUpper();` без присваивания компилируется, но ничего не меняет.

Длина строки — свойство `Length` (без скобок), считает все символы, включая пробелы.

## Идея решения
`ToUpper()` и `ToLower()` возвращают *новую* строку; исходная строка неизменяема.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        string s = "Turbo Pascal";

        Console.WriteLine(s.ToUpper());
        Console.WriteLine(s.ToLower());
        Console.WriteLine(s + " " + s.Length);

        // Третий вывод не изменился: методы строк не меняют исходную строку,
        // а возвращают новую. Результат вызова нужно сохранять или выводить.
    }
}
```

## Пошаговое объяснение
1. `s.ToUpper()` создаёт новую строку `TURBO PASCAL`; `s` остаётся прежней.
2. То же с `ToLower()`.
3. Выводим `s` ещё раз с длиной `Length` = 12 (включая пробел) — строка исходная.
4. Причина — неизменяемость (immutability) строк в .NET.

## Трассировка и проверка
| Выражение | Значение |
|---|---|
| `s.ToUpper()` | `TURBO PASCAL` |
| `s.ToLower()` | `turbo pascal` |
| `s` (после обоих вызовов) | `Turbo Pascal` |
| `s.Length` | 12 (5 + 1 + 6) |

Если бы строки изменялись на месте, третий вывод показал бы последнее преобразованное значение.

## Результат
TURBO PASCAL / turbo pascal / Turbo Pascal 12

## Типичные ошибки
- Писать `s.ToUpper();` и ожидать изменения `s`.
- Вызывать `Length()` со скобками (`CS1955`): это свойство.
- Не учитывать пробел при подсчёте длины.
- Использовать `ToUpper()` для сравнения без учёта регистра вместо `StringComparison.OrdinalIgnoreCase`.

## Задания для закрепления
- Вывести строку с заглавной первой буквой каждого слова.
- Сравнить две строки без учёта регистра двумя способами.
- Обрезать пробелы по краям методом `Trim` и убедиться, что исходная строка не изменилась.
