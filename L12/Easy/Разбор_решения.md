# Разбор решения. L12-ALG-001. Регистр и длина

## Условие
Написать программу, которая объявляет строку `"Turbo Pascal"` и выводит её в верхнем регистре, в нижнем регистре, а затем ещё раз в исходном виде вместе с длиной. Объяснить в комментарии, почему третий вывод не изменился.

## Ожидаемый результат
Выведено `TURBO PASCAL`, `turbo pascal`, затем `Turbo Pascal` и длина `12`; в комментарии указано, что методы возвращают новую строку и не изменяют исходную.

## Идея решения
`ToUpper()` и `ToLower()` возвращают *новую* строку; исходная строка неизменяема.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        string s = "Turbo Pascal";

        Console.WriteLine(s.ToUpper());
        Console.WriteLine(s.ToLower());
        Console.WriteLine(s + " " + s.Length);

        // Третий вывод не изменился: методы строк не меняют исходную строку,
        // а возвращают новую. Результат вызова нужно сохранять или выводить.
    }
}
```

## Пошаговое объяснение
1. `s.ToUpper()` создаёт новую строку `TURBO PASCAL`; `s` остаётся прежней.
2. То же с `ToLower()`.
3. Выводим `s` ещё раз с длиной `Length` = 12 (включая пробел) — строка исходная.
4. Причина — неизменяемость (immutability) строк в .NET.

## Результат
TURBO PASCAL / turbo pascal / Turbo Pascal 12
