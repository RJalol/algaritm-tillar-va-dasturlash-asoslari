# L12-ALG-005. Разбиение и вывод частей

**Тема:** Л12 — Методы работы со строками. Класс StringBuilder

## Условие
Написать программу, которая разбивает строку `"Азиз;Дилноза;Рустам"` по символу «точка с запятой», выводит число полученных частей и каждую часть с порядковым номером, а затем собирает их обратно в одну строку с разделителем `" | "`.

## Ожидаемый результат
Выведено `3`, три пронумерованные части и строка `Азиз | Дилноза | Рустам`; сборка выполнена методом `string.Join`.
