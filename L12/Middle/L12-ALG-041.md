# L12-ALG-041. Подсчёт слов

**Тема:** Л12 — Объявление строк и работа с ними. Форматирование строк. Стандартные методы обработки строковых данных

## Условие
Написать программу, которая подсчитывает число слов в строке `"Алгоритмические языки и программирование"`, считая словом любую последовательность символов между пробелами. Метод `Split` не использовать. Программа должна давать верный ответ и при нескольких пробелах подряд.

## Ожидаемый результат
Выведено `4`; счётчик увеличивается только при переходе от пробела к непробельному символу, для чего заведён логический признак «находимся внутри слова».
