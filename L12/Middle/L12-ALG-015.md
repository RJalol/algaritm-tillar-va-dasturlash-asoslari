# L12-ALG-015. Изменение содержимого StringBuilder

**Тема:** Л12 — Методы работы со строками. Класс StringBuilder

## Условие
Написать программу, которая создаёт `StringBuilder` со значением `"Rat: the ideal pet"`, заменяет первый символ на `'C'` присваиванием по индексу, вставляет в начало строку `">> "`, затем очищает объект методом `Clear` и выводит длину после очистки. Объяснить в комментарии, какое из выполненных действий невозможно для типа `string`.

## Ожидаемый результат
Выведено `>> Cat: the ideal pet`, затем `0`; в комментарии указано, что присваивание отдельному символу для строки даёт ошибку `CS0200`.
