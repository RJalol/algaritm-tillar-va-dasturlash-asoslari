# L12-ALG-018. Выход за границы при извлечении

**Тема:** Л12 — Методы работы со строками. Класс StringBuilder

## Условие
Дан код:

```
string t = "Visual Studio";
Console.WriteLine(t.Substring(20));
```

Определить, скомпилируется ли фрагмент, и назвать возникающее исключение. Переписать фрагмент так, чтобы он выводил сообщение о невозможности извлечения вместо аварийного завершения.

## Ожидаемый результат
Фрагмент компилируется, но во время выполнения возбуждает `ArgumentOutOfRangeException`; в исправленном варианте перед вызовом проверяется, что индекс меньше `Length`.
