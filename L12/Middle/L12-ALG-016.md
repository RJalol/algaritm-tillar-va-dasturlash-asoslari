# L12-ALG-016. Пропущенные скобки вызова

**Тема:** Л12 — Методы работы со строками. Класс StringBuilder

## Условие
Дан код:

```
string s = "abc";
string u = s.ToUpper;
Console.WriteLine(u);
```

Объяснить, почему фрагмент не компилируется, назвать код ошибки и привести исправление. Указать, чем эта ошибка отличается от ошибки в записи `s.Length()`.

## Ожидаемый результат
Назван код `CS0428`; объяснено, что `ToUpper` — метод и требует круглых скобок, тогда как `Length` — свойство и скобок не допускает (`CS1955`).
