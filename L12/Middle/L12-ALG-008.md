# L12-ALG-008. Инициалы

**Тема:** Л12 — Методы работы со строками. Класс StringBuilder

## Условие
Написать программу, которая из строки `"Рахимов Азиз Каримович"` получает запись вида «Фамилия И.О.». Строку разбить методом `Split`, первые буквы имени и отчества взять обращением по индексу.

## Ожидаемый результат
Выведено `Рахимов А.К.`; первые буквы получены выражениями вида `parts[1][0]`.
