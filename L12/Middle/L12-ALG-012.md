# L12-ALG-012. Проверка ввода на пустоту

**Тема:** Л12 — Объявление строк и работа с ними. Форматирование строк. Стандартные методы обработки строковых данных

## Условие
Написать программу, которая для четырёх значений — `null`, пустой строки, строки из трёх пробелов и строки `"текст"` — выводит результаты `string.IsNullOrEmpty` и `string.IsNullOrWhiteSpace`. Объяснить в комментарии, для какого из четырёх значений результаты различаются и почему для этого случая нужен второй метод.

## Ожидаемый результат
Восемь логических значений; различие проявляется только на строке из пробелов — `False` у первого метода и `True` у второго.
