# L12-ALG-049. Предсказание вывода: порядок операций

**Тема:** Л12 — Объявление строк и работа с ними. Форматирование строк. Стандартные методы обработки строковых данных

## Условие
Не запуская программу, предсказать вывод каждой из четырёх строк:

```
Console.WriteLine("Сумма: " + 2 + 3);
Console.WriteLine("Сумма: " + (2 + 3));
Console.WriteLine('2' + '3');
Console.WriteLine("" + '2' + '3');
```

Затем запустить и объяснить каждый результат.

## Ожидаемый результат
Получено `Сумма: 23`, `Сумма: 5`, `101` и `23`; объяснено, что операции одного приоритета выполняются слева направо, а для двух символов `+` означает сложение их кодов.
