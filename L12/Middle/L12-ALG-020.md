# L12-ALG-020. Поиск отсутствующей подстроки

**Тема:** Л12 — Методы работы со строками. Класс StringBuilder

## Условие
Дан код:

```
string s = "Алгоритмические языки";
int pos = s.IndexOf("Python");
Console.WriteLine(s.Substring(pos));
```

Не запуская программу, предсказать, что произойдёт. Назвать значение переменной `pos` и возникающее исключение, затем проверить запуском и переписать фрагмент с проверкой.

## Ожидаемый результат
Значение `pos` равно −1, вызов `Substring` возбуждает `ArgumentOutOfRangeException`; в исправленном варианте извлечение выполняется только при `pos != -1`.
