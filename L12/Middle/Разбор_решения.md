# Разбор решения. L12-ALG-006. Методы поиска на одной строке

## Условие
Написать программу, которая для строки `"программа программиста"` выводит: индекс первого вхождения подстроки `"программ"`, индекс последнего её вхождения, результат проверки `Contains("грамм")` и длину строки. Объяснить в комментарии, почему индекс последнего вхождения не равен индексу первого.

## Ожидаемый результат
Выведено `0`, `10`, `True` и `22`; в комментарии указано, что подстрока встречается дважды.

## Идея решения
`IndexOf` возвращает индекс первого вхождения, `LastIndexOf` — последнего; `Contains` проверяет наличие подстроки.

## Решение
```csharp
using System;

class Program
{
    static void Main()
    {
        string text = "программа программиста";

        Console.WriteLine(text.IndexOf("программ"));
        Console.WriteLine(text.LastIndexOf("программ"));
        Console.WriteLine(text.Contains("грамм"));
        Console.WriteLine(text.Length);

        // Подстрока «программ» встречается дважды: с индекса 0 и с индекса 10,
        // поэтому индекс первого и последнего вхождения различаются.
    }
}
```

## Пошаговое объяснение
1. Первое вхождение «программ» — в самом начале, индекс 0.
2. Слово «программа» занимает 9 символов (0–8), пробел — индекс 9, второе слово начинается с индекса 10 — это последнее вхождение.
3. `Contains("грамм")` истинно: «грамм» входит в «программа».
4. Длина: 9 + 1 + 12 = 22.

## Результат
0 / 10 / True / 22
