# Разбор решения. S01-ALG-006. Визитка проекта

## Условие
Написать программу, выводящую пять строк текста, представляющих «визитку» учебного проекта (например: название, автор, курс, тема, дата). Перед каждым вызовом `Console.WriteLine` должен стоять отдельный однострочный комментарий, поясняющий, что именно выводится этой строкой.

## Ожидаемый результат
Пять строк текста на экране; в коде — ровно пять комментариев, каждый непосредственно перед «своим» вызовом.

## Разбор условия
**Дано:** сведения о проекте.
**Требуется:** вывести пять строк «визитки», перед каждым `Console.WriteLine` — отдельный однострочный комментарий.

## Теоретическая справка
**Комментарии** не влияют на выполнение и нужны читателю кода.

| Вид | Запись |
|---|---|
| однострочный | `// текст` |
| многострочный | `/* текст */` |
| документирующий | `/// <summary>…</summary>` |

Хороший комментарий отвечает на вопрос «зачем», а не повторяет код дословно. Ненужные комментарии устаревают и вводят в заблуждение.

## Идея решения
Нужно пять вызовов `Console.WriteLine`, перед каждым — однострочный комментарий `//`, поясняющий смысл выводимой строки. Комментарии компилятор игнорирует, они нужны читателю кода.

## Решение
```csharp
using System;

namespace ProjectCard
{
    class Program
    {
        static void Main(string[] args)
        {
            // Название проекта
            Console.WriteLine("Проект: Учёт успеваемости студентов");
            // Автор проекта
            Console.WriteLine("Автор: Азиз Каримов");
            // Курс обучения
            Console.WriteLine("Курс: Алгоритмические языки и программирование");
            // Тема работы
            Console.WriteLine("Тема: Структура программы на C#");
            // Дата выполнения
            Console.WriteLine("Дата: 13.10.2026");
        }
    }
}
```

## Пошаговое объяснение
1. Пишем стандартный каркас программы (`using`, `namespace`, `class`, `Main`).
2. Для каждой из пяти строк визитки добавляем комментарий `// ...` непосредственно над соответствующим `Console.WriteLine`.
3. Комментарий описывает, *что* выводится (назначение строки), а не повторяет код.
4. Проверяем: в теле `Main` ровно пять комментариев и пять вызовов вывода, они чередуются.

## Трассировка и проверка
| Строка | Комментарий перед ней |
|---|---|
| 1 | название проекта |
| 2 | автор |
| 3 | курс |
| 4 | тема |
| 5 | дата |

Проверка: ровно пять комментариев `//` и пять вызовов `WriteLine`, чередующихся.

## Результат
На экране пять строк визитки; в коде пять комментариев, каждый стоит прямо перед своей строкой вывода.

## Типичные ошибки
- Помещать комментарий после вызова, а не перед ним.
- Писать комментарии вроде «вывод строки» вместо пояснения смысла.
- Оставлять закомментированный старый код.
- Смешивать вид комментариев без необходимости.

## Задания для закрепления
- Добавить документирующий комментарий к `Main`.
- Записать визитку одним вызовом `Console.WriteLine` с многострочной строкой.
- Заменить даты на `DateTime.Today`.
