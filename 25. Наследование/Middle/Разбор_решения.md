# Разбор решения. L25 · Задание II · №1. Иерархия транспортных средств

## Условие
Построить иерархию: «транспортное средство» (масса, число колёс, метод описания) — «легковой автомобиль» (число мест) — «грузовой автомобиль» (грузоподъёмность). Создать массив базового типа из шести объектов разных классов и вывести описание каждого вместе с фактическим типом.

## Ожидаемый результат
Все шесть объектов хранятся в одном массиве; описание выведено унаследованным методом, а фактический тип — средствами получения сведений о типе.

## Разбор условия
**Дано:** иерархия «транспорт → легковой → грузовой».
**Требуется:** массив базового типа из шести объектов разных классов; вывести описание и фактический тип каждого.

## Теоретическая справка
**Совместимость типов в иерархии:** ссылке базового типа можно присвоить объект любого производного (восходящее преобразование выполняется неявно). Поэтому один массив `Vehicle[]` способен хранить `Vehicle`, `Car`, `Truck`.

Различайте:

- **статический тип** переменной (известен компилятору): `Vehicle`;
- **динамический (фактический) тип** объекта: `GetType()`.

Через ссылку базового типа доступны только члены базового класса. Доступ к собственным членам производного требует приведения (`as`, `is`).

## Идея решения
Иерархия Vehicle → Car → Truck. Благодаря совместимости ссылки базового типа с объектами производных классов все шесть объектов хранятся в одном массиве `Vehicle[]`; фактический тип выясняем через `GetType()`.

## Решение
```csharp
using System;

class Vehicle
{
    public double Mass;
    public int Wheels;

    public Vehicle(double mass, int wheels) { Mass = mass; Wheels = wheels; }

    public string Describe() => $"масса {Mass} кг, колёс {Wheels}";
}

class Car : Vehicle
{
    public int Seats;
    public Car(double mass, int seats) : base(mass, 4) { Seats = seats; }
}

class Truck : Car
{
    public double Capacity;
    public Truck(double mass, int seats, double capacity) : base(mass, seats) { Capacity = capacity; }
}

class Program
{
    static void Main()
    {
        Vehicle[] fleet =
        {
            new Vehicle(150, 2),
            new Vehicle(800, 3),
            new Car(1200, 5),
            new Car(1500, 7),
            new Truck(5000, 3, 8000),
            new Truck(7500, 2, 12000)
        };

        foreach (Vehicle v in fleet)
            Console.WriteLine(v.GetType().Name + ": " + v.Describe());
    }
}
```

## Пошаговое объяснение
1. `Car` наследует `Vehicle` и задаёт число колёс 4 через `base(mass, 4)`; `Truck` наследует `Car`.
2. Массив базового типа может содержать объекты любого производного класса.
3. `Describe()` унаследован и доступен через ссылку `Vehicle`.
4. `GetType().Name` возвращает фактический класс объекта (Vehicle, Car или Truck), а не тип переменной.

## Трассировка и проверка
| Элемент | Статический тип | Фактический тип |
|--:|---|---|
| 0, 1 | Vehicle | Vehicle |
| 2, 3 | Vehicle | Car |
| 4, 5 | Vehicle | Truck |

`Describe()` унаследован всеми классами и доступен через `Vehicle`. Число колёс у `Car` и `Truck` задаётся через `base(mass, 4)`.

## Результат
Шесть строк вида «Car: масса 1200 кг, колёс 4», каждая с фактическим типом объекта.

## Типичные ошибки
- Пытаться вызвать `Capacity` (член `Truck`) через ссылку `Vehicle` без приведения.
- Путать `GetType()` и `typeof(Vehicle)`.
- Нисходящее приведение без проверки (`InvalidCastException`).
- Строить иерархию из сущностей без отношения «является».
