# Разбор решения. L47 · Задание III · №1. Каркас куба

## Условие
Нарисовать каркасный куб в перспективной проекции: вершины в трёх измерениях, матрица проекции, ребра линиями `Graphics`.

## Ожидаемый результат
Куб отображается в перспективе.

## Разбор условия
**Дано:** вершины куба.
**Требуется:** нарисовать каркасный куб в перспективной проекции средствами GDI+.

## Теоретическая справка
**Трёхмерная графика на плоскости** выполняется в три этапа:

1. **Модель:** вершины (x, y, z) и рёбра (пары вершин).
2. **Преобразования:** поворот вокруг осей матрицами/формулами:
   - вокруг X: y' = y·cosα − z·sinα, z' = y·sinα + z·cosα;
   - вокруг Y: x' = x·cosβ + z·sinβ, z' = −x·sinβ + z·cosβ.
3. **Проекция:** перспективная — деление на глубину: `k = f / (z + d)`, `px = cx + x·k`, `py = cy − y·k`. Чем дальше точка, тем меньше масштаб.

Рёбра рисуются как отрезки между спроецированными вершинами.

## Идея решения
Вершины куба заданы тремя координатами. Перспективная проекция: точка (x, y, z) при расстоянии до камеры d отображается в (x·f/(z+d), y·f/(z+d)) — чем дальше точка, тем ближе к центру экрана.

## Решение
```csharp
using System;
using System.Drawing;
using System.Windows.Forms;

public class Form1 : Form
{
    private static readonly double[][] V =
    {
        new[]{-1.0,-1,-1}, new[]{ 1.0,-1,-1}, new[]{ 1.0, 1,-1}, new[]{-1.0, 1,-1},
        new[]{-1.0,-1, 1}, new[]{ 1.0,-1, 1}, new[]{ 1.0, 1, 1}, new[]{-1.0, 1, 1}
    };
    private static readonly int[][] Edges =
    {
        new[]{0,1}, new[]{1,2}, new[]{2,3}, new[]{3,0},
        new[]{4,5}, new[]{5,6}, new[]{6,7}, new[]{7,4},
        new[]{0,4}, new[]{1,5}, new[]{2,6}, new[]{3,7}
    };

    public Form1()
    {
        Text = "Куб в перспективе";
        ClientSize = new Size(500, 500);
        DoubleBuffered = true;
    }

    private PointF Project(double x, double y, double z)
    {
        // поворот вокруг осей X и Y, чтобы куб был виден «объёмно»
        double ax = 0.5, ay = 0.7;
        double y1 = y * Math.Cos(ax) - z * Math.Sin(ax);
        double z1 = y * Math.Sin(ax) + z * Math.Cos(ax);
        double x2 = x * Math.Cos(ay) + z1 * Math.Sin(ay);
        double z2 = -x * Math.Sin(ay) + z1 * Math.Cos(ay);

        double d = 4, f = 250;                                   // расстояние до камеры и «фокус»
        double k = f / (z2 + d);
        return new PointF((float)(ClientSize.Width / 2 + x2 * k), (float)(ClientSize.Height / 2 - y1 * k));
    }

    protected override void OnPaint(PaintEventArgs e)
    {
        base.OnPaint(e);
        e.Graphics.SmoothingMode = System.Drawing.Drawing2D.SmoothingMode.AntiAlias;
        using var pen = new Pen(Color.Black, 2);
        foreach (var edge in Edges)
        {
            var a = V[edge[0]]; var b = V[edge[1]];
            e.Graphics.DrawLine(pen, Project(a[0], a[1], a[2]), Project(b[0], b[1], b[2]));
        }
    }
}
```

## Пошаговое объяснение
1. Куб задан 8 вершинами с координатами ±1 и 12 рёбрами (пары индексов вершин).
2. Сначала куб поворачивается вокруг осей X и Y — иначе при проекции спереди мы увидели бы просто квадрат.
3. Перспективная проекция делит координаты на `z + d`: дальние точки уменьшаются, поэтому куб выглядит объёмным.
4. Полученные координаты смещаются в центр окна; ось Y экрана направлена вниз, поэтому знак меняется.
5. Для анимации достаточно менять углы по таймеру и вызывать `Invalidate()`.

## Трассировка и проверка
Для вершины (1; 1; 1) при α = 0,5, β = 0,7, d = 4, f = 250 вычисляется последовательность: поворот → глубина z″ → коэффициент k = 250/(z″ + 4) → пиксельные координаты.

| Проверка | Результат |
|---|---|
| вершин | 8 |
| рёбер | 12 |
| параллельные рёбра | сходятся к точке схода |

Для анимации углы увеличивают по таймеру и вызывают `Invalidate()`.

## Результат
В центре окна нарисован каркасный куб в перспективной проекции.

## Типичные ошибки
- Делить на ноль, когда `z + d = 0` (камера внутри модели).
- Перепутать порядок поворотов (результат зависит от порядка).
- Не инвертировать ось Y при переходе к экранным координатам.
- Использовать градусы вместо радиан.
