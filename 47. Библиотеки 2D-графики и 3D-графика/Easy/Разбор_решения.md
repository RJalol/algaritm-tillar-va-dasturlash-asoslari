# Разбор решения. L47 · Задание I · №1. Подключение библиотеки

## Условие
Подключить через NuGet одну из библиотек построения двумерной графики (ScottPlot или OxyPlot) и вывести пустой график на форме.

## Ожидаемый результат
Элемент отображается на форме; в списке зависимостей проекта — пакет.

## Разбор условия
**Дано:** пустой проект Windows Forms.
**Требуется:** подключить через NuGet библиотеку построения графиков и вывести пустой график.

## Теоретическая справка
**NuGet** — менеджер пакетов .NET: библиотеки подключаются командой `Install-Package` или через окно «Управление пакетами NuGet». Пакет появляется в зависимостях проекта (`.csproj`, `PackageReference`), версия фиксируется.

Популярные библиотеки двумерной графики и графиков: **ScottPlot** (`ScottPlot.WinForms`), **OxyPlot** (`OxyPlot.WindowsForms`). Общая схема: на форму добавляется элемент (`FormsPlot`, `PlotView`), данные передаются через модель, затем вызывается обновление.

Выбор библиотеки: открытая лицензия, простота API, документация, поддержка нужной платформы (WinForms, WPF, Avalonia).

## Идея решения
Библиотеки ScottPlot и OxyPlot устанавливаются как NuGet-пакеты. Ниже — вариант на ScottPlot 5 (пакет `ScottPlot.WinForms`): элемент `FormsPlot` размещается на форме, а график настраивается через `Plot`.

## Решение
```csharp
// Консоль диспетчера пакетов:  Install-Package ScottPlot.WinForms
using System;
using System.Windows.Forms;
using ScottPlot.WinForms;

public class Form1 : Form
{
    public Form1()
    {
        Text = "ScottPlot";
        Width = 640; Height = 420;

        var plot = new FormsPlot { Dock = DockStyle.Fill };
        Controls.Add(plot);

        plot.Refresh();       // отрисовать пустой график
    }
}
```

## Пошаговое объяснение
1. Подключаем пакет через менеджер NuGet (в Visual Studio: «Управление пакетами NuGet»); он появляется в зависимостях проекта.
2. Элемент `FormsPlot` — готовый графический элемент; свойство `Dock = Fill` растягивает его на форму.
3. Метод `Refresh()` заставляет элемент перерисоваться; пока данных нет, отображаются пустые оси.
4. В OxyPlot аналогично используется элемент `PlotView` и объект `PlotModel`; выбор библиотеки определяется вкусом и задачей.

## Трассировка и проверка
| Шаг | Проверка |
|---|---|
| установка пакета | в зависимостях проекта появился ScottPlot |
| добавление `FormsPlot` на форму | элемент виден, `Dock = Fill` |
| `plot.Refresh()` | отрисованы пустые оси |

Версии API разных мажорных версий библиотеки заметно различаются, поэтому в документации сверяют используемую версию.

## Результат
На форме отображается пустой график с осями; в списке зависимостей проекта присутствует пакет ScottPlot.

## Типичные ошибки
- Устанавливать пакет не для той платформы (WinForms/WPF).
- Смешивать версии пакета и примеры из документации другой версии.
- Забыть `Refresh()` после изменения данных.
- Не закрепить версию пакета.
