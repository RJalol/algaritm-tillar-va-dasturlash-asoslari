# Разбор решения. S01-ALG-001. Программа приветствия

## Условие
Написать консольную программу на C#, которая выводит на экран ровно одну строку текста: `Добро пожаловать в мир C#!`. Программа должна содержать директиву `using System;`, объявление пространства имён, класс-контейнер и корректную точку входа `Main`; имя пространства имён и класса — на усмотрение студента.

## Ожидаемый результат
На экране выводится ровно одна строка: `Добро пожаловать в мир C#!`.

## Разбор условия
**Дано:** среда с установленным .NET SDK.
**Требуется:** консольная программа C#, выводящая одну строку; должны присутствовать `using System;`, пространство имён, класс-контейнер и точка входа `Main`.

## Теоретическая справка
Минимальная консольная программа на C# состоит из:

| Элемент | Назначение |
|---|---|
| `using System;` | подключает пространство имён с классом `Console` |
| `namespace Greeting` | группирует типы проекта |
| `class Program` | контейнер кода (в C# всё находится в классах) |
| `static void Main(string[] args)` | точка входа: отсюда начинается выполнение |

С C# 9 допустимы **операторы верхнего уровня** (код без явного `Main`), но структура с классом остаётся основой для понимания.

Компиляция: исходный текст → промежуточный код IL → выполнение средой CLR (JIT-компиляция в машинный код).

## Идея решения
Минимальная консольная программа C#: директива `using System;`, пространство имён, класс и точка входа `Main`, внутри которой один вызов `Console.WriteLine`.

## Решение
```csharp
using System;

namespace Greeting
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Добро пожаловать в мир C#!");
        }
    }
}
```

## Пошаговое объяснение
1. `using System;` подключает пространство имён `System`, где находится класс `Console`.
2. `namespace Greeting` группирует типы проекта; имя выбрано произвольно.
3. `class Program` — класс-контейнер: в C# любой код находится внутри класса.
4. `static void Main(string[] args)` — точка входа: с неё начинается выполнение.
5. `Console.WriteLine(...)` выводит строку и переводит курсор на новую строку; оператор завершается точкой с запятой.

Вывод: «Добро пожаловать в мир C#!» — ровно одна строка (метод `WriteLine` добавляет перевод строки).

## Результат
На экране ровно одна строка: Добро пожаловать в мир C#!

## Типичные ошибки
- Забыть точку с запятой в конце оператора.
- Написать `main` со строчной буквы — точка входа не будет найдена.
- Не подключить `System` и писать `Console` без полного имени.
- Не закрыть фигурные скобки блоков.

## Задания для закрепления
- Вывести две строки разными вызовами.
- Использовать оператор верхнего уровня вместо класса и `Main`.
- Посмотреть IL-код сборки утилитой `ildasm` или `ILSpy`.
