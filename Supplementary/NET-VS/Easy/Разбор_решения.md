# Разбор решения. L02-ALG-001. Программа приветствия

## Условие
Написать консольную программу на C#, которая выводит на экран ровно одну строку текста: `Добро пожаловать в мир C#!`. Программа должна содержать директиву `using System;`, объявление пространства имён, класс-контейнер и корректную точку входа `Main`; имя пространства имён и класса — на усмотрение студента.

## Ожидаемый результат
На экране выводится ровно одна строка: `Добро пожаловать в мир C#!`.

## Идея решения
Минимальная консольная программа C#: директива `using System;`, пространство имён, класс и точка входа `Main`, внутри которой один вызов `Console.WriteLine`.

## Решение
```csharp
using System;

namespace Greeting
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Добро пожаловать в мир C#!");
        }
    }
}
```

## Пошаговое объяснение
1. `using System;` подключает пространство имён `System`, где находится класс `Console`.
2. `namespace Greeting` группирует типы проекта; имя выбрано произвольно.
3. `class Program` — класс-контейнер: в C# любой код находится внутри класса.
4. `static void Main(string[] args)` — точка входа: с неё начинается выполнение.
5. `Console.WriteLine(...)` выводит строку и переводит курсор на новую строку; оператор завершается точкой с запятой.

## Результат
На экране ровно одна строка: Добро пожаловать в мир C#!
