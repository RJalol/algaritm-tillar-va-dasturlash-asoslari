# L02-ALG-017. Перенос линейного алгоритма с собственным именем класса

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Используя фрагмент линейного алгоритма из темы №1, написать полную программу, в которой класс-контейнер называется не `Program`, а любым другим корректным именем по выбору студента.

## Ожидаемый результат
Программа корректно компилируется и выполняется при имени класса, отличном от `Program`, выводя вычисленное среднее арифметическое.
