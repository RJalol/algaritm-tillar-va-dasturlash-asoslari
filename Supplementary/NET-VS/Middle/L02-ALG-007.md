# L02-ALG-007. Табличная «шапка»

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Написать программу, которая выводит строку-разделитель из символов `-` (например, 20 дефисов), затем строку с заголовком (например, `Список тем`), затем снова строку-разделитель, с комментарием перед каждой строкой, поясняющим её роль.

## Ожидаемый результат
```
--------------------
Список тем
--------------------
```
