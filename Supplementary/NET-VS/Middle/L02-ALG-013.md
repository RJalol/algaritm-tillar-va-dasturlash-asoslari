# L02-ALG-013. Перенос линейного алгоритма (среднее двух чисел)

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Используя фрагмент линейного алгоритма из темы №1 (вычисление среднего арифметического двух чисел), написать полную программу с пространством имён `AverageCalculator`. Значения чисел изменить на любые другие, отличные от использованных в лекции.

## Ожидаемый результат
Программа с корректной полной структурой (`using`/`namespace AverageCalculator`/`class`/`Main`), выводящая вычисленное среднее арифметическое выбранных чисел.
