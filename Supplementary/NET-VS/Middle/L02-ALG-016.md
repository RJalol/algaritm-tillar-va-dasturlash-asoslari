# L02-ALG-016. Объединение линейного и разветвляющегося алгоритмов

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Написать одну программу, в методе `Main` которой последовательно выполняются два фрагмента из темы №1: сначала вычисление среднего арифметического двух чисел, затем определение большего из двух (возможно, других) чисел. Между блоками — комментарий, отделяющий один от другого.

## Ожидаемый результат
Два результата (среднее и большее число), каждый на отдельной строке; между блоками кода — ровно один разделяющий комментарий.
