# L02-ALG-009. Три блока с разделяющими пустыми строками

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Написать программу, выводящую три смысловых блока текста (по одной строке каждый), между которыми вставлены пустые строки (`Console.WriteLine()` без аргументов). Перед каждым блоком — комментарий, поясняющий его содержание.

## Ожидаемый результат
Три строки текста, разделённые пустыми строками, например:
```
Блок 1: введение

Блок 2: основная часть

Блок 3: заключение
```
