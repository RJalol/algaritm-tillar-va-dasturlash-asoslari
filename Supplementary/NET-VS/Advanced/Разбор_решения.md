# Разбор решения. L02-ALG-021. Точка с запятой и незакрытая скобка одновременно

## Условие
Дан код:
```
using System;

namespace DemoApp
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Первая строка")
            Console.WriteLine("Вторая строка");
        }
    
}
```
Найти оба структурных нарушения в этом коде и обосновать каждое отдельно.

## Ожидаемый результат
Два независимых нарушения, каждое с отдельным обоснованием со ссылкой на конкретное место в коде.

## Идея решения
Анализируем код как компилятор: проверяем завершённость операторов (`;`) и парность фигурных скобок.

## Решение
```csharp
// Исправленный вариант
using System;

namespace DemoApp
{
    class Program
    {
        static void Main(string[] args)
        {
            Console.WriteLine("Первая строка");   // добавлена ;
            Console.WriteLine("Вторая строка");
        }
    }                                           // добавлена закрывающая }
}
```

## Пошаговое объяснение
1. Нарушение 1: после `Console.WriteLine("Первая строка")` нет точки с запятой. Оператор в C# обязан заканчиваться `;`, иначе компилятор не понимает, где кончается инструкция (ошибка `CS1002: ; expected`).
2. Нарушение 2: открыто три блока — `namespace`, `class`, метод `Main`, а закрыто только два. Закрывающая скобка `}` после метода закрывает метод, ещё одна закрывает класс, но для `namespace` скобки не хватает (ошибка `CS1513: } expected`).
3. Нарушения независимы: первое относится к синтаксису оператора, второе — к структуре вложенных блоков.
4. Исправление: добавляем `;` и недостающую `}` — тем самым код становится структурно корректным.

## Результат
Найдены два независимых нарушения: пропущенная `;` в первой строке вывода и отсутствующая закрывающая скобка блока `namespace`.
