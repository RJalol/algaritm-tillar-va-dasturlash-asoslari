# L02-ALG-026. Перемещение using внутрь класса

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Объяснить (без написания кода), допустимо ли переместить строку `using System;` из начала файла внутрь тела класса `Program`, разместив её непосредственно перед методом `Main`, и почему.

## Ожидаемый результат
Однозначный обоснованный вывод о допустимости такого размещения со ссылкой на правило о том, где в C# допустимы директивы `using`.
