# L02-ALG-025. Комплексный анализ трёх одновременных нарушений

**Тема:** Л2 — Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

## Условие
Дан код:
```
using System;

namespace DemoApp
{
    class Program
    {
        static Main(string[] args)
        {
            Console.WriteLine("Первая строка")
            Console.WriteLine("Вторая строка");
        }
    }
```
Найти три различных структурных нарушения, присутствующих в этом коде, и обосновать каждое отдельно.

## Ожидаемый результат
Три различных по природе нарушения, не дублирующих друг друга, каждое — с обоснованием со ссылкой на конкретное место в коде.
