# L02. Создание, структура и связь языка программирования C# с .NET. Архитектура .NET. Среда Visual Studio

Практические задания к теме №2 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Особенность этой темы

В отличие от темы №1, задания этой темы используют **реальный код на C#**. При этом содержание строго ограничено рамками темы — **структурой программы**: директива `using`, пространство имён, класс-контейнер, точка входа `Main`, вызовы `Console.Write`/`Console.WriteLine`, комментарии. Переменные, типы данных, арифметика и управляющие конструкции (`if`, `for` и т.\,п.) не вводятся — они относятся к темам №3 и далее.

Исключение — группа заданий «перенос алгоритмов темы №1» (Middle, ALG-013–020): в них используются уже знакомые по теме №1 фрагменты кода, а проверяется именно правильность окружающей структуры программы, а не сама вычислительная логика.

## Структура папки

```
L02/
├── Easy/       5 заданий  (L02-ALG-001 – L02-ALG-005)
├── Middle/     15 заданий (L02-ALG-006 – L02-ALG-020)
└── Advanced/   10 заданий (L02-ALG-021 – L02-ALG-030)
```

## Уровни сложности

| Уровень | Диапазон | Характеристика |
|---|---|---|
| Easy | ALG-001–005 | Написание минимальных программ с заданным текстовым выводом; поиск структурной ошибки (незакрытая скобка, регистр `Main`) |
| Middle | ALG-006–020 | Программы с несколькими блоками вывода и комментариями; перенос алгоритмов темы №1 в полную структуру программы |
| Advanced | ALG-021–030 | Поиск нескольких одновременных структурных нарушений; объяснение влияния структурных модификаций (без написания кода) |

## О диагностических заданиях

Часть заданий (Easy: ALG-004–005; Advanced: ALG-021–025) содержит приведённый код с намеренной структурной ошибкой — студенту нужно её найти и объяснить, а не написать программу с нуля. Такой код в файле задания приведён «как есть», в исходном виде, без исправлений; корректность встроенного кода подтверждена реальной компиляцией (Mono `mcs`) в рамках QA курса.

## Формат каждого задания (V3)

Каждый файл `L02-ALG-XXX.md` содержит только два поля: **Условие** и **Ожидаемый результат**. **Готовые решения не приводятся**.

## Материалы для подготовки

Перед выполнением заданий рекомендуется изучить лекцию по теме №2 (см. основной репозиторий пособия), в которой рассмотрены: архитектура .NET (CLR, CIL, JIT, BCL), структура минимальной программы на C# и основы работы в Visual Studio.
