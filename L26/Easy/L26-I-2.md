# L26 · Задание I · №2. Неявное обращение к базовому конструктору

**Тема:** Л26 — Конструкторы при наследовании

## Условие
Объявить базовый класс с конструктором без параметров, задающим значения по умолчанию, и производный класс с конструктором, в котором обращение к базовому классу **не записано**. Создать объект и определить по выводу, был ли вызван конструктор базового класса. Затем записать обращение явно и сравнить вывод.

## Ожидаемый результат
Оба варианта дают одинаковый вывод; поля базового класса получили значения по умолчанию, хотя конструктор производного класса их не задавал.
