# L26 · Задание I · №5. Конструктор без параметров у класса

**Тема:** Л26 — Конструкторы при наследовании

## Условие
Объявить три класса: без единого конструктора; с одним конструктором, принимающим параметр; с двумя конструкторами. Для каждого попытаться создать объект записью без аргументов и записью с аргументом. Вывести для каждого класса число открытых конструкторов средствами получения сведений о типе.

## Ожидаемый результат
У первого класса конструктор есть, хотя не объявлялся; у второго запись без аргументов даёт `CS7036`; числа конструкторов равны 1, 1 и 2.
