# L26 · Задание I · №1. Первый конструктор производного класса

**Тема:** Л26 — Конструкторы при наследовании

## Условие
Объявить базовый класс «сотрудник» с конструктором, принимающим имя и год приёма на работу, и производный класс «преподаватель», добавляющий кафедру. Объявить конструктор производного класса, передающий два аргумента базовому. Создать объект и вывести все три значения. Из каждого конструктора вывести сообщение с его именем.

## Ожидаемый результат
Сообщение конструктора базового класса выведено **раньше** сообщения конструктора производного; все три значения заданы верно.
