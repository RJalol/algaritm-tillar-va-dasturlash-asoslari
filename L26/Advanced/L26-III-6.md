# L26 · Задание III · №6. Совместимость при изменении базового класса

**Тема:** Л26 — Конструкторы при наследовании

## Условие
Показать на проекте из базового класса и четырёх производных, как изменение набора конструкторов базового класса влияет на производные. Провести три опыта: добавить конструктор с параметрами при сохранении конструктора без параметров; удалить конструктор без параметров; сделать конструктор без параметров закрытым. Для каждого опыта записать число возникших ошибок и их коды.

## Ожидаемый результат
Первый опыт не нарушает работу производных классов, второй и третий нарушают её во всех четырёх; сформулировано правило совместимости для базовых классов, предназначенных для наследования.
