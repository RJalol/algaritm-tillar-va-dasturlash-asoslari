# L26 · Задание III · №5. Проектирование набора конструкторов

**Тема:** Л26 — Конструкторы при наследовании

## Условие
Для класса «заказ» с семью полями спроектировать набор из пяти конструкторов, покрывающих употребительные способы создания, так чтобы вся логика проверок находилась ровно в одном из них. Обосновать выбор основного конструктора и построить схему обращений между конструкторами. Проверить, что при любом способе создания объект оказывается в согласованном состоянии.

## Ожидаемый результат
Схема обращений не содержит циклов и сходится к одному конструктору; проверки записаны один раз; все пять способов создания проверены запуском.
