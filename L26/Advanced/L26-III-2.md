# L26 · Задание III · №2. Карта порядка инициализации

**Тема:** Л26 — Конструкторы при наследовании

## Условие
Для иерархии из четырёх уровней, где на каждом есть инициализатор поля, тело конструктора и статический конструктор, вывести полный порядок всех действий при создании первого и второго объектов. Составить таблицу «действие — уровень — номер по порядку — первый объект — второй объект» и объяснить каждое расхождение между двумя столбцами.

## Ожидаемый результат
Таблица заполнена фактическими данными; статические конструкторы присутствуют только в столбце первого объекта; порядок остальных действий одинаков.
