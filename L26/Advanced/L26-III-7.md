# L26 · Задание III · №7. Счётчики по уровням иерархии

**Тема:** Л26 — Конструкторы при наследовании

## Условие
В иерархии задания III.1 добавить в каждый класс собственный статический счётчик созданных объектов, увеличиваемый в конструкторе этого класса. Создать по три объекта каждого из пяти классов и вывести все счётчики. Объяснить, почему счётчик базового класса больше суммы счётчиков любого одного уровня, и составить формулу зависимости.

## Ожидаемый результат
Счётчик базового класса равен общему числу созданных объектов; счётчик каждого класса равен числу объектов этого класса и всех его потомков; формула подтверждена числами.
