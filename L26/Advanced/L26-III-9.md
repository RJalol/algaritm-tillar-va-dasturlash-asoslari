# L26 · Задание III · №9. Неизменяемая иерархия

**Тема:** Л26 — Конструкторы при наследовании

## Условие
Разработать иерархию из трёх классов, объекты которых полностью неизменяемы: все поля только для чтения, все операции возвращают новый объект. Для операций, порождающих объект того же класса, реализовать создание через конструкторы с полным набором аргументов. Проверить не менее чем на десяти операциях, что ни один исходный объект не изменился.

## Ожидаемый результат
Все операции возвращают новые объекты; исходные объекты после серии операций сохранили значения; попытка изменить любое поле отвергается компилятором.
