# L26 · Задание II · №5. Поля только для чтения в иерархии

**Тема:** Л26 — Конструкторы при наследовании

## Условие
Построить иерархию из трёх классов, в которой **все** поля объявлены только для чтения (тема №23) и каждое присваивается в конструкторе своего класса. Проверить, что после создания объекта ни одно поле изменить нельзя, и записать код ошибки при попытке присваивания. Убедиться, что производный класс не может присвоить поле базового напрямую.

## Ожидаемый результат
Все поля заданы верно; попытка присваивания вне конструктора даёт `CS0191`; попытка присвоить поле базового класса из конструктора производного также отвергается.
