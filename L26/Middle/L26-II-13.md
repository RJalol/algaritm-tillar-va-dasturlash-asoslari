# L26 · Задание II · №13. Счётчик созданных объектов в иерархии

**Тема:** Л26 — Конструкторы при наследовании

## Условие
Добавить в базовый класс иерархии II.12 статический счётчик созданных объектов, увеличиваемый в конструкторе базового класса (тема №20). Создать по два объекта каждого класса и вывести значение счётчика. Объяснить полученное число.

## Ожидаемый результат
Счётчик равен шести, а не двум: конструктор базового класса выполняется при создании объекта **любого** класса иерархии.
