# L26 · Задание II · №3. Цепочка `this`

**Тема:** Л26 — Конструкторы при наследовании

## Условие
Объявить производный класс с одним основным конструктором, обращающимся к базовому классу, и тремя вспомогательными, обращающимися через `this` и подставляющими значения по умолчанию. Из каждого конструктора вывести сообщение. Создать объекты всеми четырьмя способами и записать порядок сообщений для каждого.

## Ожидаемый результат
Конструктор базового класса выполнился ровно один раз при каждом создании; тела конструкторов производного класса выполнились в порядке, обратном обращениям.
