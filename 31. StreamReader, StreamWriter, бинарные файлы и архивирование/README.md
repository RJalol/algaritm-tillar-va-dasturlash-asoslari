# Тема 31. Работа с объектами StreamReader и StreamWriter. Бинарные файлы. Объекты BinaryWriter и BinaryReader. Сжатие и архивирование файлов

Практические задания к теме №31 дисциплины «Алгоритмические языки и программирование» (версия V3).

## Структура

```
31. StreamReader, StreamWriter, бинарные файлы и архивирование/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
└── Advanced/   10 заданий  (Задание III)
```

## Формат задания

Каждый файл `L31-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. Для каждого уровня (`Easy/`, `Middle/`, `Advanced/`) приведён один образцовый разбор — файл `Разбор_решения.md`; остальные задания предназначены для самостоятельного выполнения.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.

## Дополнительные задания по плану курса

В задания включены I-6, I-7, II-16–II-20 и III-11–III-13: бинарные файлы (`BinaryWriter`, `BinaryReader`), сжатие (`GZipStream`) и архивирование (`ZipFile`, `ZipArchive`).
