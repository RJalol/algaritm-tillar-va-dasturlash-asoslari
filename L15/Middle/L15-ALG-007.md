# L15-ALG-007. Деление с проверкой

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Написать метод `TryDivide`, возвращающий `true` при успешном делении и передающий частное через параметр `out`; при нулевом делителе метод возвращает `false`. Проверить для пар (10, 2) и (10, 0), выводя результат только после проверки признака.

## Ожидаемый результат
Для первой пары выведено `5`, для второй — сообщение о делении на нуль и значение `0`, присвоенное параметру на неуспешном пути.
