# L15-ALG-016. Пропущенный и лишний модификатор

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Дан код:

```
static void ByRef(ref int a) { a = 1; }
static void ByVal(int a) { }

int x = 5;
ByRef(x);
ByVal(ref x);
```

Определить код ошибки для каждого вызова, объяснить, чем они противоположны, и привести исправленный фрагмент.

## Ожидаемый результат
Названы коды `CS1620` (модификатор пропущен там, где требуется) и `CS1615` (модификатор указан там, где не требуется).
