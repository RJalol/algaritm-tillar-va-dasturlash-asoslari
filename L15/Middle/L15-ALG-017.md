# L15-ALG-017. Неинициализированный аргумент ref

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Дан код:

```
static void ByRef(ref int a) { a = 1; }

int y;
ByRef(ref y);
Console.WriteLine(y);
```

Назвать код ошибки и объяснить причину. Привести **два** исправления: инициализацией переменной и заменой модификатора. Объяснить, чем эти исправления различаются по смыслу.

## Ожидаемый результат
Назван код `CS0165`; первое исправление присваивает `y` начальное значение, второе заменяет `ref` на `out`; указано, что `out` годится лишь тогда, когда прежнее значение методу не нужно.
