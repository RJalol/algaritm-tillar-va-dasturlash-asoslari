# Разбор решения. L15-ALG-006. Наименьший и наибольший за один проход

## Условие
Написать метод `MinMax`, принимающий массив и возвращающий через два параметра `out` наименьший и наибольший его элементы. Массив просмотреть **один** раз. Проверить на массиве `{3, 17, 9, -5}`, объявив обе переменные прямо в списке аргументов.

## Ожидаемый результат
Выведено `min=-5` и `max=17`; начальными значениями взят первый элемент массива, а не нуль.

## Разбор условия
**Дано:** массив `{3, 17, 9, −5}`.
**Требуется:** метод `MinMax`, возвращающий через два параметра `out` наименьший и наибольший элементы за один проход.

## Теоретическая справка
**Параметры `out`** служат для возврата нескольких значений:

- вызывающий код может передать неинициализированную переменную;
- метод **обязан** присвоить значение каждому `out`-параметру на всех путях выхода (`CS0177` иначе);
- при вызове можно объявить переменную прямо в списке аргументов: `out int lo`.

Альтернативы: возврат кортежа `(int Min, int Max)` либо объекта. Идиома `TryParse` также построена на `out`.

## Идея решения
Возвращаем два значения через `out`-параметры. За один проход ищем минимум и максимум, начав с первого элемента.

## Решение
```csharp
using System;

class Program
{
    static void MinMax(int[] a, out int min, out int max)
    {
        min = a[0];
        max = a[0];
        for (int i = 1; i < a.Length; i++)
        {
            if (a[i] < min) min = a[i];
            if (a[i] > max) max = a[i];
        }
    }

    static void Main()
    {
        int[] data = { 3, 17, 9, -5 };
        MinMax(data, out int lo, out int hi);
        Console.WriteLine("min=" + lo);
        Console.WriteLine("max=" + hi);
    }
}
```

## Пошаговое объяснение
1. Параметры `out` обязаны получить значение до выхода из метода.
2. Начальное значение — `a[0]`, а не 0: иначе для массива положительных чисел минимум был бы найден неверно.
3. Цикл начинается с индекса 1 — массив просматривается один раз.
4. В вызове `out int lo, out int hi` переменные объявляются прямо в списке аргументов.

## Трассировка и проверка
Трассировка для `{3, 17, 9, −5}`:

| Шаг | a[i] | min | max |
|---|--:|--:|--:|
| старт | 3 | 3 | 3 |
| i=1 | 17 | 3 | 17 |
| i=2 | 9 | 3 | 17 |
| i=3 | −5 | −5 | 17 |

Начальные значения взяты из `a[0]`, а не 0: иначе для массива положительных чисел минимум оказался бы 0.

## Результат
min=-5, max=17

## Типичные ошибки
- Инициализировать `min` и `max` нулём.
- Не присвоить `out`-параметры (`CS0177`).
- Перебирать массив дважды, нарушая условие «один проход».
- Не обработать пустой массив (`a[0]` вызовет исключение).
