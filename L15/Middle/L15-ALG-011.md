# L15-ALG-011. Наибольшее из произвольного числа значений

**Тема:** Л15 — Методы с параметрами-массивами и ключевое слово params. Модификаторы параметров ref и out в методах

## Условие
Написать метод `MaxOf` с параметром `params`, возвращающий наибольшее из переданных целых чисел. Начальным значением взять первый элемент. Проверить для наборов (3, 17, 9), (−5, −12, −3) и для единственного значения 42.

## Ожидаемый результат
Выведено `17`, `-3` и `42`; набор из одних отрицательных чисел выявил бы ошибочную инициализацию нулём.
