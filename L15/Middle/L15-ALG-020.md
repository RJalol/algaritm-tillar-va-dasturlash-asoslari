# L15-ALG-020. Вызов params без аргументов

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Не запуская программу, предсказать результат вызова `Sum()` для метода `static int Sum(params int[] numbers)`, суммирующего элементы в цикле `foreach`. Ответить: получит ли метод значение `null`, возникнет ли исключение, чему будет равно `numbers.Length`. Затем проверить запуском.

## Ожидаемый результат
Метод получает массив **нулевой длины**, а не `null`; исключения не возникает; `Length` равно `0`, и метод возвращает `0`.
