# L15-ALG-012. Круговая перестановка трёх переменных

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Написать метод `Rotate`, переставляющий значения трёх целых переменных по кругу: первая получает значение третьей, третья — второй, вторая — первой. Проверить на значениях 1, 2 и 3.

## Ожидаемый результат
После вызова переменные содержат `3`, `1` и `2`; все три параметра объявлены с модификатором `ref`, для сохранения первого значения использована вспомогательная переменная.
