# L15-ALG-014. Предсказание вывода: замена массива

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Дан код:

```
static void Replace(int[] a)
{
    a = new int[] { 9, 9, 9 };
}

static void ReplaceRef(ref int[] a)
{
    a = new int[] { 9, 9, 9 };
}

int[] b = { 7, 7, 7 };
Replace(b);
Console.WriteLine(string.Join(" ", b));
ReplaceRef(ref b);
Console.WriteLine(string.Join(" ", b));
```

Не запуская программу, предсказать обе строки вывода. Затем запустить и объяснить различие.

## Ожидаемый результат
Предсказано `7 7 7` и `9 9 9`; объяснено, что в первом случае метод переприсвоил лишь свою копию ссылки, а во втором — саму переменную вызывающего кода.
