# L15-ALG-008. Библиотечный TryParse

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Написать программу, которая с помощью `int.TryParse` разбирает строки `"1640"` и `"abc"`, выводя для каждой признак успеха и значение параметра `out`. Объяснить в комментарии, почему при неудаче значение всё же присвоено и почему его нельзя истолковывать как разобранное число.

## Ожидаемый результат
Для `"1640"` выведено `True` и `1640`, для `"abc"` — `False` и `0`; в комментарии указано, что метод обязан присвоить значение параметру `out` на всех путях.
