# L15-ALG-010. Соединение строк методом с params

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Написать метод `Join`, принимающий обязательный разделитель и произвольное число строк, и возвращающий их соединение. Метод `string.Join` не использовать. Проверить на трёх строках и на вызове **без** строк.

## Ожидаемый результат
Для трёх строк выведено `Азиз, Дилноза, Рустам`, для вызова без строк — пустая строка; разделитель после последнего элемента не добавляется.
