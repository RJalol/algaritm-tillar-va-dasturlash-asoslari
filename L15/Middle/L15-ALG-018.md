# L15-ALG-018. Параметр out без присваивания

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Дан код:

```
static void BadOut(out int a)
{
    Console.WriteLine("нет присваивания");
}
```

Назвать код ошибки и объяснить, к **объявлению** или к **вызову** она относится. Привести исправление. Затем изменить метод так, чтобы он присваивал значение только в одной ветви `if`, и объяснить, сохранится ли ошибка.

## Ожидаемый результат
Назван код `CS0177`; ошибка относится к объявлению; при присваивании только в одной ветви ошибка сохраняется, поскольку значение должно присваиваться на **всех** путях исполнения.
