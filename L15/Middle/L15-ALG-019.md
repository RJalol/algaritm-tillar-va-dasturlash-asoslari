# L15-ALG-019. Ошибки объявления params

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Даны два объявления:

```
static void BadParams(params int[] list, int extra) { }
static void BadParams2(params int list) { }
```

Назвать код ошибки для каждого и сформулировать нарушенное правило. Привести исправленные объявления.

## Ожидаемый результат
Названы коды `CS0231` (параметр `params` должен быть последним) и `CS0225` (параметр `params` должен иметь тип коллекции).
