# L15-ALG-013. Нормализация строки через ref

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Написать метод `Normalize`, который удаляет пробелы по краям строки и переводит её в верхний регистр, изменяя **саму** переданную переменную. Проверить на строке `"   отчёт   "`. Объяснить в комментарии, почему здесь необходим модификатор `ref`, хотя `string` — ссылочный тип.

## Ожидаемый результат
Выведено `ОТЧЁТ` без пробелов; в комментарии указано, что методы строк возвращают **новую** строку, то есть выполняется переприсваивание параметра, которое без `ref` вызывающему коду не видно.
