# L15-ALG-009. Собственный метод TrySqrt

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Написать метод `TrySqrt`, вычисляющий квадратный корень вещественного числа и возвращающий `false` для отрицательного аргумента. Результат передавать через `out`. Проверить для 16 и −4.

## Ожидаемый результат
Для 16 получено `True` и `4`, для −4 — `False` и `0`; метод не возбуждает исключения и не возвращает «не число».
