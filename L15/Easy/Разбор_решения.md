# Разбор решения. L15-ALG-001. Обмен значений двух переменных

## Условие
Написать метод `Swap`, меняющий местами значения двух целых переменных. Вызвать его для переменных со значениями 3 и 8 и вывести их до и после вызова. Затем написать такой же метод **без** модификатора и показать, что он ничего не меняет.

## Ожидаемый результат
Метод без модификатора оставил значения `3 8`, метод с модификатором `ref` дал `8 3`; слово `ref` записано и в объявлении, и в вызове.

## Идея решения
По умолчанию в метод передаётся копия значения, поэтому обмен внутри метода не виден снаружи. Модификатор `ref` передаёт ссылку на переменную.

## Решение
```csharp
using System;

class Program
{
    static void SwapCopy(int a, int b)
    {
        int t = a; a = b; b = t;
    }

    static void SwapRef(ref int a, ref int b)
    {
        int t = a; a = b; b = t;
    }

    static void Main()
    {
        int x = 3, y = 8;
        SwapCopy(x, y);
        Console.WriteLine(x + " " + y);   // 3 8

        SwapRef(ref x, ref y);
        Console.WriteLine(x + " " + y);   // 8 3
    }
}
```

## Пошаговое объяснение
1. `SwapCopy` меняет локальные копии параметров, переменные `x`, `y` не затрагиваются.
2. `SwapRef` работает с самими переменными: параметры — псевдонимы `x` и `y`.
3. Слово `ref` нужно и в объявлении метода, и в вызове — так видно, что значение может измениться.

## Результат
Без ref: 3 8; с ref: 8 3.
