# L15-ALG-004. Метод с переменным числом аргументов

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Написать метод `Sum` с параметром `params`, возвращающий сумму произвольного числа целых аргументов. Вызвать его четырьмя способами: без аргументов, с одним, с четырьмя и с готовым массивом `{5, 6, 7}`.

## Ожидаемый результат
Выведено `0`, `1`, `10` и `18`; вызов без аргументов не вызывает исключения, поскольку метод получает массив нулевой длины.
