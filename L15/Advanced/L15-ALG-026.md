# L15-ALG-026. Три способа вернуть результат

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Одну и ту же задачу — вычислить площадь и периметр прямоугольника — решить тремя способами: двумя отдельными методами с возвращаемым значением; одним методом с двумя параметрами `out`; одним методом, изменяющим две переменные через `ref`. Сравнить три решения письменно: какое читается лучше, какое требует меньше кода, какое не годится и почему.

## Ожидаемый результат
Все три решения дают одинаковые значения; отмечено, что вариант с `ref` неуместен, поскольку прежние значения переменных методу не нужны, а вариант с двумя методами читается лучше всего.
