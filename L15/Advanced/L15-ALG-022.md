# L15-ALG-022. Среднее с проверкой

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Написать метод `TryGetAverage`, возвращающий `false` для пустого массива и передающий среднее арифметическое через параметр `out`. Проверить на массиве `{2, 4, 9}` и на массиве нулевой длины. Объяснить в комментарии, почему такой метод предпочтительнее метода, возвращающего среднее и падающего с исключением на пустом массиве.

## Ожидаемый результат
Для первого массива получено `True` и `5,00`, для пустого — `False` и `0`; в комментарии указано, что вызывающий код получает возможность обработать особый случай без исключения.
