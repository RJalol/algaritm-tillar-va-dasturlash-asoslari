# L15-ALG-024. Сочетание params с необязательным параметром

**Тема:** Л15 — Методы с параметрами-массивами и ключевое слово params. Модификаторы параметров ref и out в методах

## Условие
Написать метод, принимающий обязательный заголовок, **необязательный** разделитель со значением по умолчанию и параметр `params` со списком строк. Проверить, компилируется ли такое объявление, и объяснить результат исходя из правил темы №14 (необязательные параметры в конце) и настоящей темы (параметр `params` последний). Предложить работающий вариант объявления и вызвать его тремя способами.

## Ожидаемый результат
Объявление вида `(string title, string sep = ", ", params string[] parts)` **компилируется**: требование «последнее место» относится к `params`, а необязательный параметр располагается непосредственно перед ним. Три вызова — только с заголовком, с заголовком и разделителем и со списком строк — дают соответственно пустой список из `0` элементов, список из `2` элементов с заданным разделителем и список из `2` элементов с разделителем по умолчанию; последний вызов записан именованным аргументом `parts:` с готовым массивом.
