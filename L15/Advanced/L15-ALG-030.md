# L15-ALG-030. Полный аудит программы с модификаторами

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Дан код:

```
using System;

namespace ParamAudit
{
    class Program
    {
        static void Swap(int a, int b)
        {
            int t = a; a = b; b = t;
        }

        static bool TryHalf(int n, out int result)
        {
            if (n % 2 == 0)
            {
                result = n / 2;
                return true;
            }
            return false;
        }

        static void Clear(int[] a)
        {
            a = new int[a.Length];
        }

        static int Total(params int[] values, int bonus)
        {
            int s = bonus;
            foreach (int v in values) s += v;
            return s;
        }

        static void Main(string[] args)
        {
            int x = 3, y = 8;
            Swap(x, y);
            Console.WriteLine(x + " " + y);

            int half;
            TryHalf(7, out half);
            Console.WriteLine(half);

            int[] data = { 1, 2, 3 };
            Clear(data);
            Console.WriteLine(string.Join(" ", data));
        }
    }
}
```

Провести полный аудит и разнести замечания по четырём категориям: метод, не выполняющий заявленного действия из-за передачи по значению; параметр `out`, которому значение присваивается не на всех путях; переприсваивание параметра ссылочного типа вместо изменения его содержимого; нарушение правил объявления `params`. Для каждого указать код ошибки либо объяснить, почему компилятор молчит, и назвать тест-кейс, выявляющий ошибку. Привести исправленную версию.

## Ожидаемый результат
Категории разнесены верно: метод `Swap` компилируется, но значений не меняет, и вывод остаётся `3 8` — нужен модификатор `ref`; метод `TryHalf` не компилируется — `CS0177`, поскольку на пути с нечётным аргументом параметру `result` значение не присвоено, и тест-кейсом служит `TryHalf(7, ...)`; метод `Clear` компилируется, но массив не очищает — он переприсвоил свою копию ссылки, и вывод остаётся `1 2 3`; объявление `Total` даёт `CS0231`, так как параметр `params` не последний. Кроме того, отмечено, что вызов `TryHalf` без проверки возвращённого признака — самостоятельная ошибка использования.
