# L15-ALG-029. Предсказание вывода: три способа передачи

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Дан код:

```
static void A(int n) { n = 100; }
static void B(ref int n) { n = 100; }
static void C(int[] a) { a[0] = 100; }
static void D(int[] a) { a = new int[] { 100 }; }

int x = 1;
A(x); Console.WriteLine(x);
B(ref x); Console.WriteLine(x);

int[] arr = { 1 };
C(arr); Console.WriteLine(arr[0]);
arr[0] = 1;
D(arr); Console.WriteLine(arr[0]);
```

Не запуская программу, предсказать все четыре строки вывода. Затем запустить и для каждой строки объяснить результат через понятия «копия значения», «копия ссылки» и «переприсваивание параметра».

## Ожидаемый результат
Предсказано `1`, `100`, `100` и `1`; объяснено, что методы `A` и `D` изменили лишь свои копии, а `B` и `C` — данные вызывающего кода, причём по разным причинам.
