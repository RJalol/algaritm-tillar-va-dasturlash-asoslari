# L15-ALG-027. Разбор набора строк

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Дан массив строк `"1640"`, `"-42"`, `"abc"`, пустая строка, `"-"` и `"12a"`. Написать программу, которая с помощью `int.TryParse` разбирает каждую, накапливает сумму успешно разобранных чисел и подсчитывает число удач и неудач. Вывести все три величины.

## Ожидаемый результат
Удачных разборов `2`, неудачных `4`, сумма `1598`; обращение к разобранному значению выполняется только после проверки возвращённого признака.
