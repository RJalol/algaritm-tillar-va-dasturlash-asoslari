# Разбор решения. L15-ALG-021. Шесть нарушений в одном фрагменте

## Условие
Дан код:

```
static void ByRef(ref int a) { a = 1; }
static void ByVal(int a) { }
static void BadOut(out int a) { Console.WriteLine("нет присваивания"); }
static void BadParams(params int[] list, int extra) { }
static void BadParams2(params int list) { }

static void Main(string[] args)
{
    int x = 5;
    ByRef(x);
    ByVal(ref x);
    int y;
    ByRef(ref y);
}
```

Найти все нарушения, назвать код ошибки для каждого и разнести их по двум группам: ошибки **объявления** метода и ошибки **вызова** метода. Привести исправленный фрагмент.

## Ожидаемый результат
Названы коды `CS0177`, `CS0231` и `CS0225` в первой группе, `CS1620`, `CS1615` и `CS0165` — во второй; группы разнесены верно.

## Разбор условия
**Дано:** фрагмент с шестью нарушениями `ref`, `out`, `params`.
**Требуется:** найти их, назвать коды (`CS0177`, `CS0231`, `CS0225`, `CS1620`, `CS1615`, `CS0165`) и разнести по группам «объявление» и «вызов».

## Теоретическая справка
- `out` — метод обязан присвоить значение (`CS0177`).
- `params` — параметр-массив переменной длины; должен быть **последним** (`CS0231`) и иметь тип массива (`CS0225`).
- `ref` указывается при вызове, если указан в объявлении (`CS1620`); и наоборот: аргумент с `ref` для параметра без него — `CS1615`.
- Для `ref` аргумент должен быть инициализирован (`CS0165`).

## Идея решения
Для каждого фрагмента проверяем правила `ref`, `out` и `params`.

## Решение
```csharp
// Исправленный фрагмент
static void ByRef(ref int a) { a = 1; }
static void ByVal(int a) { }
static void BadOut(out int a) { a = 0; }                 // out обязан присваивать
static void BadParams(int extra, params int[] list) { }  // params - последний параметр
static void BadParams2(params int[] list) { }            // params требует массив
static void Main(string[] args)
{
    int x = 5;
    ByRef(ref x);              // ref указывается и в вызове
    ByVal(x);                  // обычный параметр без ref
    int y = 0;                 // ref требует инициализированную переменную
    ByRef(ref y);
}
```

## Пошаговое объяснение
1. Объявление: `BadOut` не присваивает `out`-параметру (`CS0177`); `params` не последний параметр (`CS0231`); `params int list` — не массив (`CS0225`).
2. Вызов: `ByRef(x)` без `ref` (`CS1620`); `ByVal(ref x)` — `ref` для параметра, объявленного без него (`CS1615`); `ByRef(ref y)` с неинициализированной `y` (`CS0165`).
3. Для `ref` переменная должна быть инициализирована до вызова, для `out` — нет, но присвоить значение метод обязан.

## Трассировка и проверка
| Группа | Фрагмент | Код |
|---|---|---|
| объявление | `BadOut` не присваивает `a` | CS0177 |
| объявление | `params` не последний | CS0231 |
| объявление | `params int list` — не массив | CS0225 |
| вызов | `ByRef(x)` без `ref` | CS1620 |
| вызов | `ByVal(ref x)` | CS1615 |
| вызов | `ByRef(ref y)` с неинициализированной `y` | CS0165 |

Различие `ref` и `out`: `ref` требует инициализации *до* вызова, `out` — присваивания *внутри* метода.

## Результат
Объявление: CS0177, CS0231, CS0225; вызов: CS1620, CS1615, CS0165.

## Типичные ошибки
- Путать `ref` и `out`.
- Помещать `params` в середину списка.
- Забывать слово `ref`/`out` при вызове.
- Передавать свойства или литералы в `ref`.
