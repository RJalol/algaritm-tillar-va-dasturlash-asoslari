# L15-ALG-025. Изменение размера массива

**Тема:** Л15 — Метод с параметрами массива и params. Модификаторы ref и out

## Условие
Написать метод `Resize`, создающий новый массив заданного размера, копирующий в него элементы прежнего и заменяющий **саму** переменную вызывающего кода. Метод `Array.Resize` не использовать. Проверить на массиве `{1, 2, 3}` при увеличении до 5 и последующем уменьшении до 2. Объяснить в комментарии, почему модификатор здесь обязателен.

## Ожидаемый результат
После увеличения массив содержит `1 2 3 0 0` длиной `5`, после уменьшения — `1 2` длиной `2`; в комментарии указано, что метод **переприсваивает** параметр, а это без `ref` вызывающему коду не видно.
