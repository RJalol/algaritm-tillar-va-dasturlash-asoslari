# Разбор решения. L51 · Задание III · №3. Игра «Крестики-нолики»

## Условие
Реализовать игру на сетке `Grid` с кнопками, определением победителя и перезапуском.

## Ожидаемый результат
Логика выигрыша верна.

## Разбор условия
**Дано:** игра «крестики-нолики».
**Требуется:** поле 3×3 в `UniformGrid`, определение победителя и ничьей, кнопка «Новая игра».

## Теоретическая справка
**Состояние и представление.** Состояние игры — массив из 9 строк (`null`, `X`, `O`) и признаки хода и окончания; кнопки лишь отображают его. Такое разделение упрощает логику и тестирование.

**Выигрышные линии:** 3 строки, 3 столбца и 2 диагонали — восемь троек индексов клеток, заданных массивом:

```
{0,1,2} {3,4,5} {6,7,8}   строки
{0,3,6} {1,4,7} {2,5,8}   столбцы
{0,4,8} {2,4,6}           диагонали
```

Победа — три одинаковые непустые клетки в одной линии. Ничья — все девять клеток заполнены без победителя.

## Идея решения
Поле 3×3 — девять кнопок в `UniformGrid`. Состояние игры хранится в массиве; после каждого хода проверяются восемь выигрышных линий (3 строки, 3 столбца, 2 диагонали).

## Решение
```xml
<!-- MainWindow.xaml -->
<Window x:Class="TicTacToe.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="Крестики-нолики" Width="320" Height="400">
    <DockPanel Margin="10">
        <Button DockPanel.Dock="Bottom" Content="Новая игра" Height="32"
                Margin="0,10,0,0" Click="NewGame_Click"/>
        <TextBlock x:Name="Status" DockPanel.Dock="Top" FontSize="16" Margin="0,0,0,8"/>
        <UniformGrid x:Name="Board" Rows="3" Columns="3"/>
    </DockPanel>
</Window>

// ---- MainWindow.xaml.cs ----
using System.Windows;
using System.Windows.Controls;

namespace TicTacToe
{
    public partial class MainWindow : Window
    {
        private static readonly int[][] Lines =
        {
            new[]{0,1,2}, new[]{3,4,5}, new[]{6,7,8},
            new[]{0,3,6}, new[]{1,4,7}, new[]{2,5,8},
            new[]{0,4,8}, new[]{2,4,6}
        };
        private readonly string[] _cells = new string[9];
        private bool _xTurn = true;
        private bool _over;

        public MainWindow()
        {
            InitializeComponent();
            for (int i = 0; i < 9; i++)
            {
                var b = new Button { FontSize = 36, Tag = i, Margin = new Thickness(2) };
                b.Click += Cell_Click;
                Board.Children.Add(b);
            }
            NewGame();
        }

        private void Cell_Click(object sender, RoutedEventArgs e)
        {
            var b = (Button)sender;
            int i = (int)b.Tag;
            if (_over || _cells[i] != null) return;

            _cells[i] = _xTurn ? "X" : "O";
            b.Content = _cells[i];

            if (HasWinner()) { Status.Text = $"Победил {_cells[i]}"; _over = true; return; }
            if (System.Array.TrueForAll(_cells, c => c != null)) { Status.Text = "Ничья"; _over = true; return; }

            _xTurn = !_xTurn;
            Status.Text = "Ходит " + (_xTurn ? "X" : "O");
        }

        private bool HasWinner()
        {
            foreach (var l in Lines)
                if (_cells[l[0]] != null && _cells[l[0]] == _cells[l[1]] && _cells[l[1]] == _cells[l[2]])
                    return true;
            return false;
        }

        private void NewGame_Click(object sender, RoutedEventArgs e) => NewGame();

        private void NewGame()
        {
            System.Array.Clear(_cells);
            foreach (Button b in Board.Children) b.Content = null;
            _xTurn = true; _over = false;
            Status.Text = "Ходит X";
        }
    }
}
```

## Пошаговое объяснение
1. Поле — `UniformGrid` 3×3, в котором все ячейки равны; кнопки создаются в цикле и хранят номер клетки в свойстве `Tag`.
2. Состояние игры — массив из 9 строк (`null`, `X` или `O`); отображение лишь отражает его.
3. После хода проверяются 8 линий, определённых заранее массивом индексов; победа — три одинаковых непустых значения в линии.
4. Ничья определяется заполнением всех клеток без победителя; после окончания игры клики игнорируются.
5. «Новая игра» очищает массив, подписи кнопок и флаги.

## Трассировка и проверка
Партия: X→4, O→0, X→2, O→8, X→6.

| Ход | Клетка | Состояние |
|--:|--:|---|
| 1 | 4 | X в центре |
| 2 | 0 | O в углу |
| 3 | 2 | X |
| 4 | 8 | O |
| 5 | 6 | X: линия {2,4,6} — победа X |

После победы дальнейшие клики игнорируются (`_over = true`).

## Результат
Игра работает: ходы чередуются, определяется победитель или ничья, кнопка «Новая игра» сбрасывает поле.

## Типичные ошибки
- Не блокировать ходы после окончания игры.
- Не проверять занятость клетки.
- Проверять победу до записи хода.
- Хранить состояние только в `Content` кнопок.
