# Разбор решения. L51 · Задание I · №1. Grid

## Условие
Разметить окно сеткой `Grid` из двух строк и двух столбцов, поместить в ячейки четыре кнопки (`Grid.Row`, `Grid.Column`).

## Ожидаемый результат
Кнопки занимают свои ячейки.

## Разбор условия
**Дано:** окно WPF.
**Требуется:** разметить окно сеткой 2×2 и разместить четыре кнопки.

## Теоретическая справка
**Контейнеры компоновки WPF:**

| Контейнер | Принцип |
|---|---|
| `Grid` | строки и столбцы |
| `StackPanel` | друг за другом (вертикально/горизонтально) |
| `DockPanel` | прикрепление к краям |
| `WrapPanel` | перенос по строкам |
| `Canvas` | абсолютные координаты |
| `UniformGrid` | ячейки одинакового размера |

В `Grid` размеры строк/столбцов задаются: фиксированно (`100`), по содержимому (`Auto`), долями (`*`, `2*`). Элемент помещается в ячейку присоединёнными свойствами `Grid.Row`, `Grid.Column` (нумерация с 0).

## Идея решения
`Grid` делит окно на строки и столбцы; элемент помещается в ячейку присоединёнными свойствами `Grid.Row` и `Grid.Column` (нумерация с нуля).

## Решение
```xml
<Window x:Class="GridDemo.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="Grid" Width="320" Height="220">
    <Grid>
        <Grid.RowDefinitions>
            <RowDefinition Height="*"/>
            <RowDefinition Height="*"/>
        </Grid.RowDefinitions>
        <Grid.ColumnDefinitions>
            <ColumnDefinition Width="*"/>
            <ColumnDefinition Width="*"/>
        </Grid.ColumnDefinitions>

        <Button Grid.Row="0" Grid.Column="0" Content="1" Margin="5"/>
        <Button Grid.Row="0" Grid.Column="1" Content="2" Margin="5"/>
        <Button Grid.Row="1" Grid.Column="0" Content="3" Margin="5"/>
        <Button Grid.Row="1" Grid.Column="1" Content="4" Margin="5"/>
    </Grid>
</Window>
```

## Пошаговое объяснение
1. `RowDefinitions` и `ColumnDefinitions` описывают сетку 2×2; значение `*` делит доступное место поровну.
2. Присоединённые свойства `Grid.Row` и `Grid.Column` указывают ячейку каждого элемента.
3. `Margin="5"` задаёт отступ со всех сторон.
4. Кнопки по умолчанию растягиваются на всю ячейку, поэтому при изменении размера окна они масштабируются.

## Трассировка и проверка
| Кнопка | Grid.Row | Grid.Column |
|---|--:|--:|
| 1 | 0 | 0 |
| 2 | 0 | 1 |
| 3 | 1 | 0 |
| 4 | 1 | 1 |

Ячейки равны (по `*`); при изменении размера окна кнопки растягиваются.

## Результат
Четыре кнопки образуют сетку 2×2 и растягиваются вместе с окном.

## Типичные ошибки
- Нумеровать строки с 1.
- Забыть объявить `RowDefinitions`/`ColumnDefinitions` — все элементы окажутся в одной ячейке.
- Указать номер строки больше числа определений.
- Использовать `Canvas` для адаптивных интерфейсов.
