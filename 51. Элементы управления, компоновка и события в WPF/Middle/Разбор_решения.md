# Разбор решения. L51 · Задание II · №7. Привязка к коллекции

## Условие
Привязать `ListBox` к `ObservableCollection<T>` и добавлять/удалять элементы кнопками.

## Ожидаемый результат
Список обновляется автоматически.

## Разбор условия
**Дано:** `ListBox` и коллекция строк.
**Требуется:** привязать список к `ObservableCollection<string>`, кнопки добавления и удаления.

## Теоретическая справка
`ObservableCollection<T>` реализует `INotifyCollectionChanged`: при добавлении, удалении, перемещении элементов она сообщает об этом, и привязанные элементы (`ListBox`, `DataGrid`) обновляются автоматически. Обычный `List<T>` таких уведомлений не создаёт.

Привязка: `ItemsSource="{Binding}"` берёт `DataContext` целиком; либо `ItemsSource="{Binding Items}"` — свойство ViewModel.

Выбранный элемент: `SelectedIndex`/`SelectedItem`; перед удалением проверяют `SelectedIndex >= 0`.

## Идея решения
`ObservableCollection<T>` уведомляет интерфейс о добавлении и удалении элементов, поэтому привязанный `ListBox` обновляется автоматически (в отличие от обычного `List<T>`).

## Решение
```xml
<!-- MainWindow.xaml -->
<Window x:Class="ListDemo.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="ObservableCollection" Width="320" Height="300">
    <DockPanel Margin="10">
        <StackPanel DockPanel.Dock="Bottom" Orientation="Horizontal" Margin="0,10,0,0">
            <Button Content="Добавить" Click="Add_Click" Width="100" Margin="0,0,10,0"/>
            <Button Content="Удалить"  Click="Remove_Click" Width="100"/>
        </StackPanel>
        <ListBox x:Name="List" ItemsSource="{Binding}"/>
    </DockPanel>
</Window>

// ---- MainWindow.xaml.cs ----
using System.Collections.ObjectModel;
using System.Windows;

namespace ListDemo
{
    public partial class MainWindow : Window
    {
        private readonly ObservableCollection<string> _items = new() { "Алгоритмы", "C#" };
        private int _n;

        public MainWindow()
        {
            InitializeComponent();
            DataContext = _items;           // ItemsSource="{Binding}" берёт DataContext целиком
        }

        private void Add_Click(object sender, RoutedEventArgs e) => _items.Add("Элемент " + (++_n));

        private void Remove_Click(object sender, RoutedEventArgs e)
        {
            if (List.SelectedIndex >= 0)
                _items.RemoveAt(List.SelectedIndex);
        }
    }
}
```

## Пошаговое объяснение
1. `DataContext = _items` делает коллекцию источником данных; запись `ItemsSource="{Binding}"` привязывает список к ней целиком.
2. Так как `ObservableCollection` реализует `INotifyCollectionChanged`, любое `Add` или `RemoveAt` сразу отображается в `ListBox` — никаких обновлений вручную.
3. С `List<string>` новые элементы остались бы невидимыми, пока список не перепривязать.
4. Перед удалением проверяется, что элемент выбран (`SelectedIndex >= 0`), иначе `RemoveAt(-1)` выбросит исключение.

## Трассировка и проверка
| Действие | Содержимое списка | Реакция интерфейса |
|---|---|---|
| старт | Алгоритмы, C# | показан |
| «Добавить» | + «Элемент 1» | строка появляется сразу |
| выбрать «C#», «Удалить» | − «C#» | строка исчезает |
| «Удалить» без выбора | без изменений | исключения нет |

## Результат
Кнопка «Добавить» добавляет строку в список, «Удалить» — удаляет выбранную; список обновляется автоматически.

## Типичные ошибки
- Использовать `List<string>` — список не обновляется.
- Заменять коллекцию целиком вместо изменения (привязка потеряна без уведомления).
- Не проверять наличие выбранного элемента.
- Изменять коллекцию из другого потока (требуется диспетчер).
