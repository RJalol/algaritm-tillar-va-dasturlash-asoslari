# L31 · Задание III · №2. Обобщённое двоичное дерево поиска

**Тема:** Л31 — Обобщённые типы (generics). Работа с универсальными классами и объектами

## Условие
Реализовать обобщённое двоичное дерево поиска с ограничением интерфейсом сравнения и операциями добавления, поиска и обхода в порядке возрастания. Узел дерева объявить вложенным закрытым типом (тема №27). Проверить дерево на числах, строках и объектах собственного класса.

## Ожидаемый результат
Обход даёт возрастающий порядок для всех трёх типов; узел недоступен извне; поиск отсутствующего элемента обработан; повторное добавление равного элемента обработано по явно описанному правилу.
