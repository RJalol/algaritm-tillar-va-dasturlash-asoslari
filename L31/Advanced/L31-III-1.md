# L31 · Задание III · №1. Обобщённая библиотека структур данных

**Тема:** Л31 — Обобщённые типы (generics). Работа с универсальными классами и объектами

## Условие
Собрать библиотеку классов (тема №27) из трёх обобщённых структур данных — стек, очередь и упорядоченный набор без повторов — и приложение, проверяющее их работу не менее чем на трёх различных аргументах типа каждая. Для набора применить ограничение интерфейсом сравнения.

## Ожидаемый результат
Библиотека собрана отдельным проектом и подключена к приложению; все три структуры проверены; ограничения выбраны по правилу «максимально сильное из допустимых» и выбор обоснован для каждой структуры.
