# L31 · Задание II · №14. Типы во время выполнения

**Тема:** Л31 — Обобщённые типы (generics). Работа с универсальными классами и объектами

## Условие
Создать объекты одного обобщённого класса с тремя разными аргументами типа и вывести для каждого имя типа и результат сравнения объектов типа среды выполнения между собой. Объяснить, почему имена совпадают, а сами типы различны.

## Ожидаемый результат
Имена одинаковы и содержат обратный апостроф с числом параметров; сравнение типов даёт `False`; объяснено, что аргументы типа сохраняются во время выполнения.
