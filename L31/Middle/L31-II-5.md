# L31 · Задание II · №5. Обобщённая сортировка

**Тема:** Л31 — Обобщённые типы (generics). Работа с универсальными классами и объектами

## Условие
Реализовать обобщённый метод сортировки массива собственным алгоритмом из темы №10 с ограничением интерфейсом сравнения. Отсортировать массив объектов собственного класса и массив строк одним и тем же методом. Сравнить полученный порядок с результатом метода `Array.Sort`.

## Ожидаемый результат
Собственная сортировка и библиотечная дали одинаковый порядок для обоих массивов; сортируемый класс реализует обобщённый интерфейс сравнения; приведений типа в коде метода нет.
