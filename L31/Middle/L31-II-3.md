# L31 · Задание II · №3. Обобщённый метод поиска

**Тема:** Л31 — Обобщённые типы (generics). Работа с универсальными классами и объектами

## Условие
Написать обобщённый метод, возвращающий индекс первого вхождения значения в массив, и метод, подсчитывающий число вхождений. Параметр типа оставить несвязанным. Затем поставить опыт: заменить сравнение методом `Equals` на оператор равенства и записать код ошибки.

## Ожидаемый результат
Оба метода работают для чисел, строк и объектов собственного класса; опыт дал `CS0019`; объяснено, почему для несвязанного параметра типа оператор равенства недоступен.
