# L31 · Задание II · №7. Ограничение базовым классом

**Тема:** Л31 — Обобщённые типы (generics). Работа с универсальными классами и объектами

## Условие
Объявить абстрактный базовый класс с общим полем и абстрактным методом, двух его наследников и обобщённое хранилище с ограничением этим базовым классом. Хранилище должно вызывать абстрактный метод для всех своих элементов. Затем убрать ограничение и записать код ошибки.

## Ожидаемый результат
Одно хранилище обслужило оба наследника, вызывая переопределённый метод; без ограничения получен `CS1061`; объяснено, что без ограничения доступны только члены `object`.
