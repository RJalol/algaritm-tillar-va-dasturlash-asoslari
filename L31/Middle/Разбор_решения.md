# Разбор решения. L31 · Задание II · №1. Копирование с преобразованием

## Условие
Читать файл через `StreamReader` и записывать в другой через `StreamWriter`, переводя текст в верхний регистр.

## Ожидаемый результат
Результат содержит исходный текст в верхнем регистре.

## Разбор условия
**Дано:** входной файл.
**Требуется:** прочитать `StreamReader`, привести каждую строку к верхнему регистру и записать `StreamWriter` в другой файл.

## Теоретическая справка
Шаблон **потоковой обработки текста:**

```
using (reader) using (writer)
{
    string line;
    while ((line = reader.ReadLine()) != null)
        writer.WriteLine(Преобразовать(line));
}
```

Преимущество: в памяти находится одна строка, поэтому программа обрабатывает файл любого размера. `ReadLine` возвращает `null` в конце файла (а пустая строка — это `""`, не `null`).

Метод `ToUpper()` учитывает текущую культуру; для независимого результата используют `ToUpperInvariant()`.

## Идея решения
Читаем исходный файл построчно через `StreamReader`, каждую строку преобразуем в верхний регистр и пишем через `StreamWriter` — файл обрабатывается потоково.

## Решение
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        using (StreamReader reader = new StreamReader("input.txt"))
        using (StreamWriter writer = new StreamWriter("output.txt"))
        {
            string line;
            while ((line = reader.ReadLine()) != null)
            {
                writer.WriteLine(line.ToUpper());
            }
        }

        Console.WriteLine(File.ReadAllText("output.txt"));
    }
}
```

## Пошаговое объяснение
1. `ReadLine` возвращает очередную строку без символа конца строки и `null`, когда файл закончился — по этому признаку завершается цикл.
2. `ToUpper()` возвращает новую строку в верхнем регистре (исходная неизменна).
3. Оба потока объявлены в `using` и закрываются автоматически, даже при ошибке.
4. Такой подход работает и для очень больших файлов, поскольку в памяти находится одна строка.

## Трассировка и проверка
Входной файл:

```
привет
мир
```

Выходной файл:

```
ПРИВЕТ
МИР
```

Число строк сохраняется; пустые строки входного файла дают пустые строки выходного.

## Результат
Файл output.txt содержит те же строки, что input.txt, в верхнем регистре.

## Типичные ошибки
- Использовать `EndOfStream` вместо `ReadLine() != null` без осторожности.
- Не закрыть писатель — файл останется пустым.
- Читать и писать в один и тот же файл (потеря данных).
- Забыть, что `ToUpper()` не меняет исходную строку.
