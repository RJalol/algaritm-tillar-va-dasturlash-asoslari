# L31 · Задание II · №9. Два параметра типа

**Тема:** Л31 — Обобщённые типы (generics). Работа с универсальными классами и объектами

## Условие
Реализовать обобщённый класс «пара» с двумя параметрами типа, методом перестановки, возвращающим пару с переставленными типами, и переопределённым методом строкового представления. Затем реализовать обобщённое хранилище пар «ключ—значение» на двух массивах с поиском значения по ключу.

## Ожидаемый результат
Перестановка возвращает объект другого сконструированного типа; хранилище работает не менее чем для двух различных сочетаний типов ключа и значения; попытка указать один аргумент типа вместо двух даёт `CS0305`.
