# L31 · Задание I · №6. Запись числа BinaryWriter

**Тема:** Л31 — Работа с объектами StreamReader и StreamWriter. Бинарные файлы. Объекты BinaryWriter и BinaryReader. Сжатие и архивирование файлов

## Условие
Записать в файл `numbers.bin` через `BinaryWriter` целое число 42, вещественное 3,14 и строку `"C#"`. Вывести размер файла.

## Ожидаемый результат
Файл создан; размер равен сумме длин записанных значений (4 + 8 + строка с префиксом длины).
