# L31 · Задание I · №4. Упаковка на опыте

**Тема:** Л31 — Обобщённые типы (generics). Работа с универсальными классами и объектами

## Условие
Присвоить одно и то же целое значение двум переменным типа `object` и проверить их тождественность методом `Reference``Equals`. Повторить тот же опыт для двух переменных типа `int`, сравнив их оператором равенства. Объяснить различие результатов, опираясь на тему №18.

## Ожидаемый результат
Проверка тождественности для упакованных значений дала `False`, сравнение целых — `True`; объяснено, что при присваивании значимого значения переменной типа `object` создаётся отдельный объект в куче.
