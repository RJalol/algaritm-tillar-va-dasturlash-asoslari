# Разбор решения. L31 · Задание I · №1. Запись через StreamWriter

## Условие
С помощью `StreamWriter` записать в файл три строки методом `WriteLine`.

## Ожидаемый результат
Файл содержит три строки.

## Разбор условия
**Дано:** три строки.
**Требуется:** записать их `StreamWriter` через `WriteLine` и прочитать файл.

## Теоретическая справка
`StreamWriter` и `StreamReader` — надстройки над потоком байтов, работающие с **текстом**: берут на себя кодировку (по умолчанию UTF-8) и перевод строк.

| Класс | Основные члены |
|---|---|
| `StreamWriter` | `Write`, `WriteLine`, `Flush`, `AutoFlush` |
| `StreamReader` | `ReadLine`, `ReadToEnd`, `Read`, `Peek`, `EndOfStream` |

**`using`** гарантирует вызов `Dispose` — буфер записывается и файл закрывается даже при исключении. Конструктор `new StreamWriter(path, append: true)` открывает файл на дозапись.

## Идея решения
`StreamWriter` записывает текст в поток; `WriteLine` добавляет строку с переводом строки. Оператор `using` гарантирует закрытие файла.

## Решение
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        using (StreamWriter writer = new StreamWriter("lines.txt"))
        {
            writer.WriteLine("Первая строка");
            writer.WriteLine("Вторая строка");
            writer.WriteLine("Третья строка");
        }

        Console.WriteLine(File.ReadAllText("lines.txt"));
    }
}
```

## Пошаговое объяснение
1. `new StreamWriter("lines.txt")` создаёт файл (или перезаписывает существующий) в кодировке UTF-8.
2. `WriteLine` записывает текст и символ конца строки.
3. По выходу из блока `using` вызывается `Dispose`, который сбрасывает буфер на диск и закрывает файл.
4. Для проверки читаем файл целиком и выводим его.

## Трассировка и проверка
| Шаг | Результат |
|---|---|
| `new StreamWriter("lines.txt")` | файл создан/обнулён |
| три `WriteLine` | три строки в буфере |
| выход из `using` | буфер сброшен, файл закрыт |
| `File.ReadAllText` | три строки с переводами |

Если убрать `using` и не вызвать `Close`/`Flush`, файл может оказаться пустым.

## Результат
Файл lines.txt содержит три строки, они выведены на экран.

## Типичные ошибки
- Не закрыть писатель.
- Перезаписать нужный файл вместо дозаписи.
- Забыть кодировку при чтении файла, созданного другой программой.
- Использовать `ReadLine` без проверки на `null`.
