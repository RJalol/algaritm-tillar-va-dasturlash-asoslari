# Разбор решения. L42 · Задание III · №3. Динамический список элементов

## Условие
Реализовать форму со списком задач: каждая задача — панель с флажком, текстом и кнопкой удаления; панели добавляются и удаляются динамически.

## Ожидаемый результат
Список обновляется без перерисовки всей формы.

## Разбор условия
**Дано:** динамический список задач.
**Требуется:** каждая задача — панель с флажком и кнопкой удаления; контейнер выстраивает панели сам.

## Теоретическая справка
**`FlowLayoutPanel`** размещает дочерние элементы друг за другом (сверху вниз при `FlowDirection.TopDown`) и автоматически переносит/прокручивает. Это избавляет от ручного расчёта координат.

**Динамическое создание элементов:** элемент создаётся оператором `new`, настраивается, подписывается на события и добавляется в `Controls`. При удалении вызывают `Controls.Remove` и `Dispose`, чтобы освободить ресурсы и обработчики.

**Замыкание:** лямбда-обработчик кнопки «✕» захватывает переменную `row`, поэтому знает, какую именно панель удалять.

## Идея решения
Каждая задача — отдельная панель с флажком, текстом и кнопкой удаления. Панели лежат в `FlowLayoutPanel`, который сам выстраивает их друг под другом.

## Решение
```csharp
using System;
using System.Drawing;
using System.Windows.Forms;

public class Form1 : Form
{
    private readonly FlowLayoutPanel _list = new FlowLayoutPanel
    {
        Dock = DockStyle.Fill, FlowDirection = FlowDirection.TopDown,
        WrapContents = false, AutoScroll = true
    };
    private readonly TextBox _input = new TextBox { Left = 10, Top = 10, Width = 220 };

    public Form1()
    {
        Text = "Список задач";
        Size = new Size(380, 400);

        var top = new Panel { Dock = DockStyle.Top, Height = 45 };
        var add = new Button { Text = "Добавить", Left = 240, Top = 8, Width = 90 };
        add.Click += (s, e) => AddTask(_input.Text);
        top.Controls.AddRange(new Control[] { _input, add });

        Controls.Add(_list);
        Controls.Add(top);
    }

    private void AddTask(string text)
    {
        if (string.IsNullOrWhiteSpace(text)) return;

        var row = new Panel { Width = 320, Height = 30, BorderStyle = BorderStyle.FixedSingle };
        var check = new CheckBox { Left = 5, Top = 5, Width = 230, Text = text };
        var del = new Button { Text = "✕", Left = 280, Top = 2, Width = 30, Height = 24 };

        check.CheckedChanged += (s, e) =>
            check.Font = new Font(check.Font, check.Checked ? FontStyle.Strikeout : FontStyle.Regular);
        del.Click += (s, e) => { _list.Controls.Remove(row); row.Dispose(); };

        row.Controls.AddRange(new Control[] { check, del });
        _list.Controls.Add(row);
        _input.Clear();
    }
}
```

## Пошаговое объяснение
1. Основа интерфейса — `FlowLayoutPanel` с `FlowDirection.TopDown`: новые панели автоматически размещаются ниже предыдущих, а при нехватке места появляется прокрутка.
2. `AddTask` создаёт для каждой задачи панель-строку с флажком и кнопкой удаления и подписывает их на события.
3. Флажок зачёркивает текст, изменяя шрифт; кнопка «✕» удаляет строку: `Controls.Remove` убирает её из контейнера, `Dispose` освобождает ресурсы.
4. Остальной интерфейс при добавлении и удалении не перерисовывается — меняется только содержимое контейнера.

## Трассировка и проверка
| Действие | Результат |
|---|---|
| добавить «купить хлеб» | в конце списка появляется новая строка |
| отметить флажок | текст зачёркнут |
| нажать «✕» | строка удалена, остальные сдвигаются |

Остальной интерфейс не перерисовывается — меняется только содержимое контейнера.

## Результат
Задачи добавляются и удаляются динамически, выполненные задачи зачёркиваются; перерисовки всей формы не требуется.

## Типичные ошибки
- Не вызывать `Dispose` — утечка ресурсов при частом добавлении/удалении.
- Использовать общую переменную в замыкании в цикле (все обработчики удалят последнюю строку).
- Задавать абсолютные координаты вместо использования контейнера.
- Не очищать поле ввода после добавления.
