# Разбор решения. L19-ALG-001. Скрытое поле и открытое свойство

## Условие
Объявить класс `Student` со **скрытым** полем балла и **открытым** свойством только для чтения, возвращающим его. Заполнить поле в конструкторе. Создать объект, вывести балл, затем добавить строку, присваивающую значение полю напрямую, и назвать код возникающей ошибки.

## Ожидаемый результат
Балл выведен через свойство; прямое присваивание полю даёт `CS0122` («недоступен из-за его уровня защиты»).

## Разбор условия
**Дано:** класс `Student`.
**Требуется:** скрытое поле балла, открытое свойство только для чтения, значение задаётся в конструкторе; показать код ошибки при прямом присваивании полю.

## Теоретическая справка
**Инкапсуляция** — сокрытие внутреннего устройства класса и предоставление контролируемого интерфейса.

Модификаторы доступа:

| Модификатор | Где виден член |
|---|---|
| `public` | везде |
| `private` (по умолчанию для членов) | только внутри своего класса |
| `protected` | внутри класса и наследников |
| `internal` | внутри своей сборки |

Типичная схема: закрытое поле + открытое свойство. Свойство только для чтения (`get` без `set`) разрешает читать значение, но не менять его снаружи.

## Идея решения
Инкапсуляция: поле закрыто (`private`), доступ к нему предоставляет открытое свойство только для чтения; значение задаётся в конструкторе.

## Решение
```csharp
using System;

class Student
{
    private int _score;

    public int Score
    {
        get { return _score; }
    }

    public Student(int score)
    {
        _score = score;
    }
}

class Program
{
    static void Main()
    {
        Student s = new Student(87);
        Console.WriteLine(s.Score);

        // s._score = 100;   // CS0122: _score недоступен из-за его уровня защиты
    }
}
```

## Пошаговое объяснение
1. `_score` объявлено `private`, значит видно только внутри класса.
2. Свойство `Score` имеет только `get` — снаружи значение можно прочитать, но не изменить.
3. Раскомментированная строка `s._score = 100;` не компилируется: ошибка `CS0122`.

## Трассировка и проверка
| Действие | Результат |
|---|---|
| `new Student(87)` | поле `_score = 87` |
| `s.Score` | 87 (через свойство) |
| `s._score = 100;` | ошибка CS0122 — недоступен из-за уровня защиты |
| `s.Score = 100;` | ошибка CS0200 — у свойства нет `set` |

Две ошибки показывают два уровня защиты: поле скрыто совсем, свойство доступно только для чтения.

## Результат
87; прямое присваивание полю даёт CS0122.

## Типичные ошибки
- Объявить поле `public` «для простоты» и потерять контроль.
- Забыть присвоить поле в конструкторе (останется 0).
- Путать `CS0122` (недоступно) и `CS0200` (нельзя записать).
- Считать, что `private` защищает от другого объекта того же класса — нет, доступ ограничен классом, а не объектом.
