# Разбор решения. L19-ALG-021. Шесть нарушений доступа в одном фрагменте

## Условие
Дан код:

```
class Helper { public int X; }

public class Service
{
    public Helper Get() { return new Helper(); }
}

class Account
{
    private decimal _balance;
    private bool IsValid(decimal a) { return a > 0; }
    protected int Shared = 2;
    public string Name { get; private set; } = "x";
    private string Code { get; public set; }
}

class Other
{
    void Use()
    {
        Account a = new Account();
        a._balance = 100;
        a.IsValid(1);
        Console.WriteLine(a.Shared);
        a.Name = "y";
    }
}
```

Найти все нарушения, назвать код ошибки для каждого и разнести их по трём группам: обращение к недоступному члену; недоступный метод доступа; нарушение правил объявления. Привести исправленный фрагмент, **не** расширяя доступ к полю `_balance`.

## Ожидаемый результат
Названы коды `CS0122` (трижды), `CS0272`, `CS0273` и `CS0050`; группы разнесены верно; в исправлении внешний код пользуется открытыми методами класса `Account`, а класс `Helper` объявлен со словом `public` либо метод `Get` сужен.

## Идея решения
Для каждого обращения определяем модификатор доступа члена и место обращения. Поле `_balance` остаётся закрытым — внешний код должен пользоваться открытыми методами.

## Решение
```csharp
// Исправленный фрагмент
public class Helper { public int X; }              // тип доступен там же, где метод Get
public class Service
{
    public Helper Get() { return new Helper(); }
}
class Account
{
    private decimal _balance;
    private bool IsValid(decimal a) { return a > 0; }
    protected int Shared = 2;
    public string Name { get; private set; } = "x";
    private string Code { get; set; }              // метод доступа не шире свойства

    public void Deposit(decimal a)
    {
        if (IsValid(a)) _balance += a;
    }
    public decimal Balance { get { return _balance; } }
    public void Rename(string n) { Name = n; }
}
class Other
{
    void Use()
    {
        Account a = new Account();
        a.Deposit(100);
        Console.WriteLine(a.Balance);
        a.Rename("y");
    }
}
```

## Пошаговое объяснение
1. Недоступный член: `a._balance`, `a.IsValid(1)` — закрытые члены, `a.Shared` — защищённый член, недоступный в несвязанном классе (`CS0122`, три случая).
2. Недоступный метод доступа: `a.Name = "y"` — сеттер закрыт, вне класса он недоступен (`CS0272`); изменять имя нужно через открытый метод `Rename`.
3. Правила объявления: `private string Code { get; public set; }` — метод доступа не может быть доступнее самого свойства (`CS0273`); `public Helper Get()` в открытом классе при внутреннем `Helper` — несогласованная доступность (`CS0050`).
4. Исправление: внешний код пользуется открытыми `Deposit`, `Balance`, `Rename`; `Helper` делаем `public`.

## Результат
Коды: CS0122 (×3), CS0272, CS0273, CS0050 — перечислены по трём группам; _balance остаётся закрытым.
