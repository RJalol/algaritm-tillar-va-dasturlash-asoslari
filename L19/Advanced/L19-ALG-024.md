# L19-ALG-024. Класс «стек» с инкапсулированным хранилищем

**Тема:** Л19 — Инкапсуляция в C#. Модификаторы доступа: public, private, protected, internal

## Условие
Объявить класс `Stack10` со скрытым массивом на десять элементов и скрытым счётчиком. Открытая часть: свойства `Count`, `IsEmpty`, `IsFull`; метод `Push`, возвращающий `false` при переполнении; метод `TryPop` с параметром `out` (тема №15). Массив наружу не отдавать. Проверить: занесение двенадцати значений подряд; снятие вершины; попытка снять с пустого стека.

## Ожидаемый результат
Переполнение наступает при занесении одиннадцатого значения, `Count` равно `10` и `IsFull` даёт `True`; снятие вершины возвращает `10` и уменьшает `Count` до `9`; `TryPop` для пустого стека даёт `False` и значение `0`.
