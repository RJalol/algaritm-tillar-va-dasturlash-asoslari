# L19-ALG-028. Проектирование открытой части

**Тема:** Л19 — Инкапсуляция в C#. Модификаторы доступа: public, private, protected, internal

## Условие
Для каждого из четырёх типов — «читательский билет», «корзина покупок», «настройки приложения», «результат измерения» — составить таблицу членов с указанием уровня доступа и обоснованием. Для каждого типа отдельно назвать **инвариант**, который обязан соблюдаться всегда, и указать, какие члены его обеспечивают. Два типа реализовать полностью.

## Ожидаемый результат
Четыре таблицы; для каждого типа назван инвариант (например, «сумма корзины равна сумме цен товаров»); во всех четырёх случаях поля-хранилища скрыты, а изменение состояния возможно только методами, поддерживающими инвариант.
