# L19-ALG-030. Полный аудит инкапсуляции

**Тема:** Л19 — Инкапсуляция в C#. Модификаторы доступа: public, private, protected, internal

## Условие
Дан код:

```
using System;

namespace AccessAudit
{
    class Config { public string Path = "/tmp"; }

    public class Repository
    {
        public int[] Items = new int[10];
        public int Count;
        private int _capacity = 10;

        public Config Settings { get; set; } = new Config();

        public bool Add(int value)
        {
            if (Count >= _capacity) return false;
            Items[Count] = value;
            Count++;
            return true;
        }

        public int Capacity { get { return _capacity; } public set { _capacity = value; } }
    }

    class Program
    {
        static void Main(string[] args)
        {
            Repository r = new Repository();
            r.Add(5);
            r.Count = 100;
            r.Items[0] = -1;
            r.Capacity = 0;
        }
    }
}
```

Провести полный аудит и разнести замечания по четырём категориям: открытое поле, разрушающее инвариант; открытое хранилище, отдаваемое наружу; ошибка объявления метода доступа; несогласованность доступности. Для каждого указать код ошибки либо объяснить, почему компилятор молчит, и назвать тест-кейс, приводящий объект в противоречивое состояние. Привести исправленную версию с полностью скрытым состоянием.

## Ожидаемый результат
Категории разнесены верно: свойство `Capacity` не компилируется — `CS0273`, поскольку модификатор метода доступа не сужает доступ; свойство `Settings` имеет тип `Config`, объявленный без модификатора, — `CS0053` (для **свойства** код отличается от `CS0050`, возникающего для метода); поле `Count` открыто, и присваивание `r.Count = 100` рассогласовывает счётчик с содержимым массива, причём компилятор молчит; массив `Items` отдан наружу, и `r.Items[0] = -1` изменяет хранилище в обход метода `Add`. В исправленной версии массив и счётчик скрыты, `Count` и `Capacity` — свойства только для чтения, а доступ к элементам предоставлен методом по индексу.
