# L19-ALG-029. Предсказание доступности

**Тема:** Л19 — Инкапсуляция в C#. Модификаторы доступа: public, private, protected, internal

## Условие
Дан класс:

```
class Base
{
    private int a = 1;
    protected int b = 2;
    internal int c = 3;
    public int d = 4;
    int e = 5;
}
```

Не запуская программу, заполнить таблицу: для каждого из пяти полей указать, доступно ли оно (а) внутри самого класса `Base`; (б) в классе `Derived : Base`; (в) в постороннем классе того же проекта; (г) в классе другого проекта. Затем проверить компиляцией те случаи, которые проверить возможно, и назвать код ошибки для недоступных.

## Ожидаемый результат
Поле `e` ведёт себя как `a`, поскольку умолчание — `private`; наследнику доступны `b`, `c` и `d`; постороннему классу того же проекта — `c` и `d`; из другого проекта — только `d`; все недоступные обращения дают `CS0122`.
