# L19-ALG-017. Модификатор метода доступа

**Тема:** Л19 — Инкапсуляция в C#. Модификаторы доступа: public, private, protected, internal

## Условие
Даны два объявления:

```
private string Name { get; public set; }
public string Code { public get; set; }
```

Назвать код ошибки для каждого и объяснить, чем нарушения различаются. Сформулировать правило, которому обязан удовлетворять модификатор метода доступа.

## Ожидаемый результат
Оба дают `CS0273`; в первом случае модификатор *шире* доступа свойства, во втором — *равен* ему; правило: модификатор метода доступа обязан быть **строго более ограничивающим**, чем доступ свойства.
