# L19-ALG-015. Обращение к скрытому члену

**Тема:** Л19 — Инкапсуляция в C#. Модификаторы доступа: public, private, protected, internal

## Условие
Дан код:

```
class Account
{
    private decimal _balance;
    private bool IsValid(decimal a) { return a > 0; }
}

class Other
{
    void Use()
    {
        Account a = new Account();
        a._balance = 100;
        a.IsValid(1);
    }
}
```

Назвать код ошибки для каждой строки, привести формулировку сообщения и предложить исправление, **не** расширяя доступ к полю.

## Ожидаемый результат
Обе строки дают `CS0122`; в исправлении внешний код обращается к открытому методу класса `Account`, а поле и вспомогательный метод остаются скрытыми.
