# L19-ALG-010. Класс «пароль»

**Тема:** Л19 — Инкапсуляция в C#. Модификаторы доступа: public, private, protected, internal

## Условие
Объявить класс `Password` со скрытым полем, хранящим **преобразованное** представление пароля, скрытым методом преобразования, открытым свойством только для чтения «задан ли пароль», открытым методом установки (пароль короче шести символов отвергается) и открытым методом проверки. Убедиться, что исходный пароль невозможно получить извне ни одним способом.

## Ожидаемый результат
До установки свойство даёт `False`; короткий пароль отвергнут, свойство по-прежнему `False`; после установки правильного — `True`, проверка верного пароля даёт `True`, неверного — `False`; ни поле, ни метод преобразования извне недоступны.
