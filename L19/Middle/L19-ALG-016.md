# L19-ALG-016. Присваивание при закрытом set

**Тема:** Л19 — Инкапсуляция в C#. Модификаторы доступа: public, private, protected, internal

## Условие
Дан класс со свойством `public string Name { get; private set; }` и строка `a.Name = "y";` вне класса. Назвать код ошибки и объяснить, чем он отличается от `CS0122` и от `CS0200`. Привести три способа изменить значение свойства правильно.

## Ожидаемый результат
Назван код `CS0272`; объяснено, что сам член доступен, недоступен только его метод доступа `set`, тогда как `CS0122` означает недоступность члена целиком, а `CS0200` — отсутствие `set` вовсе; способы — присваивание в конструкторе, в методе класса и через открытый метод, содержащий проверку.
