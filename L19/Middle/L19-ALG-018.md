# L19-ALG-018. Поле без модификатора

**Тема:** Л19 — Инкапсуляция в C#. Модификаторы доступа: public, private, protected, internal

## Условие
Дан код:

```
class Plain
{
    int hidden;
}

Plain p = new Plain();
Console.WriteLine(p.hidden);
```

Определить, скомпилируется ли фрагмент, назвать код ошибки и объяснить, почему автор мог считать поле открытым. Привести два исправления и указать, какое из них предпочтительнее.

## Ожидаемый результат
Назван код `CS0122`; объяснено, что модификатор не написан, а умолчанием служит `private`; предпочтительно добавить открытое свойство только для чтения, а не объявлять поле открытым.
