# L19-ALG-009. Четыре уровня рядом

**Тема:** Л19 — Инкапсуляция в C#. Модификаторы доступа: public, private, protected, internal

## Условие
Объявить класс `Base` с четырьмя полями — `private`, `protected`, `internal` и `public` — со значениями 1, 2, 3 и 4. Объявить класс `Derived : Base` с методом, выводящим все **доступные** ему поля. Затем из третьего класса попытаться прочитать все четыре поля объекта `Base`. Составить таблицу «поле → доступно ли наследнику → доступно ли постороннему классу».

## Ожидаемый результат
Наследнику доступны три поля из четырёх — выведено `Shared=2 Internal=3 Open=4`; постороннему классу доступны только `internal` и `public`; обращения к `private` и `protected` извне дают `CS0122`.
