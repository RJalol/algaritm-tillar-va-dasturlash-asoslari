# Разбор решения. L20-ALG-006. Статический класс со строковыми методами

## Условие
Объявить статический класс `StringUtil` с тремя методами: обращение строки, проверка палиндрома и подсчёт гласных. Библиотечные методы класса `String` применять свободно, кроме тех, что решают задачу целиком. Проверить на строках `"алгоритм"`, `"шалаш"` и `"Программирование"`.

## Ожидаемый результат
Выведено `мтирогла`, `True` для `шалаш` и `False` для `алгоритм`, число гласных `7`; все методы вызваны по имени класса.

## Разбор условия
**Дано:** строки `"алгоритм"`, `"шалаш"`, `"Программирование"`.
**Требуется:** статический класс `StringUtil` с методами обращения строки, проверки палиндрома и подсчёта гласных; вызвать методы по имени класса.

## Теоретическая справка
**Статический класс** (`static class`) содержит только статические члены; создавать его экземпляры и наследовать от него нельзя. Подходит для наборов вспомогательных функций без состояния (`Math`, `Console`).

Использование метода одного статического класса другим внутри того же класса не требует имени класса: `Reverse(s)` вызывается из `IsPalindrome`.

Решение «палиндром = строка совпадает со своим обращением» просто, но создаёт копию строки; экономнее сравнивать символы с двух концов.

## Идея решения
Статический класс объединяет вспомогательные методы без состояния; создавать его экземпляры нельзя.

## Решение
```csharp
using System;

static class StringUtil
{
    public static string Reverse(string s)
    {
        char[] chars = s.ToCharArray();
        Array.Reverse(chars);
        return new string(chars);
    }

    public static bool IsPalindrome(string s)
    {
        return s == Reverse(s);
    }

    public static int CountVowels(string s)
    {
        int count = 0;
        foreach (char c in s.ToLower())
            if ("аеёиоуыэюя".IndexOf(c) >= 0) count++;
        return count;
    }
}

class Program
{
    static void Main()
    {
        Console.WriteLine(StringUtil.Reverse("алгоритм"));
        Console.WriteLine(StringUtil.IsPalindrome("шалаш"));
        Console.WriteLine(StringUtil.IsPalindrome("алгоритм"));
        Console.WriteLine(StringUtil.CountVowels("Программирование"));
    }
}
```

## Пошаговое объяснение
1. `Reverse` превращает строку в массив символов, разворачивает и собирает новую строку.
2. `IsPalindrome` сравнивает строку с её обращением; метод использует `Reverse` — все методы вызываются по имени класса.
3. `CountVowels` приводит строку к нижнему регистру и проверяет принадлежность символа списку гласных.
4. Класс `static` не имеет конструкторов экземпляра и нестатических членов.

## Трассировка и проверка
| Вызов | Результат |
|---|---|
| `Reverse("алгоритм")` | мтирогла |
| `IsPalindrome("шалаш")` | True |
| `IsPalindrome("алгоритм")` | False |
| `CountVowels("Программирование")` | 7 |

Гласные: о, а, и, о, а, и, е — 7. Приведение `ToLower()` в `CountVowels` делает проверку нечувствительной к регистру.

## Результат
мтирогла / True / False / 7

## Типичные ошибки
- Пытаться создать экземпляр статического класса (`CS0723`/`CS0712`).
- Объявить в статическом классе нестатический метод (`CS0708`).
- Забыть о регистре при сравнении.
- Хранить в статическом классе изменяемое состояние без необходимости.
