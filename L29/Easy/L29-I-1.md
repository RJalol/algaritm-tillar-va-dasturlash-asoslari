# L29 · Задание I · №1. Первый абстрактный класс

**Тема:** Л29 — Абстрактные классы. Абстрактные данные и абстрактные методы. Переопределение в производных классах

## Условие
Объявить абстрактный класс «сотрудник» с абстрактным методом расчёта заработной платы и абстрактным свойством должности. Реализовать три производных класса с разными правилами расчёта. Заполнить массив базового типа и вывести сведения о каждом. Попытаться создать объект абстрактного класса и записать код ошибки.

## Ожидаемый результат
Все три расчёта верны; попытка создать объект абстрактного класса даёт `CS0144`.
