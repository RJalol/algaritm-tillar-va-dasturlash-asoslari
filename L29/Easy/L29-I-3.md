# L29 · Задание I · №3. Смешанное содержимое

**Тема:** Л29 — Абстрактные классы. Абстрактные данные и абстрактные методы. Переопределение в производных классах

## Условие
Дополнить абстрактный класс задания I.1 тремя видами членов: полем только для чтения, полностью реализованным методом, обращающимся к абстрактным членам, и виртуальным методом с реализацией по умолчанию. Переопределить виртуальный метод только в одном из потомков.

## Ожидаемый результат
Реализованный метод даёт разные результаты для разных потомков; виртуальный метод даёт реализацию по умолчанию везде, кроме одного класса.
