# Разбор решения. L29 · Задание I · №1. Список дисков

## Условие
С помощью `DriveInfo.GetDrives()` вывести имена всех дисков компьютера, их тип и признак готовности.

## Ожидаемый результат
Выведен список дисков с именем, типом и состоянием.

## Идея решения
Класс `DriveInfo` описывает логические диски. Статический метод `GetDrives()` возвращает их массив.

## Решение
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        foreach (DriveInfo d in DriveInfo.GetDrives())
        {
            Console.WriteLine("Диск: " + d.Name);
            Console.WriteLine("  Тип: " + d.DriveType);
            Console.WriteLine("  Готов: " + d.IsReady);
        }
    }
}
```

## Пошаговое объяснение
1. `DriveInfo.GetDrives()` возвращает `DriveInfo[]` для всех дисков системы.
2. `Name` — имя диска (например, `C:\` или `/`), `DriveType` — тип (Fixed, Removable, Network…).
3. `IsReady` показывает, готов ли диск: у неготового (например, пустой привод) остальные свойства недоступны и вызывают `IOException`.

## Результат
Для каждого диска выведены имя, тип и признак готовности.
