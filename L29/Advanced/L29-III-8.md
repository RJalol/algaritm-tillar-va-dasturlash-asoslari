# L29 · Задание III · №8. Конструкторы и проверки в абстрактной иерархии

**Тема:** Л29 — Абстрактные классы. Абстрактные данные и абстрактные методы. Переопределение в производных классах

## Условие
Для иерархии из четырёх уровней (два абстрактных) разместить проверки корректности в конструкторе каждого уровня так, чтобы каждый проверял только свои аргументы. Создать объекты с некорректными значениями на разных уровнях и определить, какая проверка срабатывает в каждом случае. Составить таблицу «некорректный аргумент — сработавшая проверка — почему».

## Ожидаемый результат
Таблица заполнена фактическими результатами; порядок срабатывания объяснён порядком выполнения конструкторов (тема №26).
