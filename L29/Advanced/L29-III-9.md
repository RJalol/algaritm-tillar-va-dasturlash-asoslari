# L29 · Задание III · №9. Абстрактный класс против набора проверок типа

**Тема:** Л29 — Абстрактные классы. Абстрактные данные и абстрактные методы. Переопределение в производных классах

## Условие
Решить одну содержательную задачу (расчёт стоимости доставки для пяти видов отправлений) двумя способами: одним классом с проверками вида отправления в теле методов и абстрактной иерархией. Сравнить решения по числу строк, по числу мест, требующих правки при добавлении шестого вида, и по возможности допустить ошибку. Добавить шестой вид в оба решения.

## Ожидаемый результат
Оба решения дают одинаковые результаты; для первого перечислены все изменённые места, для второго — показано, что существующие файлы не изменялись.
