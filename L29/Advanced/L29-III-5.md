# L29 · Задание III · №5. Шаблон обработки данных

**Тема:** Л29 — Абстрактные классы. Абстрактные данные и абстрактные методы. Переопределение в производных классах

## Условие
Разработать абстрактный класс «обработчик», реализованный метод которого задаёт неизменяемый порядок из пяти шагов, причём два шага — абстрактные (потомок обязан их предоставить), два — виртуальные (реализация по умолчанию есть), один — обычный (изменению не подлежит). Реализовать три производных класса, каждый из которых переопределяет разный набор виртуальных шагов. Показать выводом, что порядок шагов одинаков во всех трёх.

## Ожидаемый результат
Порядок шагов не нарушается ни в одном обработчике; каждый потомок реализовал ровно два обязательных шага и произвольное число необязательных.
