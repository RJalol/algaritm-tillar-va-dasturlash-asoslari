# Разбор решения. L29 · Задание III · №1. Файловый менеджер

## Условие
Создать консольный файловый менеджер: просмотр каталога, переход вверх и вниз, копирование, перемещение и удаление выбранного файла.

## Ожидаемый результат
Все команды работают; ошибки доступа обрабатываются.

## Идея решения
Файловый менеджер — цикл «команда — действие» над текущим каталогом. Для операций используются `Directory`, `File` и `Path`; ошибки доступа перехватываются.

## Решение
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string current = Directory.GetCurrentDirectory();

        while (true)
        {
            Console.WriteLine("\n== " + current + " ==");
            foreach (string d in Directory.GetDirectories(current))
                Console.WriteLine("[D] " + Path.GetFileName(d));
            foreach (string f in Directory.GetFiles(current))
                Console.WriteLine("    " + Path.GetFileName(f) + " (" + new FileInfo(f).Length + " Б)");

            Console.Write("> ");
            string[] cmd = (Console.ReadLine() ?? "").Split(' ', 3);

            try
            {
                switch (cmd[0])
                {
                    case "cd":                                   // cd <имя> или cd ..
                        string target = cmd[1] == ".."
                            ? Directory.GetParent(current)?.FullName ?? current
                            : Path.Combine(current, cmd[1]);
                        if (!Directory.Exists(target)) { Console.WriteLine("Нет такого каталога"); break; }
                        current = target;
                        break;
                    case "copy":                                  // copy <файл> <новое_имя>
                        File.Copy(Path.Combine(current, cmd[1]), Path.Combine(current, cmd[2]));
                        break;
                    case "move":                                  // move <файл> <новое_имя>
                        File.Move(Path.Combine(current, cmd[1]), Path.Combine(current, cmd[2]));
                        break;
                    case "del":                                   // del <файл>
                        File.Delete(Path.Combine(current, cmd[1]));
                        break;
                    case "exit":
                        return;
                    default:
                        Console.WriteLine("Команды: cd, copy, move, del, exit");
                        break;
                }
            }
            catch (IndexOutOfRangeException) { Console.WriteLine("Не хватает аргументов"); }
            catch (UnauthorizedAccessException) { Console.WriteLine("Нет доступа"); }
            catch (IOException e) { Console.WriteLine("Ошибка ввода-вывода: " + e.Message); }
        }
    }
}
```

## Пошаговое объяснение
1. Текущий каталог хранится в переменной `current`; в начале каждой итерации выводятся его подкаталоги и файлы с размерами (`FileInfo.Length`).
2. Команда читается как строка и делится на части методом `Split`.
3. `cd` меняет текущий каталог (`..` — на уровень выше через `Directory.GetParent`), `copy`/`move`/`del` вызывают `File.Copy`, `File.Move`, `File.Delete`.
4. Пути собираем через `Path.Combine`, чтобы не зависеть от разделителя.
5. Блок `try-catch` перехватывает недостаток аргументов, отсутствие прав и ошибки ввода-вывода (например, копирование на существующий файл) — программа продолжает работу.

## Результат
Все команды работают; ошибки доступа и некорректные команды не приводят к аварийному завершению.
