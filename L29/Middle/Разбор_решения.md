# Разбор решения. L29 · Задание II · №1. Свободное место на диске

## Условие
Для каждого готового диска вывести общий объём и свободное место в гигабайтах с двумя знаками после запятой.

## Ожидаемый результат
Значения соответствуют данным системы; неготовые диски пропущены.

## Идея решения
Содержимое каталога получаем методами `Directory.GetFiles` и `Directory.GetDirectories`, предварительно проверив существование каталога.

## Решение
```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        Console.Write("Путь к каталогу: ");
        string path = Console.ReadLine();

        if (!Directory.Exists(path))
        {
            Console.WriteLine("Ошибка: каталог не найден");
            return;
        }

        Console.WriteLine("Подкаталоги:");
        foreach (string dir in Directory.GetDirectories(path))
            Console.WriteLine("  [D] " + Path.GetFileName(dir));

        Console.WriteLine("Файлы:");
        foreach (string file in Directory.GetFiles(path))
            Console.WriteLine("  [F] " + Path.GetFileName(file));
    }
}
```

## Пошаговое объяснение
1. `Directory.Exists` защищает от `DirectoryNotFoundException`.
2. `GetDirectories` и `GetFiles` возвращают полные пути, `Path.GetFileName` оставляет только имя.
3. Выводим подкаталоги и файлы отдельными списками с пометками [D] и [F].

## Результат
Для существующего каталога выведены подкаталоги и файлы; для несуществующего — «Ошибка: каталог не найден».
