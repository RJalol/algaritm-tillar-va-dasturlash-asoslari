# L29 · Задание II · №4. Реализованный метод поверх абстрактных

**Тема:** Л29 — Абстрактные классы. Абстрактные данные и абстрактные методы. Переопределение в производных классах

## Условие
В абстрактном классе задания II.3 объявить полностью реализованный метод расчёта годового дохода, обращающийся к абстрактному свойству ставки. Проверить, что метод даёт разные результаты для разных потомков, не будучи переопределённым ни в одном из них.

## Ожидаемый результат
Метод объявлен один раз и не переопределён нигде; результаты различаются по правилам потомков.
