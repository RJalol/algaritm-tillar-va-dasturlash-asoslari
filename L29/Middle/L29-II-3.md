# L29 · Задание II · №3. Абстрактные свойства

**Тема:** Л29 — Абстрактные классы. Абстрактные данные и абстрактные методы. Переопределение в производных классах

## Условие
Объявить абстрактный класс «вклад» с абстрактным свойством ставки только для чтения и абстрактным свойством владельца с обоими методами доступа. Реализовать три производных класса, применив три разных способа: вычисляемое свойство, свойство с полем-хранилищем и проверкой в методе доступа `set`, свойство с преобразованием в методе доступа `get`.

## Ожидаемый результат
Все три способа работают; абстрактное свойство задало требование, не предписав способа его выполнения.
