## Структура

```
L29/
├── README.md
├── Easy/       5 заданий   (Задание I)
├── Middle/     15 заданий  (Задание II)
```

## Формат задания

Каждый файл `L29-<I|II|III>-<номер>.md` содержит два поля: **Условие** и **Ожидаемый результат**. Готовые решения не приводятся.

Нумерация локальна для каждого блока: Задание I — 1..5, Задание II — 1..15, Задание III — 1..10.
