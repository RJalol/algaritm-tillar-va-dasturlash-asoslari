# L20-ALG-014. Обращение к члену экземпляра из статического метода

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Дан код:

```
class Counter
{
    public static int Total;
    public int Value;
    public static int Bad() { return Value; }
}
```

Назвать код ошибки и объяснить причину. Привести **два** исправления: превращением поля в статическое и передачей объекта параметром метода.

## Ожидаемый результат
Назван код `CS0120`; оба исправления компилируются, и указано, что второе применимо, когда поле обязано оставаться членом экземпляра.
