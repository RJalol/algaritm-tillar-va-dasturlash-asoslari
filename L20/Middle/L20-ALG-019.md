# L20-ALG-019. Момент выполнения статического конструктора

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Не запуская программу, предсказать порядок вывода для кода, в котором строка выводится до первого обращения к классу со статическим конструктором, затем происходят два обращения к статическому полю и создаются два объекта. Затем проверить запуском и объяснить каждое расхождение с предсказанием.

## Ожидаемый результат
Сообщение статического конструктора появляется **между** первой строкой программы и первым выведенным значением поля; при втором обращении оно не появляется; сообщение конструктора экземпляра появляется дважды.
