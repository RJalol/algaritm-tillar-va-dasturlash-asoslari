# L20-ALG-007. Статический метод-фабрика

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Объявить класс с закрытым конструктором (тема №19) и открытым **статическим** методом, создающим объект только при допустимых аргументах и возвращающим его. Объяснить в комментарии, почему этот метод обязан быть статическим.

## Ожидаемый результат
Объект создаётся только через статический метод; в комментарии указано, что метод вызывается тогда, когда объекта ещё нет, и потому не может быть методом экземпляра.
