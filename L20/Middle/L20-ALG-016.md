# L20-ALG-016. Член экземпляра в статическом классе

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Дан код:

```
static class Util
{
    public int Field;
    public void Method() { }
    public Util() { }
}
```

Назвать код ошибки для каждой из трёх строк и объяснить, какие из них дают одинаковый код и почему. Привести исправленный класс.

## Ожидаемый результат
Поле и метод дают `CS0708`, конструктор — `CS0710`; объяснено, что конструктор экземпляра выделен отдельным сообщением; в исправлении все члены объявлены со словом `static`, а конструктор удалён либо сделан статическим.
