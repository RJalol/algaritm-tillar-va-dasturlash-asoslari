# L20-ALG-013. Различие const и static readonly

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Объявить в одном классе поле `const`, поле `static readonly` и обычное статическое поле. Присвоить полю `static readonly` значение в статическом конструкторе, а не в объявлении. Попытаться присвоить значение полю `const` в статическом конструкторе и назвать код ошибки. Изменить обычное статическое поле из `Main` и убедиться, что это допустимо.

## Ожидаемый результат
Поле `static readonly` успешно присвоено в статическом конструкторе; присваивание полю `const` не компилируется; обычное статическое поле изменяется откуда угодно.
