# L20-ALG-012. Класс-журнал

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Объявить класс `Logger` со скрытым статическим счётчиком строк, статическим свойством-префиксом, статическим свойством только для чтения «число строк», статическим конструктором и статическим методом записи, выводящим строку вида `[ПРЕФИКС 001] текст`. Записать три сообщения, изменив префикс после первого, и вывести итоговое число строк.

## Ожидаемый результат
Три строки с номерами `001`, `002` и `003`, причём первая с исходным префиксом, а две последующие — с изменённым; итоговое число строк `3`.
