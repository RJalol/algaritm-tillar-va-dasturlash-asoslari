# L20-ALG-018. Ошибки статического конструктора

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Дан код:

```
class Ctor
{
    public static int X;
    public static Ctor(int a) { X = a; }
}
```

Назвать **два** кода ошибки и объяснить, какие два правила нарушены. Привести исправленный класс, сохранив возможность задать начальное значение поля.

## Ожидаемый результат
Названы коды `CS0132` (параметры недопустимы) и `CS0515` (модификаторы доступа недопустимы); в исправлении значение задаётся внутри статического конструктора без параметров.
