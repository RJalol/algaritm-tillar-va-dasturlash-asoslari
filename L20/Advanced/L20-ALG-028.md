# L20-ALG-028. Статический или нестатический

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Для каждого из восьми членов определить, должен ли он быть статическим, и обосновать выбор: (а) имя студента; (б) число студентов в системе; (в) метод, вычисляющий факториал; (г) метод, вычисляющий средний балл студента; (д) значение π; (е) ставка налога, общая для всех заказов; (ж) метод, создающий объект после проверки аргументов; (з) метод, выводящий карточку объекта. Два случая реализовать полностью.

## Ожидаемый результат
Статическими объявлены (б), (в), (д), (е) и (ж); членами экземпляра — (а), (г) и (з); для каждого выбора приведено обоснование через принадлежность величины типу или объекту.
