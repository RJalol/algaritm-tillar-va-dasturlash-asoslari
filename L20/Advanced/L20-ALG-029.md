# L20-ALG-029. Предсказание вывода: порядок инициализации

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Дан код:

```
class A
{
    public static int Value = Init("поле A");
    static A() { Console.WriteLine("статический конструктор A"); }
    static int Init(string s) { Console.WriteLine(s); return 1; }
}

Console.WriteLine("начало");
Console.WriteLine(A.Value);
Console.WriteLine(A.Value);
Console.WriteLine("конец");
```

Не запуская программу, предсказать все строки вывода и их порядок. Затем проверить запуском и объяснить, что выполняется раньше — инициализатор статического поля или статический конструктор — и сколько раз выполняется каждый.

## Ожидаемый результат
После строки «начало» выведено «поле A», затем «статический конструктор A», затем два раза `1` и «конец»; инициализаторы статических полей выполняются **до** статического конструктора, и оба — по одному разу.
