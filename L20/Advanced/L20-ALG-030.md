# L20-ALG-030. Полный аудит программы со статическими членами

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Дан код:

```
using System;

namespace StaticAudit
{
    static class Registry
    {
        public static int Count;
        public string Name;
        public Registry() { }
        public static void Add() { Count++; }
    }

    class Item
    {
        public static int Total;
        public int Price;

        public Item(int price) { Price = price; Total += price; }

        public static int Average() { return Total / Price; }

        public static Item(int a) { Total = a; }
    }

    class Program
    {
        static void Main(string[] args)
        {
            Registry r = new Registry();
            Item i = new Item(100);
            Console.WriteLine(i.Total);
        }
    }
}
```

Провести полный аудит и разнести замечания по четырём категориям: члены экземпляра в статическом классе; создание статического класса; ошибки статического конструктора; смешение уровня типа и уровня экземпляра. Для каждого назвать код ошибки. Привести исправленную версию, в которой класс `Registry` остаётся статическим, а метод `Average` даёт осмысленный результат.

## Ожидаемый результат
Названы коды `CS0708` (поле `Name`), `CS0710` (конструктор `Registry`), `CS0723` и `CS0712` (строка создания), `CS0132` и `CS0515` (объявление `public static Item(int a)`), `CS0120` (обращение к `Price` из статического метода) и `CS0176` (обращение к `Total` через объект). В исправленной версии `Registry` содержит только статические члены и не создаётся, статический конструктор объявлен без параметров и без модификатора доступа, а средняя цена вычисляется через статический счётчик числа объектов.
