# L20-ALG-023. Статический класс пересчёта единиц

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Объявить статический класс с не менее чем шестью методами пересчёта: температура в обе стороны, длина (метры и футы) в обе стороны, масса (килограммы и фунты) в обе стороны. Добавить статические константы коэффициентов. Проверить каждый метод и убедиться, что двойной пересчёт возвращает исходное значение с точностью до округления.

## Ожидаемый результат
Пересчёт 100 градусов Цельсия даёт `212`, нуля — `32`, обратный пересчёт 212 даёт `100,00`; для каждой пары двойной пересчёт восстанавливает исходное значение; коэффициенты объявлены как `const`.
