# Разбор решения. L20-ALG-001. Счётчик созданных объектов

## Условие
Объявить класс со скрытым **статическим** полем-счётчиком, увеличиваемым в конструкторе, и открытым статическим свойством только для чтения. Вывести значение счётчика до создания объектов, затем создать три объекта и вывести снова.

## Ожидаемый результат
До создания выведено `0`, после трёх — `3`; счётчик прочитан по имени класса, а не через объект.

## Разбор условия
**Дано:** класс, объекты которого нужно считать.
**Требуется:** скрытое статическое поле-счётчик, увеличиваемое в конструкторе, и открытое статическое свойство только для чтения; вывести значение до и после создания трёх объектов.

## Теоретическая справка
**Статический член** принадлежит самому типу, а не его экземплярам: существует в единственном экземпляре и доступен по имени класса. Статическое поле инициализируется до первого использования типа.

Конструктор экземпляра выполняется при каждом `new`; статическое поле при этом общее для всех объектов — поэтому годится для счётчика созданных объектов.

К статическому члену обращаются `Widget.Count`; обращение через экземпляр (`w.Count`) — ошибка `CS0176`.

## Идея решения
Статическое поле принадлежит классу, а не объекту: оно общее для всех объектов и обнуляется один раз при загрузке типа.

## Решение
```csharp
using System;

class Widget
{
    private static int _count;

    public static int Count
    {
        get { return _count; }
    }

    public Widget()
    {
        _count++;
    }
}

class Program
{
    static void Main()
    {
        Console.WriteLine(Widget.Count);
        new Widget(); new Widget(); new Widget();
        Console.WriteLine(Widget.Count);
    }
}
```

## Пошаговое объяснение
1. Поле `_count` закрыто и статично; свойство `Count` статично и без `set`.
2. Конструктор вызывается при каждом `new` и увеличивает общий счётчик.
3. К статическому члену обращаемся по имени класса `Widget.Count`, объект для этого не нужен.

## Трассировка и проверка
| Момент | `Widget.Count` |
|---|--:|
| до создания | 0 |
| после `new Widget()` №1 | 1 |
| после №2 | 2 |
| после №3 | 3 |

Счётчик общий: не имеет значения, через какой объект проходит увеличение.

## Результат
0, затем 3

## Типичные ошибки
- Сделать счётчик полем экземпляра — каждый объект получит свой.
- Обращаться к статическому члену через объект.
- Сделать счётчик открытым полем и позволить внешнему коду его обнулить.
- Не учитывать многопоточность (для реальных программ `Interlocked.Increment`).

## Задания для закрепления
- Добавить уменьшение счётчика в деструкторе/`Dispose`.
- Присваивать каждому объекту порядковый номер из счётчика.
- Объяснить, когда выполняется статический конструктор.
