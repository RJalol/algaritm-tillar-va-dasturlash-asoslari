# Разбор решения. L20-ALG-001. Счётчик созданных объектов

## Условие
Объявить класс со скрытым **статическим** полем-счётчиком, увеличиваемым в конструкторе, и открытым статическим свойством только для чтения. Вывести значение счётчика до создания объектов, затем создать три объекта и вывести снова.

## Ожидаемый результат
До создания выведено `0`, после трёх — `3`; счётчик прочитан по имени класса, а не через объект.

## Идея решения
Статическое поле принадлежит классу, а не объекту: оно общее для всех объектов и обнуляется один раз при загрузке типа.

## Решение
```csharp
using System;

class Widget
{
    private static int _count;

    public static int Count
    {
        get { return _count; }
    }

    public Widget()
    {
        _count++;
    }
}

class Program
{
    static void Main()
    {
        Console.WriteLine(Widget.Count);
        new Widget(); new Widget(); new Widget();
        Console.WriteLine(Widget.Count);
    }
}
```

## Пошаговое объяснение
1. Поле `_count` закрыто и статично; свойство `Count` статично и без `set`.
2. Конструктор вызывается при каждом `new` и увеличивает общий счётчик.
3. К статическому члену обращаемся по имени класса `Widget.Count`, объект для этого не нужен.

## Результат
0, затем 3
