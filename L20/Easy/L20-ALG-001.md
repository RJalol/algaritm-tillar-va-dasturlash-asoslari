# L20-ALG-001. Счётчик созданных объектов

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Объявить класс со скрытым **статическим** полем-счётчиком, увеличиваемым в конструкторе, и открытым статическим свойством только для чтения. Вывести значение счётчика до создания объектов, затем создать три объекта и вывести снова.

## Ожидаемый результат
До создания выведено `0`, после трёх — `3`; счётчик прочитан по имени класса, а не через объект.
