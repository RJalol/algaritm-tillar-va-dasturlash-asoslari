# L20-ALG-004. Первый статический класс

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Объявить **статический** класс `Temperature` с двумя методами пересчёта температуры: из градусов Цельсия в градусы Фаренгейта и обратно. Проверить на значениях 100, 0 и 212. Затем попытаться создать объект этого класса и назвать код ошибки.

## Ожидаемый результат
Выведено `212`, `32` и `100,00`; попытка создать объект даёт `CS0712` («не удаётся создать экземпляр статического класса»).
