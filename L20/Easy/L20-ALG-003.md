# L20-ALG-003. Статическое свойство-настройка

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Добавить в класс статическое свойство «название учебного заведения» с начальным значением и метод экземпляра, выводящий карточку студента вместе с этим названием. Создать два объекта, вывести обе карточки, затем изменить статическое свойство и вывести карточки снова.

## Ожидаемый результат
После изменения свойства **обе** карточки содержат новое название, хотя объекты создавались до изменения; у объектов нет собственной копии этого значения.
