# L20-ALG-002. Общий источник номеров

**Тема:** Л20 — Статические члены класса. Статические методы и их ссылки. Статические классы

## Условие
Дополнить класс задания ALG-001 скрытым статическим полем «следующий номер» с начальным значением 1000 и свойством экземпляра `Id` только для чтения, получающим очередной номер в конструкторе. Создать три объекта и вывести их номера. Объяснить в комментарии, почему `Id` — член экземпляра, а источник номеров — статический.

## Ожидаемый результат
Номера `1001`, `1002` и `1003`; в комментарии указано, что источник один на весь тип, а выданный номер — свой у каждого объекта.
